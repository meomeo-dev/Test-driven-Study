# 概率基础

本单元建立概率论的基本语言与运算法则，结合桌面质检分拣站的传感器触发与视觉判定场景，
掌握从样本空间、排列组合计数、加法与乘法法则到贝叶斯逆概率推断的完整分析方法。

## 本单元知识点
- 样本空间与事件：掌握随机试验与样本空间定义，熟练进行事件的并、交、补运算并判断互斥。
- 排列与组合：掌握乘法原理、排列与组合计算公式，解决质量抽样中的样本组合数问题。
- 概率的运算法则：掌握古典概率公理，运用加法公式与补事件法则计算复合缺陷概率。
- 条件概率与独立：理解条件概率本质，运用乘法公式计算并检验工序间的随机独立性。
- 全概率公式与贝叶斯公式：掌握样本空间划分与全概率分解，理解质检报警中的基础比率效应。

## 样本空间与事件
在桌面质检分拣站中，工件每次滑入夹具并接受检测的过程称为随机试验。
试验具有三个特征：在相同工况下可重复进行；所有可能出现的结果在试验前已知；
单次试验的具体结果在完成前无法准确预知。

随机试验所有可能基本结果构成的集合称为样本空间，通常记为 S。
样本空间的子集称为随机事件，简称为事件，常用大写字母 A、B、C 等表示。
必然事件在每次试验中必然发生，即样本空间 S 本身；不可能事件记为 ∅。

事件之间的运算对应集合运算：
- 并事件（和事件）A ∪ B：事件 A 或事件 B 至少有一个发生。
- 交事件（积事件）A ∩ B 或 AB：事件 A 与事件 B 同时发生。
- 补事件（对立事件）Ā：事件 A 不发生。A 与 Ā 满足 A ∩ Ā = ∅ 且 A ∪ Ā = S。
- 互斥事件（互不相容）：若 A ∩ B = ∅，则 A 与 B 在单次试验中不可能同时发生。

### 例题
分拣站连续抽检 2 个打印件，用 1 表示合格，用 0 表示不合格。
(1) 写出该试验的样本空间 S；
(2) 设事件 A 为“至少有 1 个合格品”，事件 B 为“第 1 个工件为不合格品”，
写出事件 A、事件 B 以及交事件 A ∩ B 包含的基本事件。

解答：
(1) 样本空间包含按先后顺序排列的 4 个有序基本事件：
S = {(1, 1), (1, 0), (0, 1), (0, 0)}。
(2) 至少有 1 个合格品包含除了两件皆不合格之外的所有结果：
A = {(1, 1), (1, 0), (0, 1)}。
第 1 个工件不合格即首位为 0：
B = {(0, 1), (0, 0)}。
交事件 A ∩ B 表示“第 1 个不合格且至少有 1 个合格”，即第 2 个必须合格：
A ∩ B = {(0, 1)}。

### 常见错误
- 混淆互斥与对立：两事件互斥只要求不能同时发生，并不要求其并集包含所有结果；
只有并集为样本空间且互斥的两事件才是对立事件。
- 混淆“至少”与“恰好”：“至少 1 个合格”包含 1 个和多个合格，
不能遗漏全部合格的极端情形。

## 排列与组合
在质检抽样和工序排程中，经常需要确定可能出现的状态或样本选法的数量。
分步乘法计数原理指出：若完成一件事需经过 k 个有序步骤，
第 1 步有 n1 种方法，第 2 步有 n2 种方法……第 k 步有 nk 种方法，
则完成这件事共有 n1 × n2 × ... × nk 种不同方法。

当从 n 个不同元素中取出 m 个元素（m ≤ n）时：
- 排列关注选出元素的排列顺序。排列总数记为 P(n, m)，计算公式为：
P(n, m) = n × (n - 1) × ... × (n - m + 1) = n! / (n - m)!
- 组合不关注顺序，只关注元素构成的集合。组合总数记为 C(n, m)，计算公式为：
C(n, m) = P(n, m) / m! = n! / [m!(n - m)!]
组合数具有对称性质：C(n, m) = C(n, n - m)。

质量抽样中常面对超几何计数问题：从包含 N 个零件（其中次品 D 个）的批次中
随机抽取 n 个样品，抽得恰好 k 个次品的选法组合数为：
C(D, k) × C(N - D, n - k)

### 例题
分拣站进料箱内装有 10 个 3D 打印件，其中已知有 2 个尺寸超差，其余 8 个合格。
质检员随机抽取 3 个工件进行复核，求恰好抽到 1 个尺寸超差件的抽取组合数。

解答：
抽取过程分为两步完成：
第 1 步，从 2 个超差件中选取 1 个，选法有 C(2, 1) = 2 种；
第 2 步，从 8 个合格件中选取剩余的 2 个工件，选法有：
C(8, 2) = (8 × 7) / (2 × 1) = 28 种。
根据分步乘法原理，恰好抽到 1 个超差件的总组合数为：
C(2, 1) × C(8, 2) = 2 × 28 = 56 种。

### 常见错误
- 抽样不计顺序时误用排列公式 P(n, m) 代替组合公式 C(n, m)，导致样本数被多算了 m! 倍。
- 在分步抽样计数中只计算了次品的选法，漏掉了从剩余合格品池中选取合格品的步骤。

## 概率的运算法则
概率是度量随机事件发生可能性大小的数值，记为 P(A)，满足 0 ≤ P(A) ≤ 1。
对于基本事件有限且等可能的古典概型，事件 A 的概率等于 A 包含的基本事件数除以
样本空间的基本事件总数。必然事件概率 P(S) = 1，不可能事件概率 P(∅) = 0。

概率运算的核心法则是加法公式与补事件法则：
- 概率加法公式：对任意两个事件 A 与 B，有
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
含义是两事件并集的概率等于各自概率之和减去重复计算的交集概率。
- 互斥事件加法公式：若 A 与 B 互斥（A ∩ B = ∅），则 P(A ∪ B) = P(A) + P(B)。
- 补事件（对立事件）法则：P(Ā) = 1 − P(A)。
在工程检测中，“至少出现一种缺陷”常通过 1 减去“无缺陷”的概率来简便计算。

### 例题
桌面分拣站对工件进行质检，单件出现“孔径偏小”（事件 A）的概率为 0.06，
出现“表面拉丝”（事件 B）的概率为 0.05，两类缺陷同时出现的概率为 0.02。
求：(1) 工件至少存在一种缺陷的概率；(2) 工件完全无缺陷的概率。

解答：
(1) 由概率加法公式，至少存在一种缺陷的概率为：
P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 0.06 + 0.05 − 0.02 = 0.09。
(2) 完全无缺陷即事件 A ∪ B 的对立事件，由补事件法则：
P(无缺陷) = 1 − P(A ∪ B) = 1 − 0.09 = 0.91。

### 常见错误
- 忽略交事件重复项：在两事件不互斥时直接写 P(A ∪ B) = P(A) + P(B)，
导致概率被夸大甚至可能算出大于 1 的荒谬结果。
- 错把对立事件当成完全相反：“至少一个次品”的对立面是“全为合格品”，
而非“全为次品”。

## 条件概率与独立
在事件 B 已经发生的条件下，事件 A 发生的概率称为条件概率，记为 P(A|B)。
其计算定义式为（要求 P(B) > 0）：
P(A|B) = P(A ∩ B) / P(B)
条件概率把考察的样本空间从全集 S 压缩到了事件 B 这一局部范围内。

由定义可导出概率乘法公式：
P(A ∩ B) = P(B) × P(A|B) = P(A) × P(B|A)

事件独立性反映了事件之间是否存在统计关联：
- 若两事件满足 P(A ∩ B) = P(A) × P(B)，或等价地 P(A|B) = P(A)，
则称事件 A 与事件 B 相互独立。这表明 B 的发生不改变 A 发生的可能性。
- 独立性与互斥性有本质区别：对两个概率大于 0 的事件，
若相互独立则必能同时发生（P(A ∩ B) > 0），因而绝不可能互斥；
若两事件互斥，则 B 发生必然导致 A 不能发生（P(A|B) = 0 ≠ P(A)），二者极度相关。

### 例题
分拣站工件连续经过两道完全独立的检测工序：红外到位传感器与工业相机视觉测量。
已知工件顺利通过传感器检测的概率为 0.96，通过相机视觉检测的概率为 0.90。
求：(1) 一个工件顺利通过两道工序的概率；
(2) 若已知工件已通过传感器检测，它同时通过相机检测的条件概率。

解答：
设 A 为通过传感器，B 为通过相机。由题意 A 与 B 相互独立。
(1) 由独立事件乘法公式：
P(A ∩ B) = P(A) × P(B) = 0.96 × 0.90 = 0.864。
(2) 因 A 与 B 相互独立，传感器通过与否不影响相机通过率，由独立性定义：
P(B|A) = P(B) = 0.90。

### 常见错误
- 混淆条件概率 P(A|B) 与联合概率 P(A ∩ B)：前者分母是缩小后的事件 B 概率，
后者分母是整个样本空间。
- 误认为“互斥”等同于“独立”，在计算独立事件并集或互斥事件交集时乱套公式。

## 全概率公式与贝叶斯公式
若事件组 B1, B2, ..., Bn 两两互斥且其并集等于整个样本空间 S，
则称其为样本空间的一个划分（完备事件组）。

全概率公式用于由“原因”推导“总体结果”：
设 {B1, B2, ..., Bn} 为样本空间的划分，对任一事件 A，有：
P(A) = P(B1)P(A|B1) + P(B2)P(A|B2) + ... + P(Bn)P(A|Bn) = Σ P(Bi)P(A|Bi)
它将复杂的总体概率拆解为各来源的先验概率与其条件概率的加权和。

贝叶斯公式则用于“由果溯因”的逆概率推断：
当观察到结果事件 A 已经发生，推断其由特定原因 Bk 引起的后验概率为：
P(Bk|A) = [P(Bk)P(A|Bk)] / P(A) = [P(Bk)P(A|Bk)] / [Σ P(Bi)P(A|Bi)]

质检中的基础比率效应：
在实际检测中，若真实缺陷率 P(D)（先验概率/基础比率）极低，
即便相机的检出率极高、误报率极低，庞大合格品基数带来的误报（假阳性）
数量仍可能多于真实缺陷件数，导致“报警时工件真有缺陷的后验概率”显著低于直觉。

### 例题
分拣站检测一批 3D 打印件，已知该批次真实缺陷率为 0.02（基础比率）。
相机检测系统对缺陷件的报警概率（灵敏度）为 0.95，对合格件的误报率为 0.05。
若某工件触发了系统报警，求该工件实际确实存在缺陷的后验概率（保留两位小数）。

解答：
设 D 为工件有缺陷，D̄ 为工件合格；A 为系统发出报警。
已知 P(D) = 0.02，P(D̄) = 1 − 0.02 = 0.98；
条件概率为 P(A|D) = 0.95，P(A|D̄) = 0.05。
首先由全概率公式计算系统总报警概率：
P(A) = P(D)P(A|D) + P(D̄)P(A|D̄) = 0.02 × 0.95 + 0.98 × 0.05 = 0.019 + 0.049 = 0.068。
接着由贝叶斯公式计算报警工件真有缺陷的后验概率：
P(D|A) = [P(D)P(A|D)] / P(A) = 0.019 / 0.068 ≈ 0.2794。
结果保留两位小数为 0.28（即仅约 28%）。

### 常见错误
- 忽视基础比率：把检出灵敏度 P(A|D) 直接当成报警后的真缺陷概率 P(D|A)。
- 遗漏假阳性分母：在全概率分母中只计算真缺陷报警项，漏加合格品的误报项。

## 单元小结
- 样本空间与事件是概率论的集合基石，必须严格区分互斥（无交集）与对立（互斥且和为全集）。
- 排列与组合是离散事件计数的数学工具，有先后次序用排列 P(n, m)，无先后次序用组合 C(n, m)。
- 概率加法公式修正了交集的重复计算，补事件法则常能化繁为简地求解“至少出现一次”问题。
- 条件概率在给定局部信息下更新样本空间，独立性表明信息互不影响，两正概率事件独立必不互斥。
- 全概率公式用于正向分解总概率，贝叶斯公式用于逆向修正信念，低缺陷率下的假阳性不容忽视。
