# 数据与描述统计

本单元依托桌面质检分拣站的尺寸测量与判定场景，系统学习数据类型与测量尺度、
集中趋势与离散程度指标，以及基于直方图和箱线图的分布形态与异常值识别方法。

## 本单元知识点
- 数据类型与测量尺度：掌握定性与定量、离散与连续划分，区分四种测量尺度。
- 均值与加权平均：掌握算术平均与加权平均算法，理解均值受极端值拉偏的性质。
- 中位数、众数与集中趋势：掌握中位数与众数求法，理解偏态分布下指标差异与选择。
- 极差、方差与标准差：掌握极差、无偏样本方差与标准差计算，理解变异系数用途。
- 直方图、四分位数与箱线图：掌握频数分组与双峰识别，掌握箱线图离群点判定准则。

## 数据类型与测量尺度
在桌面质检分拣站中，传感器和视觉检测系统采集的各类数据具有不同的数学属性。
按属性特征，数据首先划分为定性数据（分类与顺序）与定量数据（数值度量）。
定量数据又细分为离散型（如缺陷个数、料盒计件数）与连续型（如厚度、直径、耗时）。

测量尺度由低到高分为四类：
1. 名义尺度（Nominal）：仅用于分类与标识，无大小优劣之分，
   如工件编号、合格判定（True/False）、料盒通道号。
2. 顺序尺度（Ordinal）：具备先后等级次序，但间距无统一度量标准，
   如外观划痕等级（优、良、差）、尺寸公差等级（IT6、IT7）。
3. 区间尺度（Interval）：间距具有明确数学意义，但没有绝对物理零点，
   如摄氏温度，其差值有意义，但不能做乘除倍数比较。
4. 比率尺度（Ratio）：具备确定单位和绝对物理零点（零表示完全没有），
   如工件厚度、重量、检测耗时，可进行加减乘除及倍数运算。

质检实务中必须严格根据测量尺度选用统计方法，禁止对名义或顺序尺度做数值算术平均。

### 例题
质检站 CSV 文件导出一组记录：工件编号为 08，表面等级为“良”，实测厚度为
10.25 mm，环境温度为 22 ℃。请指出这四个字段分别对应的测量尺度。
解答：
1. 工件编号“08”用于唯一标识实体，数值无大小意义，属于名义尺度。
2. 表面等级“良”反映质量优劣顺序但级差无具体数值，属于顺序尺度。
3. 实测厚度“10.25 mm”存在物理绝对零点且可做倍数运算，属于比率尺度。
4. 环境温度“22 ℃”零点为人为设定且不能做倍数乘除，属于区间尺度。

### 常见错误
1. 将工位编号、工件批号等数字编码误当作定量数据进行求和或算术平均。
2. 对优、良、差等顺序尺度赋予 3、2、1 分后直接做加减平均，忽视其非等距性。
3. 认为 40 ℃ 的温度是 20 ℃ 的两倍，混淆了区间尺度与比率尺度的倍数含义。

## 均值与加权平均
算术平均数（Mean）是度量一组数据中心位置最基础的指标，用 x̄ 表示。
计算公式为所有数据之和除以样本量 n：
```
x̄ = (Σx) / n = (x₁ + x₂ + ... + xₙ) / n
```
算术平均数利用了每一个样本数据的信息，且满足离差之和恒为零，即 Σ(x − x̄) = 0。

当数据由不同批次或不同子组汇集，且各组样本量（权重 w）不相同时，
直接将各组均值简单相加平均会导致严重偏差，必须采用加权平均数：
```
x̄_w = (Σ(w · x)) / (Σw)
```

均值对极端值（离群点）高度敏感。如果夹具定位异常或传感器受光线干扰产生单次
极大或极小的异常读数，均值会被剧烈拉偏，从而掩盖整批工件的真实受控状态。

### 例题
质检站分三次抽取某批工件测定平均长度：第 1 组 10 件，均值 50.2 mm；
第 2 组 30 件，均值 50.0 mm；第 3 组 10 件，均值 50.6 mm。求总平均长度。
解答：
由于各组抽取件数不同，必须以件数作为权重计算加权平均数：
总样本量 Σw = 10 + 30 + 10 = 50 件。
加权总和 Σ(w · x) = 10 × 50.2 + 30 × 50.0 + 10 × 50.6
                  = 502 + 1500 + 506 = 2508 mm。
加权平均值 x̄_w = 2508 / 50 = 50.16 mm。
若误用简单平均计算，则得出 (50.2 + 50.0 + 50.6) / 3 = 50.27 mm，放大了小样本组的影响。

### 常见错误
1. 在合并不同批量检验批的合格率或平均尺寸时，忽视批量权重直接取简单算术平均。
2. 在现场出现夹具干涉产生超大尺寸读数时，仍直接用均值向车间汇报工件标准尺寸。

## 中位数、众数与集中趋势
中位数（Median）是将样本数据按数值大小排列后，位于正中间位置的数值。
若样本量 n 为奇数，中位数为第 (n + 1) / 2 个数值；
若样本量 n 为偶数，中位数为第 n / 2 与第 (n / 2 + 1) 两个数值的算术平均值。
中位数的核心优势在于稳健性：其取值不受数据集中两端极端异常值的影响。

众数（Mode）是一组数据中出现频次最高的数值。众数既适用于数值型数据，
也适用于定性分类数据（如分拣中最常见的缺陷类型）。一组数据可能无众数或有多众数。

数据分布的形态决定了集中趋势指标的相互关系：
1. 对称分布：数据在中心两侧均匀分布，均值 ≈ 中位数 ≈ 众数。
2. 右偏分布（正偏态）：右侧存在极大离群值长拖尾，均值 > 中位数 > 众数。
3. 左偏分布（负偏态）：左侧存在极小值长拖尾，均值 < 中位数 < 众数。
在数据分布严重偏斜或存在粗大误差时，中位数是反映典型水平的首选指标。

### 例题
分拣工位测得 7 件工件的孔径（单位：mm）为：10.02、10.01、10.03、10.02、
10.01、10.50、10.02。计算其中位数和众数，并说明集中趋势指标的选择。
解答：
1. 升序排序：10.01、10.01、10.02、10.02、10.02、10.03、10.50。
2. 样本量 n = 7 为奇数，中位数为第 (7 + 1) / 2 = 4 项，即 10.02 mm。
3. 数值 10.02 出现 3 次，出现频次最高，众数为 10.02 mm。
4. 算术均值为 (10.01×2 + 10.02×3 + 10.03 + 10.50) / 7 = 70.61 / 7 ≈ 10.09 mm。
   由于第 7 个读数 10.50 mm 属于异常粗大误差，均值被拉高，应选用中位数 10.02 mm
   代表正常加工尺寸。

### 常见错误
1. 样本量为偶数时忘记对中间两个数求平均，或未做大小排序直接取记录表中项。
2. 面对偏态分布或受污染数据，不经分析机械选用均值作为唯一评价指标。

## 极差、方差与标准差
离散程度反映数据围绕中心位置波动的剧烈程度，是质检公差控制的核心依据。
极差（Range）是最大值与最小值之差：R = x_max − x_min。
极差计算最快，但完全依赖极值，无法反映中间所有数据的波动细节。

样本方差（s²）度量各测量值与均值离差平方的平均水平。为了消除用样本均值
估计总体均值所消耗的自由度，获得总体方差的无偏估计，分母必须除以 n − 1：
```
s² = (Σ(x − x̄)²) / (n − 1)
```
样本标准差（s）是样本方差的算术平方根，公式为 s = √(s²)。标准差与原始
测量数据具有完全相同的物理量纲（如 mm），便于直接与工程图纸公差带比较。

变异系数（CV）是标准差与均值的比值，公式为 CV = s / x̄。变异系数是
消除量纲影响的无量纲相对离散指标，常用于比较均值相差悬殊或单位不同的两组工件波动。

### 例题
分拣工位连续测量 5 件样件外径（mm）：10.0、10.2、10.0、9.8、10.0。
计算其极差 R、样本方差 s² 与样本标准差 s。
解答：
1. 均值 x̄ = (10.0 + 10.2 + 10.0 + 9.8 + 10.0) / 5 = 50.0 / 5 = 10.0 mm。
2. 极差 R = 10.2 − 9.8 = 0.4 mm。
3. 各观测值与均值的离差分别为：0.0、0.2、0.0、−0.2、0.0。
   离差平方和 Σ(x − x̄)² = 0.0² + 0.2² + 0.0² + (−0.2)² + 0.0² = 0.08 mm²。
4. 样本方差 s² = 0.08 / (5 − 1) = 0.08 / 4 = 0.02 mm²。
5. 样本标准差 s = √0.02 ≈ 0.14 mm。

### 常见错误
1. 计算样本方差时分母误用样本量 n，未进行自由度 n − 1 修正。
2. 将方差的单位（mm²）与原始公差单位（mm）直接混为一谈。
3. 比较大尺寸工件与微型零件的加工稳定性时，直接用绝对标准差对比而未使用变异系数。

## 直方图、四分位数与箱线图
频数直方图通过将连续测量数据划分为等间距的区间（组），统计各组频数绘制柱形。
直方图能直观揭示工艺状态：单峰对称说明加工平稳；若出现两个明显尖峰（双峰），
通常意味着数据混入了不同模具腔号、两台不同机床或两批材料的混合产品。

分位数通过位置切分反映分布特征。四分位数将升序数据等分为四部分：
下四分位数 Q1（25% 分位数）、中位数 Q2（50% 分位数）、上四分位数 Q3（75% 分位数）。
四分位距（IQR）定义为 IQR = Q3 − Q1，它度量了中间 50% 核心数据的离散宽度。

箱线图（Box Plot）利用五数概括（最小值、Q1、Q2、Q3、最大值）展示数据架构。
工业质检中常采用内限准则识别潜在离群点（异常读数）：
```
下侧内限 = Q1 − 1.5 · IQR
上侧内限 = Q3 + 1.5 · IQR
```
任何落在 [Q1 − 1.5·IQR, Q3 + 1.5·IQR] 区间之外的测量数据点均被标记为离群点。

### 例题
某批 12 件工件高度（mm）排序后求得 Q1 = 20.0 mm，Q3 = 24.0 mm。
现场测得一件尺寸为 31.0 mm 的工件。利用 1.5·IQR 准则判断该工件是否为离群点。
解答：
1. 计算四分位距：IQR = Q3 − Q1 = 24.0 − 20.0 = 4.0 mm。
2. 计算离群点判定门限：
   下侧门限 = Q1 − 1.5 · IQR = 20.0 − 1.5 × 4.0 = 14.0 mm。
   上侧门限 = Q3 + 1.5 · IQR = 24.0 + 1.5 × 4.0 = 30.0 mm。
3. 判定区间为 [14.0, 30.0] mm。
   测得值 31.0 mm > 30.0 mm，超出了上侧门限，因此判定为上侧离群点。

### 常见错误
1. 误以为箱线图箱体上下边界是数据的最小值和最大值，混淆了四分位数与极值。
2. 计算离群点门限时，错误地从中位数 Q2 出发加减 1.5·IQR。
3. 看到双峰直方图时误以为是随机测量噪声，忽略了多机台或多批料混杂的工程根本原因。

## 单元小结
- 数据类型决定运算规则：区分定性与定量、名义/顺序/区间/比率尺度，禁止对非等距尺度滥用算术均值。
- 集中趋势选型有依据：对称分布首选均值，偏态或包含粗大误差数据首选抗噪稳健的中位数，分类数据选用众数。
- 离散程度刻画公差精度：样本方差与标准差分母为 n − 1；面对量纲不同或均值悬殊的工件组采用变异系数对比。
- 分布形态直指工艺异常：直方图双峰提示机台或原料混杂，箱线图结合 1.5·IQR 准则可自动化筛选离群异常件。
- 描述统计是分析波动的起点：均值、标准差与图形共同回答数据的中心、散布和形态。
