# 估计与检验
本单元依托桌面质检分拣站的传感器与尺寸测量数据，学习如何用抽样样本推断工件尺寸与不良率等总体参数，并依据统计证据对加工质量做出科学决策。

## 本单元知识点
- 点估计：理解用样本统计量估计总体未知参数的思想与无偏估计的统计学含义。
- 置信区间：掌握均值置信区间的构建与计算，正确理解置信水平及样本量的影响。
- 假设检验入门：掌握原假设、备择假设、检验统计量与 p 值，识别两类判断错误。
- 比例的估计：掌握工件不良率置信区间的正态近似估计方法与所需样本量的估算。

## 点估计
在桌面质检分拣站中，传送带上源源不断送来大批量工件。我们无法对每一个
工件进行破坏性或全量测量，因而总体均值 μ、总体方差 σ² 和总体不良率 p
等总体参数是客观存在但未知的固定常数。点估计是通过抽样获取部分工件，
计算出某个样本统计量，并用该单一数值直接作为总体参数的估计值。

常用的点估计量包括：使用样本均值 x̄ = (Σxᵢ)/n 估计总体均值 μ；使用
样本比例 p̂ = x/n（其中 x 为样本中不合格品数，n 为样本量）估计总体不良率 p；
使用样本方差 s² = Σ(xᵢ − x̄)²/(n − 1) 估计总体方差 σ²。样本方差开平方
得到的样本标准差 s = √s² 则是总体标准差 σ 的点估计值。

评价估计量优劣的核心标准之一是无偏性。如果一个估计量的数学期望等于所
估计的总体参数真值（即 E(θ̂) = θ），则称该估计量为无偏估计量。无偏性
并不保证某一次具体抽样的估计结果完全没有误差，而是表明在长期重复抽样
中，所有可能得到的估计值平均而言与真实参数完全一致，不存在系统性偏差。

在样本方差的计算公式中，分母使用自由度 n − 1 而非样本量 n，正是为了
保证无偏性。由于样本离均差是围绕样本均值 x̄ 计算的，其离差平方和必然
小于围绕真实总体均值 μ 计算的离差平方和。除以 n − 1 恰好补偿了这种
对波动的低估，使 s² 成为总体方差 σ² 的无偏估计。

### 例题
题目：分拣工位的激光测距传感器对随机抽检的 5 件 3D 打印定位块厚度
进行测量，记录读数（单位：mm）分别为 20.1、19.9、20.0、20.2、19.8。
请计算该批定位块厚度总体均值 μ 的点估计值，以及厚度总体方差 σ² 的无偏点
估计值。

解答：
第一步，计算样本均值作为总体均值的点估计值：
x̄ = (20.1 + 19.9 + 20.0 + 20.2 + 19.8) / 5 = 100.0 / 5 = 20.0 mm。
第二步，计算各测量值与样本均值的离差：
20.1 − 20.0 = 0.1，19.9 − 20.0 = −0.1，20.0 − 20.0 = 0.0，
20.2 − 20.0 = 0.2，19.8 − 20.0 = −0.2。
第三步，计算离差平方和：
Σ(xᵢ − x̄)² = 0.1² + (−0.1)² + 0.0² + 0.2² + (−0.2)²
= 0.01 + 0.01 + 0.00 + 0.04 + 0.04 = 0.10 mm²。
第四步，除以自由度 n − 1 计算无偏样本方差：
s² = 0.10 / (5 − 1) = 0.10 / 4 = 0.025 mm²。
因此，总体均值 μ 的点估计值为 20.0 mm，总体方差 σ² 的点估计值为 0.025 mm²。

### 常见错误
- 将点估计值等同于总体真值：误认为抽样计算出的样本均值 x̄ 必定是总体真实
  均值，忽略了单次抽样具有随机波动性。
- 计算样本方差时除以 n：错误使用 n 作分母，导致低估总体真实方差。
- 误解无偏性的统计含义：将“无偏”理解为“单次估计绝对精准、毫无误差”，
  实际上无偏性只代表无限次重复抽样均值的长期无偏向性。

## 置信区间
点估计虽然给出了未知参数的具体参考数值，但无法度量估计结果的精度与
可靠性。区间估计结合抽样分布规律，由样本数据构造出一个包含总体未知参数
的数值区间，并给出该区间覆盖真实参数的置信水平（通常取 95% 或 99%）。

根据中心极限定理，当从均值为 μ、标准差为 σ 的总体中抽取容量为 n 的
大样本（或总体本身近似正态分布）时，样本均值 x̄ 的抽样分布近似服从正态
分布，其标准误为 σ/√n。双侧置信水平为 1 − α 的总体均值置信区间公式为：
x̄ ± z · (σ/√n)
其中 z 为标准正态分布的双侧临界值，例如 95% 置信水平对应 z = 1.96。
公式中的 z · (σ/√n) 称为边际误差 E，区间总宽度等于 2E。

必须严格区分置信水平的统计学内涵：总体真值 μ 是客观存在的固定常数，
并不是随机变量；随机变动的是由每次不同样本构建出的区间端点。95% 置信水平
表示如果反复独立进行大量抽样并分别计算区间，大约有 95% 的区间会成功
覆盖真实参数 μ。对于已经根据具体数据算出的确定区间，总体均值要么在其中，
要么不在其中，不能说“总体均值有 95% 的概率落在此区间内”。

区间宽度与样本量密切相关。由边际误差 E = z · (σ/√n) 可知，在置信水平
和总体波动已知时，边际误差与 √n 成反比。若要使估计精度翻倍（即边际误差
和区间宽度缩小为原来的一半），抽检的样本量 n 必须扩大为原来的 4 倍。

### 例题
题目：分拣工位加工一批销轴，已知工艺固有标准差 σ = 0.06 mm。传感器
随机记录了 36 件销轴的外径，算得样本均值 x̄ = 15.02 mm。已知标准正态分布
满足 P(Z ≤ 1.96) = 0.975，求该批销轴总体平均外径 μ 的 95% 置信区间。

解答：
第一步，计算样本均值的抽样标准误：
标准误 = σ / √n = 0.06 / √36 = 0.06 / 6 = 0.01 mm。
第二步，确定 95% 置信水平对应的双侧临界值 z：
因为双侧显著性水平 α = 0.05，单侧面积为 0.025，查表得 z = 1.96。
第三步，计算边际误差 E：
E = z · (σ / √n) = 1.96 × 0.01 = 0.0196 mm。
第四步，计算置信区间端点：
区间下限 = x̄ − E = 15.02 − 0.0196 = 15.0004 mm。
区间上限 = x̄ + E = 15.02 + 0.0196 = 15.0396 mm。
因此，该批销轴总体平均外径的 95% 置信区间为 [15.0004 mm, 15.0396 mm]。

### 常见错误
- 概率主体颠倒：宣称“总体均值有 95% 的概率落在该区间内”，错误地把总体
  参数当成随机变量。
- 混淆总体分布范围与均值估计区间：误以为 95% 置信区间代表 95% 的单个工件
  尺寸落在此范围内。
- 线性误解样本量效益：误以为样本量翻倍即可将置信区间宽度减半，忽略了
  样本量处于平方根分母中。

## 假设检验入门
在自动化质检中，工程师常需根据抽样数据判断产线状态是否发生异常。假设
检验基于统计反证法逻辑：首先提出两个互斥假设，原假设 H₀（代表基准状态、
无实质差异或符合公差标准，如 μ = μ₀）和备择假设 H₁（代表存在实质差异、
工艺失控或有待证实的推断，如 μ ≠ μ₀、μ > μ₀ 或 μ < μ₀）。

为了利用数据进行仲裁，需要构造检验统计量。在总体标准差 σ 已知时，
检验均值的常用统计量为 z = (x̄ − μ₀) / (σ/√n)。若原假设 H₀ 成立，
该统计量服从标准正态分布。根据样本计算出实际的 z 值后，可通过 p 值进行
决策。p 值是指在原假设成立的前提下，观察到当前样本统计量或更极端情况
的概率。

显著性水平 α 是事先划定的检验拒绝阈值（常用 0.05 或 0.01），代表允许
承担的犯错风险上限。检验决策规则十分清晰：若 p ≤ α，说明在原假设下小
概率事件发生，统计证据足以推翻现状，故拒绝 H₀，接受 H₁；若 p > α，
说明当前样本与原假设的偏离在随机波动合理范围内，不能拒绝 H₀。

由于抽样具有不确定性，统计决策存在两类错误风险：
- 第一类错误（弃真）：原假设本为真却被错误拒绝。其发生概率为 α，在质检
  中对应生产方风险（将正常批次误判为异常）。
- 第二类错误（取伪）：原假设本为假却未能被拒绝。其发生概率记为 β，在质检
  中对应使用方风险（让异常不合格品流向下一道工序）。
在样本量固定时，降低 α 会使判定标准变严，从而导致 β 升高；只有增加
样本量 n，才能同时有效压缩两类错误的发生概率。

### 例题
题目：分拣站监控某连杆冲压件的厚度，标准设计均值 μ₀ = 2.00 mm，已知
加工过程总体标准差 σ = 0.04 mm。工程师怀疑模具松动使工件厚度偏大，抽取
16 件工件测得平均厚度 x̄ = 2.02 mm。设定显著性水平 α = 0.05，检验原假设
H₀: μ = 2.00 对备择假设 H₁: μ > 2.00。已知 P(Z ≤ 2.00) = 0.9772。

解答：
第一步，建立单侧检验假设：
H₀: μ = 2.00 mm（厚度正常），H₁: μ > 2.00 mm（厚度偏大）。
第二步，计算样本均值的标准误：
标准误 = σ / √n = 0.04 / √16 = 0.04 / 4 = 0.01 mm。
第三步，计算检验统计量 z 值：
z = (x̄ − μ₀) / (σ/√n) = (2.02 − 2.00) / 0.01 = 0.02 / 0.01 = 2.00。
第四步，计算右侧 p 值并与显著性水平比较：
p 值 = P(Z ≥ 2.00) = 1 − P(Z ≤ 2.00) = 1 − 0.9772 = 0.0228。
因为 p = 0.0228 < α = 0.05，所以在 0.05 显著性水平下拒绝原假设 H₀，
有充分统计证据支持模具可能松动导致厚度显著偏大。

### 常见错误
- 把未拒绝原假设当作“证明原假设为真”：当 p > α 时，仅说明当前样本证据
  不足以推翻 H₀，不能据此认定原假设绝对正确。
- 混淆 p 值的统计定义：把 p 值错误解读为“原假设成立的概率”或“备择
  假设为假的概率”。
- 颠倒两类错误类型：混淆生产方风险（弃真，α）与使用方风险（取伪，β）。

## 比例的估计
在分拣工位中，相机检测工件表面划痕并输出“合格/不合格”二值结果。
工件出现缺陷的概率对应总体不良率 p。从批次中抽检 n 件，不合格品数 x
服从二项分布。样本不良率计算为 p̂ = x/n。

当样本量充分大且满足大样本条件（一般要求 np̂ ≥ 5 且 n(1 − p̂) ≥ 5）
时，样本比例 p̂ 的抽样分布近似服从正态分布，其均值为 p，标准误为
√(p(1 − p)/n)。由于总体比例 p 未知，工程中采用样本比例 p̂ 估算标准误，
总体不良率 p 的双侧置信区间计算公式为：
p̂ ± z · √(p̂(1 − p̂) / n)
其中 z 同样为标准正态分布的双侧临界值（如 95% 水平取 z = 1.96）。

在制定抽样质检方案前，需预估所需抽样量以保证估计精度。若希望在 1 − α
置信水平下，估计不良率的边际误差不超过 E，所需最小样本量估算公式为：
n = [z² · p*(1 − p*)] / E²
其中 p* 为事先已知的先验不良率估计值。

如果产线完全新建或缺少历史数据，没有任何可靠先验信息，考虑到二次函数
p*(1 − p*) 在 p* = 0.5 时取得最大值 0.25，取 p* = 0.5 代入计算可获得
最保守（最大容量）的样本量。这一最保守设计可确保无论真实不良率为何值，
估计结果的边际误差均绝不会突破预定限度 E。

### 例题
题目：相机视觉检测系统在传送带上随机检测了 400 件注塑连接器，发现有
32 件存在毛刺缺陷。已知 P(Z ≤ 1.96) = 0.975，求该批连接器总体毛刺不良率
p 的 95% 置信区间。

解答：
第一步，计算样本不良率点估计值：
p̂ = 32 / 400 = 0.08。
第二步，检验正态近似条件：
np̂ = 400 × 0.08 = 32 ≥ 5，n(1 − p̂) = 400 × 0.92 = 368 ≥ 5，
合格品与不良品数均不小于 5，满足大样本正态近似条件。
第三步，计算样本比例的标准误估计值：
标准误 = √(0.08 × (1 − 0.08) / 400) = √(0.08 × 0.92 / 400)
= √(0.0736 / 400) = √0.000184 ≈ 0.01356。
第四步，计算边际误差 E：
E = 1.96 × 0.01356 ≈ 0.0266。
第五步，计算置信区间端点：
下限 = 0.08 − 0.0266 = 0.0534，上限 = 0.08 + 0.0266 = 0.1066。
因此，该批连接器总体不良率的 95% 置信区间为 [0.0534, 0.1066]
（即 5.34% 至 10.66% 之间）。

### 常见错误
- 样本量过小滥用公式：在缺陷数极少（np̂ < 5）时强行套用正态近似公式，
  可能导致算出的置信区间下限为负数的荒谬结论。
- 百分比与小数代错：在样本量公式中将 5% 的边际误差误代入为 5 而非 0.05，
  导致算出的样本量出现严重量级错误。
- 缺乏先验信息时盲目预估极小值：在无历史数据时随意假设极低不良率计算
  样本量，导致实际抽样规模严重不足，抽样精度无法达标。

## 单元小结
- 点估计通过样本均值、样本比例与无偏样本方差给出未知总体参数的单点最佳
  猜测，无偏性从长期重复抽样角度保证了估计量无系统性偏差。
- 置信区间通过标准误和临界值定量反映估计不确定性，95% 置信水平代表反复
  抽样算法区间的覆盖率，样本量扩大 4 倍可使区间宽度减半。
- 假设检验以反证法为逻辑基石，通过 z 统计量和 p 值与显著性水平 α 的比较
  决定是否拒绝原假设，并在弃真（α）与取伪（β）两类风险间取得平衡。
- 比例估计利用正态近似评估二分类属性合格率，通过边际误差与保守原则
  （p* = 0.5）能够科学确定满足质检工程精度目标的最低抽样件数。
