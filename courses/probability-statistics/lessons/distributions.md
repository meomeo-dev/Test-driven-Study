# 随机变量与分布

本单元建立从随机事件到数值化变量的桥梁，系统学习离散型与连续型典型分布
及其期望、方差与概率计算，为质检分拣站的缺陷建模与尺寸公差分析提供核心工具。

## 本单元知识点

- 随机变量与期望：离散随机变量及其分布列，期望与方差的物理意义、计算及线性性质。
- 二项分布：独立重复伯努利试验，二项概率公式及其期望和方差的应用。
- 泊松分布：单位时间或单位空间内微小概率缺陷事件的发生规律与参数特征。
- 正态分布与 z 分数：连续型尺寸分布的正态曲线、参数含义、标准化 z 分数与查表计算。

## 随机变量与期望

在桌面质检分拣站中，工件经传感器检测后可能产生不同的数值结果，例如复检次数、
表面划痕数或工位处理耗时。随机变量就是把随机试验的每一个可能结果映射为一个确定
实数的变量，通常用大写字母 X、Y 表示。只能取有限个或可列个离散数值的变量称为离散
随机变量，列出每个可能取值 xi 及其对应概率 P(X = xi) = pi 的表格称为分布列。分布列
必须满足两条基本公理：每个概率非负（pi ≥ 0），且全部概率之和严格等于 1（Σpi = 1）。

数学期望 E(X) 是随机变量所有可能取值的加权平均值，权重即为对应发生的概率，公式为
E(X) = Σ xi·pi。在质检实务中，期望反映了流水线长期运行下的平均水平或理论中心。
方差 Var(X) 衡量随机变量偏离其均值的离散程度，定义为各取值与期望差值平方的加权平均，
即 Var(X) = E[(X - E(X))²] = Σ (xi - E(X))²·pi；在手工计算时，常用化简公式
Var(X) = E(X²) - [E(X)]²，其中 E(X²) = Σ xi²·pi。方差的算术平方根称为标准差 σ(X)。

期望具有非常重要的线性性质：对于任意常数 a 和 b，恒有 E(aX + b) = aE(X) + b。
对于两个随机变量 X 和 Y，无论它们是否独立，期望均满足加法可加性：E(X + Y) = E(X) + E(Y)。
而方差受常数乘法缩放的影响为平方关系：Var(aX + b) = a²Var(X)；当且仅当 X 与 Y 相互
独立时，才具有方差可加性：Var(X + Y) = Var(X) + Var(Y)。

### 例题

质检站视觉相机对疑似超差工件触发复检，最多复检 2 次。设某工件复检次数为 X，其分布列为：
X = 0（一次通过未复检）的概率为 0.6；X = 1（复检 1 次）的概率为 0.3；X = 2（复检 2 次）
的概率为 0.1。求 X 的数学期望 E(X) 与方差 Var(X)。

解答步骤：
1. 计算数学期望 E(X)：
   E(X) = 0×0.6 + 1×0.3 + 2×0.1 = 0 + 0.3 + 0.2 = 0.5（次）。
   这表明长期平均来看，每个工件需复检 0.5 次。
2. 计算随机变量平方的期望 E(X²)：
   E(X²) = 0²×0.6 + 1²×0.3 + 2²×0.1 = 0 + 0.3 + 0.4 = 0.7。
3. 利用化简公式计算方差 Var(X)：
   Var(X) = E(X²) - [E(X)]² = 0.7 - 0.5² = 0.7 - 0.25 = 0.45。

### 常见错误

- 误以为期望 E(X) 必须是变量 X 的可能取值之一。实际上期望是加权平均值，
  例如平均复检 0.5 次，但单次检测中复检次数只能是整数 0、1 或 2。
- 计算线性变换的方差时忘记对系数平方，误写成 Var(aX + b) = aVar(X) - b；
  常数项 b 不影响波动，系数 a 必须平方为 a²。
- 混淆期望与方差的可加性前提，误以为 E(X + Y) = E(X) + E(Y) 也需要独立性假设，
  实际上期望加法对任意相关关系的变量均恒成立。

## 二项分布

在质检分拣线上，我们经常连续检测 n 个工件，每个工件经过相机判定只有两种互斥结果：
合格或不合格。如果每次试验中事件发生的概率 p 保持恒定，且每次试验的结果互不影响
（即各次试验相互独立），这样的 n 次独立重复试验称为 n 重伯努利试验。

设在 n 次独立重复试验中，合格品（或缺陷品）出现的总件数为 X，则 X 服从参数为 n 和 p
的二项分布，记作 X ~ B(n, p)。随机变量 X 取值为 k（k = 0, 1, 2, ..., n）的概率由二项概率
公式给出：
P(X = k) = C(n, k) · pᵏ · (1 - p)ⁿ⁻ᵏ
其中 C(n, k) = n! / [k! · (n - k)!] 为组合数，表示从 n 次试验中选出 k 次成功的组合种数。

二项分布的数字特征可以直接由单次伯努利试验推导：
- 数学期望：E(X) = n · p。
- 方差：Var(X) = n · p · (1 - p)。
- 标准差：σ = √[n · p · (1 - p)]。
当工件缺陷率 p 很低时，方差近似等于 np；当 p = 0.5 时，在给定样本量 n 下方差达到极大值。

### 例题

质检站传送带连续送检 n = 5 个工件，历史合格率为 p = 0.8，各件检测相互独立。
求：（1）这 5 个工件中恰有 4 个合格的概率 P(X = 4)；（2）合格件数 X 的期望与方差。

解答步骤：
1. 计算恰有 4 件合格的概率：
   C(5, 4) = 5! / (4! · 1!) = 5。
   P(X = 4) = C(5, 4) · 0.8⁴ · (1 - 0.8)¹ = 5 · 0.4096 · 0.2 = 0.4096。
2. 计算合格件数的数学期望：
   E(X) = n · p = 5 · 0.8 = 4.0（件）。
3. 计算合格件数的方差：
   Var(X) = n · p · (1 - p) = 5 · 0.8 · 0.2 = 0.8。

### 常见错误

- 忽略二项分布的“独立性”前提。若生产工艺发生漂移导致缺陷成批连带产生，
  前一个工件的结果影响后一个，此时数据不再服从二项分布。
- 计算概率时漏乘组合数 C(n, k)，直接写成 pᵏ · (1 - p)ⁿ⁻ᵏ，这仅仅代表了特定某一种
  顺序出现的概率，忽略了这 k 次成功可以分散在 n 次试验中的不同位置。

## 泊松分布

在质量控制实务中，某些缺陷事件属于“小概率且发生空间连续”，例如 3D 打印定位夹具
表面单位面积的气孔数、钢带表面每米长度的划痕数，或分拣系统每小时的偶发误报数。
当试验次数 n 极大而每次发生概率 p 极微小，但乘积 λ = n · p 保持稳定常数时，
二项分布的极限即为泊松分布。

设随机变量 X 表示在固定时间或单位空间内某偶发事件发生的次数，其参数为单位区间内
的平均发生率 λ（λ > 0）。若 X 服从泊松分布，记作 X ~ P(λ)，其概率质量函数为：
P(X = k) = [λᵏ · e^(−λ)] / k!   (k = 0, 1, 2, ...)
其中 e 为自然对数的底（e ≈ 2.71828），k! 为 k 的阶乘，特别规定 0! = 1。

泊松分布具有一个鲜明的数学特征：其期望和方差数值严格相等，即：
- 数学期望：E(X) = λ。
- 方差：Var(X) = λ。
- 标准差：σ = √λ。
若实际质检统计中缺陷计数的样本方差远大于样本均值（称为过度离散），通常提示缺陷分布
不均匀或工序环境存在聚集性波动。

### 例题

桌面质检站的定位夹具表面平均每件出现 λ = 1 处微小气孔缺陷，缺陷数 X 服从泊松分布。
已知 e⁻¹ ≈ 0.3679。求：（1）一个夹具表面完全没有气孔缺陷（X = 0）的概率；
（2）该夹具表面缺陷数 X 的数学期望与标准差。

解答步骤：
1. 计算 X = 0 的概率：
   根据泊松公式，P(X = 0) = [1⁰ · e⁻¹] / 0! = 1 · 0.3679 / 1 = 0.3679。
2. 期望与标准差计算：
   根据泊松分布性质，E(X) = λ = 1（处）。
   方差 Var(X) = λ = 1，因此标准差 σ = √Var(X) = √1 = 1（处）。

### 常见错误

- 混淆泊松分布的方差与标准差。因为 Var(X) = λ，部分学习者误以为标准差也是 λ，
  实际上标准差是 √λ。
- 忽略考察区间的缩放。λ 与所考察的单位时间或面积绑定；若考察时间从 1 小时扩大到
  3 小时，参数 λ 必须同步乘以 3 变为 3λ。

## 正态分布与 z 分数

分拣工位测量的物理尺寸（如垫圈厚度、销轴直径）属于连续型随机变量。由于加工中受到
无数微小、独立的偶然因素综合影响，测量尺寸通常呈现中间密集、两端对称衰减的钟形
曲线，这种分布称为正态分布（或高斯分布），记作 X ~ N(μ, σ²)。

正态曲线由位置参数 μ（总体均值）和尺度参数 σ（总体标准差）完全确定：
- μ 决定对称中心：曲线关于直线 x = μ 轴对称，并在 x = μ 处达到最高峰。
- σ 决定离散程度：σ 越小，曲线越高瘦尖锐，数据越集中；σ 越大，曲线越矮胖平缓。
对于连续型随机变量，取单点值的概率为 0，即 P(X = x) = 0；区间概率对应正态曲线下该
区间与横轴围成的面积，全部曲线下面积总和为 1。

为了利用标准正态分布表求任意正态分布的概率，需进行标准化变换，计算 z 分数：
z = (x - μ) / σ
z 分数表示测量值 x 偏离均值 μ 相当于多少个标准差单位。若 X ~ N(μ, σ²)，则标准化后的
变量 Z = (X - μ)/σ 服从标准正态分布 Z ~ N(0, 1)。
正态分布满足著名的 68–95–99.7 经验规则：
- 约 68.27% 的测量值落在 [μ - σ, μ + σ] 区间内（|z| ≤ 1）。
- 约 95.45% 的测量值落在 [μ - 2σ, μ + 2σ] 区间内（|z| ≤ 2）。
- 约 99.73% 的测量值落在 [μ - 3σ, μ + 3σ] 区间内（|z| ≤ 3）。

### 例题

分拣站测量某打印定位销的直径 X（单位：mm），X 服从正态分布 N(10.0, 0.04)，即均值
μ = 10.0 mm，标准差 σ = 0.2 mm。实测某件直径为 10.3 mm。
求：（1）该工件尺寸的标准化 z 分数；（2）已知标准正态分布累积概率 P(Z ≤ 1.5) = 0.9332，
求直径不超过 10.3 mm 的概率 P(X ≤ 10.3)。

解答步骤：
1. 计算标准化 z 分数：
   z = (x - μ) / σ = (10.3 - 10.0) / 0.2 = 0.3 / 0.2 = 1.5。
   这表示该尺寸高出设计均值 1.5 个标准差。
2. 计算累积概率：
   P(X ≤ 10.3) = P(Z ≤ 1.5)。查表已知 P(Z ≤ 1.5) = 0.9332。
   因此直径不超过 10.3 mm 的概率为 93.32%。

### 常见错误

- 计算 z 分数时分母误用方差 σ² 代替标准差 σ。例如本题中方差为 0.04，若除以 0.04
  会导致 z = 7.5 的严重错误。
- 混淆单侧尾部与累积概率。正态分布表通常给出累积概率 P(Z ≤ z)，若求超差概率 P(Z > z)，
  必须使用对立事件概率转化：P(Z > z) = 1 - P(Z ≤ z)。

## 单元小结

- 随机变量是试验结果到实数的映射；数学期望 E(X) 描述长期加权中心且具线性性质，
  方差 Var(X) 描述偏离中心的离散程度。
- 二项分布适用于 n 次独立重复的是非质检判定，均值为 np，方差为 np(1 - p)。
- 泊松分布适用于描述稀有离散缺陷的发生计数，其核心特征是期望与方差均等于参数 λ。
- 正态分布是连续物理尺寸的基准模型；通过 z = (x - μ)/σ 将任意正态变量标准化为
  N(0, 1)，再借助 68–95–99.7 规则或标准正态分布表计算公差合格率。
