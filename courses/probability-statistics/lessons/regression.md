# 相关与回归

本单元学习如何通过散点图和相关系数分析变量之间的关联强度，并通过一元线性
回归方程建立定量预测模型，解决质检测量与设备标定中的数据分析问题。

## 本单元知识点
- 散点图与相关系数：掌握散点图形态辨识，理解相关系数 r 的取值与统计含义，明确相关不等于因果。
- 一元线性回归：掌握最小二乘回归直线 ŷ = a + bx 的构建、残差性质及预测的内插与外推范围。

## 散点图与相关系数
1. 散点图的概念与形态辨识：
在桌面质检分拣工位上，相机视觉读数、传感器电压与工件真实尺寸等数据通常
成对出现。散点图是将配对数据 (x, y) 绘制在直角坐标系中的基础工具。
通常横轴 x 代表自变量（如标准件名义尺寸或设定压力），纵轴 y 代表因变量
（如相机像素宽度或测量读数）。通过观察点集的分布走向，可以直观判断两个
变量之间是否存在关联形态：点集向右上倾斜为正相关，向右下倾斜为负相关；
若点集弥散无规则或呈水平带状，则表明线性关系微弱；若呈现对称的弯曲形状，
则表明可能存在非线性关系。

2. 样本相关系数 r 的定义与公式：
样本相关系数 r（皮尔逊积矩相关系数）用于定量度量两个连续变量之间线性
关联的紧密程度与方向。设样本容量为 n，两变量分别为 x 和 y，其计算公式为：
```
r = Σ((x - x̄)(y - ȳ)) / √(Σ(x - x̄)² · Σ(y - ȳ)²)
```
式中，x̄ 和 ȳ 分别为 x 和 y 的样本均值。分子是离差交叉乘积之和，分母是两个
变量各自离差平方和乘积的算术平方根。公式亦可表示为两变量样本协方差除以
各自样本标准差之积：r = s_xy / (s_x · s_y)。

3. 相关系数 r 的取值范围与性质：
- 取值范围：-1 ≤ r ≤ 1。
- 方向判断：当 r > 0 时为正相关，表明 y 总体随 x 增大而增大；当 r < 0 时为
  负相关，表明 y 总体随 x 增大而减小。
- 强度判断：|r| 越接近 1，线性关联越强；r = 1 为完全正线性相关，点全在一条
  斜率为正的直线上；r = -1 为完全负线性相关；|r| 越接近 0，线性关系越弱。
- 尺度不变性：r 是无量纲量。对 x 或 y 进行非零常数倍缩放（如单位由厘米换算
  为毫米）或平移，都不会改变 |r| 的数值；同号缩放时 r 符号不变。
- 局限性：r 仅对线性关系敏感。若两变量呈现极强的非线性曲线关系（如圆或二次
  抛物线），计算出的 r 可能接近 0。

4. 相关不等于因果：
统计上的强相关性仅表明两变量在数值变化上呈现同步规律，并不能直接推断出
其中一个变量是引起另一个变量变化的物理原因。
两者强相关往往可能是因为受到第三个共同变量（潜在混杂因素）的驱动。例如，
在分拣工位长时间运行中，电控箱温度与检测判定废品率同时显著升高（r = 0.88），
其实质原因是环境气温整体上升与连续工作时长增加，而非“废品率上升导致箱温
升高”。如果未进行受控实验，切勿将相关性直接作为因果干预的依据。

### 例题
分拣工位使用红外测距传感器校准定位夹具，记录了 5 次标定位置 x（mm）与传感器
输出电压 y（V）的测量数据：
工件 1: x = 10, y = 2
工件 2: x = 20, y = 4
工件 3: x = 30, y = 5
工件 4: x = 40, y = 7
工件 5: x = 50, y = 7
请计算两变量的样本相关系数 r（结果保留三位小数），并解释其统计意义。

解答：
第一步，计算样本均值：
x̄ = (10 + 20 + 30 + 40 + 50) / 5 = 150 / 5 = 30
ȳ = (2 + 4 + 5 + 7 + 7) / 5 = 25 / 5 = 5

第二步，计算离差平方和与离差交叉乘积和：
Σ(x - x̄)² = (-20)² + (-10)² + 0² + 10² + 20² = 400 + 100 + 0 + 100 + 400 = 1000
Σ(y - ȳ)² = (-3)² + (-1)² + 0² + 2² + 2² = 9 + 1 + 0 + 4 + 4 = 18
Σ(x - x̄)(y - ȳ) = (-20)(-3) + (-10)(-1) + 0(0) + 10(2) + 20(2)
                 = 60 + 10 + 0 + 20 + 40 = 130

第三步，代入公式求解 r：
r = 130 / √(1000 × 18) = 130 / √18000 ≈ 130 / 134.164 ≈ 0.969

解释：r ≈ 0.969，表明标定距离与输出电压之间存在极强的正线性相关关系，
随着标定板距离增加，传感器输出电压呈现明显的线性升高趋势。

### 常见错误
1. 忽视非线性分布：当两变量呈现明显弯曲形态（如抛物线）时，依然盲目依赖 r
   进行判断。若 r 接近 0 便草率断定两变量“毫无关联”。
2. 混淆相关与因果：仅凭两组质检指标计算出较高相关系数，便直接认定具有因果
   操控机制，忽略了环境、工艺参数等未被观测的潜变量影响。
3. 误判单位敏感性：误以为单位改变会影响相关系数数值，例如将长度单位由毫米
   改为微米后重复计算 r，实际上无量纲的 r 值保持不变。

## 一元线性回归
1. 一元线性回归模型：
当散点图与相关系数确认两变量具有显著线性关系后，可建立一元线性回归模型
定量刻画因变量 y 随自变量 x 的变动规律：
ŷ = a + bx
式中，x 为自变量（输入或预测变量），ŷ 为因变量 y 的预测值或平均期望值。
b 为回归直线斜率，反映自变量 x 每变动 1 个单位时，因变量 y 的平均变动量；
a 为截距，表示 x = 0 时预测的基准水平。

2. 最小二乘准则与参数求解：
最小二乘法（Ordinary Least Squares, OLS）是确定直线参数 a 和 b 的核心
方法。其目标是使所有样本点的垂直残差平方和达到最小，即：
```
min Σ(y - ŷ)² = min Σ(y - (a + bx))²
```
根据极值求导法则，解正规方程组可得参数计算公式：
```
b = Σ((x - x̄)(y - ȳ)) / Σ(x - x̄)²
a = ȳ - b · x̄
```
斜率 b 亦可表示为 b = r · (s_y / s_x)。由此可知，回归直线必定经过样本的
几何中心点 (x̄, ȳ)。

3. 残差的概念与性质：
残差（Residual）记为 e，是样本实际观测值与回归预测值之间的垂直偏差：
e = y - ŷ
残差反映了线性模型无法解释的随机扰动与测量误差。在最小二乘法下，残差具备
重要代数性质：
- 所有观测点的残差代数和严格恒等于 0，即 Σe = 0，残差均值 ē = 0。
- 残差与自变量 x 不相关，即 Σ(x · e) = 0。
在质检实务中，分析残差图有助于诊断测量系统是否存在非线性或方差不均问题。

4. 回归预测与内插、外推边界：
将特定的自变量数值 x_0 代入拟合方程，可得到对应的点预测值 ŷ_0 = a + b · x_0。
- 内插（Interpolation）：在样本自变量的观测区间 [x_min, x_max] 内进行预测。
  由于该区间已有实测数据支持，内插预测通常具有较高的可靠性。
- 外推（Extrapolation）：超出样本观测区间进行预测。在工程实务中外推需极度
  谨慎，因为超出已知数据范围后，设备的物理响应可能发生质变（如气缸行程受限、
  传感器饱和或夹具非线性形变），导致严重预测偏差。

### 例题
质检站为评估相机曝光时间 x（单位：ms）对工件边缘灰度对比度 y（单位：灰度值）
的影响，采集了 5 组校准数据：
工件 1: x = 10, y = 40
工件 2: x = 15, y = 52
工件 3: x = 20, y = 60
工件 4: x = 25, y = 75
工件 5: x = 30, y = 83
(1) 求一元线性回归直线方程 ŷ = a + bx；
(2) 预测曝光时间为 22 ms 时的灰度对比度；
(3) 检验 5 个样本点的残差之和是否为 0。

解答：
(1) 第一步，计算样本均值：
x̄ = (10 + 15 + 20 + 25 + 30) / 5 = 100 / 5 = 20
ȳ = (40 + 52 + 60 + 75 + 83) / 5 = 310 / 5 = 62

第二步，计算自变量离差平方和与交叉乘积和：
Σ(x - x̄)² = (-10)² + (-5)² + 0² + 5² + 10² = 100 + 25 + 0 + 25 + 100 = 250
Σ(x - x̄)(y - ȳ) = (-10)(-22) + (-5)(-10) + 0(-2) + 5(13) + 10(21)
                 = 220 + 50 + 0 + 65 + 210 = 545

第三步，求解斜率 b 与截距 a：
b = 545 / 250 = 2.18
a = ȳ - b · x̄ = 62 - 2.18 × 20 = 62 - 43.6 = 18.4
故一元线性回归方程为：ŷ = 18.4 + 2.18x。

(2) 代入 x = 22 进行内插预测：
ŷ = 18.4 + 2.18 × 22 = 18.4 + 47.96 = 66.36（灰度值）。

(3) 计算各点预测值与残差 e = y - ŷ：
点 1: ŷ = 18.4 + 2.18(10) = 40.2，e1 = 40 - 40.2 = -0.2
点 2: ŷ = 18.4 + 2.18(15) = 51.1，e2 = 52 - 51.1 = +0.9
点 3: ŷ = 18.4 + 2.18(20) = 62.0，e3 = 60 - 62.0 = -2.0
点 4: ŷ = 18.4 + 2.18(25) = 72.9，e4 = 75 - 72.9 = +2.1
点 5: ŷ = 18.4 + 2.18(30) = 83.8，e5 = 83 - 83.8 = -0.8
残差之和 Σe = (-0.2) + 0.9 + (-2.0) + 2.1 + (-0.8) = 0，验证成立。

### 常见错误
1. 颠倒自变量与因变量：在计算斜率 b 时，错误地将分子与分母颠倒，或将因变量
   的离差平方和错当成分母。分母必须严格为自变量的离差平方和 Σ(x - x̄)²。
2. 残差正负号混淆：误将残差定义为“预测值减实际值”。残差的标准定义为观测值
   减去预测值（e = y - ŷ），残差为负表示预测值高于实际观测值。
3. 盲目外推造成控制失误：脱离样本数据的有效区间 [x_min, x_max] 强行推算极端
   情况下的输出值，忽视了硬件物理特性的非线性边界与饱和区。

## 单元小结
- 散点图是探索双变量相关关系的直观起点，样本相关系数 r 定量度量线性关联的
  方向与强度，其取值范围严格在 [-1, 1] 之间。
- 统计上的高相关并不等于因果关系，强相关可能受未观测的共同潜变量驱动，不能
  在未做受控实验的情况下盲目推导因果操控。
- 最小二乘法通过最小化垂直残差平方和确定一元线性回归直线 ŷ = a + bx，回归直线
  必定经过样本中心点 (x̄, ȳ)。
- 残差 e = y - ŷ 是实际值与拟合值的偏差，所有样本点残差之和严格恒等于 0，
  残差分析是检验模型假设的重要工具。
- 回归预测应遵循内插原则，严格限定在样本自变量观测范围内；跨范围外推存在
  模型失效风险，必须慎重评估物理可行性。
