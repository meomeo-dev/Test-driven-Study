# 抽样与抽样分布

本单元学习如何从质检分拣站的生产总体中科学抽样，掌握样本均值的期望与标准误计算规律，并理解中心极限定理如何支持我们用正态模型评估非正态总体的抽样波动。

## 本单元知识点
- 总体、样本与抽样偏差：区分质检总体与样本，掌握简单随机抽样与分层抽样，识别系统偏差与跨批次抽样要求。
- 样本均值的抽样分布：理解样本均值自身的随机波动规律，掌握数学期望 E(x̄) = μ 与标准误 SE = σ/√n 的计算。
- 中心极限定理：掌握大样本下样本均值近似正态分布的成立条件、实际应用价值与常见认知误区。

## 总体、样本与抽样偏差
在桌面质检分拣站中，总体（Population）是指我们要研究并推断的全部工件集合，
例如某 3D 打印机今日生产的全部 2000 件定位卡扣。总体参数（如全部工件尺寸的
真实均值 μ 和总体方差 σ²）通常无法逐一测量或耗时过长。样本（Sample）则是
为了质检评估而实际抽取的局部工件集合，样本容量记为 n。

抽样方法直接决定样本是否具备代表性。简单随机抽样（SRS）要求总体中每个个体
都有均等的机会被抽中，适合批次单一、生产条件平稳的工序。分层抽样
（Stratified Sampling）则先将总体按关键特征划分为互不重叠的子层（例如按多台
3D 打印机编号、不同成型机位或不同供料批次），再按各层工件数占总体的比例在层内
随机抽样。分层抽样能确保关键子群全部被覆盖，大幅降低层间差异带来的估计误差。

如果抽样过程违背随机原则，就会产生系统性的抽样偏差（Sampling Bias）。常见
偏差包括方便抽样（例如质检员只拿取传送带入口处或料盒最顶层的工件，忽视料盒
底部挤压变形的工件）和时间窗口偏差（仅测量早晨刚开机前 10 分钟的工件，忽视
喷嘴升温稳定后的尺寸漂移）。抽样偏差是系统性误差，单纯增加样本数量无法消除
偏差。

跨批次抽样强调生产环境的时变特性。3D 打印所用的耗材卷批号、环境温湿度与喷嘴
磨损会随时间变化。如果仅在单一耗材批次中密集取样，所得结论就无法推广到后续
批次。稳健的质量监控必须跨生产批次、跨班次设置合理的抽样点。

### 例题
【例题】质检站需对当日两台 3D 打印机生产的 800 个夹具进行尺寸抽检。已知 1 号机
生产了 600 个，2 号机生产了 200 个。质检员计划总共抽取 40 个样品。
（1）若采用按比例分层抽样，两台机应各抽多少个？
（2）若质检员为了省事，直接从 1 号机下料料盒最上方抓取 40 个零件，这种做法会
带来什么问题？

【解答】
（1）1 号机占比为 600 / 800 = 75%，应抽数量为 40 × 75% = 30 个。
2 号机占比为 200 / 800 = 25%，应抽数量为 40 × 25% = 10 个。
（2）直接从 1 号机料盒顶部抓取属于方便抽样。一方面完全遗漏了 2 号机的工件，
无法反映不同打印机的机差；另一方面顶部工件可能集中于停机前最后阶段，无法
反映升温期或长时间连续打印的尺寸变化，导致严重的抽样偏差。

### 常见错误
1. 混淆样本容量与抽样代表性：误以为“只要样本量够大就一定准确”。若抽样方法
存在系统偏差，样本量再大也只会精确地估计出偏差后的错误结论。
2. 忽视批次内部层别：直接将多台机器混合在一起进行盲抽，导致抽样遗漏产量较小
但质量波动较大的机器。

## 样本均值的抽样分布
当我们从均值为 μ、标准差为 σ 的工件总体中随机抽取容量为 n 的样本时，每次
抽出的 n 个零件计算出的样本均值 x̄ 是不完全相同的。如果反复进行独立抽样，
不同样本得到的 x̄ 会形成一个概率分布，这个分布被称为样本均值的抽样分布
（Sampling Distribution of the Sample Mean）。

样本均值的抽样分布具有两个核心数学性质：
第一，样本均值的期望等于总体均值，即 E(x̄) = μ。这说明样本均值是总体均值的
无偏估计量，在长期反复抽样中不会系统性偏高或偏低。
第二，样本均值的标准差被称为标准误（Standard Error, 简称 SE），其计算公式为：
SE = σ / √n
其中 σ 为总体标准差，n 为样本容量。

标准误度量了样本均值围绕总体均值波动的离散程度，反映了估计的精度。由公式
可知，标准误与样本量 n 的平方根成反比。要将抽样误差减小一半（精度提高一倍），
样本容量必须扩大为原来的 4 倍（因为 √4 = 2）；要将标准误缩减至三分之一，
样本量必须增至 9 倍。质检设计时需平衡测量成本与抽样精度，不能盲目堆砌样本。

### 例题
【例题】分拣站测量的某款传感器外壳厚度总体均值 μ = 5.00 mm，总体标准差
σ = 0.16 mm。质检员每次从流水线上随机抽取 n = 16 件工件计算平均厚度。
（1）计算样本均值 x̄ 的数学期望 E(x̄) 与标准误 SE。
（2）如果希望将样本均值的标准误降低到 0.02 mm，每次应抽取多少件工件？

【解答】
（1）根据样本均值抽样分布的性质：
期望值 E(x̄) = μ = 5.00 mm。
标准误 SE = σ / √n = 0.16 / √16 = 0.16 / 4 = 0.04 mm。
（2）设所需样本量为 n'，由 SE' = σ / √n' = 0.02 可得：
√n' = σ / SE' = 0.16 / 0.02 = 8
两边平方解得：n' = 8² = 64 件。
因此每次需抽取 64 件工件。

### 常见错误
1. 混淆总体标准差 σ 与样本均值标准误 SE：σ 衡量的是单个零件尺寸的个体间
变异，而 SE 衡量的是组均值估计值的波动范围。当 n > 1 时，SE 必然小于 σ。
2. 误认样本容量与精度的线性关系：误以为样本量增加 2 倍精度就提高 2 倍。
实际上标准误只缩减为 1/√2 ≈ 0.707 倍。

## 中心极限定理
中心极限定理（Central Limit Theorem, 简称 CLT）是统计推断的基石。该定理
指出：无论总体服从何种概率分布（即使总体是偏态分布、双峰分布或离散均匀分布），
只要其具有有限的均值 μ 和方差 σ²，当独立随机抽取的样本容量 n 足够大时，
样本均值 x̄ 的抽样分布都近似服从正态分布：
x̄ ~ N(μ, σ² / n)
标准化变量 Z = (x̄ - μ) / (σ / √n) 近似服从标准正态分布 N(0, 1)。

在工业质检与工程应用中，通常约定俗成的规则是当样本容量 n ≥ 30 时，样本均值
的抽样分布便可良好地用正态分布进行近似。如果原始总体的偏态非常严重或存在多峰，
则通常需要更大的样本容量（如 n ≥ 50 或 100）。若总体本身已是正态分布，则不论
样本容量 n 为何值，样本均值都严格服从正态分布。

中心极限定理赋予了质检统计极大的现实威力：在实际分拣流水线中，打印热变形、
机械震动、传感器微小漂移等复合因素往往使工件尺寸的真实总体分布未知或非正态。
然而，质检工程师无需确切探知原始总体的函数形式，只要每组抽检零件数满足大样本
条件，就可以直接运用正态分布的 z 分数与累积概率表来计算抽检均值超标的风险。

### 例题
【例题】质检站传送带到位传感器的响应时间总体呈右偏分布，均值 μ = 60.0 ms，
标准差 σ = 15.0 ms。工控电脑每隔一小时自动采集一组 n = 36 次响应时间的均值 x̄。
根据中心极限定理，计算样本均值 x̄ 不超过 65.0 ms 的概率。
（已知标准正态分布累积概率 P(Z ≤ 2.0) = 0.9772）

【解答】
因为样本容量 n = 36 ≥ 30，且响应时间相互独立，由中心极限定理可知，样本均值
x̄ 近似服从正态分布，其均值和标准误分别为：
E(x̄) = μ = 60.0 ms
SE = σ / √n = 15.0 / √36 = 15.0 / 6 = 2.5 ms
将目标值 x̄ = 65.0 ms 标准化为 z 分数：
z = (65.0 - 60.0) / 2.5 = 5.0 / 2.5 = 2.0
因此所求概率为：
P(x̄ ≤ 65.0) = P(Z ≤ 2.0) = 0.9772。

### 常见错误
1. 误以为“中心极限定理会让原始数据变正态”：样本容量增大只让“样本均值”的
抽样分布趋向正态，原始总体和抽出的单批测量值直方图依然保持原始偏态或双峰。
2. 忽视独立同分布前提：在工件生产中若存在刀具逐步磨损或严重温漂，样本个体间
不再相互独立，此时不能简单套用经典中心极限定理。

## 单元小结
- 抽样代表性取决于抽样机制而非单纯数量，按机台和批次分层抽样可有效避免方便
  抽样带来的系统偏差。
- 样本均值是总体均值的无偏估计，其标准误 SE = σ/√n 随样本容量平方根衰减，
  四倍样本方可换取两倍精度。
- 中心极限定理证明了当 n 足够大时，样本均值近似正态分布，使质检人员能直接使用
  正态模型对非正态工件总体进行推断。
- 严格区分单件测量值分布与样本均值抽样分布：单件反映生产本身特异性，样本均值
  抽样分布反映统计估计的精确度。
