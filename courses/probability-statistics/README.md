# 概率论与数理统计

从尺寸读数、抽样和变异判断质量数据是否稳定。

## 学习起点

能计算均值、比例和百分数即可开始。系统学习概率分布与估计时再配合高数。

- 描述统计 → 概率与条件概率 → 抽样 → 区间估计和回归。

## 学完能做什么

- 用均值、离散程度和直方图读测量数据。
- 区分总体、样本、抽样偏差和条件概率。
- 用独立批次评估质量结果。

**桌面质检分拣站实作**。记录 10 个不同打印件的尺寸，再对同一件重复测量。分别画出两组读数并解释波动来源。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 数据与描述统计 | 数据类型与测量尺度；均值与加权平均；中位数、众数与集中趋势；极差、方差与标准差；直方图、四分位数与箱线图 |
| 概率基础 | 样本空间与事件；排列与组合；概率的运算法则；条件概率与独立；全概率公式与贝叶斯公式 |
| 随机变量与分布 | 随机变量与期望；二项分布；泊松分布；正态分布与 z 分数 |
| 抽样与抽样分布 | 总体、样本与抽样偏差；样本均值的抽样分布；中心极限定理 |
| 估计与检验 | 点估计；置信区间；假设检验入门；比例的估计 |
| 相关与回归 | 散点图与相关系数；一元线性回归 |
| 质量数据应用 | 控制图入门；测量波动与重复性；打印件尺寸波动分析（自评） |

“打印件尺寸波动分析”是自评实作，没有练习题。
按[质量数据应用讲义](lessons/quality-data.md)中的自评清单完成后，
在学习路径中标记已会。
