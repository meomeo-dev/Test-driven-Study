变量与基本数据类型、数值算术运算、文本字符串操作以及控制台输入与格式化输出。

- 输入与格式化输出：掌握 input 接收与转换，掌握 f-string 对齐与保留小数格式化。

## 运行脚本与 print
Python 是一门解释型编程语言。在桌面质检工位编写控制与数据处理程序时，
我们将代码保存在以 .py 为扩展名的纯文本文件中，由 Python 解释器逐行读取并执行。
print() 函数用于在终端输出运行信息。print() 可以接收多个参数，默认使用空格分隔；
若传入 sep 参数，可指定自定义分隔字符，例如在工件编号、状态与测量值之间插入逗号。
单行注释以井号 # 开头，解释器在执行代码时会自动忽略注释内容。在实际编写脚本时，
应使用注释清晰说明传感器信号判断、气缸动作逻辑与测量参数含义。
当脚本语法有误或运行时出错时，Python 解释器会打印详细的错误回溯（Traceback）。
初学者排查报错时，应首先查看 Traceback 的最后一行，该行明确给出了错误类型与诱因。

### 例题
编写代码在控制台输出质检工位的就绪状态，包含工位编号、状态标记与响应时间，
字段之间使用竖线与空格分隔，并包含必要的单行注释。
```python
# 初始化桌面质检站通信状态
station_id = "STATION-01"
status = "READY"
latency_ms = 12

# 使用自定义分隔符输出工位运行参数
print(station_id, status, latency_ms, sep=" | ")
```
运行结果：
```
STATION-01 | READY | 12
```

### 常见错误
1. 拼写错误：将内置函数 print 误写为 Print 或 prnt，导致抛出 NameError。
2. 分隔符参数位置或拼写错误：将 sep 误拼写为 step，或误将其写在待输出内容前。
3. 面对报错无从下手：通读整段调用栈而忽略最后一行，未能第一时间获取核心错误。

## 变量与基本类型
变量是计算机内存中用来保存数据的具名容器。在 Python 中使用等号 = 进行赋值，
变量首次赋值即完成创建，且在程序后续执行过程中可以随时被重新赋值为新数据。
变量命名必须遵循规则：只能由英文字母、数字和下划线组成，不能以数字开头，
严格区分字母大小写，且不能使用 class、if、def、for 等 Python 保留关键字。
桌面质检分拣站的数据处理涉及四种最基本的数据类型：
1. 整数（int）：用于计量工件数量或工位料盒编号，例如 pass_count = 120。
2. 浮点数（float）：用于记录测量尺寸与传感器电压等连续量，例如 length = 24.58。
3. 字符串（str）：用成对单引号或双引号包裹的文本，例如 part_id = "PART-A01"。
4. 布尔值（bool）：表示逻辑真假，仅有 True 和 False 两个值，首字母必须大写。
使用内置函数 type() 可以直接查看并验证指定变量或表达式的当前数据类型。

### 例题
定义记录单个工件属性的变量，包含工件编号、实测直径、合格标志与分拣通道，
并依次输出各变量的数据类型。
```python
# 记录单个工件检测指标
item_code = "PART-902"
diameter = 18.05
is_passed = True
channel_no = 1

# 打印各变量的数据类型
print(type(item_code))
print(type(diameter))
print(type(is_passed))
print(type(channel_no))
```
运行结果：
```
<class 'str'>
<class 'float'>
<class 'bool'>
<class 'int'>
```

### 常见错误
1. 变量名使用非法字符：在变量名中出现短横线（如 item-id）或以数字开头命名。
2. 布尔常量大小写错误：误将布尔值写成小写 true 或 false，导致系统报 NameError。
3. 颠倒赋值符号两侧内容：误将 10 = total 写入脚本，导致 SyntaxError 语法错误。

## 算术运算与类型转换
Python 提供完整的算术运算符：加 +、减 -、乘 *、浮点除 /、整除 //、取模 % 与幂 **。
运算符优先级遵循数学常规：括号 () 具有最高优先级，其后依次为幂运算 **，
接着是乘法、浮点除、整除与取模，最后是加减法。特别注意：浮点除 / 结果始终为 float。
整除运算符 // 向下取整，取模运算符 % 返回除法的余数。在分拣装箱计算中，
// 运算用于求出已装满的标准料盒数，% 运算则用于求出剩余未装满的散件件数。
不同类型的数据不能随意混用算术计算。Python 提供内置类型转换函数：
- int(x)：截断小数部分转为整数，或将纯整数字符串转换为整数。
- float(x)：转换为浮点数；包含小数点的字符串必须通过 float() 转换。
- str(x)：将数值转换为字符串文本，用于拼接或显示。
- round(x, n)：把数值修约到 n 位小数；恰好处于中间的值取偶数，例如 round(2.5) 得 2。

### 例题
质检工位传送带送来 53 件待检工件，标准合格品料盒容量为 10 件。编写脚本计算
可装满的标准盒数、剩余散件数，以及批次目标的达成百分比并保留一位小数。
```python
total_parts = 53
box_capacity = 10

# 计算满盒数与剩余散件数
full_boxes = total_parts // box_capacity
loose_parts = total_parts % box_capacity
target_rate = (total_parts / 60) * 100

print("满盒数量:", full_boxes)
print("剩余散件:", loose_parts)
print("达成比例%:", round(target_rate, 1))
```
运行结果：
```
满盒数量: 5
剩余散件: 3
达成比例%: 88.3
```

### 常见错误
1. 字符串与数字直接加减：尝试执行 "50" + 10 导致抛出 TypeError 异常。
2. 对带小数点的文本直接调用 int()：如 int("12.5") 会报错，应先转 float。
3. 误判除法返回类型：误认为 20 / 5 返回整数 4，实际运算结果始终为浮点数 4.0。

## 字符串操作
字符串在工件条码解析、状态标记提取与 CSV 文件处理中被高频使用。
字符串可以通过 + 进行拼接，通过 * 进行重复，内置函数 len() 用于获取字符总长度。
字符串支持双向索引：正向索引从 0 开始递增，负向索引从 -1（末尾字符）开始递减。
切片语法为 s[start:stop:step]，截取从 start 到 stop-1 的左闭右开子字符串。
常用内置字符串处理方法包括：
- upper() 与 lower()：统一转换为大写或小写，常用于标准化检测判定标识。
- strip()：去除字符串两端的空格与换行符，是清洗工位原始文本数据的关键步骤。
- split(sep)：按照指定分隔符将字符串拆分为列表，是后续解析 CSV 行的核心工具。
- replace(old, new)：将目标字符替换为新字符。
- sep.join(list)：使用指定连接符将字符串列表组合成新的完整字符串。
f-string（格式化字符串字面值）以字母 f 开头，在花括号 {} 中直接嵌入变量或表达式。

### 例题
清洗带有前后空格和换行符的工位串口记录 " SN-2026-FAIL \n"，提取工件序列号、
将判定状态转为小写，并使用 f-string 组合成规范的日志摘要输出。
```python
raw_log = " SN-2026-FAIL \n"
clean_log = raw_log.strip()
fields = clean_log.split("-")
serial_prefix = fields[0]
serial_num = fields[1]
status = fields[2].lower()

summary = f"序列号: {serial_prefix}{serial_num}, 最终判定: {status}"
print(summary)
```
运行结果：
```
序列号: SN2026, 最终判定: fail
```

### 常见错误
1. 索引越界访问：访问超出字符串最大有效索引范围的位置导致 IndexError。
2. 试图直接修改字符串：执行 s[0] = "A" 报错，字符串在 Python 中属于不可变对象。
3. 混淆 strip 与 split 的职责：试图用 strip 拆分字段或用 split 清理首尾空格。

## 输入与格式化输出
input() 函数用于阻塞并等待用户在控制台键盘输入数据。
必须牢记的核心规则：无论用户在键盘上输入什么字符，input() 的返回值始终是 str。
若需要将用户输入的公差或工件数用于数学运算，必须显式调用 int() 或 float()。
在控制台输出工位报表时，为了使表格纵向对齐，可使用 f-string 格式说明符：
- {val:.2f}：控制浮点数输出精度，格式化为保留 2 位小数。
- {val:>6}：设置输出宽度为 6 个字符，内容靠右对齐；{val:<6} 表示靠左对齐。
- 组合格式 {val:>8.2f}：设置总字符宽度为 8 且保留两位小数，右对齐显示。
这能使工件编号、实测尺寸与检测偏差在终端形成整齐规整的报表列。

### 例题
模拟操作员在终端输入工件厚度的上限值，转换为浮点数后与实测值计算偏差，
使用 f-string 控制输出宽度与保留小数位数，生成整齐的对齐报表。
```python
# 模拟控制台接收输入 "10.50"
user_input = "10.50"
upper_limit = float(user_input)
measured_val = 10.428
diff = upper_limit - measured_val

print(f"标准上限: {upper_limit:>8.2f} mm")
print(f"实测读数: {measured_val:>8.2f} mm")
print(f"安全裕度: {diff:>8.2f} mm")
```
运行结果：
```
标准上限:    10.50 mm
实测读数:    10.43 mm
安全裕度:     0.07 mm
```

### 常见错误
1. 未对 input() 结果进行转换直接执行算术运算，导致触发 TypeError。
2. 格式说明符语法遗漏冒号或点号：误写成 {val.2f} 引发 SyntaxError。
3. 对齐方向符号混淆：将右对齐 > 误写为左对齐 <，导致控制台报表无法纵向对齐。

## 单元小结
- 1. Python 脚本以 .py 结尾由解释器执行，print 与 Traceback 构成基础调试手段。
- 2. int、float、str、bool 是质检数据表达基石，变量遵循命名规范并支持重新赋值。
- 3. 算术运算符支持装箱与产能核算，除法 / 恒得 float，混合运算须显式类型转换。
- 4. 字符串切片、strip 清洗、split 拆分与 f-string 为解析质检 CSV 奠定基础。
- 5. input 获取控制台输入始终为字符串，借助格式说明符可输出对齐规整的工位报表。
