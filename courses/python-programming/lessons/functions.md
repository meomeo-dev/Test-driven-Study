# 函数与模块

本单元学习如何用函数封装工件检测逻辑、掌握参数与作用域规则、使用标准库组织分拣脚本，并编写文档字符串与简单测试保证程序可靠运行。

## 本单元知识点

- 定义与调用函数：使用 def 封装可复用代码，掌握形参、实参及 return 返回值机制。
- 参数与作用域：掌握默认参数与关键字参数，理解作用域并规避可变默认参数陷阱。
- 模块与标准库：掌握 import 语法，运用 math 与 statistics 等标准库组织代码。
- 文档字符串与简单测试：编写标准 docstring 说明函数规范，使用 assert 验证边界。

## 定义与调用函数

在工件分拣站中，重复出现的操作（如尺寸合规判断、料盒分类提示）
如果反复复制粘贴代码，会导致程序冗长且难以维护。
函数是组织好的、可重复使用的独立代码段，用于实现单一或相关联的功能。

Python 使用 def 关键字定义函数，函数名后紧跟圆括号与形参列表，
末尾加上冒号，函数体必须保持统一的缩进（通常为 4 个空格）。
函数定义时的变量称为形参，调用时传入的具体数据称为实参。
函数通过 return 语句将计算结果返回给调用者，并立即终止当前函数的执行。
如果函数执行完毕未遇到 return，或 return 后面没有表达式，
Python 会默认返回一个特殊值 None。

### 例题

编写一个函数 check_dimension(length, min_l, max_l)，
判断工件长度是否落在公差范围内。如果合格返回字符串 PASS，
否则返回 FAIL。调用该函数检测长度为 50.3 毫米的工件（公差为 49.5 到 50.5）。

解答代码如下：

```python
def check_dimension(length, min_l, max_l):
    if min_l <= length <= max_l:
        return "PASS"
    return "FAIL"

part_len = 50.3
verdict = check_dimension(part_len, 49.5, 50.5)
print("工件判定结果：", verdict)

# 运行结果：
# 工件判定结果： PASS
```

### 常见错误

1. 混淆 print 与 return：在函数内只用 print 输出结果而忘记 return，
   导致外部变量接收到的返回值是 None，后续数据统计运算抛出异常。
2. 函数定义头部漏掉冒号，或函数体内部代码未按 4 个空格对齐。
3. 在 return 语句之后编写后续代码，导致该部分语句成为永远无法执行的死代码。

## 参数与作用域

定义函数时，可以为参数指定默认值。带有默认值的形参在调用时变为可选参数；
如果不传参，则自动采用默认值；若传参，则覆盖默认值。
语法规定：没有默认值的形参必须排在所有带默认值形参的前面。
调用函数时，既可以按位置依次传参，也可以使用形参名称以关键字参数形式传参，
关键字参数允许颠倒参数顺序，但必须写在所有位置参数的后面。

作用域决定了变量的可访问范围。函数内部创建的变量属于局部作用域，称为局部变量，
仅在函数调用期间有效，外部无法直接访问。函数外部定义的变量属于全局作用域。
在函数内可直接读取全局变量，但直接对其赋值会创建同名局部变量。

可变默认参数陷阱：函数的默认参数表达式只在函数定义时求值一次。
如果使用可变对象（如列表 [] 或字典 {}）作为默认参数，该对象会在所有调用间共享。
工程规范是将默认值设为 None，在函数体内部动态新建独立对象。

### 例题

编写记录分拣异常的函数 log_defect(defect_code, record_list=None)，
规避可变默认参数陷阱，并将工件缺陷代码加入列表后返回列表。

解答代码如下：

```python
def log_defect(defect_code, record_list=None):
    if record_list is None:
        record_list = []
    record_list.append(defect_code)
    return record_list

run1 = log_defect("E01")
run2 = log_defect("E02")
print("运行1记录：", run1)
print("运行2记录：", run2)

# 运行结果：
# 运行1记录： ['E01']
# 运行2记录： ['E02']
```

### 常见错误

1. 直接使用 def func(data=[]) 定义函数，导致多次调用时意外累积上一轮数据。
2. 定义形参时将无默认值参数写在带默认值参数之后，引发 SyntaxError。
3. 试图在函数外部直接读取函数内部的临时局部变量，引发 NameError。

## 模块与标准库

模块是一个包含 Python 代码的 .py 文件。
使用模块可以将庞大的分拣系统分解为多个职责单一的小文件。
导入模块主要有两种方式：import 模块名 与 from 模块名 import 函数名。
前者通过 模块名.函数名 访问，命名空间清晰；后者直接调用函数名，书写更简短。

Python 内置了丰富的标准库，无需安装即可直接使用：
math 模块提供基础数学运算，如 math.sqrt 计算平方根，math.floor 向下取整；
statistics 模块提供常用统计运算，如 statistics.mean 计算算术平均值，
statistics.median 计算中位数，statistics.stdev 计算标准差；
random 模块支持随机模拟，如 random.choice 从工件列表中随机抽样。

导入本地模块时，将自定义脚本（如 sorter_tools.py）放在当前工作目录下，
直接使用 import sorter_tools 即可调用其中定义的函数。

### 例题

桌面分拣站需要对一批工件外径测量数据进行统计汇总。
使用 statistics 模块计算该批工件外径的平均值与中位数，保留两位小数。

解答代码如下：

```python
import statistics

diameters = [20.02, 19.98, 20.05, 19.95, 20.00]
avg_val = statistics.mean(diameters)
med_val = statistics.median(diameters)

print(f"平均外径: {avg_val:.2f} mm")
print(f"中位数外径: {med_val:.2f} mm")

# 运行结果：
# 平均外径: 20.00 mm
# 中位数外径: 20.00 mm
```

### 常见错误

1. 模块文件名与 Python 标准库同名（如自己创建了 math.py），导致官方库被遮蔽。
2. import 模块时误加上了 .py 后缀（如 import tools.py），引发 ModuleNotFoundError。
3. 使用 from 模块 import * 导致当前命名空间被污染，难以追溯函数具体来源。

## 文档字符串与简单测试

文档字符串（docstring）是置于函数体首行的多行字符串，通常使用三对双引号包裹。
用于规范说明函数的功能设计、输入形参类型与含义、返回值以及可能抛出的异常。
养成编写 docstring 的习惯，便于团队维护代码，并能通过 help() 函数查看说明。

程序开发必须通过测试验证其正确性。
assert（断言）语句是 Python 提供的轻量测试工具，语法为：assert 条件表达式, 提示信息。
当条件为 True 时程序平稳继续；当条件为 False 时立即抛出 AssertionError 并中断。

编写测试用例必须兼顾常规用例与边界情况：
包含标准合格件、不合格件的正常值；
包含处于公差边缘的临界值（如恰好等于上限或下限），检验比较符是否包含等号；
包含空列表、空字符串或异常零值等空输入，确保程序不会崩溃。

### 例题

为工件合格判定函数编写规范的文档字符串，并使用 assert 编写针对
常规值、边界值及空输入的测试用例。

解答代码如下：

```python
def is_passed(score):
    """判定检测评分是否达到合格线。

    参数:
        score: 工件视觉检测得分（0 到 100 整数）
    返回:
        True 表示合格（>=60），False 表示不合格
    """
    return score >= 60

# 简单单元测试
assert is_passed(85) is True, "常规高分应该合格"
assert is_passed(40) is False, "常规低分应该不合格"
assert is_passed(60) is True, "临界及格线 60 分应该判定合格"
assert is_passed(59) is False, "临界 59 分应该判定不合格"
print("全部断言测试通过！")

# 运行结果：
# 全部断言测试通过！
```

### 常见错误

1. assert 语句后加圆括号将条件与提示写成元组（如 assert(condition, "error")），
   在 Python 中非空元组始终被视为 True，导致断言永远不会生效。
2. 测试用例仅覆盖正常正向数据，忽略了临界值、零值或负值等边界输入。
3. 文档字符串写在 def 语句之外或普通注释位置，导致 help() 无法提取到文档。

## 单元小结

- 函数使用 def 封装，通过形参接收输入、return 返回结果，无 return 默认返回 None。
- 掌握位置参数、默认参数与关键字参数规则，禁止使用可变对象作为默认值。
- 变量按作用域隔离，函数内优先使用局部变量，尽量避免随意篡改全局变量。
- 借助 import 充分复用标准库（如 math、statistics）与本地模块，提升工程组织效率。
- 编写清晰的 docstring 说明接口契约，善用 assert 覆盖边界与极端输入实施快速验证。
