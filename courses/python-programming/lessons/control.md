# 条件与循环

本单元围绕桌面质检分拣站的检测控制场景，学习使用比较运算与布尔逻辑构建判定规则，通过 if 分支控制分拣挡板动作，
并借助 for 和 while 循环实现工件检测记录的批量扫描、计数统计与流程调度。

## 本单元知识点
- 比较与布尔逻辑：掌握关系运算符、链式比较、逻辑运算符与短路求值，理解 0、空字符串与空列表的假值特性。
- if 分支：掌握 if/elif/else 缩进规范与多分支先后顺序，实现工件尺寸区间判定与动作分流。
- for 循环与 range：掌握 range 函数边界、序列遍历、累加计数与 enumerate 索引生成。
- while 与 break、continue：掌握条件循环机制，使用 break 提前跳出与 continue 跳过本次迭代，避免程序死循环。

## 比较与布尔逻辑
比较运算符用于评估两个操作数的大小或相等关系，包含 ==（等于）、!=（不等于）、
<（小于）、<=（小于等于）、>（大于）以及 >=（大于等于）。
比较表达式的求值结果为布尔类型（bool），仅包含 True（真）与 False（假）两个值。
在工件检测中，常用于比对实际测量尺寸与标准公差界限。

Python 支持自然的链式比较语法，例如 19.8 <= width <= 20.2。
该写法等价于 (19.8 <= width) and (width <= 20.2)，能够直观表达
工件尺寸公差的双向闭区间约束，比多次逻辑连接更为精炼，易于阅读和维护。

布尔逻辑运算符包含 and（与）、or（或）和 not（非）。
Python 在计算逻辑表达式时采用“短路求值”（short-circuit evaluation）规则：
对于 and 运算，若左侧表达式为假，则整体必然为假，不再计算右侧表达式；
对于 or 运算，若左侧表达式为真，则整体必然为真，同样跳过右侧表达式。
合理利用短路求值不仅能减少冗余计算，还能避免对无效值的异常访问（例如先判断列表非空再取 lst[0]）。

在 Python 的条件判断上下文中，所有对象都具备固有的真值属性（Truthiness）。
数值 0、0.0、空字符串 ""、空列表 []、空字典以及 None 在求值时
均被视作 False；非零数值与包含元素的容器对象均被视作 True。

### 例题
题目：质检站传感器测得某工件宽度为 20.05 毫米，检测就绪标志位正常。
编写代码使用链式比较与逻辑运算符判定工件是否位于合格公差区间
[19.90, 20.10] 毫米内，且传感器无报警信号，输出最终质检合格布尔值。

```python
width = 20.05
sensor_ready = True
alarm_active = False

# 链式比较公差区间，并结合短路逻辑运算符
is_qualified = (19.90 <= width <= 20.10) and sensor_ready and not alarm_active
print("工件检测是否合格:", is_qualified)
```
运行结果：
```
工件检测是否合格: True
```
解答说明：19.90 <= 20.05 <= 20.10 结果为 True；sensor_ready 为 True；
alarm_active 为 False，取反 not 后为 True。三者经 and 运算得出最终合格结果 True。

### 常见错误
1. 混淆赋值号 = 与相等比较符 ==：在判断语句中误写 if width = 20.0 会直接引发 SyntaxError。
2. 误写复合逻辑判断：将“宽度等于 20 或 21”误写为 width == 20 or 21。由于非零整数 21 恒为真，该表达式恒为 True，
   应显式写为 width == 20 or width == 21。

## if 分支
if 分支语句根据给定条件的真假决定执行哪一段代码块。
Python 使用严格的代码缩进（官方规范推荐 4 个英文空格）来标明代码块的层级，
不再使用大括号或关键字 end。同一缩进层级的语句属于同一个分支执行体。

if / elif / else 语句提供了结构化的多分支选择方案。
执行时自上而下依次求值各个条件：一旦某一个分支条件满足，执行该分支内部代码，
随后跳过后续所有 elif 和 else；若全部条件均不满足，则执行 else 代码块。

在工件分类等尺寸区间划分场景中，分支条件的编排顺序至关重要。
必须遵循互斥且从严到宽（或单向数值递进）的次序组织条件，
否则较宽松的条件写在前面会“遮蔽”后方更细致严格的分支，造成逻辑误判。

### 例题
题目：质检挡板控制系统读取工件厚度 thickness（单位毫米）。
标准合格厚度为 5.0 毫米，允许公差为 ±0.1 毫米。
若厚度在 [4.9, 5.1] 区间内判定为合格入库；厚度大于 5.1 毫米为偏大，
分拣挡板动作推入返修盒；厚度小于 4.9 毫米为偏小，推入报废盒。
编写分支代码输出执行动作。

```python
thickness = 5.25

if 4.9 <= thickness <= 5.1:
    action = "合格入库"
elif thickness > 5.1:
    action = "超差偏大，送返修料盒"
else:
    action = "超差偏小，送报废料盒"

print(f"测量厚度: {thickness}mm，分拣动作: {action}")
```
运行结果：
```
测量厚度: 5.25mm，分拣动作: 超差偏大，送返修料盒
```
解答说明：thickness 为 5.25，首先判断 4.9 <= 5.25 <= 5.1 为 False；
接着评估 elif 条件 5.25 > 5.1 为 True，因此执行返修动作并跳过后续 else。

### 常见错误
1. 遗漏条件末尾的英文冒号 : 或缩进混乱，导致语法解析失败。
2. 宽泛条件排在严格条件之前：例如先判断 thickness > 4.0 再判断 thickness > 5.1，导致大于 5.1 的数据被前者截流。

## for 循环与 range
for 循环用于按顺序遍历可迭代对象（如字符串、列表、range 序列）中的每一个元素，
循环体对每个元素执行一次处理逻辑，适用于循环次数明确或已知数据集的批量扫描。

range(start, stop, step) 生成等差整数序列，遵循左闭右开规则：
包含起始值 start，但不包含终止值 stop；步长 step 默认为 1。
例如 range(0, 5) 产生 0, 1, 2, 3, 4 共 5 个整数。若仅传入一个参数 range(n)，
则默认 start 为 0。

在批次检测中，常用 for 循环配合累加器进行统计（如合格品计数与总重累加）。
累加器变量必须在循环外部初始化为零；若在循环内初始化，每次迭代均会被重置。

内置函数 enumerate(iterable, start=0) 在每次迭代时同时返回元素索引与元素本身，
使脚本无需手动维护下标即可输出工件批次流水号与数据记录。

### 例题
题目：质检站检测了一批工件孔径数据（毫米），列表为 [10.02, 9.95, 10.15, 9.98, 10.05]。
合格公差范围为 9.96 至 10.08 毫米。编写 for 循环遍历该批次，
利用 enumerate 打印工件序号与合格状态，并统计该批次的合格工件总数。

```python
holes = [10.02, 9.95, 10.15, 9.98, 10.05]
pass_count = 0

for idx, d in enumerate(holes, start=1):
    if 9.96 <= d <= 10.08:
        pass_count += 1
        status = "合格"
    else:
        status = "不合格"
    print(f"工件 #{idx}: 孔径 {d}mm -> {status}")

print(f"检测完成，合格总数: {pass_count} / {len(holes)}")
```
运行结果：
```
工件 #1: 孔径 10.02mm -> 合格
工件 #2: 孔径 9.95mm -> 不合格
工件 #3: 孔径 10.15mm -> 不合格
工件 #4: 孔径 9.98mm -> 合格
工件 #5: 孔径 10.05mm -> 合格
检测完成，合格总数: 3 / 5
```
解答说明：enumerate 从 1 开始编排工件序号；循环体内逐个比对公差并累计合格数量，
最终统计出 5 件中有 3 件合格。

### 常见错误
1. 误以为 range(1, 5) 包含数字 5，导致实际循环次数少了一次。
2. 累加变量写在 for 循环体内初始化，例如在循环内写 pass_count = 0，导致无法正确累加总数。

## while 与 break、continue
while 循环在给定的条件表达式保持为 True 时重复执行循环体。
它特别适合执行次数不固定、依赖外部传感器状态变化或直到出现特定中断信号的控制流程。
如果进入循环前条件即为 False，则循环体一次也不会执行。

break 语句用于立即跳出并终止当前循环，程序直接跳转到循环体之后的语句继续运行。
在质检站中，常用 break 处理急停按钮按下、料道堵塞或连续严重超差等紧急终止事件。

continue 语句用于提前结束本次循环，跳过循环体中位于 continue 之后的剩余语句，
直接返回循环起始处进行下一次条件判定。常用于过滤脏数据、跳过传感器瞬态噪声等。

防范死循环是编写 while 循环的核心守则。循环体内部必须存在能够改变循环条件的语句
（如索引递增、读入新传感器状态），或包含必定能触发的 break 退出机制。

### 例题
题目：模拟工件连续到位检测。列表存储了一组工件传感器信号值（单位毫米），
其中负值表示传感器被干扰的无效噪声，数值 999.0 表示料道清空停机信号。
使用 while 循环处理数据，遇到负值跳过不计，遇到 999.0 立即终止分拣并打印统计数。

```python
sensor_stream = [15.2, -1.0, 15.0, 14.8, 999.0, 15.1]
valid_count = 0
pos = 0

while pos < len(sensor_stream):
    reading = sensor_stream[pos]
    pos += 1
    if reading == 999.0:
        print("收到清料停机信号，终止循环")
        break
    if reading < 0:
        print("滤除瞬态噪声记录")
        continue
    valid_count += 1

print(f"实际记录有效工件数: {valid_count}")
```
运行结果：
```
滤除瞬态噪声记录
收到清料停机信号，终止循环
实际记录有效工件数: 3
```
解答说明：pos 指针递增保证循环持续前移；-1.0 触发 continue 跳过累加；
999.0 触发 break 终止循环，最终统计了 15.2、15.0、14.8 共 3 个有效工件。

### 常见错误
1. 在 while 循环中使用 continue 时漏写指针递增语句，导致下标停留在原地引发死循环。
2. 循环判断条件恒为 True（如 while True:）却未在分支中编写 break 退出逻辑。

## 单元小结
- 比较运算符生成布尔值，结合链式比较与 and、or、not 能严密表达工件公差区间，并具备短路特性。
- if/elif/else 依托 4 空格缩进实现多分支选择，条件编排必须注意从严到宽的互斥顺序以防逻辑遮蔽。
- for 循环与 range(start, stop, step) 组合适合确定范围的遍历，enumerate 能高效同步跟踪记录序号与数值。
- while 循环用于条件驱动任务，配合 break 实现急停退出、continue 实现脏数据过滤，必须严格维护循环变量以防死循环。
