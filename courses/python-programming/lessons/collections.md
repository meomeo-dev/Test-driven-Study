# 列表、字典与集合

本单元围绕桌面质检分拣站的数据管理，学习使用列表、推导式、字典、
元组、集合及嵌套结构组织测量数据与工件检测台账。

## 本单元知识点
- 列表：创建与索引，增删改查，切片截取，内置统计函数与成员判断。
- 列表推导式与排序：推导式过滤变换，sorted 与 sort 原地及反向排序。
- 字典：键值对映射，get 安全查值，items 遍历与频次统计。
- 元组与集合：元组不可变性与拆包，集合唯一性去重与集合运算。
- 记录列表与嵌套结构：字典列表台账，嵌套索引取值与按字段筛选。

## 列表
列表（list）是 Python 中基础的有序、可变容器，使用方括号 [] 定义。
在分拣工位中，传送带上传感器采集到的连续工件尺寸、检测用时等
时间序列数据，都可以依序存放于列表中。

列表支持正向索引（从 0 开始）与反向索引（从 -1 开始），并可通过
切片语法 list[start:stop:step] 截取左闭右开区间的子列表。
列表是可变对象，支持通过 append 在末尾添加元素、insert 在指定位置
插入元素，以及通过 pop 按索引弹出或 remove 按值删除元素。

Python 内置的 len、sum、max、min 函数可快速计算列表的长度与极值，
使用 in 关键字可快速判断特定工件数据是否存在于列表中。

### 例题
分拣站测量了 5 个工件的外径（单位：mm），需要追加最新测量值，
截取中间 3 个读数，并统计最大尺寸。

```python
diameters = [19.8, 20.1, 19.9, 20.4, 20.0]
diameters.append(20.2)
middle_readings = diameters[1:4]
max_dia = max(diameters)

print("截取结果:", middle_readings)
print("最大尺寸:", max_dia)
```
运行结果：
```text
截取结果: [20.1, 19.9, 20.4]
最大尺寸: 20.4
```

### 常见错误
1. 索引越界：访问超过 len(list)-1 的索引会抛出 IndexError。
2. 混淆 append 与 extend：append 会将传入的列表整体作为一个单一元素
   插入末尾，导致出现嵌套列表。
3. 切片边界误解：切片 [1:4] 仅包含索引 1、2、3，不包含索引 4。

## 列表推导式与排序
列表推导式提供了一种根据现有序列快速创建新列表的紧凑语法，
格式为 [表达式 for 变量 in 序列 if 条件]。
在质检站中，常用于一行代码筛选超差工件或批量转换测量单位。

数据排序有两种常见方式：内置函数 sorted() 与列表方法 list.sort()。
sorted(list) 会返回一个升序排列的新列表，原列表保持不变；
list.sort() 则直接就地修改原列表，其返回值为 None。

两者均支持 reverse=True 参数实现降序排列，以及 key 参数指定
排序依据（例如按偏差的绝对值 key=abs 进行排序）。

### 例题
分拣工位采集到一组工件的高度偏差值（单位：微米），需筛选出
所有正向偏差，并按绝对值由大到小排序。

```python
diffs = [-15, 22, -8, 30, -5, 12]
positive_diffs = [d for d in diffs if d > 0]
sorted_by_abs = sorted(diffs, key=abs, reverse=True)

print("正向偏差:", positive_diffs)
print("绝对值降序:", sorted_by_abs)
```
运行结果：
```text
正向偏差: [22, 30, 12]
绝对值降序: [30, 22, -15, 12, -8, -5]
```

### 常见错误
1. 误接收 sort 的返回值：将 data.sort() 赋值给新变量，新变量的值为 None。
2. 推导式中 if 条件位置混淆：单分支过滤条件应放在 for 语句后面；
   放在 for 前面的是 if-else 完整三元表达式。

## 字典
字典是键值对（key-value）的映射容器，使用大括号 {} 定义，并保持键的插入顺序。
字典中的键必须是可哈希的不可变类型（如字符串、整数、元组）且不可重复；
在质检系统中，字典非常适合用于记录单个工件的多项属性或统计计数。

直接使用 d[key] 访问不存在的键会触发 KeyError 异常。实务中推荐
使用 d.get(key, 默认值)，当键不存在时返回设定的安全默认值。
通过 d[key] = value 可以新增或修改键值对，del 或 pop 可删除键值对。

遍历字典时，d.keys() 返回所有键，d.values() 返回所有值，
而 d.items() 则返回键值二元组，最常用于循环中同时获取键和值。

### 例题
统计分拣站当前批次各个分拣箱（合格品、超差废品、返修件）的
工件落入数量，并安全查询待处理数量。

```python
bins = {"pass": 42, "scrap": 3}
bins["rework"] = 5
bins["pass"] += 1

pending = bins.get("pending", 0)
for box, count in bins.items():
    print(f"{box}: {count}")
print("待处理数:", pending)
```
运行结果：
```text
pass: 43
scrap: 3
rework: 5
待处理数: 0
```

### 常见错误
1. 直接读取不存在的键导致 KeyError，应优先使用 d.get() 提供默认值。
2. 误将列表等可变对象作为字典的键，会引发 TypeError: unhashable type。

## 元组与集合
元组（tuple）是使用小括号 () 定义的不可变序列。由于其不可修改，
常用于存储固定结构的数据，如工件在定位夹具上的三维坐标 (x, y, z)。
元组支持多变量同时拆包赋值，使代码简明清晰。

集合（set）是使用大括号 {} 定义的无序不重复元素集，打印时的元素顺序不固定，
需要稳定输出时用 sorted(集合) 转成列表。
使用 set() 可以对包含重复读取记录的列表实现一键去重。
注意空集合必须使用 set() 创建，{} 会被 Python 识别为空字典。

集合支持高效的数学集合运算：交集 &（两批均出现的工件）、
并集 |（出现过的所有工件）、差集 -（仅在某一批次出现的工件）。

### 例题
使用元组记录分拣相机校准坐标并拆包；使用集合比对相机检测合格与
气动分拣入箱的工件编号集合，找出未入箱的工件。

```python
pos = (150, 80, 25)
x, y, z = pos

detected = {101, 102, 103, 104, 105}
sorted_items = {101, 102, 104}
missing = detected - sorted_items

print(f"坐标: x={x}, y={y}, z={z}")
print("未分拣工件:", sorted(missing))
```
运行结果：
```text
坐标: x=150, y=80, z=25
未分拣工件: [103, 105]
```

### 常见错误
1. 尝试修改元组元素：tuple 是不可变的，给其元素赋值会抛出 TypeError。
2. 将空字典当作空集合：{} 是空字典，空集合必须写为 set()。

## 记录列表与嵌套结构
由字典组成的列表（List of Dictionaries）是工业脚本中表示表格数据、
CSV 台账的标准嵌套数据结构，每个字典代表一条独立的工件记录。

访问嵌套结构时采用多层级索引：records[0] 获取第一条记录字典，
records[0]["status"] 获取该工件的状态字段。
结合 for 循环或列表推导式，可以根据字段值实现高效的条件筛选。

在处理嵌套数据时，外层列表维持了工件进站的先后时序，
内层字典则通过语义化键名清晰描述工件的几何尺寸与质检判定。

### 例题
分析质检台账列表，筛选所有被拒收（reject）的工件编号，
并计算合格品（pass）的平均加工直径。

```python
records = [
    {"id": "W01", "dia": 20.02, "status": "pass"},
    {"id": "W02", "dia": 20.35, "status": "reject"},
    {"id": "W03", "dia": 19.98, "status": "pass"},
]

reject_ids = [r["id"] for r in records if r["status"] == "reject"]
pass_dias = [r["dia"] for r in records if r["status"] == "pass"]
avg_pass_dia = sum(pass_dias) / len(pass_dias)

print("拒收工件:", reject_ids)
print(f"合格品均值: {avg_pass_dia:.2f}")
```
运行结果：
```text
拒收工件: ['W02']
合格品均值: 20.00
```

### 常见错误
1. 索引层级倒置：误写为 records["status"][0]，列表不能用字符串做索引。
2. 缺少键安全检查：记录中若有行缺少某字段，直接访问会抛出 KeyError。

## 单元小结
- 列表支持增删改查与切片，是保存工件时序读数的基础容器。
- 列表推导式能高效过滤变换数据，sorted 与 sort 支持灵活排序。
- 字典以键值对管理工件多维属性，利用 get 避免键缺失异常。
- 元组保证数据不可篡改并支持拆包，集合实现高速去重与交并差运算。
- 字典列表是工件检测台账的核心组织形态，支撑多字段检索与统计分析。
