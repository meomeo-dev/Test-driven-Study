# Python 程序设计

从基础语法到整理工件检测记录和处理异常。

## 学习起点

会操作电脑。即使没有编程经历，也可从变量开始。

- 语法基础 → 函数与异常 → 读取 CSV → 汇总合格和拒收记录。

## 学完能做什么

- 用列表、字典、循环和函数处理一批数据。
- 读取 CSV 并检查空值、格式和错误记录。
- 输出可核对的计数及统计结果。

**桌面质检分拣站实作**。写一个脚本读取含工件编号与判定结果的 CSV，列出无法解析的行，并分别统计合格和拒收数。

## 课程内容

1.1.0 版包含七个单元、28 个知识点和 139 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| Python 入门与基本类型 | 运行脚本与 print；变量与基本类型；算术运算与类型转换；字符串操作；输入与格式化输出 |
| 条件与循环 | 比较与布尔逻辑；if 分支；for 循环与 range；while 与 break、continue |
| 列表、字典与集合 | 列表；列表推导式与排序；字典；元组与集合；记录列表与嵌套结构 |
| 函数与模块 | 定义与调用函数；参数与作用域；模块与标准库；文档字符串与简单测试 |
| 文件与异常 | 读写文本文件；异常处理；用 csv 模块读写表格；检查记录：空值与格式 |
| 数据汇总与统计 | 计数与分组汇总；均值、最值与比例；排序与报告输出；时间戳与日期 |
| 检测记录处理项目 | 脚本结构与调试；检测记录统计脚本（自评） |

“检测记录统计脚本”是自评实作，没有练习题。
按[检测记录处理项目讲义](lessons/project.md)中的自评清单完成后，
在学习路径中标记已会。
