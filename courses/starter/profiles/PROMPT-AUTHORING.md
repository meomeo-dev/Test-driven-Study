# 记忆宫殿提示词编写指南

课包已包含三份可以直接运行的提示词。先用默认题验证流程，再按下面的空格
填写本课程的教学要求，改写到对应提示词中。这里的 `[填写：…]` 是作者的
起草位置。运行时只读取 `course.json` 引用的提示词和图像模板。

## 一、联网取证 · palace-research.txt

这一步要交给构思模型一份短小、可核对的证据笔记。先划清题内证据与外部资料的
职责，再写搜索范围。对时效性规则，写清适用地区、版本或生效时间。

```text
学习目标：[填写：遇到什么线索，学员要做哪个判断或动作？]
题内依据：[填写：以题干、逐字稿、图表、原始数值中的哪些内容为准？]
检索范围：[填写：外部资料用来核实哪一条规则、定义或通用方法？]
来源优先级：[填写：哪些机构、原始资料或教学出处适合本课程？]
证据笔记：[填写：原文定位或复算结果、规则的出处和适用条件、尚存缺口。]
```

**示例。** 教初学者把四分之一写成小数。用题目中的 `1 ÷ 4` 复算出
`0.25`，再检索支持「等分整体」或「分数表示除法」的教学资料。记录来源
链接和它支持的教学主张。题内结果、外部教学依据和对常见误区的推断分别写清。

## 二、场景构思 · palace-planning.txt

构思应说明如何用可见的关系记住判断方法。先规定本课程怎么找出答案，再规定
哪类场景、图示或对照最能表达它。

```text
判断步骤：[填写：圈出条件 → 核对原文或复算 → 检查一个易错点。]
选择画面：[填写：哪类题用一个动作，哪类题用图示或同尺度对照？]
视觉锚点：[填写：画出哪个物件、动作或位置关系？它对应什么事实？]
混淆项：[填写：学员会错在哪个词、条件、单位或数量关系？如何辨认？]
回忆检查：[填写：遮住答案后，看图能说出哪个线索和对应判断？]
交给生图：[填写：确切的对象、位置、数量和允许出现在图中的逐字标签。]
```

**示例。** `1 ÷ 4` 用一条表示 `1` 的等长带，均分四格，只填满一格。
填色的一格标注 `1/4 = 0.25`。遮住式子后，学员可以从图上回答「着色
部分占整个条带的几分之几」。

保持平台已有的 JSON 字段。把学习目标和场景放进 `scene`，把可见线索及含义
写入 `anchors`，把有依据的易错点写入 `pitfalls`。在 `image_prompt` 中
逐字列出需要画的对象与标签，生图模型可以直接照着绘制。研究依据写入
`research`，具体字段和长度由平台约束。

## 三、生图模板 · memory-palace.json

这一份定义该课程的画面习惯。把图像模型可直接执行的指令写入
`prompt_template` 字符串。优先定下唯一的视觉焦点，再规定什么必须准确呈现。

```text
构图：[填写：一个连续场景、一个图示，或确有教学必要的对照。]
视觉锚点：[填写：主体在什么位置，关键对象如何排列、对齐或相互作用？]
文字：[填写：哪些短词、数字、单位或公式需要逐字保留？]
验图：[填写：画面最容易误画哪个条件？完成后应当逐项核对什么？]
```

**示例。** 平视绘制一条均分为四个同宽格的条带，左侧第一格填深蓝。把
`整体 = 1` 放在整条下方，把 `1/4 = 0.25` 放在着色格旁。核对格数、
着色数和等号。留出空白，让数量关系在手机上也能看清。

图像模板里的运行时变量如下。把题目与答案保留为校验材料。想让一段话出现在
图中时，在画面指令中明确列出要印的字。

| 变量 | 运行时内容 |
| --- | --- |
| `{{QUESTION_TEXT}}` | 必填。平台提供题干、选项和可用讲解。 |
| `{{REFERENCE_ANSWER}}` | 必填。平台提供题库参考答案。 |
| `{{PALACE_ADDRESS}}` | 可选。使用者输入的记忆地点，可以为空。 |

## 发布前验收

挑一题普通题和一题容易误读的题。分别看实际证据笔记、场景 JSON、最终生图
提示词和成图。每项满分 20，目标总分至少 90。五项全部核对后再打分。

| 项目 | 满分判据 |
| --- | --- |
| 证据准确 | 引文能定位，计算可复算，外部主张能追溯来源和适用条件。 |
| 判断可迁移 | 图中线索能帮助学员在另一题做同类判断。 |
| 画面可执行 | 主体、位置、关系、数量及文字足够明确。 |
| 成图可读 | 手机尺寸能看清焦点，数值、标注和关键关系与计划一致。 |
| 三段衔接 | 同一判断贯穿三段，运行时变量正常替换，课包与 JSON 校验通过。 |

引文错误、数值错误、画面改变题目条件或模板无法运行时，先修正再发布。
修改提示词后提高 `course.json` 的课程版本，并运行 `npm run course:check`。
