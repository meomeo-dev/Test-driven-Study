# 参数化建模与 3D 打印

从尺寸草图、切片到能重复定位工件的 FDM 夹具。

## 学习起点

会用毫米表示尺寸即可。参数化建模可先在电脑完成，试印时使用可借用的 FDM 打印机。

- 画支架草图并约束孔距 → 打印间隙试片 → 制作定位夹具。
- 把同一个工件取放 20 次，观察它是否每次贴紧同一组基准面。

## 学完能做什么

- 用草图约束、拉伸和孔位参数建立支架。
- 识别切片预览中的首层、支撑和层方向。
- 用试片验证间隙，并记录打印方向、材料和实测尺寸。

**桌面质检分拣站实作**。设计一块带两个安装孔的定位底板，并用三组不同孔径的试片确定装配尺寸。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 参数化建模基础 | 参数化建模流程；草图与几何元素；几何约束；尺寸约束与完全约束 |
| 特征建模 | 拉伸与旋转；孔特征与阵列；圆角、倒角与抽壳；参数表与设计变更 |
| 装配与工程图 | 基准面与参考几何；装配与配合约束；工程图与文件导出 |
| FDM 原理与材料 | FDM 工作原理；常用材料与选用；调平、首层与喷嘴 |
| 切片与参数 | 切片流程与预览；层高、壁厚与填充；支撑与打印方向；速度、温度与冷却 |
| 面向打印的设计 | 面向 FDM 的设计规则；间隙试片与孔径补偿；常见打印缺陷与排查；打印件测量与记录；后处理与热熔螺母 |
| 定位夹具 | 定位原理与基准面；定位夹具设计；定位底板与间隙试片（自评） |

“定位底板与间隙试片”是自评实作，没有练习题。
按[定位夹具讲义](lessons/fixtures.md)中的自评清单完成后，
在学习路径中标记已会。
