# 代数、三角与空间几何

为 CAD 和高数补齐单位、坐标、斜率、角度与投影。

## 学习起点

会基本四则运算。小数和百分数可先练项目内的《基础数学》。

- 比例与单位 → 坐标与斜率 → 直角三角形 → 二维草图和三维投影。

## 学完能做什么

- 换算长度单位并读懂坐标。
- 用斜率和勾股定理解释尺寸。
- 用正弦、余弦理解角度和投影。

**桌面质检分拣站实作**。在 CAD 画一个两边长分别为 30 和 40 mm 的直角三角形，对照公式测量斜边。

## 课程内容

1.1.0 版包含七个单元、27 个知识点和 134 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 比例与单位 | 比与比例；长度与面积单位换算；科学记数法与有效数字；百分比与相对误差 |
| 代数式与方程 | 代数式与运算律；一元一次方程；公式变形；二元一次方程组；一元二次方程 |
| 坐标与函数图像 | 平面直角坐标系；斜率与直线方程；距离与中点公式；函数与图像 |
| 直角三角形与三角函数 | 勾股定理；正弦、余弦与正切；解直角三角形；弧度与弧长 |
| 三角函数与平面几何 | 单位圆与任意角；正弦定理与余弦定理；圆、扇形与均布孔；极坐标与直角坐标换算 |
| 立体几何与投影 | 面积与体积；空间直角坐标；三视图与正投影；空间角与投影长度 |
| 草图中的几何 | 草图约束中的几何关系；直角三角形草图核对（自评） |

“直角三角形草图核对”是自评实作，没有练习题。
按[草图中的几何讲义](lessons/sketch-geometry.md)中的自评清单完成后，
在学习路径中标记已会。
