# 草图中的几何

本单元学习参数化 CAD 草图中的几何约束与尺寸标注，通过代数与几何关系理解图元的
定位与自由度，并以直角三角形夹具草图完成软件实测与理论计算的闭环核对。

## 本单元知识点

- 草图约束中的几何关系：理解平行、垂直、相切、同心、对称等约束的数学本质，
  用尺寸约束消除图元自由度以达到完全定义。
- 直角三角形草图核对（自评）：在 CAD 中绘制 30 mm 与 40 mm 直角三角形草图，
  运用勾股定理与反三角函数完成软件测量核对。

## 草图约束中的几何关系

在桌面质检分拣站的机械结构设计中，相机固定板、分拣挡板和工件定位夹具等零件
都需要在参数化 CAD 软件中先绘制二维草图。草图的核心控制机制是几何约束与尺寸约束，
它们在数学本质上是一组联立代数方程。

1. 方向与位置约束的数学条件：
- 水平与竖直约束：水平约束强制两端点纵坐标相等（y₁ = y₂），直线斜率 k = 0；
  竖直约束强制两端点横坐标相等（x₁ = x₂），直线斜率不存在（Δx = 0）。
- 平行约束：对应两条直线的方向向量共线，在斜率存在时表现为斜率相等（k₁ = k₂）。
- 垂直约束：对应两直线夹角为 90°；在两直线均不与坐标轴平行时，对应斜率乘积为
  负倒数，即 k₁ · k₂ = -1。
- 重合约束：点与点重合强制两点坐标相等（x₁ = x₂ 且 y₁ = y₂）；点与线重合强制点的
  坐标满足该直线的代数方程。
- 对称约束：两图元关于对称轴线镜像对称。若对称轴直线为 Ax + By + C = 0，对称点
  P₁(x₁, y₁) 与 P₂(x₂, y₂) 的几何条件包含两条代数方程：
  一是对称点连线的中点落在对称轴上，即 A·((x₁ + x₂)/2) + B·((y₁ + y₂)/2) + C = 0；
  二是两对称点连线与对称轴垂直，即方向向量与法向量平行。

2. 相切与同心约束的数学条件：
- 相切约束：对于直线与圆（或圆弧），切点处半径垂直于切线，几何条件为圆心到直线的
  垂直距离等于圆的半径，即 d = r。对于两圆相切，外切条件为两圆心距离等于半径之和，
  即 d = r₁ + r₂；内切条件为两圆心距离等于半径差的绝对值，即 d = |r₁ - r₂|。
- 同心约束：强制两个圆或圆弧的圆心坐标完全重合，即 (x₁, y₁) = (x₂, y₂)。同心约束
  仅锁定相对位置，两圆的半径仍彼此独立，各自保留大小自由度。

3. 自由度与完全定义：
二维平面直角坐标系中，任何一个几何图元都具有一定的自由度（Degree of Freedom）。
一个独立自由的点具有 2 个自由度（x 与 y 坐标）；一条线段具有 4 个自由度（两端点各
2 个坐标，也可以理解为刚体的 2 个位置坐标、1 个倾斜角度和 1 个长度尺寸）。
几何约束限制了几何元素之间的相对平行、垂直、同心或相切等拓扑关系；尺寸约束则
指定了具体的数值大小（如线段长度、孔心间距、圆弧半径、夹角度数）。
当草图中施加的约束方程总数恰好等于所有图元的自由度总数，且方程相互独立无矛盾时，
草图达到“完全约束”（完全定义）。若约束不足，拖动图元会发生非预期的位移或变形；
若约束重复或冲突，则会导致代数方程组超定或无解，引发“过约束”报错。

4. 定位基准与坐标约束：
仅有相对几何约束（如平行、垂直）无法确定图元在空间中的绝对位置。
在分拣站装配模型中，必须选定设计基准（例如零件的安装基准面、销孔中心或
草图坐标原点）。通过施加与基准坐标轴的重合、同心或距离尺寸约束，才能消除
图形在平面内的刚体平移与旋转自由度，实现零件在分拣工位上的准确装配。

### 例题

在质检分拣站的下料滑道侧板草图中，水平传送带基准线 L₁ 的方程为 y = 0
（单位：mm）。工程师绘制了一个用于安装导向轮的圆弧 C，标注其半径尺寸为
R = 25 mm，圆心坐标设为 (x₀, y₀)，位于第一象限。
现为圆弧 C 与基准线 L₁ 施加“相切”几何约束，并标注尺寸约束：圆心到坐标原点
O(0, 0) 的水平投影距离为 40 mm。
求导向轮圆弧圆心坐标 (x₀, y₀) 的精确数值，以及该圆的标准代数方程。

分析：
1. 自由度识别：圆在平面中具有 3 个自由度（圆心 x 坐标、y 坐标以及半径 R）。
2. 已知条件匹配：题目给定了半径尺寸 R = 25 mm，消除了 1 个大小自由度；
   给定了圆心水平距离尺寸 40 mm，消除了 1 个横向位置自由度；施加相切几何
   约束，提供了一个垂直距离方程，消除了最后 1 个纵向位置自由度。
3. 求解目标：通过联立几何约束与尺寸约束方程，求出圆心唯一解并写出圆方程。

解：
第一步：分析水平尺寸约束。
圆心横坐标到 y 轴的距离为 40 mm，且题干限定圆心位于第一象限（x₀ > 0），
因此直接确定横坐标：
x₀ = 40 mm。

第二步：分析相切几何约束。
圆弧 C 与水平基准线 L₁（y = 0）相切，其几何条件是圆心到直线 L₁ 的垂直距离
等于圆弧的半径 R。
圆心 (x₀, y₀) 到直线 y = 0 的垂直距离为纵坐标的绝对值 |y₀ - 0| = |y₀|。
因此代数关系为 |y₀| = R = 25 mm。
由于圆心位于第一象限（y₀ > 0），取正根得纵坐标：
y₀ = 25 mm。
综上，导向轮圆弧的圆心绝对坐标被唯一锁定为 (40, 25) mm。

第三步：建立圆的标准方程。
根据平面解析几何中圆的标准方程 (x - a)² + (y - b)² = r²，将圆心 (40, 25)
与半径 25 代入：
(x - 40)² + (y - 25)² = 25² = 625。
至此，圆心的位置自由度与圆弧的大小自由度均被完全消除，草图达到完全定义。

### 常见错误

1. 误将几何约束等同于尺寸约束：在草图中为矩形施加了水平与垂直约束，仅确定了四边
   相互平行与垂直的矩形特征，但矩形的长、宽以及在坐标平面内的坐标未定，依然处于
   欠约束状态，必须补充具体尺寸标注。
2. 尺寸链闭环导致过约束：例如已经标注了定位孔 A 到孔 B 的水平距离为 30 mm，孔 B 到
   孔 C 为 20 mm，若再次标注孔 A 到孔 C 的总长为 50 mm，就形成了过约束（冗余方程），
   CAD 软件会报警提示删除冗余驱动尺寸。
3. 相切约束的方向翻转：相切方程在数学上通常存在内外切或直线两侧的两个实数解。若
   草图绘制时图元初始位置偏离设计意图过远，CAD 求解器可能会收敛到错误的外侧或内侧
   相切分支，需要通过辅助草图尺寸或拖拽预定位纠正。

## 直角三角形草图核对（自评）

目标：
在参数化 CAD 软件中利用几何约束与驱动尺寸精确构建两直角边分别为 30 mm 与
40 mm 的直角三角形定位靠模草图。通过勾股定理与反三角函数公式推导斜边理论
长度与锐角理论度数，并利用 CAD 软件中的从动尺寸（参考测量工具）完成实测
核对，建立数理公式与 CAD 几何求解器的双向对应认知。

材料或准备：
- 计算机一台，已安装任意标准二维或三维 CAD 软件（如 FreeCAD、Fusion 360、
  AutoCAD、SolidWorks 或 Onshape 等）。
- 科学计算器或带三角函数的计算程序，用于计算平方根与反正切函数 arctan。
- 实验记录本与草稿纸，用于手算记录理论推导值与软件从动测量值。

步骤：
1. 新建草图环境：启动 CAD 软件新建零件模型，选取 XY 水平基准面创建草图，
   显示坐标原点与基准坐标轴。
2. 绘制水平底边并约束：使用直线工具以原点 (0, 0) 为起点沿 X 轴正向绘制一条
   线段。为该线段施加“水平”几何约束，并添加尺寸标注，将其长度严格设定为
   40 mm。此时底边完全变黑（完全约束）。
3. 绘制垂直直角边并约束：使用直线工具再次以原点 (0, 0) 为起点沿 Y 轴正向绘制
   一条线段。为该线段施加“竖直”几何约束（或与底边施加“垂直”约束），并添加
   尺寸标注，将其长度严格设定为 30 mm。确认两直角边在原点处重合且夹角为 90°。
4. 绘制斜边并检查完全定义：使用直线工具连接竖直边的上端点与水平边的右端点，
   闭合形成直角三角形。检查所有图元颜色或软件状态栏，确认草图已达到完全定义
   状态（无任何未约束自由度）。
5. 调出从动尺寸读取实测值：使用尺寸标注工具标注斜边长度（当软件提示过约束时，
   选择转换为“参考尺寸”或“从动尺寸”），记录测量值；接着使用角度标注工具
   分别测量斜边与 40 mm 底边的夹角，以及斜边与 30 mm 竖直边的夹角。
6. 理论公式核对与比对：在草稿纸上手算斜边理论值 c = √(30² + 40²) 与两锐角
   理论值 θ₁ = arctan(30/40)、θ₂ = arctan(40/30)，将手算结果与软件实测读数
   进行高精度比对并记录误差。

### 自评清单

1. 几何与尺寸约束规范：直角三角形两直角边起点准确固定在原点，分别具有水平与
   竖直约束，尺寸精确为 40 mm 与 30 mm，草图无多余自由度，处于完全约束状态。
2. 斜边尺寸核对达标：软件测得的参考从动斜边长度精确显示为 50.00 mm，与勾股定理
   计算 c = √(30² + 40²) = √(900 + 1600) = √2500 = 50 mm 严格一致。
3. 锐角度数核对达标：软件测得底边锐角约为 36.87°（arctan 0.75 ≈ 36.8699°），
   竖直边锐角约为 53.13°（arctan 1.3333 ≈ 53.1301°），两角之和严格为 90.00°。
4. 深刻理解从动量本质：明确斜边长度与两锐角已由直角条件与两直角边尺寸唯一确定，
   属于从动几何量，强行添加驱动尺寸会导致几何超定与过约束报错。
5. 闭环文档记录完整：在实验记录本上整齐记录 CAD 软件截图参数、手算推导步骤及
   绝对误差（理论值与测量值差值小于 0.01 mm 和 0.01°）。

完成上述 5 项检查且全部达标后，请在“学习路径”中把该知识点标记为“已会”。

## 单元小结

1. 参数化草图中的几何约束（平行、垂直、相切、对称、同心）本质上是几何图元坐标的
   代数方程，限制了几何元素的相对运动方向与相对位置。
2. 尺寸约束提供了具体的几何标量，与几何约束共同作用消除图元的自由度，驱动草图
   从欠约束达到完全定义状态。
3. 约束关系遵循代数方程组的相容性与独立性原则，欠约束导致尺寸漂移，而过约束或
   矛盾约束会导致 CAD 求解器无解报错。
4. 直角三角形是工业夹具与机构设计中最基础的几何单元，其实测斜边与角度严格遵循
   勾股定理与三角函数规律，是验证参数化建模尺寸逻辑的基石。
5. 驱动尺寸与从动测量尺寸具有严格的单向依赖关系，理论计算是验证软件建模正确性的
   底层标准。
