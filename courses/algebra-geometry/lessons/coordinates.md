# 坐标与函数图像

本单元学习平面直角坐标系、直线的斜率与方程、两点距离与中点公式，以及函数图像与读图分析方法。

## 本单元知识点
- 平面直角坐标系：建立工件基准原点与坐标轴，掌握象限划分、坐标表示与平移规律。
- 斜率与直线方程：理解斜率变化率含义，掌握斜截式与两点式方程，判定平行与垂直。
- 距离与中点公式：掌握两点间欧几里得距离与中点坐标公式，计算夹具定位孔中心距。
- 函数与图像：理解函数映射关系，掌握一次与二次函数图像特征、顶点对称轴与读图。

## 平面直角坐标系
在桌面质检分拣站中，待检工件放置在检测平台上，必须建立统一的空间参考系。
平面直角坐标系由两条在原点 O(0, 0) 处互相垂直的数轴组成：水平方向为 X 轴
（向右为正方向），垂直方向为 Y 轴（向上为正方向）。两轴长度单位通常统一为 mm。

两坐标轴将坐标平面分为四个象限：右上为第一象限 (x > 0, y > 0)，
左上为第二象限 (x < 0, y > 0)，左下为第三象限 (x < 0, y < 0)，
右下为第四象限 (x > 0, y < 0)。位于 X 轴或 Y 轴上的点不属于任何象限。
平面上任意特征点的位置由有序数对 (x, y) 唯一确定，x 为横坐标，y 为纵坐标。

工件特征点沿坐标轴平移时遵从代数加减规则：
点 P(x, y) 向右平移 a 个单位变为 (x + a, y)，向左平移 a 个单位变为 (x - a, y)；
向上平移 b 个单位变为 (x, y + b)，向下平移 b 个单位变为 (x, y - b)。

在 CAD 参数化建模和机器视觉中，定位夹具的基准角点常设为用户坐标系原点 (0, 0)，
相机识别出的各轮廓点或工件圆孔中心均可直接转换为该参考系下的坐标值。

### 例题
题目：
分拣站夹具托盘的原点设在左下角定位挡块顶点 O(0, 0)。检测探头初始位于
点 A(15 mm, 20 mm)。若将探头先向右平移 35 mm，再向下平移 12 mm 到达检测点 B，
求点 B 的坐标，并判断点 B 位于第几象限。

解答：
根据坐标平移规则，横坐标向右增加 35 mm，纵坐标向下减少 12 mm：
xB = 15 + 35 = 50 mm
yB = 20 - 12 = 8 mm
因此点 B 的坐标为 (50 mm, 8 mm)。
因为 xB = 50 > 0 且 yB = 8 > 0，所以点 B 位于第一象限。

### 常见错误
- 混淆横坐标与纵坐标的书写顺序，将 (x, y) 误写为 (y, x)。
- 坐标平移时方向与正负号混淆，将向下平移误记为加法，导致纵坐标计算错误。
- 误将位于坐标轴上的特征点（例如 (0, 25 mm)）划入某个象限中。

## 斜率与直线方程
斜率用于度量直线在坐标系中的倾斜程度与倾斜方向。
经过两点 P₁(x₁, y₁) 与 P₂(x₂, y₂) 的直线斜率 k 定义为纵坐标增量与横坐标增量的比值：
k = Δy / Δx = (y₂ - y₁) / (x₂ - x₁)，其中要求 x₁ ≠ x₂。

特殊位置直线的斜率特性如下：
- 水平线：所有点纵坐标相同，Δy = 0，斜率 k = 0，直线方程形式为 y = c。
- 竖直线：所有点横坐标相同，Δx = 0，分母为零，斜率不存在，方程形式为 x = c。

直线的常用代数方程形式：
- 斜截式：y = kx + b，其中 k 为斜率，b 为直线在 Y 轴上的截距（交点坐标为 (0, b)）。
- 点斜式：已知直线上一点 (x₁, y₁) 及斜率 k 时，方程为 y - y₁ = k(x - x₁)。
- 两点式：已知两点 (x₁, y₁)、(x₂, y₂)（x₁ ≠ x₂ 且 y₁ ≠ y₂）时，
  方程为 (y - y₁) / (y₂ - y₁) = (x - x₁) / (x₂ - x₁)，等价于先求 k 再用点斜式。

两条不重合直线 l₁ 与 l₂（斜率分别为 k₁ 与 k₂）的位置关系判定规则：
- 平行关系：若 l₁ // l₂，则 k₁ = k₂（倾斜程度相同）。
- 垂直关系：若 l₁ ⊥ l₂，则 k₁ · k₂ = -1，即互相垂直的直线斜率互为负倒数（k₂ = -1 / k₁）。

### 例题
题目：
分拣站的一条直线滑道边缘经过点 P₁(10 mm, 15 mm) 与 P₂(30 mm, 25 mm)。
求该滑道边缘所在直线的斜率 k 和斜截式方程；若分拣推杆边缘与该滑道边缘垂直，
求推杆边缘所在直线的斜率。

解答：
1. 计算滑道边缘所在直线的斜率：
   k = (25 - 15) / (30 - 10) = 10 / 20 = 0.5。
2. 将点 P₁(10, 15) 与 k = 0.5 代入点斜式方程：
   y - 15 = 0.5(x - 10)
   y = 0.5x - 5 + 15
   y = 0.5x + 10。
   因此该直线方程的斜截式为 y = 0.5x + 10。
3. 两直线垂直时斜率满足 k₁ · k₂ = -1，推杆边缘直线的斜率：
   k_push = -1 / 0.5 = -2。

### 常见错误
- 计算斜率时将横纵坐标差颠倒，错误算成 Δx / Δy。
- 忽略竖直线的斜率不存在，强行使用斜截式导致分母除以零错误。
- 记忆垂直斜率关系时漏掉负号，误记为互为倒数 k₁ · k₂ = 1。

## 距离与中点公式
在平面直角坐标系中，设两特征点分别为 P₁(x₁, y₁) 与 P₂(x₂, y₂)。
两点间的直线距离可通过直角三角形勾股定理导出。水平方向直角边长为 |x₂ - x₁|，
垂直方向直角边长为 |y₂ - y₁|。两点间欧几里得距离公式为：
d = √((x₂ - x₁)² + (y₂ - y₁)²)。

距离公式广泛用于测量工件加工孔的中心跨距、料盒边缘距离以及传感器探头位移。
由于坐标差经过平方运算，计算时两点的先后代入次序不影响距离的计算结果。

线段 P₁P₂ 的中点 M(x_m, y_m) 的坐标为两端点坐标的算术平均值：
x_m = (x₁ + x₂) / 2
y_m = (y₁ + y₂) / 2

中点公式常用于确定对称工件的几何中心、定位夹具双定位销的对称基准线，
或通过已知端点和中点反求另一对称特征点的空间坐标。

### 例题
题目：
工件定位夹具底板上有两个固定销孔，在质检坐标系下的圆心坐标分别为
孔 1 坐标 C₁(20 mm, 30 mm)，孔 2 坐标 C₂(60 mm, 60 mm)。
求两定位孔的中心距 d 以及两孔连线中点 M 的坐标。

解答：
1. 计算两孔中心距 d：
   d = √((60 - 20)² + (60 - 30)²)
     = √(40² + 30²)
     = √(1600 + 900)
     = √2500 = 50 mm。
2. 计算连线中点 M 的坐标：
   x_m = (20 + 60) / 2 = 80 / 2 = 40 mm
   y_m = (30 + 60) / 2 = 90 / 2 = 45 mm
因此两孔中心距为 50 mm，两孔连线的中点坐标为 (40 mm, 45 mm)。

### 常见错误
- 距离公式中忘记开平方根，将 d² 误当成两点距离 d。
- 中点公式中误将两端点坐标相减除以 2，混淆了中点均值与长度差值。
- 坐标为负数时代入公式未正确处理负负得正，导致差值或和值符号计算错误。

## 函数与图像
函数描述了输入与输出之间的单值依赖规律：对于自变量 x 在定义域内的每一个值，
因变量 y 都有唯一确定的值与之对应，记作 y = f(x)。
在直角坐标系中，所有满足关系的坐标点 (x, f(x)) 构成了函数的图像。

工业场景中常见的一次函数形式为 y = kx + b (k ≠ 0)，图像是一条直线：
- k > 0 时，y 随 x 增大而增大，直线从左向右上升；
- k < 0 时，y 随 x 增大而减小，直线从左向右下降；
- b 为纵截距，即直线与 Y 轴交点 (0, b)。

二次函数的一般式为 y = ax² + bx + c (a ≠ 0)，其图像是一条抛物线：
- a > 0 时抛物线开口向上，顶点为最低点，函数有最小值；
- a < 0 时抛物线开口向下，顶点为最高点，函数有最大值；
- 抛物线对称轴方程为 x = -b / (2a)；
- 顶点坐标公式为 (-b / (2a), (4ac - b²) / (4a))；
- 顶点式方程为 y = a(x - h)² + k，顶点坐标直接对应为 (h, k)，对称轴为 x = h。

读图求值是质检站数据分析的核心基本功：
通过传感器输出特性曲线，从横轴给定自变量垂直引线交于曲线，水平投影至纵轴读值；
反之亦可根据报警阈值在纵轴找对应点，反求横轴的安全工作范围。

### 例题
题目：
分拣站气缸推力输出 F（单位：N）与控制电压 U（单位：V，0 ≤ U ≤ 8）
满足二次函数关系：F = -2U² + 16U + 10。
求该二次函数图像的对称轴电压，以及推力达到最大时的输出数值。

解答：
函数对应各项系数为 a = -2，b = 16，c = 10。
因为 a = -2 < 0，抛物线开口向下，在顶点处取得最大值。
1. 计算对称轴对应的控制电压：
   U = -b / (2a) = -16 / (2 · (-2)) = -16 / (-4) = 4 V。
2. 将 U = 4 V 代入函数计算顶点推力值：
   F_max = -2 · 4² + 16 · 4 + 10
         = -2 · 16 + 64 + 10
         = -32 + 64 + 10 = 42 N。
因此对称轴电压为 4 V，气缸达到的最大推力为 42 N。

### 常见错误
- 记忆对称轴公式时遗漏负号，误记为 x = b / (2a)。
- 误判抛物线极值性质，在 a < 0 开口向下时误认为函数具有最小值。
- 在顶点式 y = a(x - h)² + k 中忽视括号内的减号，将对称轴错写为 x = -h。

## 单元小结
- 平面直角坐标系将物理平面数字化，通过有序数对 (x, y) 确定位置，平移遵从代数加减。
- 直线斜率体现几何倾斜与物理变化率，斜截式 y = kx + b 直观反映斜率与纵截距；平行斜率相等，垂直斜率互为负倒数。
- 两点距离公式基于勾股定理，中点坐标公式基于平均值，二者是测量孔距与对称特征的核心工具。
- 一次函数反映均匀线性变化，二次函数刻画极值与对称特性；掌握图像对称轴与顶点计算能够指导工业传感与机械传动参数整定。
