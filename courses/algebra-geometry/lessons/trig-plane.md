# 三角函数与平面几何

本单元围绕桌面质检分拣站的工件定位、连杆传动与法兰安装，系统学习单位圆与任意角、
正弦与余弦定理、圆与扇形及均布孔几何计算、极坐标与直角坐标互化，为旋转机构控制与
传感器定位建立严谨的数学模型。

## 本单元知识点
- 单位圆与任意角：掌握单位圆坐标定义 (cosθ, sinθ)、各象限符号及同角平方恒等式。
- 正弦定理与余弦定理：掌握斜三角形的边角关系公式，求解任意三角形未知边长与角度。
- 圆、扇形与均布孔：掌握圆周长与面积、扇形度量公式，以及圆周均布孔的直角坐标计算。
- 极坐标与直角坐标换算：掌握极坐标与直角坐标双向互化公式，结合象限准确确定极角。

## 单位圆与任意角
在平面直角坐标系中，以坐标原点为顶点、x 轴正半轴为始边。射线逆时针旋转形成的角
定义为正角，顺时针旋转形成的角定义为负角。旋转量不受 360° 限制，可推广至任意实数。

以原点为圆心、半径 r = 1 的圆称为单位圆。任意角 θ 的终边与单位圆交于唯一一点 P(x, y)，
其坐标直接定义了三角函数：x = cos θ，y = sin θ，且在 x ≠ 0 时 tan θ = y/x = sin θ / cos θ。
这表明单位圆周上任意一点的坐标都可以直接写为 (cos θ, sin θ)。

三角函数的符号完全由交点所在的象限决定：
- 第一象限（x > 0, y > 0）：sin θ > 0，cos θ > 0，tan θ > 0；
- 第二象限（x < 0, y > 0）：sin θ > 0，cos θ < 0，tan θ < 0；
- 第三象限（x < 0, y < 0）：sin θ < 0，cos θ < 0，tan θ > 0；
- 第四象限（x > 0, y < 0）：sin θ < 0，cos θ > 0，tan θ < 0。

由单位圆方程 x² + y² = 1 可直接导出同角三角函数的基本平方恒等式：
sin²θ + cos²θ = 1。
已知某角的正弦或余弦值及其所在象限时，可利用该恒等式求出另一个三角函数值。

### 例题
在质检站的旋转检测台上，伺服电机驱动工件转盘旋转了 θ = 120°。求该角度在单位圆上
的交点坐标 P(cos 120°, sin 120°) 以及正切值 tan 120°。

解答：
1. 确定象限与参考角：120° 位于第二象限，其与负 x 轴的夹角为 180° − 120° = 60°。
2. 确定坐标数值与正负号：第二象限横坐标为负、纵坐标为正，因此：
   cos 120° = −cos 60° = −1/2
   sin 120° = sin 60° = √3/2
3. 得单位圆交点坐标：P(−1/2, √3/2)。
4. 计算正切值：tan 120° = sin 120° / cos 120° = (√3/2) / (−1/2) = −√3。

### 常见错误
- 忽略角度所在象限导致符号判定错误，例如误将第二象限的余弦值写为正数 1/2。
- 由 sin²θ + cos²θ = 1 开平方求值时漏掉象限判定，未给余弦或正弦添加正确的负号。

## 正弦定理与余弦定理
在桌面分拣站的连杆传动机构与相机光轴测量中，大量三角形并非直角三角形，必须借助
正弦定理与余弦定理求解斜三角形。

正弦定理指出：在任意三角形 ABC 中，各边长与对应角的正弦值之比相等，且等于外接圆
直径 2R，即：
a / sin A = b / sin B = c / sin C = 2R
正弦定理适用于已知两角和任意一边，或已知两边和其中一边的对角的情形。

余弦定理指出：任意一边的平方等于其余两边的平方和减去这两边与其夹角余弦积的两倍：
a² = b² + c² − 2bc·cos A
b² = a² + c² − 2ac·cos B
c² = a² + b² − 2ab·cos C
当夹角为 90° 时，因 cos 90° = 0，余弦定理即退化为勾股定理 c² = a² + b²。

当已知三角形三边长度时，可通过余弦定理的变形公式求解未知角：
cos C = (a² + b² − c²) / (2ab)
若 cos C > 0，则角 C 为锐角；若 cos C = 0，则为直角；若 cos C < 0，则为钝角。

### 例题
分拣站推杆机构的两根连杆长度分别为 a = 50 mm，b = 80 mm，两杆连接处的夹角为
C = 60°。求两连杆远端两铰接点之间的直线距离 c。

解答：
1. 已知两边长 a = 50 mm，b = 80 mm，夹角 C = 60°，选用余弦定理求对边。
2. 代入公式展开计算：
   c² = a² + b² − 2ab·cos C
   c² = 50² + 80² − 2·50·80·cos 60°
      = 2500 + 6400 − 8000·0.5
      = 8900 − 4000 = 4900
3. 两端开平方求得直线间距：c = √4900 = 70 mm。

### 常见错误
- 记忆余弦定理公式时混淆符号或系数，误写为 a² + b² − ab·cos C 或 a² + b² + 2ab·cos C。
- 在钝角三角形中计算时，未注意钝角余弦值为负（cos C < 0），未进行负负得正运算，
  导致最终边长算小。

## 圆、扇形与均布孔
分拣站的转盘、安装法兰及料盒导轨均由圆与扇形构成。设圆的半径为 r，直径为 d = 2r：
整圆周长公式为 C = 2πr = πd，整圆面积公式为 A = πr² = (1/4)πd²。

当圆心角为 α（单位必须为弧度 rad）时，弧长与扇形面积公式为：
弧长 l = r·α
扇形面积 S = (1/2)·r²·α = (1/2)·l·r
若圆心角以角度 θ（单位为度 °）给出，扇形面积换算为 S = (θ / 360°)·πr²。

工业装配法兰通常在半径为 r 的分布圆上加工 n 个均匀分布的螺栓孔。圆周均布孔的
几何特征是相邻两孔间的分度角恒定：
Δθ = 360° / n（角度制）或 Δθ = 2π / n（弧度制）。

若起始孔（孔号 k = 0）设定在初始角 θ₀（通常为 0°），则第 k 个孔（k = 0, 1, ..., n − 1）
的极角为 θ_k = θ₀ + k·Δθ。其在直角坐标系中的中心坐标为：
x_k = r·cos θ_k
y_k = r·sin θ_k

### 例题
质检站定位法兰盘的分度圆半径 r = 50 mm，圆周上均布 4 个螺栓定位孔。起始孔位于
θ₀ = 0°。求第 2 个孔（k = 1）与第 3 个孔（k = 2）的直角坐标。

解答：
1. 计算均布分度角：Δθ = 360° / 4 = 90°。
2. 计算第 2 个孔（k = 1）：
   角度 θ₁ = 0° + 1·90° = 90°
   x₁ = 50·cos 90° = 50·0 = 0 mm
   y₁ = 50·sin 90° = 50·1 = 50 mm
   故第 2 个孔坐标为 (0, 50) mm。
3. 计算第 3 个孔（k = 2）：
   角度 θ₂ = 0° + 2·90° = 180°
   x₂ = 50·cos 180° = 50·(−1) = −50 mm
   y₂ = 50·sin 180° = 50·0 = 0 mm
   故第 3 个孔坐标为 (−50, 0) mm。

### 常见错误
- 计算扇形面积 S = (1/2)·r²·α 时混淆度与弧度，直接代入角度值（如代入 60 而非 π/3）。
- 计算均布孔坐标时混淆正弦与余弦，错误地将横坐标写为 r·sin θ、纵坐标写为 r·cos θ。

## 极坐标与直角坐标换算
在工业视觉检测中，相机的像素传感器输出直角坐标 (x, y)，而旋转工作台或分拣机械臂
依靠回转角度与延伸半径工作，需要将直角坐标与极坐标相互转换。

极坐标系由原点处的极点 O 与水平向右的极轴 Ox 构成。平面内任意点 P 的位置由两个量
确定：极径 r（点 P 到极点 O 的距离，规定 r ≥ 0）和极角 θ（极轴逆时针转到射线 OP 的角），
记作 (r, θ)。

极坐标转直角坐标公式对任意象限均通用：
x = r·cos θ
y = r·sin θ

直角坐标转极坐标时，极径与极角的计算步骤如下：
1. 极径计算：r = √(x² + y²)。
2. 极角确定：先由 tan θ = y/x（x ≠ 0）求出参考角，再结合 (x, y) 所在象限确定极角：
   - 第一象限（x > 0, y > 0）：θ = arctan(y/x)
   - 第二象限（x < 0, y > 0）：θ = 180° − arctan(|y/x|)
   - 第三象限（x < 0, y < 0）：θ = 180° + arctan(|y/x|)
   - 第四象限（x > 0, y < 0）：θ = 360° − arctan(|y/x|)
   若 x = 0，当 y > 0 时 θ = 90°；当 y < 0 时 θ = 270°。

### 例题
相机检测到传送带上某工件质心的直角坐标为 (x, y) = (−30, 30√3) mm。若旋转分拣臂需以
极坐标 (r, θ) 进行定位，求该点的极径 r 与极角 θ（0° ≤ θ < 360°）。

解答：
1. 计算极径 r：
   r = √(x² + y²) = √((−30)² + (30√3)²) = √(900 + 2700) = √3600 = 60 mm。
2. 判定象限并求极角 θ：
   点 (−30, 30√3) 横坐标为负、纵坐标为正，位于第二象限。
   计算比值 tan θ = y/x = (30√3) / (−30) = −√3，其参考角为 60°。
   根据第二象限规则，极角 θ = 180° − 60° = 120°。
3. 得到极坐标为 (60 mm, 120°)。

### 常见错误
- 仅用计算器的反三角函数 arctan(y/x) 计算极角，忽略点处于第二或第三象限，导致角度
  产生 180° 的方向性颠倒。
- 误将极径 r 算成负数；极径表示点到原点的欧几里得距离，在标准工程定义中始终满足 r ≥ 0。

## 单元小结
- 单位圆建立了任意角三角函数的几何模型，坐标 (cos θ, sin θ) 与平方恒等式
  sin²θ + cos²θ = 1 是旋转运动计算的核心依据。
- 正弦定理与余弦定理摆脱了直角三角形的约束，可直接计算连杆机构中斜三角形的任意边与角。
- 圆周均布孔通过等分圆周角 Δθ = 360°/n，结合极坐标投影公式即可高效推导所有孔位直角坐标。
- 极坐标与直角坐标的互化是机器视觉感知（直角）与伺服旋转执行（极坐标）之间的核心桥梁，
  求极角时务必根据坐标符号判定象限。
