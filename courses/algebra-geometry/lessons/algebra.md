# 代数式与方程

本单元学习用字母表达工程参数、用运算律化简代数式、求解一元一次方程与二元一次方程组、
进行工程公式变形，以及用一元二次方程求解几何尺寸与工况参数。

## 本单元知识点
- 代数式与运算律：掌握字母表达、去括号与合并同类项，运用乘法分配律与乘法公式展开化简。
- 一元一次方程：运用等式性质进行移项与系数化为 1，建立实际分拣工况的线性方程并求解。
- 公式变形：将多变量工程物理公式变形为目标待求变量的解析式，支撑参数化设计与换算。
- 二元一次方程组：掌握代入消元法与加减消元法，求解机构双向尺寸、料盒计数等双未知量问题。
- 一元二次方程：掌握因式分解与求根公式法，利用判别式确定工程尺寸解的存在性与实际意义。

## 代数式与运算律
代数式是用运算符号把数和表示数的字母连接而成的式子。在分拣站的定位夹具与机械结构
设计中，各个几何特征的尺寸往往由基准尺寸与变量关联。

合并同类项与去括号是化简代数式的基础。含有相同字母且相同字母的指数也相同的项称为
同类项。合并同类项时，将系数相加，字母和字母的指数保持不变。去括号时遵循符号法则：
括号前面是加号，去掉括号和它前面的加号，括号内各项符号不变；括号前面是减号，去掉
括号和它前面的减号，括号内各项符号全部改变。

整式乘法遵循乘法分配律：a(b + c) = ab + ac。在参数化几何展开中，经常使用两个基本
乘法公式：
完全平方公式：(a + b)² = a² + 2ab + b²，(a - b)² = a² - 2ab + b²。
平方差公式：(a + b)(a - b) = a² - b²。

### 例题
分拣站定位夹具底板预留开槽，总长度表达式为 3(2x - 4) - 2(x - 5) + 6 mm。
请化简该代数式，并求当 x = 8 mm 时的总长度。
解：
第一步：去括号，注意负号分配。
原式 = 6x - 12 - 2x + 10 + 6
第二步：合并同类项。
原式 = (6x - 2x) + (-12 + 10 + 6) = 4x + 4
第三步：代入 x = 8 mm 计算。
总长度 = 4 × 8 + 4 = 36 mm。

### 常见错误
- 括号前面为负号时，去括号只改变了第一项的符号，漏改后面各项的符号。
- 展开 (a + b)² 时漏掉中间的乘积项 2ab，错误写成 a² + b²。

## 一元一次方程
只含有一个未知数，且未知数的最高次数为 1 的整式方程称为一元一次方程，其标准形式为
ax + b = 0（其中 a ≠ 0）。

求解一元一次方程的核心是利用等式基本性质：等式两边同加（或减）同一个数或整式，
等式仍然成立；等式两边同乘（或除以）同一个不为 0 的数，等式仍然成立。

通用求解步骤包括：去分母、去括号、移项（将含有未知数的项移至等号一边，常数项移至
另一边，移项必须变号）、合并同类项得到 ax = c、系数化为 1 得到 x = c / a。

列方程解应用题的关键在于寻找等量关系。在分拣系统中，位移等于速度乘以时间，
总间距等于各段部件尺寸之和。

### 例题
分拣传送带以恒定速度 v = 120 mm/s 输送工件。从到位传感器触发拍照检测，到气动分拣
挡板动作，工件前移了 360 mm。若气动挡板的机械动作延迟为 0.5 s，求相机视觉检测与
算法判定消耗的时间 t。
解：
设视觉检测与判定时间为 t 秒，则传送带总输送时间为 (t + 0.5) 秒。
根据位移 = 速度 × 时间，列方程：
120(t + 0.5) = 360
去括号：120t + 60 = 360
移项：120t = 360 - 60 = 300
系数化为 1：t = 300 / 120 = 2.5 s。
答：相机视觉检测与判定消耗的时间为 2.5 s。

### 常见错误
- 移项时忘记改变符号，导致正负号颠倒。
- 方程两边同乘分母以去分母时，漏乘不含分母的常数项。

## 公式变形
工程实践中经常需要根据已知量求解特定待测未知量，这种在保持恒等关系的前提下解出
指定字母的过程称为公式变形。

公式变形的本质是以待求字母为未知数解方程，其他字母均视为已知常数。

常用变形方法：
1. 线性关联公式变形：如总尺寸公式 L = a + 2b，求 b 则先移项得 2b = L - a，
   再除以系数得 b = (L - a) / 2。
2. 乘积与商式公式变形：如电功率公式 P = UI，求电流得 I = P / U；如欧姆定律
   I = U / R，求电阻得 R = U / I。
3. 涉及分母的公式变形：先两边同乘分母消去分母，再集中待求项。例如传动线速度公式
   v = πdn / 60，变形求转速 n 时，两边乘 60 得 60v = πdn，再除以 πd 得
   n = 60v / (πd)。

### 例题
圆柱形待检工件的底面圆周长测量公式为 C = πd。若分拣视觉系统通过边缘检测测得
周长 C = 157 mm，取 π = 3.14，求工件直径 d 的变形公式及数值。
解：
第一步：将 C = πd 变形为以 d 为主元的公式。
方程两边同除以 π，得：
d = C / π
第二步：代入测量数据计算。
d = 157 / 3.14 = 50 mm。
答：直径计算公式为 d = C / π，该工件直径为 50 mm。

### 常见错误
- 待求变量在分母位置时直接颠倒等式，忽略了整体倒数运算规则。
- 变形过程中混淆了加减项与乘除因子的运算优先级。

## 二元一次方程组
含有两个未知数，且含有未知数的项的次数都是 1 的整式方程组成的方程组称为二元一次
方程组。

二元一次方程组的解法核心是“消元”，即将二元问题转化为一元一次方程求解。主要方法有两种：
1. 代入消元法：从一个方程中用含有一个未知数的代数式表示另一个未知数，然后代入
   另一个方程。适合某个方程中存在系数为 1 或 -1 的未知数。
2. 加减消元法：通过将方程两边同乘适当常数，使两个方程中某一未知数的系数绝对值
   相等，然后两式相加或相减消去该未知数。适合两方程各项系数均不为 1 的情形。

在分拣站统计与尺寸定位中，经常利用方程组确定两种工件的数量配比或双定位孔的相对坐标。

### 例题
分拣站某生产批次共分拣工件 50 件，存入合格料盒与不合格料盒。已知合格工件每个质量
为 80 g，不合格工件每个质量为 60 g，分拣完毕后料盒中工件总质量为 3700 g。
求分拣出的合格工件数 x 与不合格工件数 y。
解：
根据工件总数与总质量建立方程组：
x + y = 50 （式 1）
80x + 60y = 3700 （式 2）
采用代入消元法：
由式 1 得：y = 50 - x (式3)
将式 3 代入式 2：
80x + 60(50 - x) = 3700
展开化简：80x + 3000 - 60x = 3700
20x = 700，解得 x = 35
将 x = 35 代入式 3：y = 50 - 35 = 15。
答：合格工件为 35 件，不合格工件为 15 件。

### 常见错误
- 两式相减消元时，没有对减数方程的各项统统变号，导致常数项或其余项符号错误。
- 求出一个未知数后，代入计算另一个未知数时抄错或算错。

## 一元二次方程
只含有一个未知数，且未知数的最高次数是 2 的整式方程称为一元二次方程。其一般形式为
ax² + bx + c = 0（其中 a ≠ 0）。

求解一元二次方程的主要方法包括：
1. 因式分解法：若方程左边能分解为 (px + m)(qx + n) = 0，则 px + m = 0 或
   qx + n = 0。这是计算最快的方法。
2. 求根公式法：对于 ax² + bx + c = 0，根由公式确定：
   x = (-b ± √(b² - 4ac)) / (2a)
   其中式子 Δ = b² - 4ac 称为根的判别式。

判别式判据：
- 当 Δ > 0 时，方程有两个不相等的实数根；
- 当 Δ = 0 时，方程有两个相等的实数根；
- 当 Δ < 0 时，方程无实数根。

在机械工程设计中，负数根或无实根往往意味着该几何尺寸在物理上无法加工或不合理。

### 例题
定位夹具底座需要预留一个矩形安装槽，槽的长比宽多 20 mm，测量其开槽面积为 2400 mm²。
求该安装槽的宽 w 与长 L。
解：
设矩形安装槽的宽为 w mm，则长为 (w + 20) mm。
根据矩形面积公式列方程：
w(w + 20) = 2400
整理得一元二次方程一般形式：
w² + 20w - 2400 = 0
因式分解法：寻找积为 -2400、和为 20 的两数，为 60 与 -40。
(w + 60)(w - 40) = 0
解得：w₁ = -60，w₂ = 40。
由于尺寸必须大于 0，舍去负根 w = -60 mm，取 w = 40 mm。
长 L = w + 20 = 40 + 20 = 60 mm。
答：安装槽的宽为 40 mm，长为 60 mm。

### 常见错误
- 使用求根公式时，忘记分母是 2a 而不是 2，或将 -b 符号弄反。
- 求解出两个数学根后，忘记结合工程实际舍去负值或无物理意义的根。

## 单元小结
- 运算律与乘法公式是代数变形的基础，去括号与合并同类项时必须严格遵守符号规则。
- 一元一次方程通过移项与系数化为 1 求解单变量工况，是工程线性参数标定的基础工具。
- 公式变形通过恒等变换求解指定主元，是参数化建模与多物理量相互换算的必备能力。
- 二元一次方程组的核心是消元，代入法与加减法互为补充，可高效解决双变量几何与计数问题。
- 一元二次方程通过因式分解与求根公式求解二次关系，判别式决定解的存在性，须结合物理实际检验。
