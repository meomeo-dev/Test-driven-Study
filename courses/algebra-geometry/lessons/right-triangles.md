# 直角三角形与三角函数

本单元深入学习直角三角形的几何特性与三角函数定义，结合分拣站结构掌握边角解算与弧度弧长计算。

## 本单元知识点
- 勾股定理：直角三角形三边平方和关系、常用勾股数组合及直角逆定理判定。
- 正弦、余弦与正切：锐角的对边、邻边与斜边比值定义及特殊角三角函数值。
- 解直角三角形：已知边角求解其余未知量、反三角函数求角及工装坡度倾角。
- 弧度与弧长：弧度制几何意义、度与弧度转换关系及圆弧长计算公式。

## 勾股定理
在平面几何中，直角三角形两条直角边的平方和恒等于斜边的平方。设直角边长分别为 a
和 b，斜边长为 c，则三边满足基本方程：
a² + b² = c²
由该公式可直接导出求斜边与直角边的计算式：c = √(a² + b²)，b = √(c² - a²)。
在分拣站工装夹具加工中，该公式用于精确定位斜向安装孔与导轨支架中心距。

勾股数是指能够满足 a² + b² = c² 的三个正整数组合。最基础且常用的组合是 3-4-5，
以及由它成比例缩放得到的 6-8-10、15-20-25、30-40-50 等；此外 5-12-13 也是常见的
工程勾股数。掌握勾股数可以在不使用计算器的情况下迅速心算出常见标准结构的尺寸。

勾股定理逆定理规定：若一个三角形的三边长满足 a² + b² = c²，则该三角形必为直角
三角形，其中 c 为最长边且对角为 90° 直角。在装配分拣工位滑轨和垂直立柱时，常
通过测量三点间的直线距离来快速检验两个构件是否严格垂直。

### 例题
分拣站的相机立柱与水平工作台呈直角分布。装配技工在立柱上距台面 60 mm 处打孔，
在工作台上距立柱 80 mm 处打孔，准备安装一根斜向支撑杆。求两安装孔的中心距 c。
解：
1. 识别几何条件：直角三角形两直角边 a = 60 mm，b = 80 mm。
2. 根据勾股定理：
c² = a² + b² = 60² + 80² = 3600 + 6400 = 10000 mm²
3. 开平方求斜边：
c = √10000 = 100 mm
也可直接利用 3-4-5 勾股数扩大 20 倍快速得出支撑杆安装孔距为 100 mm。

### 常见错误
- 求直角边时误用加法：已知斜边 c 和一条直角边 a，求另一边时错写为
  b = √(c² + a²)，正确计算应减去已知直角边的平方。
- 混淆直角边与最长斜边：代入公式前未确认哪一条边与 90° 直角相对，误将直角边当
  成斜边代入，导致计算结果严重失真。

## 正弦、余弦与正切
在直角三角形中，指定一个锐角 θ 后，三条边根据相对位置具有唯一命名：与角 θ 相
对的直角边称为对边（opposite），与角 θ 相邻的直角边称为邻边（adjacent），直角
所对的最长边称为斜边（hypotenuse）。

锐角三角函数定义为两边长度的比值，与三角形的实际尺寸大小无关，仅取决于角度：
正弦：sin θ = 对边 / 斜边
余弦：cos θ = 邻边 / 斜边
正切：tan θ = 对边 / 邻边 = sin θ / cos θ
对于任意锐角，其正弦与余弦取值均介于 0 与 1 之间，而正切值随角度增大可超过 1。

工程常用特殊角（30°、45°、60°）的三角函数值必须熟记：
- 30° 角：sin 30° = 1/2 = 0.5，cos 30° = (√3)/2 ≈ 0.866，tan 30° = (√3)/3 ≈ 0.577
- 45° 角：sin 45° = (√2)/2 ≈ 0.707，cos 45° = (√2)/2 ≈ 0.707，tan 45° = 1
- 60° 角：sin 60° = (√3)/2 ≈ 0.866，cos 60° = 1/2 = 0.5，tan 60° = √3 ≈ 1.732

### 例题
分拣站的下料滑槽与水平地面呈 30° 倾角，已知工件下滑的导轨斜面长度为 200 mm。
求下料滑槽的垂直高度 h 与水平跨度 L。
解：
1. 确定几何元素：倾角 θ = 30°，斜边 c = 200 mm。
2. 计算垂直高度 h（30° 角的对边）：
h = c · sin 30° = 200 · 0.5 = 100 mm
3. 计算水平跨度 L（30° 角的邻边）：
L = c · cos 30° = 200 · ((√3)/2) = 100√3 ≈ 173.2 mm

### 常见错误
- 颠倒对边与邻边的相对位置：观察锐角时未立足于该角顶点，误将邻边当成对边，
  导致正弦与余弦公式用反。
- 记混特殊角的正弦与余弦值：例如误记 sin 30° 为 (√3)/2，造成工程估算数值出现
  明显偏差。

## 解直角三角形
解直角三角形是指根据直角三角形中已知的局部元素（边长或角度），推算出所有未知
元素的过程。直角三角形两锐角互余，即 A + B = 90°；三边满足勾股定理 a² + b² = c²。

解直角三角形的核心求解路径分为两类：
1. 已知两边：若已知两直角边 a 和 b，先求斜边 c = √(a² + b²)，再通过正切比值由
反三角函数求角：A = arctan(a/b)；若已知一边与斜边，先求另一边再求锐角。
2. 已知一边一锐角：已知角 A 可直接求出另一角 B = 90° - A，再利用正弦或余弦公
式分别乘除已知边长求出未知各边。

反三角函数是三角函数的逆运算：若已知 tan θ = y/x，则通过反正切 θ = arctan(y/x)
即可计算出倾角 θ 的度数。工程设计中斜面坡度定义为垂直高差与水平跨度之比，即
坡度 i = 高差 / 水平距 = tan α，因此坡面倾角 α = arctan(i)。

### 例题
分拣站的推料气缸驱动一块直角斜楔块，底面水平跨度为 80 mm，垂直顶升高度为
20 mm。求该斜楔块的坡度 i，斜面与底面的倾角 θ（保留一位小数），以及斜边长 c。
解：
1. 计算坡度 i：i = 高度 / 水平跨度 = 20 / 80 = 0.25（即 1:4 或 25%）。
2. 计算倾角 θ：tan θ = 0.25，取反正切 θ = arctan(0.25) ≈ 14.0°。
3. 计算斜边长度 c：c = √(80² + 20²) = √(6400 + 400) = √6800 ≈ 82.5 mm。

### 常见错误
- 坡度计算上下颠倒：误将水平跨度除以垂直高差，算成了坡度的倒数。
- 计算反三角函数时量纲模式错误：计算器或脚本默认处于弧度模式，未切换至角度
  模式（DEG），导致算出的倾角值出现巨大偏差。

## 弧度与弧长
在平面几何与运动控制中，弧度（radian）是用半径度量圆周弧长的单位制度。当一段
圆弧的长度 s 恰好等于该圆的半径 r 时，该圆弧所对应的圆心角大小被定义为 1 弧度。

因为半径为 r 的整圆周长为 2πr，对应的圆心角为 360°，所以有严格等式：
2π rad = 360°，即 π rad = 180°
由此得出角度与弧度的相互换算规则：
- 度转弧度：θ_rad = deg · (π / 180)，例如 90° = π/2 rad，45° = π/4 rad。
- 弧度转度：deg = θ_rad · (180 / π)，1 rad ≈ 180° / 3.1416 ≈ 57.296°。

在弧度制下，圆弧长度计算极为简捷：
s = r · θ（其中 θ 必须是以弧度为单位的圆心角）
若圆心角以角度制给出为 n°，则必须先转换为弧度，写为 s = r · (n · π / 180)。

### 例题
分拣工位合格品料盒前的分拣摆臂旋转半径为 120 mm，单片机控制其摆动 45° 角将
工件拨入料盒。求摆角对应的弧度值，以及摆臂末端划过的弧长 s（取 π ≈ 3.1416）。
解：
1. 换算弧度：θ = 45 · (π / 180) = π/4 rad ≈ 0.7854 rad。
2. 计算弧长：s = r · θ = 120 · (π/4) = 30π ≈ 30 · 3.1416 ≈ 94.2 mm。

### 常见错误
- 弧长公式直接代入角度制：未将角度转换为弧度，直接计算 120 · 45，导致弧长算
  大数十倍。
- 换算系数方向乘反：度转弧度时误乘了 180/π，使得转换后的数值量级严重畸变。

## 单元小结
- 勾股定理 a² + b² = c² 是解析直角三角形边长几何关系的基础，逆定理用于直角检验。
- 正弦、余弦与正切定义了锐角边长比率，熟记 30°、45°、60° 特殊角值可快速估算。
- 解直角三角形结合勾股定理与反三角函数，可系统推算斜楔工装的坡度、高差与倾角。
- 弧度制通过弧长与半径之比建立角量度，弧长公式 s = rθ 实现了转角与线位移的统一。
