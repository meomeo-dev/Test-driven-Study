# 基尔霍夫定律

本单元围绕桌面质检分拣站的低压供电与传感接口，深入学习基尔霍夫电流定律
（KCL）、基尔霍夫电压定律（KVL）以及节点电压法的基本分析方法，为多支路
电路的参数计算与故障排查奠定基础。

## 本单元知识点

- 基尔霍夫电流定律：掌握集总电路节点的电流汇聚规律，理解流入节点电流之和等于流出电流之和。
- 基尔霍夫电压定律：掌握闭合回路电压升降平衡规律，理解沿闭合回路各段电压代数和为零。
- 节点电压法入门：掌握以参考地为基准电位，对未知独立节点建立 KCL 方程求解节点电压。

## 基尔霍夫电流定律

在桌面质检分拣站的电路中，各模块往往共用电源母线或在某处汇集，形成多个支路
相交的点。电路中三个或三个以上支路交汇的电气连接点被称为“节点”（Node）。

基尔霍夫电流定律（Kirchhoff's Current Law, 简称 KCL）是电路分析的核心定律
之一，其物理本质是电荷守恒定律：电荷在集总电路的任何节点处既不能被凭空产生，
也不能凭空消失或持续堆积。

KCL 的核心内容与公式表达：
1. 在任意时刻，流入任一节点的电流总和等于流出该节点的电流总和，即：
   ∑ I_流入 = ∑ I_流出
2. 若规定流入节点的电流为正（+），流出节点的电流为负（-），则汇聚于任一
   节点的各支路电流代数和恒等于零，即 ∑ I = 0。
3. 在分拣站工位中，5 V 稳压电源母线节点同时为单片机主控板、到位红外光电
   传感器和指示灯供电，输入该节点的总电流必定等于各个负载支路吸收电流的总和。

### 例题

在桌面质检分拣站电气柜中，开关电源输出的 5 V 主供电线引入接线端子节点 A。
已知从外部电源流入节点 A 的总电流为 1200 mA。该节点引出三条负载支路：
单片机主控板吸收电流 180 mA，到位传感器模块吸收电流 40 mA，其余电流全部
提供给分拣舵机驱动模块。求流入舵机驱动模块的电流为多少毫安？

解答步骤：
1. 确定研究对象与参考方向：选取接线端子 A 为分析节点。主电源电流向节点 A
   流入，三条负载支路电流均自节点 A 向外流出。
2. 依据 KCL 列写电流平衡方程：
   I_输入 = I_单片机 + I_传感器 + I_舵机
3. 代入已知数据（单位统一为 mA）：
   1200 = 180 + 40 + I_舵机
   1200 = 220 + I_舵机
4. 求解未知电流：
   I_舵机 = 1200 - 220 = 980 mA
答：流入分拣舵机驱动模块的电流为 980 mA（即 0.98 A）。

### 常见错误

- 单位未统一：直接将安培（A）与毫安（mA）数值混合运算，导致计算结果产生
  上千倍的数量级偏差。
- 参考方向混淆：未仔细辨别支路电流是“流入”还是“流出”节点，误将同侧流出的
  电流放在等号两侧相减。
- 漏算并联支路：忽视了微小的板载状态指示灯或传感器支路电流，导致电流核算
  出现缺漏。

## 基尔霍夫电压定律

在分拣站的执行机构回路（如 12 V 推杆电磁阀或电机驱动）中，电流沿导线从电源
正极出发，流经保护电阻、驱动管和负载线圈后返回电源负极，构成闭合路径。电路中
由若干支路组成的任何一条闭合路径被称为“回路”（Loop）。

基尔霍夫电压定律（Kirchhoff's Voltage Law, 简称 KVL）的物理本质是能量守恒
定律：在集总电路中，电荷沿任意闭合路径移动一周返回起点，电场力所作的净功为零，
其电位变化量总和必定为零。

KVL 的核心内容与公式表达：
1. 沿任意选定的闭合回路绕行方向（顺时针或逆时针），各段电压降的代数和
   恒等于零，即 ∑ U = 0。
2. 也可表述为：沿闭合回路绕行一周，电位升高的总和等于电位降低的总和，即：
   ∑ U_升 = ∑ U_降
3. 绕行正负号判定约定：若绕行方向从元件负极跨向正极（电位升高），计为电位升；
   若绕行方向与电阻中的电流方向一致跨过电阻（电位降低），则产生数值为
   U = I × R 的电压降。

### 例题

分拣工位的电磁推杆驱动回路中，直流稳压电源提供 12 V 输出。该回路顺次串联了
一个 2 Ω 的检流保护电阻 R_s、一个导通工作状态的 MOS 管开关、以及推杆线圈。
已知回路正常吸合电流为 1.5 A，MOS 管完全导通时的管压降为 0.6 V。求电磁推杆
线圈两端获得的实际工作电压为多少伏？

解答步骤：
1. 确定回路与绕行方向：选定沿回路电流流向（顺时针）进行绕行一周。
2. 计算已知元件上的电压降：
   - 检流电阻上的电压降 U_s = I × R_s = 1.5 A × 2 Ω = 3.0 V。
   - MOS 管导通压降已知 U_mos = 0.6 V。
3. 根据 KVL 列写闭合回路电压升降平衡方程（电源电位升 = 各负载电位降之和）：
   E = U_s + U_mos + U_coil
4. 代入数值求解：
   12 = 3.0 + 0.6 + U_coil
   12 = 3.6 + U_coil
   U_coil = 12 - 3.6 = 8.4 V
答：电磁推杆线圈两端的实际工作电压为 8.4 V。

### 常见错误

- 回路遗漏元件：在列写回路方程时，只关注主要负载，遗忘了采样电阻、线缆内阻
  或开关管自身的导通压降。
- 绕行符号颠倒：在沿回路累加电压时，正负极性判断不一致，把电源的升压与电阻的
  降压写在同侧相加，造成方程错误。

## 节点电压法入门

当分拣工位的电路变得更加复杂，例如包含多个分压电阻网络、多路稳压基准源或
传感器交汇接口时，逐个列写回路方程不仅繁琐，而且容易产生冗余。

节点电压法（Node Voltage Method）是以电路中各节点的“电位”作为未知量，
对独立节点列写 KCL 方程，进而求解全电路各支路电学量的系统化方法。

求解单独立未知节点的标准四个步骤：
1. 选定参考地（Reference Node）：在电路中选取公共汇流排或电源负极作为
   参考零电位点（GND），设其电位 V_GND = 0 V。
2. 标定未知节点：找出连接了三个或以上支路的非参考节点，设其对地电位为 V_A。
3. 用节点电位表达各支路电流：假定所有支路电流均从节点 A 向外流出。若某支路
   经电阻 R 连接至已知电位点 V_k，则由欧姆定律可得流出电流：
   I = (V_A - V_k) / R
4. 对节点 A 列 KCL 方程并求解：令流出该节点的所有支路电流之和等于零：
   ∑ (V_A - V_k) / R_k = 0

### 例题

在桌面分拣站的光敏电阻比较器前端，信号节点 A 汇集了三条支路：
- 支路 1 经电阻 R1 = 200 Ω 接至 5 V 传感器基准电源；
- 支路 2 经电阻 R2 = 300 Ω 接至系统地（0 V）；
- 支路 3 经电阻 R3 = 600 Ω 接至单片机的 3.3 V 辅助偏置电源。
已知比较器输入端为高阻态（流入电流视为 0 A）。请用节点电压法求节点 A 的
对地电压 V_A。

解答步骤：
1. 选系统公共地为参考节点，电位为 0 V，待求节点为 A，电位记为 V_A。
2. 假定各支路电流均自节点 A 向外流出：
   - 流向 5 V 电源支路的电流：I_1 = (V_A - 5) / 200
   - 流向 0 V 参考地支路的电流：I_2 = (V_A - 0) / 300
   - 流向 3.3 V 电源支路的电流：I_3 = (V_A - 3.3) / 600
3. 根据 KCL，对节点 A 列写流出电流代数和方程：
   (V_A - 5) / 200 + V_A / 300 + (V_A - 3.3) / 600 = 0
4. 方程两边同乘以公倍数 600 去分母：
   3 × (V_A - 5) + 2 × V_A + 1 × (V_A - 3.3) = 0
   3 V_A - 15 + 2 V_A + V_A - 3.3 = 0
   6 V_A - 18.3 = 0
   6 V_A = 18.3
   V_A = 18.3 / 6 = 3.05 V
答：信号节点 A 对地的电压为 3.05 V。

### 常见错误

- 支路电流电位差颠倒：在写 (V_A - V_k) / R 时，将首末电位写反，导致方程中
  正负号混乱。若设定为流出电流，必须统一用“本节点电位减去对端节点电位”。
- 忘记设定参考地：未明确以 GND（0 V）为基准，导致算出的数值失去物理参考依据。
- 忽视恒流或高阻支路特性：当支路有确定的恒流源时误除以电阻；或者未注意到运放/
  单片机高阻输入脚的电流近似为 0 A。

## 单元小结

- 1. 基尔霍夫电流定律（KCL）揭示了节点电荷守恒，任意时刻流入节点的电流之和
     恒等于流出电流之和，是分析并联与多分支负载供电分配的基础。
- 2. 基尔霍夫电压定律（KVL）揭示了回路能量守恒，沿闭合回路绕行一周电压代数和
     为零（升等于降），是校核驱动回路压降、导通裕量及器件选型的准则。
- 3. 节点电压法以公共地（0 V）为参考，通过设定未知节点电位并对该节点列写 KCL
     方程，极大地简化了多电源与多电阻互联网络的求解过程。
- 4. 在实际分拣工位电路设计中，严格标定电流流向与电位参考点，统一物理量单位，
     是确保计算正确并快速排除工位电路故障的关键习惯。
