# 电路基础

用电压、电流和功率分析低压传感器与执行器电路。

## 学习起点

会四则运算和单位换算。实验使用低压直流供电。

- 欧姆定律 → 串并联 → 万用表实测 → 传感器信号检查。

## 学完能做什么

- 区分电压、电流、电阻和功率。
- 计算串并联关系和简单分压。
- 在接入开发板前核对电源、地和信号电平。

**桌面质检分拣站实作**。搭建一个 5 V 电阻分压电路，先计算再测量中点对地的电压。

## 课程内容

1.1.0 版包含七个单元、30 个知识点和 144 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成
学习顺序。表中同一单元的知识点以分号分隔。

| 单元 | 知识点 |
| --- | --- |
| 电学量与单位 | 电流与电荷；电压、电位与地；电阻与导体；单位与词头换算；功率与电能 |
| 欧姆定律与功率计算 | 欧姆定律；功率计算；电阻额定功率与选型 |
| 串联、并联与分压 | 串联电路；并联电路；混联电路化简；电阻分压 |
| 基尔霍夫定律 | 基尔霍夫电流定律；基尔霍夫电压定律；节点电压法入门 |
| 万用表测量与安全 | 测电压（并联）；测电流（串联）；测电阻与通断；低压实验安全与电源；面包板与接线；5 V 分压实测（自评） |
| 元件与传感器信号 | 电容与 RC 时间常数；LED 与限流电阻；开关与上拉、下拉电阻；传感器信号与电平检查；三极管与 MOSFET 开关 |
| 电源、负载与故障排查 | 直流电源与稳压；负载与电机供电；电路故障排查；传感器接口实作（自评） |

“5 V 分压实测”和“传感器接口实作”是自评实作，没有练习题。
按[万用表测量与安全讲义](lessons/measurement.md)和[电源、负载与故障排查讲义](lessons/power-loads.md)中的自评清单完成后，
在学习路径中标记已会。
