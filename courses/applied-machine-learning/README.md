# 机器学习与工业质检

建立缺陷分类基线，用独立批次验证漏检、误剔和延迟。

## 学习起点

会 Python，并理解比例和基本统计。先做出能运行的视觉检测基线。

- 标注缺陷 → 建立基线 → 训练与调阈值 → 用独立批次验收。

## 学完能做什么

- 理解分类阈值和混淆矩阵。
- 按实物或批次划分训练、验证和测试数据。
- 用同一测试集比较规则法与模型。

**桌面质检分拣站实作**。在独立工件批次上记录真实结果、规则法判定和模型判定，报告漏检率、误剔率和处理耗时。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 机器学习与质检任务 | 机器学习任务类型；规则法基线；特征、标签与样本 |
| 数据与标注 | 缺陷标注规范；训练、验证与测试划分；类别不平衡；特征缩放与预处理 |
| 基础模型 | k 近邻；逻辑回归与概率输出；决策树与随机森林；损失函数与梯度下降 |
| 评估与阈值 | 混淆矩阵；精确率、召回率与 F1；阈值与 ROC 曲线；按代价选择阈值 |
| 泛化与调参 | 过拟合与欠拟合；交叉验证；超参数调节；正则化 |
| 图像分类与复现 | 图像特征与卷积网络入门；数据增强；建模流水线与复现 |
| 上线验收 | 处理耗时与吞吐；独立批次验收；数据漂移与监控；规则法与模型对比验收（自评） |

“规则法与模型对比验收”是自评实作，没有练习题。
按[上线验收讲义](lessons/deployment.md)中的自评清单完成后，
在学习路径中标记已会。
