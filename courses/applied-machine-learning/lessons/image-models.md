# 图像分类与复现

本单元学习工业视觉质检中的深度特征提取、数据增强与建模流水线，掌握利用
预训练卷积网络提取特征结合轻量分类器解决小样本缺陷检测的方法，并建立
严防数据泄露的工程化可复现流程。

## 本单元知识点

- 图像特征与卷积网络入门：对比手工特征与自主学习特征，理解卷积核局部感受
  野与参数共享机制，利用迁移学习应对工业质检小样本过拟合风险。
- 数据增强：掌握小范围旋转、微小平移与光照微调等变换方法，严格遵循物理
  标签语义不变原则，坚守增强变换仅作用于训练集的边界。
- 建模流水线与复现：使用 scikit-learn Pipeline 将预处理与分类器严格绑定以
  阻断数据泄露，结合随机种子、数据版本哈希与超参数记录实现完整实验复现。

## 图像特征与卷积网络入门

在桌面质检分拣站中，工件表面缺陷（如划痕、裂纹、杂质等）通常形态多变。
传统规则法主要依赖工程师手工设计的几何与统计特征（如灰度直方图、投影长
宽比、连通域面积与梯度算子）。手工特征对复杂背景、环境光漂移和形态变异
极为敏感，泛化能力脆弱。而卷积神经网络（CNN）通过多层网络结构端到端自
主学习特征：浅层网络自发捕获低阶的边缘、纹理与斑块等局部细节，深层网络
逐步组合出工件局部轮廓与复杂缺陷的高阶语义表征。

卷积层的核心计算机制在于局部感受野与权重共享。卷积核（滤波器）以滑动
窗口形式在二维图像平面上移动，与局部图像像素进行逐点相乘累加并加上偏置。
相比每个输入输出节点全互联的全连接层，局部连接保留了图像二维网格的空间
拓扑邻近关系；同一卷积核在整张图像上使用同一组权重参数，极大地削减了待
学习的参数规模，赋予了网络对缺陷位置的平移鲁棒性。

工业现场最大的现实约束是缺陷样本极其稀缺，桌面分拣工位初期往往仅能收集
到几十张真实缺陷工件图像。如果从头随机初始化训练一个包含数百万参数的深
度网络，模型会迅速“死记硬背”训练样本中的夹具阴影或背景噪点，导致训练
损失接近零但线上验证严重失效的过拟合灾难。工业落地推荐采用迁移学习
（Transfer Learning）：直接加载在大规模通用视觉数据集（如 ImageNet）上
训练完毕的骨干网络（Backbone），冻结其所有卷积特征提取层权重，仅将其输
出的特征向量送入逻辑回归或单层轻量分类器进行训练。

### 例题

质检分拣站新部署了冲压零件表面划痕检测任务。产线采集到 30 张划痕缺陷图像
和 120 张合格工件图像。工程师面对两种技术路线：
方案甲：新建一个 5 层卷积神经网络，从头初始化所有权重并训练 200 轮；
方案乙：使用开源轻量预训练网络提取 512 维特征向量，冻结特征层，仅训练一
个二分类逻辑回归分类器。
请从过拟合风险与工程可行性角度进行对比评估，并给出选择建议与理由。

完整解答：
应选用方案乙。
理由分析：
1. 过拟合风险：缺陷样本仅 30 张，总样本量 150 张，属于典型的小样本困境。
   方案甲即使只有 5 层卷积，参数量仍达数十万，参数自由度远超样本信息量，
   模型极易过度拟合背景杂色与特定工件微小划痕，导致泛化性能崩溃；方案乙
   顶层逻辑回归仅需学习 512 个权重与 1 个偏置共 513 个参数，自由度受限，
   能强力抑制小样本过拟合。
2. 工程可行性：方案乙复用了成熟网络提取通用边缘、纹理特征的能力，特征提
   取后逻辑回归收敛迅速，工控机在推断时计算开销小，适合产线毫秒级节拍。

### 常见错误

- 误将训练集准确率 100% 视作上线标准：在小样本缺陷集上从头训练深度网络，
  极易因参数过度拟合得到虚高训练指标，但真实分拣时漏检率和误剔率居高不下。
- 盲目放开全部网络层微调：在仅有几十张缺陷图时对整个骨干网络解冻训练，
  反向传播的大梯度会破坏预训练权重已有的通用视觉特征，造成负迁移。

## 数据增强

数据增强通过对已有训练样本施加确定性或随机的变换，人为合成更多逼真的变
体，以此扩充训练数据分布的多样性，促使模型学习对无关扰动不敏感的不变性
表征。在工件由定位夹具固定、上方光源照明的工业分拣工位中，合理的数据增
强方式包括：在机械定位间隙允许的微小范围内做随机旋转与小幅度平移、模拟
供电或环境光微弱漂移的小范围亮度与对比度微调。

数据增强的第一核心红线是绝不能破坏物理标签语义。增强操作必须严格受限于
真实工况的物理规律。如果对带有单向安装凹槽的工件做镜像翻转，就会把“方
向装反”的缺陷样本翻转为“装配正确”，导致严重的标签污染；若亮度增强过
度，使微弱裂纹的灰度差被截断饱和消失，模型就会被灌入“无缺陷”的假标
签；若几何变形过大导致工件尺寸比例失真，会破坏基于几何形状的判定规则。

数据增强的第二核心红线是增强只能应用于训练集。测试集与验证集的唯一使命
是真实、客观地度量模型在产线未见原始图像上的真实判别能力，必须百分之百
保留真实物理分布。如果在划分训练集与测试集之前对整个数据集先做增强，同
一张工件母图的不同变体就会同时渗入训练集和测试集，造成严重的数据泄露，
导致离线评估指标虚高，完全失去对分拣站实际漏检率与误剔率的预测价值。

### 例题

桌面分拣工位用于检测轴承端面的微小裂纹。轴承在圆形定位槽内可自由转动，
相机垂直下照，顶置环形光源照明。工程师准备在图像处理脚本中加入以下三种
数据增强策略：
策略一：[0°, 360°] 全范围随机旋转；
策略二：随机将像素灰度值完全反转（255 - 原始值）；
策略三：在执行 5 折交叉验证划分前，先将全部原始图像各旋转扩充 4 倍。
请逐一判断各项策略是否合理，并说明工程理由。

完整解答：
策略一合理。轴承为圆形结构，工件在圆形定位槽内具有天然的旋转对称性，自
然状态下可能以任意角度进入拍摄视野，全角度随机旋转完全契合真实物理工况，
有助于模型学习旋转不变性。
策略二不合理。灰度反转会使原本呈现暗条纹的凹陷裂纹变成发亮线条，原本反
光的金属基底变成暗色，颠倒了光照反射与微观形貌的物理对应关系，破坏了标
签原有的视觉语义。
策略三不合理。在数据划分前统一扩充会导致同一张轴承原图的不同旋转版本被
随机分入训练折与验证折，造成严重的验证集信息泄露，使交叉验证指标脱离产
线实际表现。正确操作应是在每折切分后仅对训练折进行独立数据增强。

### 常见错误

- 划分前全量增强：先扩充数据总量再做训练与测试划分，致使测试集混入衍生
  副本，制造虚假的极高准确率。
- 盲目套用自然图像极端增强：在工件检测中直接引入大角度透视扭曲或色彩抖
  动，改变了缺陷形态与材质固有色泽，导致模型学到错误特征。

## 建模流水线与复现

工业视觉检测系统的特征预处理（如特征归一化 StandardScaler、降维 PCA 等）
包含均值、标准差或主成分方向等待拟合统计量。若在整个数据集上计算这些统
计量，测试集或验证集的分布特征就会在模型训练前提前泄漏，造成评估结果
盲目乐观。scikit-learn 的 Pipeline 将一系列数据转换步骤与最终分类器串联
组装为一个原子化的评估器对象。在调用 fit 方法时，流水线仅依据当前训练集
拟合转换器；在 predict 时，自动沿用训练集固化的统计量转换新样本，在架构
层级切断了数据泄露途径。

为了保证实验与算法交付结果可检验，必须对随机性进行显式控制。在样本划
分（如 train_test_split）、交叉验证分折（KFold）以及具有随机特性的分类器
（如随机森林、带有随机求解器的逻辑回归）中，均需固定随机种子（如
random_state=42）。固定种子确保了同一软硬件环境下算法输出的一致性。需
注意，随机种子不能消除模型方差；若改变种子后模型在测试集上的漏检率剧烈
跳变，表明模型对数据扰动过敏，应重点扩充样本或降低模型复杂度。

完整的工业质检模型复现体系必须同时固化三个要素：
1. 数据集版本：冻结训练集与测试集图片清单，记录样本图像与标签文件的
   哈希指纹（如 SHA-256），避免原始文件增删改动导致评估基准漂移；
2. 代码与流水线架构：将特征提取、标准化与分类器超参数完整封装于可执
   行代码中，消除手动临时预处理；
3. 运行环境与工位元数据：登记 Python 依赖库版本、相机曝光增益配置、
   分拣决策阈值以及混淆矩阵测试指标基线。

### 例题

某质检工程师编写了如下模型评估代码：
```python
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42
)
pipe = Pipeline([
    ('scaler', StandardScaler()),
    ('clf', LogisticRegression(random_state=42))
])
pipe.fit(X_train, y_train)
```
请分析：
1. 该代码中 StandardScaler 的均值与方差是在哪个数据集上计算得出的？
2. 后续使用 pipe.predict(X_test) 对测试集进行预测时，测试样本的标准化
   参数来自哪里？这种设计是如何避免数据泄露的？

完整解答：
1. 在执行 pipe.fit(X_train, y_train) 时，StandardScaler 仅在 X_train（
   训练集）上调用 fit 计算特征的均值与方差。
2. 后续调用 pipe.predict(X_test) 时，StandardScaler 仅调用 transform，
   直接使用训练集固化好的均值与方差对测试样本进行缩放，绝不会重新根据测试
   集计算均值或方差。这种机制确保了测试集数据对模型完全保持“不可见”，严
   格杜绝了测试集信息渗入特征工程所导致的数据泄露。

### 常见错误

- 预处理全局执行：在切分数据集前直接对全量特征调用 fit_transform，导致测
  试集先验统计信息泄露。
- 忽视环境与数据哈希：仅在代码中写死 random_state，但未锁定数据文件版本与
  三方库依赖，导致重新拉取代码后无法复现指标。

## 单元小结

- 工业微小缺陷样本场景下，直接从头训练深度卷积网络面临极大过拟合风险，
  推荐利用在大规模通用数据集上预训练的卷积网络提取特征，并微调顶层分类器。
- 卷积核利用局部感受野捕获空间拓扑结构，并通过权重共享机制大幅压缩参数量。
- 数据增强必须受制于实际工况的物理规律，保持标签语义不变，且只能作用于
  训练集，严禁对测试集与验证集进行合成增强。
- 采用 scikit-learn Pipeline 将预处理与模型绑定，可从工程机制上避免预处理
  环节的数据泄露；结合固定的随机种子、数据版本哈希与超参数记录，保障质检系统全生命
  周期的可复现性与可审计性。
