# 数据与标注

本单元围绕桌面质检分拣站的数据工程核心环节，系统学习缺陷标注规范、数据集防泄漏划分、
类别不平衡应对策略以及特征预处理标准工程规程。

## 本单元知识点
- 缺陷标注规范：掌握缺陷类别定义与图例、双人一致性评估、争议样本仲裁及标签噪声防控。
- 训练、验证与测试划分：理解三类数据集职责，掌握按工件实体分组划分与数据泄漏防范机制。
- 类别不平衡：剖析工业低缺陷率下的准确率失真陷阱，掌握分层抽样、代价敏感权重与重采样。
- 特征缩放与预处理：掌握标准化与归一化计算，严格落实训练集参数单向传递与缺失值填补规程。

## 缺陷标注规范

工业质检模型的效果上限由标注数据的质量决定。标注规范（Labeling Guideline）是
质检员与算法开发人员共同遵循的技术协议。规范中必须对良品基准以及各类缺陷
（如金属工件的表面划痕、冲压凹坑、油污杂质、边缘裂纹）给出明确的物理定义，
包括最小缺陷长度、宽度、面积阈值以及典型光学反射特征，并附带合格与不合格的标杆金样图例。

在多人协作或多批次生产标注中，必须对标注一致性（Labeling Consistency）进行定量监控。
常用评估方法是由两名质检员对同一批工件图像进行独立盲测标注，计算两者判定完全一致的
样本比例（一致样本数 / 总比对样本数）。若一致率低于预设工程门槛（如 90%），
则表明缺陷边界定义模糊或光照条件引起判断歧义，需要及时召集评审并更新作业指导书。

针对边缘反光微弱、划痕深浅处于临界状态的疑难样本，严禁标注人员凭主观猜测随意归类。
规范的工程处置流程是设立“争议样本池”，由高级质检工程师与工艺专家集中复核仲裁，
或者在分拣工位上调整光源角度进行二次复拍确认。

标注错误会导致数据集中存在标签噪声（Label Noise）。标签噪声会使分类模型学到错误的
特征关联，造成决策边界严重偏移；若模型过度拟合了错误标签，还会导致离线评估指标失真，
在流水线在线推理时引发不可控的漏检或误剔。

### 例题
桌面分拣站采集了 200 个带金属反光的轴承工件图像。两名质检员独立盲标，结果如下：
两人均判定为良品的工件有 160 个，均判定为划痕缺陷的有 26 个；质检员甲判定为缺陷而
乙判定为良品的有 8 个，甲判定为良品而乙判定为缺陷的有 6 个。请计算两名质检员的
标注一致率，并给出针对分歧样本的处理建议。

解答：
两名质检员判定完全一致的样本总数 = 160 + 26 = 186 个。
标注一致率 = 186 / 200 = 0.93，即 93.0%。
对于存在分歧的 14 个样本（8 + 6），严禁直接丢弃或随机指派标签，应将其提取至争议样本池，
由质检主管对照标准金样图例进行终审裁定，并将判定特征增补到标注指南中。

### 常见错误
- 缺陷定义缺乏量化尺寸门槛，仅凭质检人员主观感觉区分“轻微划痕”与“良品”。
- 将难以判定的临界样本直接删除，导致训练集丢失真实工况中的边缘过渡特征。
- 盲目相信单人单次标注结果，未建立跨人员盲测比对与抽样复验机制。

## 训练、验证与测试划分

机器学习模型开发必须将数据集严格划分为训练集、验证集和测试集三个独立集合。
训练集用于模型学习内部可学习参数（如权重和偏置）；验证集用于监控过拟合、调整超参数
以及比对不同模型架构的表现；测试集用于最终评估模型的泛化能力，在整个研发流程中
仅在最终验收阶段运行评估一次。

桌面质检分拣工位的典型采集流程是：同一个工件放置在定位夹具上，经步进电机旋转或多角度相机
连续拍摄多张图片。划分数据集时，必须以“工件物理实体（Workpiece ID）”或“生产批次（Batch）”
为单位执行分组划分（Group Split），确保同一个工件的所有关联图片完整归入同一个子集。

如果直接对所有图片执行简单的随机打乱切分，同一个工件的不同角度照片就会同时散落在训练集和
测试集中。这种现象称为数据泄漏（Data Leakage）。此时模型并非学会了通用的缺陷特征，
而是记住了该特定工件的特有背景划痕、材质纹理或反光噪点，导致离线评估分数虚高，
但上线部署到新工件流水线后识别准确率严重衰退。

### 例题
分拣工位共有 300 个加工工件，每个工件在固定夹具上被工业相机拍摄 3 张照片
（正面、侧面 45 度、侧面 135 度），总计 900 张图像。若按 70%:15%:15% 的比例划分
训练集、验证集和测试集，应如何执行划分以杜绝数据泄漏？测试集中包含多少张图片？

解答：
划分必须按工件实体 ID 执行分组划分，不能直接按 900 张图片随机乱序切分。
工件总数为 300 个，测试集分得工件数 = 300 × 15% = 45 个工件。
验证集分得工件数 = 300 × 15% = 45 个工件，训练集分得工件数 = 300 × 70% = 210 个工件。
测试集包含的图像总数 = 45 × 3 = 135 张。
同理验证集包含 135 张图像，训练集包含 630 张图像。
这样保证任何工件的多角度照片绝不跨集合交叉分布。

### 常见错误
- 在图像文件级别直接调用打乱拆分函数，导致同一工件的不同视角图片跨集泄漏。
- 在观察测试集的低分表现后，反向调整特征工程方法或模型参数，使测试集失去无偏检验价值。
- 划分时未考虑生产批次效应，测试集未包含不同机床或原材料批次生产的样本。

## 类别不平衡

在工业自动化质检产线中，成熟生产工艺的良品率通常在 95% 乃至 99% 以上，采集到的真实缺陷
工件（正类）在总样本中占比极低。如果直接采用分类准确率（Accuracy）评估模型，当模型将
所有工件全部无脑判定为良品时，准确率依然可高达 99%，但对缺陷工件的漏检率却达到 100%，
这在工业生产中会导致严重的不合格品流出事故。

为了在划分数据集时不丢失本就稀少的缺陷样本，必须采用分层抽样（Stratified Split）。
分层划分能够确保训练集、验证集和测试集中的缺陷与良品比例与全集总体分布严格保持一致，
避免测试集因为随机采样出现缺陷样本过少甚至为零的极端情况。

在模型训练层面，解决类别不平衡的核心手段包括：
1. 代价敏感学习（Cost-sensitive Learning）：在损失函数中引入类别权重（如 class_weight='balanced'），
   将漏检缺陷（FN）的惩罚系数设置为误剔良品（FP）的数倍至数十倍。
2. 重采样技术：在训练集内部对少数类缺陷样本进行过采样（如图像仿射变换增强、特征合成），
   或者对多数类良品样本进行有代表性的欠采样，平衡各类别对梯度优化的贡献。

### 例题
某批次采集了 2000 个工件记录，其中良品 1900 个，缺陷品 100 个。质检模型在测试集上
判定出 120 个缺陷品，经人工复核核对，其中 80 个为真正缺陷品。请计算该模型的准确率、
漏检率与误剔率。

解答：
根据统一约定，缺陷为正类，良品为负类。
实际缺陷总数 TP + FN = 100，TP = 80，漏检数 FN = 100 - 80 = 20。
实际良品总数 TN + FP = 1900，误剔数 FP = 120 - 80 = 40，TN = 1900 - 40 = 1860。
模型准确率 = (TP + TN) / 总样本 = (80 + 1860) / 2000 = 1940 / 2000 = 97.0%。
模型漏检率 = FN / (TP + FN) = 20 / 100 = 20.0%。
模型误剔率 = FP / (FP + TN) = 40 / 1900 ≈ 2.11%。

### 常见错误
- 在良品率高达 98% 的场景下，盲目追求并宣称模型准确率达到 98%，忽视漏检指标。
- 在划分训练集和验证集之前对少数类样本执行复制过采样，导致相同样本泄漏至验证集。
- 采用无规则随机欠采样粗暴剔除良品样本，丢失了重要的工艺公差边缘良品特征。

## 特征缩放与预处理

分拣工位提取的表格特征通常具有截然不同的物理量纲与数值区间。例如工件投影面积特征通常
在数千平方毫米，长宽比在 1.0 到 3.0 之间，而平均反射灰度值在 0 到 255 之间。如果不做
特征缩放，数值跨度巨大的面积特征将在距离计算（如 KNN、SVM）或基于梯度的优化过程中
占据绝对主导地位，导致尺度较小的关键特征失效。

常用的两种特征缩放方法包括：
1. 标准化（Z-score 标准化）：
   x_norm = (x - μ) / σ
   其中 μ 为均值，σ 为标准差。处理后特征均值为 0，标准差为 1，适合大多数基于梯度的学习算法。
2. 归一化（Min-Max 缩放）：
   x_scaled = (x - x_min) / (x_max - x_min)
   将特征线性缩放至 [0, 1] 区间，适合特征具有明确物理边界且分布均匀的场景。

特征工程的黄金原则是：缩放参数（μ、σ、x_min、x_max）以及缺失值填充统计量必须严格仅使用
训练集数据进行拟合（fit），然后将这组固定参数应用（transform）到验证集与测试集。
当光电传感器偶发通信丢包导致特征缺失时，必须使用训练集计算的中位数或均值进行填充，
严禁直接删除测试样本或在测试集上重新拟合参数。

### 例题
分拣站提取工件表面缺陷的长度特征，训练集统计计算得最小长度为 20 像素，最大长度为 120 像素。
现采用 Min-Max 归一化对特征进行缩放。在测试集中出现一个缺陷长度实测值为 45 像素的工件，
使用训练集拟合的参数对其进行归一化计算，归一化后的特征值是多少？

解答：
归一化计算公式为：x_scaled = (x - x_min) / (x_max - x_min)。
依据训练集统计参数：x_min = 20，x_max = 120，极差 x_max - x_min = 100。
测试样本实测值 x = 45。
代入公式计算：x_scaled = (45 - 20) / (120 - 20) = 25 / 100 = 0.25。
该测试样本归一化后的特征值为 0.25。测试集必须使用训练集的极值参数，不能重新计算。

### 常见错误
- 在数据集划分前对全量数据集执行标准化或归一化，导致测试集分布信息提前泄露给模型。
- 对验证集和测试集分别依据各自样本计算均值和标准差，破坏了特征在统一空间中的可比性。
- 产线遇到传感器数值偶发缺失直接丢弃整条记录，导致分拣工位无法完成物理出件与挡板控制。

## 单元小结
- 标注规范是质量基石：明确缺陷物理量化门槛，通过双人盲标监控一致性，建立争议池防控标签噪声。
- 严守工件实体隔离划分：按物理工件或生产批次进行分组划分，彻底杜绝同工件多角度照片跨集泄漏。
- 破除不平衡准确率陷阱：在分层抽样基础上结合代价敏感权重与重采样，核心关注漏检率与误剔率。
- 特征预处理参数单向传递：缩放均值、极差与缺失值填充量均由训练集拟合，验证与测试集仅做固定变换。
