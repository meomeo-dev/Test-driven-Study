# 评估与阈值

本单元围绕桌面质检分拣站的实际产线需求，深入学习二分类模型的核心评估指标、
概率输出与阈值调整机制，以及基于非对称误判代价的最优分拣决策方案。

## 本单元知识点
- 混淆矩阵：掌握 TP、FP、FN、TN 构成，明确缺陷为正类时漏检与误剔的对应，理解准确率局限。
- 精确率、召回率与 F1：掌握精确率、召回率、F1 计算，以及漏检率与误剔率的产线含义。
- 阈值与 ROC 曲线：掌握概率阈值调整对漏检与误剔的影响，理解 ROC 曲线、AUC 及 PR 曲线。
- 按代价选择阈值：建立非对称误判代价模型，依据总损失最小化选定阈值并设计复检区间。

## 混淆矩阵
在桌面质检分拣站中，工件经传感器触发拍摄后，视觉模型输出合格与否的二分类判定。
工业质检统一约定以“缺陷品”为正类（Positive），以“良品”为负类（Negative）。
分拣机构依据模型判定执行动作：将判定为缺陷的工件拨入废料盒，良品则放行。

混淆矩阵将模型的预测结果与工件的真实物理标签交叉汇总为 2×2 统计矩阵：
- 真正例（TP）：真实为缺陷，模型判定为缺陷，工件被正确剔除。
- 假正例（FP）：真实为良品，模型判定为缺陷，导致良品被丢弃，称为“误剔”。
- 假负例（FN）：真实为缺陷，模型判定为良品，导致缺陷品流出，称为“漏检”。
- 真负例（TN）：真实为良品，模型判定为良品，工件被正确放行。

准确率（Accuracy）定义为所有判定正确的工件数占总检测工件数的比例：
```
Accuracy = (TP + TN) / (TP + FP + FN + TN)
```
在工业质检中，缺陷品通常只占极少比例（例如 1%）。若模型将全部工件都判定为良品，
准确率可高达 99%，但漏检率高达 100%，因此准确率在样本不平衡场景下具有欺骗性。

```python
from sklearn.metrics import confusion_matrix
y_true = [1, 0, 0, 1, 0]
y_pred = [1, 0, 1, 1, 0]
tn, fp, fn, tp = confusion_matrix(y_true, y_pred).ravel()
```

### 例题
某批次共有 1000 件轴承工件送入分拣站，其中真实缺陷品 20 件，真实良品 980 件。
视觉系统判定缺陷品 30 件，其中包含 18 件真实缺陷；其余 970 件被判定为良品。
请写出混淆矩阵的四个指标数值，并计算分类准确率。

【解答】
1. 真实缺陷共 20 件，其中 18 件被正确判为缺陷，故 TP = 18；
   其余 2 件缺陷被错误判为良品（漏检），故 FN = 20 - 18 = 2。
2. 模型共判定缺陷 30 件，其中 18 件为真缺陷，
   误将良品判为缺陷（误剔）的数量为 FP = 30 - 18 = 12。
3. 真实良品共 980 件，误剔 12 件，故正确判为良品的数量为 TN = 980 - 12 = 968。
4. 准确率 Accuracy = (TP + TN) / 总数 = (18 + 968) / 1000 = 986 / 1000 = 98.6%。

### 常见错误
- 混淆正负类约定：错误将良品设为正类，导致将“误剔”混同为 FN，颠倒工业常识。
- 盲信高准确率：在缺陷率极低的数据集上，忽视漏检导致的严重后果，仅凭准确率定论。

## 精确率、召回率与 F1
为了在类别不平衡时全面评估质检性能，必须引入精确率与召回率：
精确率（Precision）反映模型剔除的工件中有多少确实是缺陷品：
```
Precision = TP / (TP + FP)
```
召回率（Recall）反映真实存在的缺陷工件中有多少被模型成功检出：
```
Recall = TP / (TP + FN)
```

在工业分拣中，漏检率与误剔率具有直接的产线经济与质量意义：
- 漏检率 = FN / (TP + FN) = 1 - Recall，衡量缺陷工件流向客户或下道的风险。
- 误剔率 = FP / (FP + TN)，衡量合格品被错误报废或降级的物料损失比例。
注意误剔率的分母是全体真实良品数（FP + TN），切勿与 Precision 的分母混淆。

F1 分数是精确率与召回率的调和平均数，综合衡量模型兼顾两者的能力：
```
F1 = 2 × Precision × Recall / (Precision + Recall)
```
相比算术平均，调和平均对较小数值更加敏感。只要精确率或召回率有一项极低，
F1 分数就会大幅拉低，能有效惩罚偏科的分类模型。

### 例题
分拣站测试了 200 件工件，混淆矩阵统计为：TP = 16，FP = 8，FN = 4，TN = 172。
请计算该模型在该批次上的精确率、召回率、漏检率、误剔率与 F1 分数。

【解答】
1. 精确率 Precision = 16 / (16 + 8) = 16 / 24 ≈ 0.667（即 66.7%）。
2. 召回率 Recall = 16 / (16 + 4) = 16 / 20 = 0.80（即 80.0%）。
3. 漏检率 = 1 - Recall = 4 / (16 + 4) = 0.20（即 20.0%）。
4. 误剔率 = 8 / (8 + 172) = 8 / 180 ≈ 0.044（即 4.4%）；分母是全体良品，
   不是被判为缺陷的 24 件。
5. F1 = 2 × 0.667 × 0.80 / (0.667 + 0.80) ≈ 0.727。

### 常见错误
- 误剔率分母混淆：计算误剔率时误把 (TP + FP) 当作分母，其实际分母为真实良品数。
- 割裂权衡指标：脱离业务片面追求 100% 精确率导致大量漏检，或片面追求 100% 召回率
  导致大量良品被误报废。

## 阈值与 ROC 曲线
逻辑回归等分类算法通常输出工件属于缺陷类的连续概率值 p（介于 0 到 1 之间）。
产线控制系统依据决策阈值 θ 判定类别：当 p ≥ θ 时判定为缺陷，执行挡板剔除。

阈值的高低调节直接决定了分拣工位的松紧策略：
- 调低阈值 θ（例如降至 0.20）：检出标准放宽，更多工件被报为缺陷，漏检减少
  （Recall 提升），但更多良品被错杀，误剔率（FP）升高。
- 调高阈值 θ（例如升至 0.80）：检出标准趋严，只有确信缺陷才剔除，误剔减少，
  但轻微缺陷容易被放行，漏检率（FN）升高。

ROC 曲线以假正例率（FPR = FP / (FP + TN)）为横轴，以真正例率（TPR = Recall）为纵轴，
描绘阈值从 1 逐渐减小到 0 时模型的完整轨迹。AUC 为 ROC 曲线下面积，
对有区分能力的模型取值在 0.5 到 1.0 之间（0.5 相当于随机猜测）。AUC 越接近 1.0，代表模型无论阈值如何设定，区分良品
与缺陷品排序的能力越强，且不受正负样本比例漂移的影响。
PR 曲线（Precision-Recall）以 Recall 为横轴、Precision 为纵轴，在缺陷样本
极少的严重不平衡工业场景中，能更直接展现误剔数对精确率的压制效应。

### 例题
已知 4 件工件的真实标签（1 为缺陷，0 为良品）与模型预测缺陷概率：
工件 A (1, 0.90)，工件 B (0, 0.70)，工件 C (1, 0.40)，工件 D (0, 0.20)。
若将分类阈值 θ 从 0.50 下调至 0.30，请分析漏检数与误剔数的变化。

【解答】
1. 当 θ = 0.50 时：
   判定为缺陷（p ≥ 0.50）：工件 A（真实缺陷，TP=1）、工件 B（真实良品，FP=1）。
   判定为良品（p < 0.50）：工件 C（真实缺陷，FN=1）、工件 D（真实良品，TN=1）。
   此时漏检数 FN = 1，误剔数 FP = 1。
2. 当 θ = 0.30 时：
   判定为缺陷（p ≥ 0.30）：工件 A（TP）、工件 B（FP）、工件 C（真实缺陷，TP=2）。
   判定为良品（p < 0.30）：工件 D（真实良品，TN=1）。
   此时漏检数 FN = 0（漏检由 1 降为 0），误剔数 FP = 1（保持不变）。
3. 结论：通过合理调低阈值，成功检出了潜在缺陷工件 C，消除了漏检。

### 常见错误
- 以为 AUC 高就无需选阈值：AUC 仅表示模型排序潜力，现场必须选定具体阈值落地。
- 误以为 ROC 曲线会随样本正负比例失衡而改变：ROC 的横纵轴均在真实类内部做归一化，
  对样本类别比例具有良好的不变性。

## 按代价选择阈值
在工业质检实际场景中，两类错误判定的财务与信誉损失高度不对称：
- 漏检代价（C_FN）：缺陷品混入合格品出厂，导致召回、罚款甚至安全事故，代价极高。
- 误剔代价（C_FP）：良品被误报废，损失通常仅为材料损耗或人工二次检验费，代价较低。

产线总误判代价损失函数定义为：
```
Total Cost = C_FN × FN + C_FP × FP
```
在离线验证集上遍历候选阈值 θ，计算不同阈值下的混淆矩阵和总代价，
寻找使 Total Cost 最小的阈值 θ* 作为分拣站的设定阈值。当 C_FN 远大于 C_FP 时，
最优阈值往往显著低于默认的 0.50。

为兼顾极端漏检控制与产线节拍，工程中常采用“复检区间”（双阈值策略）：
设定低阈值 θ_low 与高阈值 θ_high（0 < θ_low < θ_high < 1）：
- p < θ_low：高置信度良品，自动放行进入成品箱；
- p ≥ θ_high：高置信度缺陷，驱动挡板直接剔除；
- θ_low ≤ p < θ_high：模糊待定工件，分流至人工复检工位或二次多角度复拍。
复检区间将高代价的不确定性交由人工介入，在保障质量的同时控制了人工复检负荷。

### 例题
某分拣站测试集包含 50 件缺陷品与 450 件良品。
设定漏检一件代价 C_FN = 500 元，误剔一件代价 C_FP = 20 元。
现有两套候选阈值方案：
方案 1（θ = 0.40）：FN = 2，FP = 15；
方案 2（θ = 0.20）：FN = 0，FP = 40。
请分别计算两套方案的总代价，并说明应选用哪一套方案。

【解答】
1. 方案 1 总代价：
   Cost_1 = 500 × 2 + 20 × 15 = 1000 + 300 = 1300 元。
2. 方案 2 总代价：
   Cost_2 = 500 × 0 + 20 × 40 = 0 + 800 = 800 元。
3. 比较：Cost_2 (800 元) < Cost_1 (1300 元)，方案 2 经济性更优，应选用方案 2。
   虽然方案 2 误剔多了 25 件，但避免了 2 件代价高昂的漏检，有效控制了总损失。

### 常见错误
- 脱离真实代价追求指标对称：忽视 C_FN 远大于 C_FP 的现实，盲目追求 F1 最大化。
- 复检区间范围过宽：导致大量工件流入人工复检，超过人工处理节拍造成产线堆料。

## 单元小结
- 工业质检约定缺陷为正类，混淆矩阵将分拣结果清晰划分为 TP、FP（误剔）、FN（漏检）与 TN。
- 面对缺陷罕见的不平衡产线数据，单纯依赖准确率会产生严重误导，必须重点评估精确率、
  召回率（防漏检）以及误剔率。
- 概率阈值是连接模型输出与机械动作的控制旋钮，调低阈值防漏检但增误剔；ROC 与 PR 曲线
  全面刻画了不同阈值下的动态权衡。
- 工业决策以非对称误判总代价最小化为根本目标，配合双阈值复检区间可实现质量与效率的平衡。
