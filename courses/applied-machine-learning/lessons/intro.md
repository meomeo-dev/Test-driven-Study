# 机器学习与质检任务

本单元学习机器学习在工业视觉质检中的任务形式、规则法基线构建及特征标签体系。

## 本单元知识点
- 机器学习任务类型：区分监督与无监督、分类与回归，明确训练与预测边界。
- 规则法基线：掌握用固定阈值建立初始基线，确立模型必须同集胜过基线的原则。
- 特征、标签与样本：理解工业样本与标签定义，掌握二维特征矩阵的组织结构。

## 机器学习任务类型
工业视觉质检的核心目标是通过传感器与计算设备，对生产线上流转的工件进行自动化
质量状态评估。在桌面质检分拣站中，工件经由到位传感器触发相机采集图像，算法
做出合格或不合格的判定后，由微控制器或 PLC 驱动挡板执行物理分选。理解机器
学习在质检系统中的定位，首先需要明确其任务范式与工程适用边界。

机器学习任务主要分为监督学习与无监督学习。在质检场景中，监督学习是指利用
质检员预先标记好的“真实质量状态”（标签）与对应的工件图像数据训练算法，模型
学习从图像到类别的映射关系；无监督学习则在没有人工标签的情况下，仅依靠工件
数据本身的统计分布发现异常或聚类聚集。大部分工业质检缺陷判别属于监督学习。

根据输出目标的形式，预测任务进一步划分为分类任务与回归任务：
- 分类任务：模型输出离散的类别符号，例如二分类中的良品（0）与缺陷品（1），
  或者多分类中的划伤、裂纹、凹坑等具体缺陷类型。
- 回归任务：模型输出连续的数值，例如预测工件孔径的毫米偏差、表面镀层厚度
  或划痕的微米深度。

质检系统的运行被严格区分为离线训练与在线预测两个阶段。离线训练阶段通常在工控机
或服务器端利用历史积累的样本集优化模型参数，该过程允许较高的计算耗时；在线
预测阶段（推理）则部署在分拣站现场，要求在工件到达挡板前的严格节拍时间内（如
50 毫秒以内）接收新特征并即时输出判定，此时模型参数保持固定不再更新。

并非所有质检环节都需要引入机器学习。当工序满足以下条件时，应优先采用传统方法：
1. 物理特征极其稳定，通过简单的光学打光即可获得反差极大的高对比度二值图像；
2. 判定逻辑清晰，单个尺寸或灰度阈值规则即可达到 100% 的准确判定；
3. 工位节拍要求达到微秒级响应，边缘计算硬件无法承担额外模型推理开销。

### 例题
题目：
桌面分拣站负责检测五金垫圈表面是否存在油污缺陷。质检主管提供了 800 张带有人工
标注是否含油污的图像。分拣站的动作要求是：当传感器检测到垫圈到位后，在 40 毫秒
内输出“合格”或“油污品”，由气动推杆将油污品剔除至不合格料盒。
请问：该任务属于监督学习还是无监督学习？属于分类任务还是回归任务？在现场推杆
执行分选瞬间，系统处于训练阶段还是预测阶段？

解答：
1. 该任务属于监督学习。因为系统拥有质检人员预先标注的“是否含油污”明确标签，
   模型需依据这批标注样本学习判别规律。
2. 该任务属于二分类任务。系统最终需要输出的是离散状态判定（“合格”或“油污品”），
   而非连续物理尺寸。
3. 现场推杆动作瞬间处于在线预测阶段。此时模型加载离线训练好的固定权重，输入
   实时采集的特征并毫秒级输出推断结果，驱动执行机构动作。

### 常见错误
- 误认为任何质检工序都必须使用机器学习。忽略了稳定打光下的几何尺寸测量等
  使用单片机阈值比对更快速可靠的工程现实。
- 混淆在线预测与离线训练。误以为分拣站推杆每次剔除工件时都在自动重新训练模型。

## 规则法基线
规则法基线是指在开发任何复杂的机器学习算法之前，利用明确的物理测量值或简单
统计量（如平均灰度、反光区域像素面积、最大局部梯度等），通过人工设定的固定阈值
和条件判断语句（if-else）建立的初始质检判定程序。

规则法基线在工业检测项目中扮演着不可替代的角色：
1. 确立性能标尺：它是最简单、计算成本最低的参照系，为后续复杂模型设定及格线。
2. 评估硬件极限：如果规则法在现场完全失效，往往暴露出当前打光方案或机械夹具
   存在严重的物理缺陷，需要优先整改硬件而非盲目堆砌复杂算法。
3. 极速落地验证：规则法能够以极低的代码量快速接入分拣站 PLC，完成全流程联动。

评估机器学习模型时，必须遵循“同一独立测试集”的对比原则：
任何声称超越基线的机器学习模型，必须与规则法基线在完全相同的工件测试批次上
运行，使用完全相同的性能评价指标进行横向比较。脱离同一测试集所得出的“模型优于
基线”结论在统计与工程上均不成立。

在工业质检中，通常将缺陷品定义为正类（Positive），良品定义为负类（Negative）。
核心评估指标计算方式如下：
```
漏检率 = FN / (TP + FN)
误剔率 = FP / (FP + TN)
```
其中 TP 表示正确检出的缺陷数，FN 表示被误判为良品的缺陷数（漏检），TN 表示
正确判定的良品数，FP 表示被误判为缺陷的良品数（误剔）。模型必须在漏检率、
误剔率上不劣于基线且有明显改善，同时处理耗时仍满足节拍，才具备上线替代价值。

### 例题
题目：
在桌面分拣站上测试某批次 100 个轴承工件，其中真实缺陷品 20 个，真实良品 80 个。
规则法基线判定结果为：正确检出 16 个缺陷，漏检 4 个缺陷；正确判定 72 个良品，
误剔 8 个良品。平均每件处理耗时 2 毫秒。
算法工程师训练了一个分类模型，在同一批次上的结果为：检出 19 个缺陷，漏检 1 个
缺陷；正确判定 76 个良品，误剔 4 个良品，处理耗时 15 毫秒。
请分别计算规则法与模型的漏检率和误剔率，并评价该模型是否胜过基线。

解答：
1. 规则法基线指标：
   实际缺陷数 TP + FN = 20，漏检 FN = 4，漏检率 = 4 / 20 = 20.0%；
   实际良品数 TN + FP = 80，误剔 FP = 8，误剔率 = 8 / 80 = 10.0%。
2. 机器学习模型指标：
   漏检 FN = 1，漏检率 = 1 / 20 = 5.0%；
   误剔 FP = 4，误剔率 = 4 / 80 = 5.0%。
3. 评价：在相同测试集上，模型的漏检率从 20% 降至 5%，误剔率从 10% 降至 5%，
   虽然耗时由 2 毫秒增加至 15 毫秒，但在分拣站允许的节拍内显著降低了漏检风险，
   因此该模型切实胜过了基线。

### 常见错误
- 在训练集上评估模型，并拿结果去与测试集上的规则法基线对比，导致严重过拟合偏差。
- 盲目追求 0 毫秒耗时优势而忽视高漏检率，或片面追求低漏检而引发极高误剔率。

## 特征、标签与样本
工业检测数据在送入机器学习模型之前，必须按照数学规范抽象为结构化数据结构。
- 样本（Sample）：每一个被检测的实体对象。在桌面分拣站中，相机对一个到位工件
  完成一次曝光所获得的独立检测记录，即构成一个样本。
- 标签（Label）：工件客观存在的真实质检状态，通常记作 y。在二分类中，一般约定
  良品标记为数值 0（负类），缺陷品标记为数值 1（正类）。
- 特征（Feature）：反映工件表面物理或光学属性的数值度量，例如平均灰度、边缘
  梯度、高亮反光面积占比等。多个特征组合成一个一维向量，称为特征向量 x。

当收集了 N 个工件样本，且每个样本提取了 D 个数值特征时，所有特征向量纵向
堆叠构成一个二维特征矩阵 X。在 Python 与 NumPy 规范中：
```
X 的形状 (shape) 为 (N, D) = (样本数, 特征数)
y 的形状 (shape) 为 (N,)   = (样本数,)
```
矩阵 X 的每一行对应一个唯一的工件，矩阵 X 的每一列对应所有工件的某一特定特征。

从工件原始图像提取数值特征的过程，实质上是将高维的图像像素阵列
（高度 × 宽度 × 通道数）转化为定长低维数值向量的过程。例如，通过统计计算得到
全图平均灰度、计算轮廓周长与面积的比值、统计阈值分割后黑斑像素连通域的几何中心
偏移量等。这些数值直接反映了缺陷在几何与色度上的异常程度。

工业质检系统的检测记录通常以 CSV 格式保存，每一行包含工件编号、提取的各项
特征数值、规则法判断结论、模型预测概率及实际真实标签，为持续迭代提供依据。

### 例题
题目：
桌面分拣站对连续通过的 3 个工件提取了 2 个特征：平均灰度（mean_gray）与缺陷
面积像素数（defect_area）。已知工件 1（良品）特征为 [180.5, 0]；工件 2（缺陷）
特征为 [120.0, 45]；工件 3（良品）特征为 [175.2, 2]。
请写出用 NumPy 构建该批次特征矩阵 X 与标签向量 y 的代码，并给出 X 和 y 的 shape。

解答：
使用 Python 与 NumPy 构建二维特征矩阵与一维标签向量的代码如下：
```python
import numpy as np
X = np.array([
    [180.5, 0.0],
    [120.0, 45.0],
    [175.2, 2.0]
])
y = np.array([0, 1, 0])
```
检查数组形状得到：
X.shape 为 (3, 2)，表示 3 个工件样本，每个样本包含 2 个特征；
y.shape 为 (3,)，表示包含 3 个工件的一维真实标签数组。

### 常见错误
- 特征矩阵维度颠倒。误将特征矩阵构建为 (特征数, 样本数) 的形状，导致传入模型时报
  维度不匹配错误。
- 标签混入特征矩阵中。把工件的类别标签作为第 D+1 列放入 X 中一起参与训练，造成
  严重的特征泄露（Data Leakage）。

## 单元小结
- 工业视觉质检主要依托监督学习范式，以离线训练学习参数、在线预测实施毫秒级分选。
- 具备高稳定物理条件与清晰阈值的工位应坚持传统规则法，避免非必要引入机器学习。
- 规则法基线是系统研发的基石，新模型必须在完全相同的独立测试集上经受漏检率、
  误剔率与实时耗时的综合对比验证。
- 检测数据以 (N, D) 的特征矩阵 X 与 (N,) 的标签向量 y 标准化组织，从原始像素
  阵列提取稳定数值特征是传统模型质检的核心桥梁。
