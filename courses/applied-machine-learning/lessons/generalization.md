# 泛化与调参

本单元学习如何识别与应对工件分拣模型在实际运行中的过拟合与欠拟合，掌握交叉验证、
网格搜索与正则化的核心方法，确保质检系统在未知新批次上具有稳定可靠的泛化能力。

## 本单元知识点

- 过拟合与欠拟合：通过训练误差与验证误差的关系以及学习曲线诊断模型复杂度匹配度。
- 交叉验证：利用 k 折与分组交叉验证评估模型性能的均值与波动，防范批次数据泄漏。
- 超参数调节：明确参数与超参数的区别，通过网格搜索在验证集上优选配置并闭卷测试。
- 正则化：理解 L2 惩罚项对权重幅度的约束机制，通过调节强度参数 C 平衡模型方差。

## 过拟合与欠拟合

在桌面质检分拣站中，模型不仅要在已标注的工件图像特征上表现良好，
更要在后续传送带持续送来的全新批次工件上维持低漏检率与低误剔率。
这种在未参与训练的新样本上的判定能力被称为泛化能力（Generalization）。

欠拟合（Underfitting）指模型结构过于简单，未能充分拟合工件缺陷的真实规律。
例如仅使用单层浅层决策树去区分微小划痕与复杂光照反光，会导致模型在训练集和
验证集上的分类错误率都维持在较高水平。此时模型表现为高偏差（High Bias）。

过拟合（Overfitting）指模型结构过于复杂，在学习真实缺陷特征的同时，
强行记住了训练集中特定批次的光影明暗、背景噪点或机械夹具划痕。
此时模型在训练集上的错误率极低甚至为 0，但在新批次验证集上的错误率显著升高。
此时模型表现为高方差（High Variance）。

学习曲线（Learning Curve）展示了训练误差与验证误差随训练样本量增加的轨迹：
- 欠拟合状态下，随样本增加，训练误差上升，验证误差下降，但两者迅速收敛于
  一个较高的错误率平台期。此时单纯增加同分布样本量无法解决性能瓶颈。
- 过拟合状态下，训练误差长期处于极低值，验证误差明显偏高，两条曲线之间存在
  宽阔的泛化间隙。只有大幅补充多样性样本或削减模型复杂度，间隙才会收敛。

### 例题

题目：分拣工位在固定光源下采集了 600 个冲压工件，训练不同最大深度（max_depth）
的决策树模型。评估记录显示：树深为 2 时，训练错误率为 18.2%，验证错误率为 18.8%；
树深为 5 时，训练错误率为 5.1%，验证错误率为 6.0%；树深为 12 时，训练错误率为 0.3%，
验证错误率为 15.6%。请诊断树深为 2 与树深为 12 时模型的状态，并指出分拣站应选用的树深。

解答：
1. 树深为 2 时，训练错误率与验证错误率均接近 18%，模型容量过小，无法捕捉有效特征，
   处于典型的欠拟合状态。
2. 树深为 12 时，训练错误率仅 0.3%，但验证错误率高达 15.6%，二者差距过大，
   模型过度记忆了训练集中的特定背景噪点，处于严重的过拟合状态。
3. 树深为 5 时，验证错误率最低（6.0%）且与训练错误率（5.1%）非常贴近，
   模型复杂度与缺陷规律最为匹配，分拣站应选用树深为 5 的配置。

### 常见错误

- 误将训练集零错误率当作调优目标：训练集达到 100% 准确率通常意味着模型记住了噪声，
  上线面对新批次工件时极易发生严重漏检或误剔。
- 混淆欠拟合与过拟合的应对方向：面对欠拟合时盲目裁剪特征或增加惩罚，
  会导致模型表达能力进一步退化。

## 交叉验证

单次将采集数据切分为训练集与验证集存在较强的随机偶然性。
若验证集偶然抽到边缘清晰的工件，评估指标便会虚高；
若抽到反光异常批次，指标则异常悲观。
k 折交叉验证（k-Fold Cross-Validation）将数据集均分为 k 个互斥折，
轮流以其中 1 折作为验证集、其余 k-1 折作为训练集，循环执行 k 次建模与评估。

k 折评估不仅输出 k 次验证指标的均值，还给出折间波动范围（标准差）。
均值反映了模型在该分布下的平均泛化水平，波动大小则体现了模型对数据切分扰动的稳定性。
波动过大说明模型在特定子集上表现脆弱，抗干扰能力不足。

在工业质检场景中，工件往往按批次、冲压机台或生产班次产出。
同批次工件具有极其相似的表面纹理、微观粗糙度与夹具反光。
若采用无序随机打乱切分，同批次样本会同时散落于训练折与验证折，造成批次特征泄漏。

分组交叉验证（GroupKFold）将批次或机台标识（如 batch_id）作为分组约束，
严格保证同一分组的所有样本要么全部进入训练折，要么全部进入验证折。
该策略真实模拟了质检站面对从未见过的全新工件批次时的跨批次泛化表现。

### 例题

题目：分拣工位采集了 4 个批次（批次 101、102、103、104）共 400 个工件，
每个批次各 100 个。工程师需要评估缺陷分类器的稳定性。
请写出使用 4 折 GroupKFold 的具体划分流程，并说明为何严禁使用普通打乱的 KFold。

解答：
1. 划分流程：以工件批次编号作为分组标签（groups）。在 4 轮迭代中，
   依次留出 1 个批次作为验证折，其余 3 个批次合并作为训练折：
   第 1 折：批次 101 验证，批次 102、103、104 训练；
   第 2 折：批次 102 验证，批次 101、103、104 训练；
   第 3 折：批次 103 验证，批次 101、102、104 训练；
   第 4 折：批次 104 验证，批次 101、102、103 训练。
2. 统计 4 次验证指标的平均值与折间标准差，以此作为最终泛化评估。
3. 禁用普通 KFold 的原因：若按样本随机打乱划分，同一批次的微弱反光特性与特定磨损
   纹理会同时渗透到训练集与验证集，产生虚假的优异指标；
   当模型部署到产线面对未知新批次 105 时，指标往往会出现严重滑坡。

### 常见错误

- 忽略工业数据的批次效应：在存在机台或批次聚集的数据集上使用普通随机切分，
  导致评估结果严重脱离实际生产工况。
- 仅关注指标均值而忽略折间方差：当模型各折平均准确率达标，但某一折漏检率异常偏高时，
  未能深入排查该批次对应的光照或材质异常。

## 超参数调节

在机器学习中，必须明确区分两类不同的参数体系：
- 模型参数（Parameters）：模型内部在训练阶段由优化算法自动学习更新的数值，
  例如逻辑回归中的特征权重 w 与偏置 b。
- 超参数（Hyperparameters）：在训练启动前由算法工程师手动设定、
  用于控制模型结构复杂度和学习过程的外部配置项，
  例如决策树的 max_depth、随机森林的 n_estimators、正则化系数 C 等。

网格搜索（GridSearchCV）是一种穷举搜索超参数的工程方法。
工程师为每个超参数设定离散候选值列表，算法自动生成所有候选值的笛卡尔积组合，
并在每个配置下运行交叉验证，最终按设定目标（如 F1 分数）挑选出最优超参数组合。

工业调参核心原则：
所有超参数调优与结构挑选过程，必须严格限定在训练集与验证折构成的闭环内完成。
独立测试集（Test Set）在整个搜索调优过程中必须保持绝对闭卷，仅在所有参数完全
敲定后，用于最终的单次上线前验收。若反复根据测试集的评估结果倒推修改超参数，
测试集信息将被严重污染，导致评估失去客观真实性。

### 例题

题目：工程师使用网格搜索为分拣站的决策树模型优选超参数。
待调参数网格为：最大深度 max_depth 候选列表 [3, 5, 8]，
最小分割样本数 min_samples_split 候选列表 [2, 5, 10]，
评估采用 5 折交叉验证。
请计算网格搜索阶段模型总拟合次数，并说明最优参数选出后如何生成最终交付模型。

解答：
1. 超参数配置组合数：3 × 3 = 9 种不同配置组合。
2. 搜索阶段总拟合次数：每种参数组合需执行 5 折交叉验证，
   因此共需拟合 9 × 5 = 45 次模型。
3. 最终模型生成方式：网格搜索根据交叉验证的综合得分选出表现最优的超参数配置后，
   将全部训练集数据合并，使用该最优配置重新拟合训练一次，
   生成最终模型交付独立测试集进行单次无偏评估。

### 常见错误

- 混淆模型内部参数与外部超参数：误认为逻辑回归的权重系数可以通过网格搜索离散枚举，
  或误以为树深是模型自发计算收敛的。
- 测试集参与超参数选择：在测试集上评估发现指标不理想后，反复修改超参数网格重新测试，
  挑选最好的一次汇报，导致评估彻底失真。

## 正则化

在提取多维视觉特征（如边缘对比度、表面粗糙度、灰度共生方差等）训练分类器时，
若特征之间存在共线性，或某些特征受产线光照影响剧烈，
无约束的优化算法可能会为这些敏感特征赋予极大的权重系数。
这会导致模型对输入图像的轻微扰动过度敏感，从而引发严重的过拟合。

L2 正则化（Ridge 惩罚）在损失函数中增加特征权重平方和惩罚项：
```
目标函数 = (1 / 2) * Σ (w_i)² + C * Σ 单样本对数损失
```
该惩罚项迫使优化算法在减小分类误差的同时，将所有特征权重的绝对值向 0 压缩，
使权重分布更加平滑，抑制极端大权重的产生，消除对单一不可靠特征的过度依赖。

在 scikit-learn 的 LogisticRegression 中，超参数 C 是正则化强度的倒数：
- 当 C 极大（如 C = 1000）时，正则化惩罚极其微弱，模型权重不受约束，
  模型复杂度高，容易发生过拟合；
- 当 C 极小（如 C = 0.01）时，正则化惩罚极其强烈，所有特征权重被深度压缩，
  模型复杂度低，容易发生欠拟合；
- 工程师需要在交叉验证中调节 C 值，在模型偏差与方差之间取得平衡。

工程注意事项：
由于 L2 正则化直接对权重系数绝对数值的平方施加惩罚，
在训练前必须先对所有输入特征进行标准化（StandardScaler），
消除量纲差异；否则尺度小的特征需要很大的权重才能起作用，会被不合理地过度惩罚。

### 例题

题目：分拣工位提取了 10 维连续特征训练逻辑回归模型以检测轴承表面裂纹。
在未加正则化约束（C = 10000）时，反光特征权重高达 42.5，
模型在验证集上的误剔率高达 21.0%。
将 C 调小至 0.2 并完成特征标准化后，反光特征权重降为 1.8，验证集误剔率下降至 5.0%。
请从正则化机理解释误剔率大幅改善的原因。

解答：
1. C = 10000 时正则化约束微弱，反光特征权重过大，表明模型过度放大了工件表面反光的
   局部波动，把特定批次光源引起的亮斑误判为裂纹缺陷，导致极高的误剔率。
2. C = 0.2 时 L2 正则化施加了强约束，强力惩罚了过大的权重系数，
   迫使反光特征权重由 42.5 压缩至 1.8，模型转而综合平衡边缘与纹理等多维特征。
3. 权重收缩降低了模型方差，增强了模型对光照微弱波动的抗干扰能力，
   因而验证集误剔率从 21.0% 大幅回落至 5.0%，显著增强了工业实用性。

### 常见错误

- 颠倒 C 与正则化惩罚强度的对应关系：误以为 C 越大惩罚越强，
  在过拟合时错误地继续增大 C 值导致过拟合加重。
- 未经特征标准化直接应用 L2 正则化：不同特征量纲差异悬殊时，
  数值范围小的特征需要大权重，会被过度压缩，扭曲特征的真实贡献。

## 单元小结

- 泛化性能是工业质检分拣系统的核心指标，通过训练与验证误差的学习曲线，
  能够准确定位模型当前的偏差与方差状态。
- 面对工件生产的批次效应，应使用 GroupKFold 隔离批次信息进行交叉验证，
  兼顾性能均值与折间波动以评估鲁棒性。
- 超参数决定模型容量与学习行为，必须在训练-验证流程中利用网格搜索进行调优，
  严守测试集单次闭卷评估红线。
- L2 正则化通过惩罚过大权重抑制过拟合，在预先进行特征标准化的基础上，
  合理调节强度倒数参数 C 可有效在欠拟合与过拟合间寻得平衡。
