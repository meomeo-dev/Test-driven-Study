# 零基础阶梯进阶英语（一）

## 课程概述
- **学制与学时**：标准学期制课程，共 9 单元，90 课时（每课时 60 分钟，总计 5,400 教学分钟）。
- **课程定位**：第一学期（90课时）：国际音标、拼读规律、基础语法骨架、高频日常交流句型与短对话理解。
- **配套大纲**：详见 `syllabus_180h.json`。

## 单元结构
1. **国际音标与自然拼读规律**（10 课时）
2. **名词与代词系统精讲**（10 课时）
3. **一般现在时与动词基础形态**（10 课时）
4. **形容词、副词与比较结构**（10 课时）
5. **现在进行时与介词空间方位系统**（10 课时）
6. **一般过去时与动词演化系统**（10 课时）
7. **情态动词与义务能力规范**（10 课时）
8. **疑问句系统与日常工作交际**（10 课时）
9. **第一学期综合实战复习与阶段评估**（10 课时）
