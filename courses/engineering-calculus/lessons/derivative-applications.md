# 导数的应用
本单元学习如何将导数工具应用于工程实践，通过单调性、极值、最优化建模、
微分线性近似及相关变化率，解决质检分拣站中的机械速度、精度容差与结构优化问题。

## 本单元知识点
- 单调性与极值：利用一阶导数符号判定运行状态，求解驻点与极值，确定机构运行区间最值。
- 最优化问题：建立目标函数与物理约束方程，求解结构耗材最省与运行效率最高的最优参数。
- 线性近似与微分：用一阶微分估算自变量微小扰动带来的系统误差传递与工件尺寸容差。
- 速度、加速度与相关变化率：分析位置对时间的导数关系，建立机构多变量联动变化率方程。

## 单调性与极值
导数反映了函数在某一点的瞬时变化率与变化趋势。在桌面质检分拣站的输送与推杆控制中，
电机的升速阶段、减速平层以及挡板摆角均需要通过函数的单调性进行区间规划。
若在区间 (a, b) 内导数恒有 f'(x) > 0，则函数 f(x) 在该区间严格单调递增；
若恒有 f'(x) < 0，则函数 f(x) 严格单调递减。

当可导函数在点 x₀ 处满足 f'(x₀) = 0 时，称 x₀ 为函数的驻点。
利用一阶导数判别极值：若自变量从左向右经过 x₀ 时，f'(x) 由正变负，
则 f(x₀) 为局部极大值；若由负变正，则 f(x₀) 为局部极小值；
若导数符号在驻点两侧保持不变，则该驻点不是极值点。

工程实际中多数设备运行在闭区间 [a, b] 内。连续函数在闭区间必有最大值与最小值。
求解最值时，需先计算区间内部所有驻点的函数值，再与区间两个端点值 f(a)、f(b) 进行比较，
其中数值最大者即为最大值，数值最小者即为最小值。

### 例题
分拣站推杆挡板角位移函数为 θ(t) = -2t³ + 9t² - 12t + 10（单位：rad），时间 t ∈ [0, 3]（s）。
求推杆在 [0, 3] 区间内的驻点，以及角位移的最大值和最小值。

解：
对时间 t 求导得：
```
θ'(t) = -6t² + 18t - 12 = -6(t² - 3t + 2) = -6(t - 1)(t - 2)
```
令 θ'(t) = 0，得区间 [0, 3] 内部的驻点为 t₁ = 1 s，t₂ = 2 s。
计算驻点及闭区间端点的函数值：
```
θ(0) = 10 rad
θ(1) = -2(1) + 9(1) - 12(1) + 10 = 5 rad（由负到正，极小值）
θ(2) = -2(8) + 9(4) - 12(2) + 10 = 6 rad（由正到负，极大值）
θ(3) = -2(27) + 9(9) - 12(3) + 10 = 1 rad
```
比较各点数值可知：推杆在 t = 0 s 时取得最大角位移 10 rad，
在 t = 3 s 时取得最小角位移 1 rad。

### 常见错误
1. 误将所有驻点都当成极值点，忽略了导数可能在驻点两侧同号（如 f(t) = t³ 在 t = 0 处）。
2. 计算闭区间上的工程最值时，只寻找内部极值点，遗漏了对区间起点和终点端点值的核算。

## 最优化问题
工程设计往往追求成本最低、材料最省、行程耗时最短或输出效率最高。
这类问题在数学上统称为最优化问题。微积分通过极值理论为工程寻优提供了精确解法。

建立最优化数学模型的一般步骤如下：
第一，根据工程实际需求明确目标量（如表面积、功耗）与决策变量（如尺寸、转速）；
第二，依据几何关系、守恒定律或设备物理规格列出约束方程，消去多余变量，
建立仅含单一决策变量的目标函数表达式，并注明该变量符合实际工况的物理定义域；
第三，对目标函数求导，求出定义域内的驻点，并结合单调性或实际背景确认全局最优解。

工程中许多最优化函数定义在开区间 (0, +∞) 上。若目标函数在物理定义域内只有唯一的驻点，
且从工程实际判断该物理量必定存在最小值（或最大值），
则该驻点对应的极值就是全局最优解，无需复杂的边界验证。

### 例题
质检分拣站需通过 3D 打印制作一个无盖的长方体零件收集盒。
盒底为正方形，边长设为 x cm，高为 h cm。要求盒子内部净容积固定为 V = 4000 cm³。
求使耗用打印耗材表面积 S 达到最小时的底面边长 x。

解：
由容积约束 V = x²h = 4000，可得高关于底边长的表达式 h = 4000 / x²（x > 0）。
无盖收集盒的表面积由一个底面和四个侧面构成，目标函数为：
```
S(x) = x² + 4xh = x² + 4x(4000 / x²) = x² + 16000 / x  (x > 0)
```
对边长 x 求一阶导数：
```
S'(x) = 2x - 16000 / x²
```
令 S'(x) = 0，解得 2x³ = 16000，即 x³ = 8000，解得唯一正实数根 x = 20 cm。
当 0 < x < 20 时，S'(x) < 0，函数单调递减；当 x > 20 时，S'(x) > 0，函数单调递增。
因此，当底面边长为 20 cm（此时高 h = 10 cm）时，表面积最小，打印最省材料。

### 常见错误
1. 目标函数列式不完整，例如漏掉无盖与有盖的区别，或将侧面积计算错误。
2. 求得代数驻点后未代入实际工程物理定义域检验（如求出负数根未予舍去）。

## 线性近似与微分
在分拣站的检测系统中，传感器受噪声影响会产生微小测量误差，
机械加工的定位销和夹具也存在微小的加工公差。微分学提供了分析微小误差传递的工具。

设函数 y = f(x) 在点 x₀ 可导。当自变量产生微小增量 Δx 时，函数的实际增量 Δy 可以表示为：
```
Δy = f'(x₀)Δx + α
```
其中 α 是当 Δx 趋近于 0 时比 Δx 更高阶的无穷小。称 dy = f'(x₀)Δx 为函数在 x₀ 处的微分。
当 |Δx| 较小时，可以用线性微分近似代替实际增量：Δy ≈ dy = f'(x₀)Δx。
这也等价于用切线方程近似代替原曲线：L(x) = f(x₀) + f'(x₀)(x - x₀)。

在工程测量中，常用微分进行误差传递分析：
绝对误差估计公式：|Δy| ≈ |f'(x₀)| · |Δx|；
相对误差估计公式：|Δy / y₀| ≈ |(f'(x₀) · Δx) / f(x₀)|。

### 例题
分拣工位视觉相机检测圆形零件的半径。测得某批次零件半径为 r = 50.0 mm，
相机测量允许的最大绝对误差为 |Δr| ≤ 0.2 mm。
利用微分估算由此计算出的零件横截面积 A = πr² 的最大绝对误差与相对误差。

解：
面积函数为 A(r) = πr²，对半径 r 求导得 A'(r) = 2πr。
在 r = 50.0 mm 处，面积微分表达式为 dA = A'(r)dr = 2πr Δr。
绝对误差传递估算：
```
|ΔA| ≈ |dA| = 2π(50.0 mm)(0.2 mm) = 20π mm² ≈ 62.8 mm²
```
相对误差传递估算：
```
|ΔA / A| ≈ |dA / A| = (2πr Δr) / (πr²) = 2|Δr / r| = 2 × (0.2 / 50.0) = 0.8%
```
计算表明，半径测量存在 0.4% 的相对误差时，面积计算将产生约 0.8% 的相对误差。

### 常见错误
1. 混淆绝对误差与相对误差的概念，直接将自变量的相对误差与因变量绝对误差相加减。
2. 在自变量变化幅度很大时盲目套用微分公式，忽略了非线性项带来的显著截断偏差。

## 速度、加速度与相关变化率
在工件输送与分拣推杆机构中，各构件的运动状态随时间 t 动态变化。
微积分用一阶导数和二阶导数精确刻画了运动学的核心物理量：
若工件位移函数为 s(t)，则其瞬时速度为 v(t) = s'(t) = ds/dt，
其瞬时加速度为 a(t) = v'(t) = s''(t) = d²s/dt²。

在平面联动机构中，多个运动部件的几何位置通过机构约束相互绑定。
若两个物理量 x 与 y 均随时间 t 变化，且满足几何关系方程 F(x, y) = 0，
两端对时间 t 求导（利用复合函数链式法则），即可得到 dx/dt 与 dy/dt 之间的代数关系，
这种问题称为相关变化率（Related Rates）。

求解相关变化率的关键是：先写出与时间无关的几何约束关系，
然后再对时间 t 求隐函数导数，切不可在求导之前提前代入特定时刻的瞬时数值。

### 例题
分拣机构中连杆 AB 长度为 L = 250 mm，端点 A 在垂直导向槽下滑，端点 B 推动工件沿水平滑道移动。
两端点满足几何关系 x² + y² = 250²（坐标单位 mm）。
当端点 A 运动至高度 y = 150 mm，且正以 dy/dt = -80 mm/s 向下滑动时，
求此时工件端点 B 的水平推进速度 dx/dt。

解：
当 y = 150 mm 时，由几何约束解得水平位置：
```
x = √(250² - 150²) = √(62500 - 22500) = √40000 = 200 mm
```
对约束方程 x² + y² = 250² 两端关于时间 t 求导（运用链式法则）：
```
2x(dx/dt) + 2y(dy/dt) = 0  =>  dx/dt = -(y / x) · (dy/dt)
```
将瞬时几何数据 x = 200 mm，y = 150 mm，dy/dt = -80 mm/s 代入：
```
dx/dt = -(150 / 200) · (-80) = 60 mm/s
```
工件端点 B 此时正以 60 mm/s 的瞬时速度向外平移推进。

### 常见错误
1. 在对几何方程求导前过早将特定瞬时的位置常数代入，导致变量被当作常数求导得到零。
2. 对多变量隐函数求导时遗漏时间链式因子（如将 x² 对 t 求导错写为 2x 而非 2x(dx/dt)）。

## 单元小结
- 导数的符号决定函数增减性，导数为零的驻点结合符号变化是寻找局部极值与设备工作极限的基石。
- 最优化问题通过物理约束将多变量降维为单变量目标函数，利用驻点快速定位工程最优工艺参数。
- 微分 dy = f'(x)Δx 建立了输出扰动与输入误差的线性映射，是量化测量公差与精度传递的核心工具。
- 机构联动中各部件运动速率通过几何方程建立联系，经由时间链式法则求导即可解算各构件的相关变化率。
