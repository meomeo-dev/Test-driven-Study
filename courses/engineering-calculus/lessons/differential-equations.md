# 一阶微分方程

本单元学习一阶微分方程的概念、解析解法、一阶线性系统阶跃响应与欧拉数值求解，
掌握桌面质检分拣站中驱动电机、工件冷却及数字控制器运动追踪的建模与分析方法。

## 本单元知识点
- 微分方程的基本概念：理解微分方程、阶、通解与初值条件，掌握验证解与特解求法。
- 可分离变量方程：掌握变量分离与两边积分，求解质检工件冷却及转速衰减规律。
- 一阶线性系统与时间常数：建立一阶惯性模型，分析电机启动阶跃响应与时间尺度。
- 欧拉法数值求解：运用一阶显式欧拉递推格式，在离散控制器中逐步估算工件状态。

## 微分方程的基本概念
含有未知函数及其导数的方程称为微分方程。方程中所含未知函数导数的最高阶数
称为微分方程的阶。只含一阶导数的方程称为一阶微分方程，常写为 dy/dt = f(t, y)。
在桌面质检分拣站中，工件位移 x(t) 与速度 v(t) 满足 dx/dt = v(t)，挡板驱动电机的
角速度在摩擦阻力下满足 dω/dt = -k·ω，这些都是典型的工程一阶微分方程。

微分方程的解是代入方程后使等式恒成立的函数。含有独立任意常数且常数个数
等于方程阶数的解称为通解；由系统具体初始状态确定任意常数后的唯一解称为特解。
初始状态对应的附加条件称为初值条件，例如在 t = 0 时工件速度 v(0) = v₀。
求解带有初值条件的微分方程问题统称为初值问题（IVP）。

检验一个给定函数是否为微分方程的解，通常执行两步：
1. 对该函数求关于自变量的导数；
2. 将函数及其导数分别代入微分方程左右两端，验证等式在区间内是否恒成立；
若有初值条件，还需将初始自变量代入函数，核对是否精确满足初值。

### 例题
在桌面质检分拣站中，挡板回位电机的转速 n(t)（单位：r/min）随时间 t（单位：s）
的变化满足微分方程 dn/dt = -2n。已知电机初始转速 n(0) = 1200 r/min。
请验证函数 n(t) = 1200·e^(-2t) 是该初值问题的解，并求出 t = 1 s 时的转速值。

解答：
1. 验证初值条件：
将 t = 0 代入给定函数：
n(0) = 1200·e^(0) = 1200·1 = 1200 r/min，精确满足初始条件。
2. 验证微分方程：
对 n(t) 求关于时间 t 的一阶导数：
dn/dt = d/dt [1200·e^(-2t)] = 1200 · (-2) · e^(-2t) = -2400·e^(-2t)
将 n(t) 代入微分方程右端：
-2n = -2 · [1200·e^(-2t)] = -2400·e^(-2t)
方程左端导数与右端代数式恒等，因此 n(t) 确为该微分方程的解。
3. 计算 t = 1 s 时的转速：
n(1) = 1200·e^(-2) ≈ 1200 × 0.1353 ≈ 162.4 r/min。

### 常见错误
- 混淆通解与特解：未代入初始条件确定常数 C 便将含参通解作为机构运动方程。
- 求导遗漏复合函数链式法则：对 e^(-2t) 求导时漏乘内层导数 -2 导致验证失败。
- 混淆代数方程的根与微分方程的解：误以为解方程是求数字 t 而非求函数关系。

## 可分离变量方程
若一阶微分方程经代数变形后可以写成 g(y)·dy = f(t)·dt 的形式，即等式两侧分别
只含有单一变量及其微分，则称其为可分离变量微分方程。分拣站工件的冷却、
机构自由减速及电容充放电等物理过程均广泛服从这类方程。

可分离变量方程的求解步骤规范如下：
1. 移项分离变量：通过乘除运算将含未知函数 y 的项与 dy 归于等式一端，
将含自变量 t 的项与 dt 归于等式另一端；
2. 两边不定积分：分别计算 ∫ g(y) dy = ∫ f(t) dt + C，并合并为一个任意常数 C；
3. 确定具体特解：若能显化则解出 y(t)，随后利用初值条件代入求得常数 C。

牛顿冷却定律是分拣检测工位的典型实例：工件温度 T 随时间 t 的变化率与其和
环境温度 T_env 的温差成正比，即 dT/dt = -k·(T - T_env)，其中 k > 0 为散热系数。
分离变量得 dT/(T - T_env) = -k dt，积分求解即可得到温度衰减函数。

### 例题
分拣站刚检测完的金属工件初始温度 T₀ = 80 °C，输送带环境温度 T_env = 20 °C。
工件降温过程满足 dT/dt = -0.1·(T - 20)。求工件温度 T(t) 的特解表达式，
并计算经过 t = 10 s 后工件的温度（保留一位小数）。

解答：
1. 分离变量：
将温差项移至左边，时间微分 dt 移至右边：
1/(T - 20) dT = -0.1 dt
2. 两端同时积分：
∫ 1/(T - 20) dT = ∫ (-0.1) dt
ln|T - 20| = -0.1t + C₁
去绝对值并取指数：T - 20 = e^(-0.1t + C₁) = C·e^(-0.1t)（令 C = e^(C₁)）
得通解为 T(t) = 20 + C·e^(-0.1t)
3. 代入初值求特解：
已知 t = 0 时 T(0) = 80 °C，代入得 80 = 20 + C·e⁰ ==> C = 60
因此特解为 T(t) = 20 + 60·e^(-0.1t)
4. 计算 t = 10 s 时的温度：
T(10) = 20 + 60·e^(-0.1 × 10) = 20 + 60·e^(-1) ≈ 20 + 60 × 0.3679 = 42.1 °C。

### 常见错误
- 积分时遗漏积分常数 C：直接写出无常数的式子，导致后续无法拟合实际初温。
- 指数代数变形出错：误将 ln(T - 20) = -kt + C 展开为 T - 20 = e^(-kt) + C。
- 分离变量未彻底：等式某一侧同时混杂了变量 y 与自变量 t 便匆忙开始积分。

## 一阶线性系统与时间常数
工业自动化与分拣系统中最为常见的一阶动态模型为一阶惯性环节，其标准
微分方程形式为：
τ·(dy/dt) + y = K·u(t)
其中 y(t) 为系统输出响应（如电机速度或传送带线速度），u(t) 为控制输入信号，
K 为静态增益（反映系统最终的放大比例），τ 为时间常数（反映响应的惯性延迟）。

当输入为幅值为 u 的阶跃信号且系统初始状态为零（y(0) = 0）时，方程的阶跃
响应解析解为：
y(t) = K·u·(1 - e^(-t/τ))
随着时间推移，项 e^(-t/τ) 趋近于零，系统输出逐渐平滑趋近于稳态值 y_ss = K·u。

时间常数 τ 是刻画系统过渡过程快慢的基准标尺：
1. 当 t = τ 时，y(τ) = K·u·(1 - e⁻¹) ≈ 0.632·K·u，输出达到最终稳态值的 63.2%；
2. 当 t = 2τ 时，y(2τ) ≈ 0.865·K·u，输出达到稳态值的 86.5%；
3. 当 t = 3τ 时，y(3τ) ≈ 0.950·K·u，输出达到稳态值的 95.0%；
4. 当 t = 4τ 时，y(4τ) ≈ 0.982·K·u，输出已进入稳态值的 2% 误差带；
5. 当 t = 5τ 时，y(5τ) ≈ 0.993·K·u，输出已达到稳态值的 99.3%。
在工程实务中，通常取约 4τ（2% 误差带）至 5τ（暂态偏差不足 1%）作为进入稳态的判据，
输出只是无限趋近而不会严格等于稳态值。

### 例题
分拣输送带直流电机的转速响应满足微分方程 0.2·(dv/dt) + v = 40·u。输入电压恒定
为 u = 10 V，初始转速 v(0) = 0 mm/s。求系统时间常数 τ、稳态速度 v_ss 以及
电机达到 95% 稳态速度所需的上升时间。

解答：
1. 识别模型参数：
对照标准形式 τ·(dv/dt) + v = K·u，已知方程已完成归一化（v 前系数为 1），
可直接读出时间常数 τ = 0.2 s，静态增益 K = 40 (mm/s)/V。
2. 计算稳态输出值：
稳态速度为 v_ss = K·u = 40 × 10 = 400 mm/s。
阶跃响应方程为 v(t) = 400·(1 - e^(-t / 0.2)) mm/s。
3. 计算达到 95% 稳态速度的时间：
依题意令 1 - e^(-t / 0.2) = 0.95，得 e^(-t / 0.2) = 0.05。
取自然对数：-t / 0.2 = ln(0.05) ≈ -2.9957。
解得 t = 0.2 × 2.9957 ≈ 0.60 s，约为 3τ。

### 常见错误
- 提取时间常数时未将 y 项系数化为 1：例如面对 2·(dy/dt) + 4y = 8 时误认 τ = 2。
- 误解时间常数的物理含义：误以为在 t = τ 时系统已经结束过渡过程达到稳态。
- 混淆稳态值与输入量：误将输入量 u 当作稳态响应，忽略了静态增益 K 的放大倍数。

## 欧拉法数值求解
工业现场许多复杂的物理与运动控制模型难以求出初等解析解。在单片机或 PLC
控制器中，通常采用固定的控制周期 h（即时间步长 Δt）对连续微分方程进行离散化
近似求解。显式欧拉法是数值微积分中最直观的基础算法。

欧拉法的几何本质是用离散点处的切线折线代替真实的运动曲线。设一阶微分方程
初值问题为 dy/dt = f(t, y)，y(t₀) = y₀。由导数的差商近似定义，当步长 h 较小时：
(yₙ₊₁ - yₙ) / h ≈ dy/dt = f(tₙ, yₙ)
整理可得显式欧拉迭代公式：
yₙ₊₁ = yₙ + h·f(tₙ, yₙ)
其工程含义为：下一采样周期的状态预估值 = 当前状态值 + 步长 × 当前斜率。

步长 h 是平衡计算精度与控制器资源的关键参数：
1. 步长越小，截断误差越小，离散轨迹越逼近真实物理曲线，但单位时间内迭代
运算步数成倍增长；
2. 步长过大时，局部误差急剧累积，甚至会引发数值计算发散与剧烈振荡。
在控制工程中，采样步长 h 通常应显著小于系统固有时间常数 τ（如 h ≤ 0.1τ）。

### 例题
分拣推杆电机的位移 x(t) 满足微分方程 dx/dt = 10 - 2x，初始位移 x(0) = 0 mm。
设定控制器采样步长 h = 0.1 s。请利用欧拉法迭代公式计算 t₁ = 0.1 s 与
t₂ = 0.2 s 时的位移估计值 x₁ 与 x₂（保留两位小数）。

解答：
状态变化率斜率函数为 f(t, x) = 10 - 2x。
已知初值：t₀ = 0 s，x₀ = 0 mm，离散步长 h = 0.1 s。
1. 计算第 1 步迭代（t₁ = 0.1 s）：
当前斜率为 f(t₀, x₀) = 10 - 2 × 0 = 10 mm/s。
依欧拉公式外推：
x₁ = x₀ + h · f(t₀, x₀) = 0 + 0.1 × 10 = 1.00 mm。
2. 计算第 2 步迭代（t₂ = 0.2 s）：
将第 1 步结果代入计算当前新斜率：
f(t₁, x₁) = 10 - 2 × 1.00 = 8.00 mm/s。
依欧拉公式继续外推：
x₂ = x₁ + h · f(t₁, x₁) = 1.00 + 0.1 × 8.00 = 1.00 + 0.80 = 1.80 mm。
结论：在 t = 0.1 s 处位移约为 1.00 mm，在 t = 0.2 s 处位移约为 1.80 mm。

### 常见错误
- 斜率计算时混淆时刻：在第 2 步外推时仍沿用第 0 步的初始斜率，导致失去动态更新。
- 递推式遗漏步长 h：误将增量计算写为 xₙ₊₁ = xₙ + f(tₙ, xₙ)，造成物理量纲混乱。
- 忽略算法稳定性判据：在快速响应系统中盲目选取过大步长导致结果发散。

## 单元小结
- 微分方程建立了物理量与其变化率之间的动态约束，初值条件是求得唯一特解的物理基石。
- 可分离变量方程通过变量分离与两边不定积分，能精确求解工件冷却与速度阻尼衰减规律。
- 一阶惯性模型 τ·(dy/dt) + y = K·u 揭示了系统的动态迟滞，经历 1τ 响应达 63.2%，约 4τ 进入 2% 误差带，约 5τ 达稳态。
- 显式欧拉法通过 yₙ₊₁ = yₙ + h·f(tₙ, yₙ) 实现了连续微分方程在数字控制器中的离散数值落地。
