# 积分的应用

本单元学习定积分在工程实践中的核心应用，包括根据瞬时速度与流量计算累计量、
求取连续变化物理量的时间平均值，以及通过微元法求解构件面积、体积与变力做功。

## 本单元知识点

- 累计量与净位移：理解速度积分与速率积分的区别，掌握位移累计与注胶体积的定积分计算方法。
- 函数的平均值：掌握连续函数在区间上定积分平均值的定义，应用于工位平均温度与平均功率核算。
- 面积、体积与功：掌握两曲线交界截面积、旋转体圆盘法体积以及气缸推杆变力做功的微元积分。

## 累计量与净位移

在工程现场，许多物理量无法直接静态测量，而是以瞬时速率（如流速、线速度、
角速度）的形式由传感器连续记录。定积分的物理本质，就是把区间 [a, b] 细分为
无数个微小时间段 dt，将每个微元内的瞬时变化量相乘再无限累加，求得宏观累计量。

速度与位移的微积分关系是工控定位的核心。设工件或皮带沿直线运动，瞬时速度为
v(t)。在时间区间 [t₁, t₂] 内，速度关于时间的定积分表示质点的相对位置变化量，即
净位移：
Δs = s(t₂) - s(t₁) = ∫(t₁→t₂) v(t) dt

净位移具有方向性，其代数符号取决于正反向移动的相对大小。如果机构在运行中
存在往复反向运动（即 v(t) 改变符号），要评估导轨摩擦或输送带实际走过的总路程，
必须消除方向抵消效应，对瞬时速率（速度的绝对值）进行积分：
S = ∫(t₁→t₂) |v(t)| dt
此时必须先找出速度零点 v(t) = 0，将区间分段，分别计算各段定积分的绝对值后求和。

除机械运动外，流体与胶水加注同样遵循累计量规律。点胶电磁阀的瞬时流量为 Q(t)
（单位 mm³/s），在检测合格工件后的注胶时间段 [0, T] 内，注入定位槽的胶水
总体积为：
V = ∫₀ᵀ Q(t) dt

### 例题

【例题 1】分拣站的气动推杆在复位与推料测试中，速度传感器测得其沿直线滑轨的
速度函数为 v(t) = 3t² - 12t + 9（单位：mm/s，时间 t 的单位为 s）。
求推杆从 t = 0 s 到 t = 3 s 内的净位移与推杆滑块通过的总路程。

【解】
第一步：计算净位移。根据定积分定义，净位移等于速度函数的直接定积分：
Δs = ∫₀³ (3t² - 12t + 9) dt
求出原函数：
∫ (3t² - 12t + 9) dt = t³ - 6t² + 9t + C
代入积分上下限：
Δs = [t³ - 6t² + 9t]₀³
   = (3³ - 6 · 3² + 9 · 3) - (0)
   = (27 - 54 + 27) - 0 = 0 mm
这说明在 3 s 结束时，推杆刚好回到初始测试原点，净位移为 0 mm。

第二步：计算总路程。令速度函数为 0 寻找转向点：
3t² - 12t + 9 = 3(t - 1)(t - 3) = 0
解得速度零点 t = 1 s 和 t = 3 s。
在区间 [0, 1] 内，取测试点 t = 0.5 s，v(0.5) > 0，推杆正向推进；
在区间 [1, 3] 内，取测试点 t = 2 s，v(2) = 3(4) - 24 + 9 = -3 < 0，推杆反向返回。
因此总路程需在 t = 1 s 处分段积分：
S = ∫₀¹ (3t² - 12t + 9) dt + ∫₁³ -(3t² - 12t + 9) dt
分别求各段积分绝对值：
S₁ = [t³ - 6t² + 9t]₀¹ = (1 - 6 + 9) - 0 = 4 mm
S₂ = -[t³ - 6t² + 9t]₁³ = -[(27 - 54 + 27) - (1 - 6 + 9)] = -(0 - 4) = 4 mm
总路程为：
S = S₁ + S₂ = 4 + 4 = 8 mm
因此，推杆在 3 s 内的净位移为 0 mm，通过的总路程为 8 mm。

### 常见错误

1. 混淆净位移与总路程：在机构存在反向回程时，直接对速度 v(t) 积分来求总路程，
   导致正反向位移相互抵消，严重低估导轨实际磨损。
2. 分段积分漏判符号：求解总路程时，未解出速度零点并检验区间正负，导致反向
   运动段未取相反数变为正值，造成结果错误。
3. 累计体积时单位未统一：流量单位常为 mL/min 或 L/h，若积分时间变量 t 以秒（s）
   为单位，未先进行 60 或 3600 的单位换算，导致结果出现数十倍偏差。

## 函数的平均值

在桌面质检分拣站中，电机的驱动功率、加热管的固化温度以及视觉相机的补光照度
随工序循环不断波动。为了评估热平衡、能耗定额与元器件寿命，需要用一个恒定的
代表值来描述整个工作周期的物理水平，这就是连续函数的平均值。

对于 n 个离散采样数据，算术平均值为各数值之和除以 n。当采样点数趋于无穷且
采样间隔趋于零时，离散求和转变为定积分。若函数 f(x) 在闭区间 [a, b] 上连续，
则 f(x) 在该区间上的平均值 f_avg 定义为：
f_avg = (1 / (b - a)) · ∫ₐᵇ f(x) dx

该定义的几何意义十分直观：以平均值 f_avg 为高度、以区间长度 (b - a) 为底边
构成的矩形，其面积刚好等于曲线 y = f(x) 与 x 轴在 [a, b] 上围成的曲边梯形面积。
根据积分第一中值定理，若 f(x) 连续，则区间 [a, b] 内至少存在一点 ξ，使得
f(ξ) = f_avg，即连续变量必定能在某一瞬间真实达到其平均值。

工程中计算平均功率与平均温度时，先利用定积分求出总能量或累积热量，再除以总时间：
P_avg = (1 / (t₂ - t₁)) · ∫(t₁→t₂) P(t) dt
T_avg = (1 / (t₂ - t₁)) · ∫(t₁→t₂) T(t) dt

### 例题

【例题 2】质检站红外加热固化工位对粘接零件进行加热，在固化周期 t = 0 s 到
t = 4 s 内，电热元件的瞬时加热功率为 P(t) = 60 + 12t - 3t²（单位：W，t 单位：s）。
求电热元件在该 4 s 内消耗的总电能，以及该时间段内的平均加热功率。

【解】
第一步：计算总电能。功率关于时间的积分等于消耗的电能（焦耳，J）：
W = ∫₀⁴ P(t) dt = ∫₀⁴ (60 + 12t - 3t²) dt
求出原函数：
∫ (60 + 12t - 3t²) dt = 60t + 6t² - t³ + C
代入积分上下限：
W = [60t + 6t² - t³]₀⁴
  = (60 · 4 + 6 · 4² - 4³) - (0)
  = (240 + 96 - 64) - 0 = 272 J
即 4 s 内消耗的总能量为 272 J（即 272 W·s）。

第二步：计算平均功率。根据函数平均值公式，用总能量除以持续时间：
P_avg = (1 / (4 - 0)) · ∫₀⁴ P(t) dt
      = (1 / 4) · 272 = 68 W
答：该电热元件在 4 s 内消耗的总电能为 272 J，平均加热功率为 68 W。

### 常见错误

1. 遗漏区间跨度倒数：只求出被积函数的定积分总量（如求出 272 J），却忘记除以
   区间长度 (b - a)，把累计总量误当成平均值输出。
2. 误用两端点算术均值代替积分平均值：直接用 (f(a) + f(b)) / 2 计算，这只对
   一次线性函数有效；对于非线性功率或温度曲线，端点均值会产生较大误差。
3. 忽略中值定理成立的连续性前提：被积函数若存在阶跃突变（如继电器跳闸断电），
   平均值依然存在，但可能在全区间内没有任何一个时刻恰好等于该平均值。

## 面积、体积与功

定积分的核心数学工具是“微元法”（元素法）。只要某个物理量或几何量对于区间
具有可加性，且其微元能表示为某个连续函数与微元 dx 的乘积，就能写成定积分求解。

平面图形面积的计算是微元法的典型应用。若在区间 [a, b] 上两连续曲线始终满足
f(x) ≥ g(x)，则上曲线 y = f(x) 与下曲线 y = g(x) 围成的面积微元为
dA = [f(x) - g(x)] dx。全区域面积为：
A = ∫ₐᵇ [f(x) - g(x)] dx
若两曲线在区间内部有交点，必须以交点为分界点分段，确保每段被积函数非负。

旋转体体积（圆盘法）广泛用于加工件和轴承回转件的体积核算。曲线 y = f(x)
在区间 [a, b] 上绕 x 轴旋转一周时，在任意截面 x 处的横截面均为圆形薄圆盘，
薄圆盘的截面积为 A(x) = π [f(x)]²，厚度为 dx。体积微元为 dV = π [f(x)]² dx，
整体旋转体体积为：
V = ∫ₐᵇ π [f(x)]² dx

变力沿直线做功同样体现了微元法。当外力 F(x) 随位置 x 变化时，在极小位移 dx 内
外力近似为恒力，做功微元为 dW = F(x) dx。从位置 x = a 移动到 x = b 所做的总功为：
W = ∫ₐᵇ F(x) dx
例如压缩刚度为 k 的回位弹簧，弹力为 F(x) = kx，做功 W = (1/2)k(b² - a²)。

### 例题

【例题 3】分拣站的气缸推杆将检测不合格的工件推入侧边废料盒。推杆自滑轨起点
x = 0 m 推进至终点 x = 0.05 m（即 50 mm）。推进过程中，推杆克服工件滑行摩擦力
与压缩弹簧阻力的合力函数为 F(x) = 80 + 400x（单位：N，x 单位为 m）。
求推杆在全程 0.05 m 推料过程中克服阻力所做的总功。

【解】
根据变力做功的定积分公式，总功等于阻力函数在位移区间上的定积分：
W = ∫(0→0.05) F(x) dx = ∫(0→0.05) (80 + 400x) dx
求被积函数的原函数：
∫ (80 + 400x) dx = 80x + 200x² + C
代入位移起止限 x = 0 与 x = 0.05：
W = [80x + 200x²]，x 从 0 到 0.05
  = [80 · 0.05 + 200 · (0.05)²] - 0
  = [4.0 + 200 · 0.0025] - 0
  = 4.0 + 0.5 = 4.5 J
答：推杆在推料全程中克服阻力所做的总功为 4.5 J（焦耳）。

### 常见错误

1. 面积积分被减数与减数颠倒：未事先比对曲线相对高低，直接用下曲线减去上曲线
   进行积分，导致面积算出负数。几何面积必须恒为正值。
2. 圆盘法体积公式漏写 π 或未平方：误写成 V = ∫ f(x) dx 或 V = π ∫ f(x) dx，
   把截面半径当成了截面积。必须牢记圆盘截面积公式 A(x) = π [f(x)]²。
3. 变力做功套用恒力公式：在阻力随位移明显变化的情况下，直接用初位置力 F(0)
   或末位置力 F(0.05) 乘以总位移，导致电机选型或气源功耗评估出现严重偏差。

## 单元小结

- 累计量的核心是率函数的积分：速度定积分求得净位移，速率定积分求得总路程；
  当运动方向发生改变时二者出现分流，必须通过零点分段确保总路程的非负累积。
- 连续函数的平均值通过定积分与区间长度之比来定义，几何上对应等面积矩形的高；
  工程中广泛应用于评估波动的平均功率、热负荷温度以及等效稳态参数。
- 微元法是定积分解决工程几何与物理问题的通用钥匙，先建立 dA、dV、dW 的
  微分表达式，再在对应区间上积分求和。
- 旋转体体积利用截面圆盘面积 π[f(x)]² 进行积分；变力做功利用变力沿位移路径
  的微元 F(x)dx 进行积分，是机构驱动与能耗设计的理论基石。
