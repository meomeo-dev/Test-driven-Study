# 导数

本单元学习导数的极限定义、物理几何意义、四则求导法则、复合函数链式法则、常见超越函数求导。

## 本单元知识点

- 导数的定义与意义：掌握导数极限定义式、瞬时变化率与切线斜率物理意义，明确工程物理量纲。
- 求导法则：熟练运用常数、幂函数、常数倍、和差以及乘积与商的求导公式。
- 复合函数求导：理解链式法则原理，准确识别内外层函数并逐层展开求导。
- 指数、对数与三角函数的导数：掌握自然指数、对数与正余弦函数的导数公式及工程响应应用。

## 导数的定义与意义

导数刻画了物理量在某一瞬间的变化快慢。设因变量 y 随自变量 x 变化的规律为函数 y = f(x)。
当自变量在点 x 产生微小增量 h 时，函数产生对应增量 Δy = f(x+h) − f(x)。
若比值 Δy/h 在增量 h 趋近于 0 时的极限存在，则称函数在点 x 处可导，其极限值记作 f'(x) 或 dy/dx：
f'(x) = lim(h→0) [f(x+h) − f(x)] / h

在桌面质检分拣站中，导数的物理意义是瞬时变化率。
例如，工件位置传感器测得位移 x(t)，则其对时间 t 的导数 dx/dt 即为工件的瞬时速度 v(t)；
步进电机驱动分拣挡板旋转的角度 θ(t)，其对时间 t 的导数 dθ/dt 即为瞬时角速度 ω(t)。

导数的几何意义是函数曲线在点 (x, f(x)) 处切线的斜率。
两采样点之间的割线斜率反映的是该区间的平均变化率；
当时间跨度趋于 0 时，割线逐渐逼近切线，切线斜率即为瞬时变化率。

在工程应用中，导数必须标明物理单位。
导数的单位严格等于因变量单位除以自变量单位。
例如位移单位为 mm、时间单位为 s 时，速度单位必须为 mm/s；
加热块温度单位为 °C、时间单位为 s 时，升温速率单位必须为 °C/s。

### 例题

题目：
桌面分拣站的气动推杆推动合格工件进入料盒，推杆位移方程为 s(t) = 3t² + 2t（位移 s 单位：mm，时间 t 单位：s）。
请根据导数极限定义，求推杆在 t = 2 s 时的瞬时速度 v(2) = s'(2)。

解答：
根据导数的定义式：
v(2) = s'(2) = lim(h→0) [s(2+h) − s(2)] / h
计算各部分数值：
s(2) = 3 × (2)² + 2 × 2 = 12 + 4 = 16 mm。
s(2+h) = 3(2+h)² + 2(2+h)
= 3(4 + 4h + h²) + 4 + 2h
= 12 + 12h + 3h² + 4 + 2h
= 16 + 14h + 3h² mm。
因变量增量为：
s(2+h) − s(2) = (16 + 14h + 3h²) − 16 = 14h + 3h² mm。
构建平均速度差商：
[s(2+h) − s(2)] / h = (14h + 3h²) / h = 14 + 3h。
令时间增量 h 趋向于 0 取极限：
v(2) = lim(h→0) (14 + 3h) = 14 mm/s。
因此推杆在 t = 2 s 时的瞬时速度为 14 mm/s。

### 常见错误

- 混淆平均变化率与瞬时变化率，误用有限采样区间的 Δs/Δt 直接代替某时刻的瞬时速度。
- 忽略工程物理量纲，只写出纯数值而遗漏因变量与自变量相除后的单位（如 mm/s）。
- 在求极限时未先约去分母中的增量 h，直接代入 h = 0 导致出现 0/0 未定式而无法计算。

## 求导法则

实际工程多项式求导无需每次都使用极限定义，可以通过基本求导法则直接求解。
常数函数的导数为零，即 (C)' = 0；
幂函数求导法则是 (xⁿ)' = n xⁿ⁻¹（n 为实数）。例如 (x²)' = 2x，(x)' = 1，(1/x)' = −1/x²。

求导运算满足线性运算法则。
常数倍法则：[c · f(x)]' = c · f'(x)，常数系数在求导过程中保持不变；
和差法则：[f(x) ± g(x)]' = f'(x) ± g'(x)，多项式信号可以逐项独立求导。

对于两个变量相乘或相除的复合信号，必须遵循乘积法则与商法则。
乘积法则：[f(x) · g(x)]' = f'(x) · g(x) + f(x) · g'(x)，口诀为“前导后不导加前不导后导”；
商法则：[f(x) / g(x)]' = [f'(x) · g(x) − f(x) · g'(x)] / [g(x)]²（其中分母 g(x) ≠ 0）。

### 例题

题目：
分拣站光学传感器信号处理电路中，输出电压 V 与工件位置 x 满足关系式 V(x) = (4x + 3) / (x + 2)（x 单位：mm，V 单位：V）。
求电压随位置的瞬时变化率 V'(x)。

解答：
识别函数结构为两个一次多项式相除，应用商法则：
V'(x) = [(4x + 3)' · (x + 2) − (4x + 3) · (x + 2)'] / (x + 2)²
分别求分子中各项导数：
(4x + 3)' = 4
(x + 2)' = 1
代入分子式整理：
分子 = 4(x + 2) − (4x + 3) × 1
= 4x + 8 − 4x − 3
= 5
因此得到导数表达式：
V'(x) = 5 / (x + 2)²（单位：V/mm）。

### 常见错误

- 误将两函数乘积的导数写成各自导数的乘积，即错误套用 [f · g]' = f' · g'。
- 误将两函数商的导数写成 [f / g]' = f' / g'，或在商法则分子中颠倒减法顺序。
- 幂函数求导时遗漏常数项求导为 0 的规则，或在幂次递减时未将原指数提前作为系数。

## 复合函数求导

在工程控制系统中，许多变量之间存在级联传递关系。
例如，单片机输出控制电压 u 影响驱动电机转角，电机转角进而带动推杆位移 y。
此时 y 是 u 的函数 y = f(u)，而 u 是时间 t 的函数 u = g(t)，变量 y 构成了关于 t 的复合函数 y = f(g(t))。
其中 u 称为中间变量（内层函数），f 称为外层函数。

链式法则指出：若内层函数 u = g(x) 在 x 处可导，外层函数 y = f(u) 在对应点 u 处可导，
则复合函数对自变量 x 的导数等于外层函数对中间变量的导数乘以内层函数对自变量的导数：
dy/dx = (dy/du) · (du/dx)
写成函数符号形式为：[f(g(x))]' = f'(g(x)) · g'(x)。

求解复合函数导数的标准策略是“由外向内，分层剥离，逐层相乘”。
第一步，识别出外层函数结构，视内层为整体求导；
第二步，对内层表达式求导；
第三步，将两部分导数相乘，并把中间变量替换回原自变量。

### 例题

题目：
桌面分拣站的分拣挡板受连杆驱动，挡板位移 x 与控制电压 u 满足 x = u³（x 单位：mm，
u 取电压的伏特数值），而控制电压随时间 t（单位：s）线性上升，满足 u(t) = 3t + 1（单位：V）。
求在 t = 1 s 时，挡板的移动速度 dx/dt。

解答：
设定中间变量 u = 3t + 1，原式分解为：
外层函数：x = u³，其对 u 的导数为 dx/du = 3u²。
内层函数：u = 3t + 1，其对 t 的导数为 du/dt = 3。
由链式法则计算总导数：
dx/dt = (dx/du) · (du/dt) = 3u² · 3 = 9u²。
当 t = 1 s 时，内层变量取值为：
u(1) = 3 × 1 + 1 = 4 V。
代入计算得瞬时速度：
dx/dt = 9 × (4)² = 9 × 16 = 144 mm/s。
因此在 t = 1 s 时，挡板的瞬时移动速度为 144 mm/s。

### 常见错误

- 对外层函数求导后，忘记乘以内层函数的导数 du/dx，导致结果丢失内层系数。
- 在对外层求导的同时对内层求导，混淆了复合层次，如将 [(3x + 1)²]' 错写为 2(3x + 1)，漏乘了内层导数 3。
- 求得含中间变量 u 的导数表达式后，直接代入自变量的值，未先将自变量换算为中间变量对应的数值。

## 指数、对数与三角函数的导数

工程动态过程（如加热温升、电容充放电、机械周期摆动）广泛使用超越函数描述。
自然指数函数的导数保持形式不变：(eˣ)' = eˣ。
结合链式法则，若指数为复合函数 u(x)，则有 [e^(u(x))]' = e^(u(x)) · u'(x)。
这是描述分拣工位电磁铁线圈放电与加热头冷却规律的基础公式。

自然对数函数的导数满足 (ln x)' = 1/x（x > 0）。
结合链式法则，对数复合函数的导数为 [ln(u(x))]' = u'(x) / u(x)。
该公式常用于传感器对数变换电路的动态灵敏度分析。

简谐运动与摆臂往复机构通常由正弦和余弦函数建模。
基本三角函数导数公式为：
(sin x)' = cos x
(cos x)' = −sin x
注意余弦函数的导数带有负号。若含有角频率参数 ω，则 [sin(ωt)]' = ω cos(ωt)，[cos(ωt)]' = −ω sin(ωt)。

### 例题

题目：
分拣站打标工位的加热模块断电后，温度随时间衰减的规律为 T(t) = 25 + 75 · e^(−0.4t)（温度 T 单位：°C，时间 t 单位：s）。
求在断电初始时刻 t = 0 s 时的瞬时降温速率大小（即 |T'(0)|）。

解答：
常数项 25 的导数为 0。
对指数衰减项应用指数求导法则与链式法则：
设中间变量 u = −0.4t，则 du/dt = −0.4。
根据指数求导公式：
T'(t) = 75 · [e^(−0.4t)]' = 75 · e^(−0.4t) · (−0.4) = −30 · e^(−0.4t) °C/s。
将初始时刻 t = 0 s 代入：
T'(0) = −30 · e⁰ = −30 × 1 = −30 °C/s。
负号表明温度随时间降低，因此在 t = 0 s 时降温速率的大小为 30 °C/s。

### 常见错误

- 余弦函数求导漏掉负号，误记为 (cos x)' = sin x。
- 混淆指数函数与幂函数的求导法则，错误地将 (eˣ)' 写成 x · eˣ⁻¹。
- 对数函数求导时未除以真数本身，或在复合求导 [ln(u)]' 时漏乘内层导数 u'。

## 单元小结

- 导数是函数增量与自变量增量之比在增量趋于零时的极限，物理上表征瞬时变化率，几何上对应曲线切线斜率。
- 导数具有严格的工程物理量纲，其单位由因变量单位除以自变量单位决定，绝不能作为无量纲纯数值对待。
- 掌握幂函数、和差、常数倍以及乘积与商的运算法则，能够快速求解工业多项式及有理式信号的变化率。
- 链式法则 dy/dx = (dy/du) · (du/dx) 解决了多级传动与非线性复合传感系统的求导，遵循“由外向内，逐层相乘”。
- 指数、对数与三角函数的导数是分析一阶惯性响应、非线性标定与往复摆动机构的核心数学工具。
