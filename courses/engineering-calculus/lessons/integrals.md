# 积分

本单元学习原函数与不定积分、定积分与面积、换元与分部积分技巧以及数值
积分方法，掌握从变化率反推累计量的工程数学工具。

## 本单元知识点
- 原函数与不定积分：原函数概念、基本积分公式、积分常数 C 的物理意义及
  由初始条件确定特解。
- 定积分与面积：黎曼和的极限思想、牛顿–莱布尼茨公式、有向面积几何意义
  及定积分线性性质。
- 换元积分与分部积分：第一类换元法（凑微分）、分部积分公式及定积分换元
  换限规则。
- 数值积分：梯形法则原理、基于离散采样数据估算累计量及采样步长对估算
  误差的影响。

## 原函数与不定积分
在工业现场与自动化设备中，传感器往往直接测得物理量的瞬时变化率。例如
桌面质检分拣站的编码器测得工件传送速度 v(t)，而控制系统需要知道工件的
累计运行位移 s(t)。若已知函数 F(t) 在某区间上的导数等于 f(t)，即满足
F'(t) = f(t)，则称 F(t) 为 f(t) 在该区间上的一个原函数。

同一个导函数存在无穷多个原函数，且彼此之间仅相差一个任意常数。f(t) 的
全体原函数称为 f(t) 的不定积分，记作 ∫ f(t) dt = F(t) + C，其中 C 称为
积分常数。常见基本积分公式包括：幂函数积分 ∫ tⁿ dt = [1/(n+1)] tⁿ⁺¹ + C
（n ≠ -1）；指数函数积分 ∫ eᵃᵗ dt = (1/a) eᵃᵗ + C（a ≠ 0）；三角函数积分
∫ cos t dt = sin t + C、∫ sin t dt = -cos t + C 等。

积分常数 C 在物理与工程建模中具有鲜明的物理意义，通常代表系统的初始状态。
单凭速度变化率无法唯一确定物料在传送带上的绝对坐标。当给出确定的工况初始
条件（例如 t = 0 时工件位置 s(0) = s₀）后，代入不定积分表达式即可求出
唯一的常数 C，从而确定系统的特解。

### 例题
题目：分拣站电动推杆从复位原点启动，其推进速度随时间变化满足
v(t) = 6t² + 20t（单位：mm/s）。已知在启动瞬间（t = 0 s）推杆位于夹具
基准位 s(0) = 5 mm。求推杆位移函数 s(t)，并计算 t = 2 s 时推杆的实际位置。

解答：
第一步，对速度函数 v(t) 求不定积分获得位移通解：
s(t) = ∫ (6t² + 20t) dt = 6 × (1/3) t³ + 20 × (1/2) t² + C
     = 2t³ + 10t² + C。
第二步，代入初始条件确定积分常数 C：
已知 s(0) = 5 mm，代入通解得 2(0)³ + 10(0)² + C = 5，解得 C = 5。
因此，推杆位移函数特解为 s(t) = 2t³ + 10t² + 5（单位：mm）。
第三步，计算 t = 2 s 时的推杆位置：
s(2) = 2 × 2³ + 10 × 2² + 5 = 2 × 8 + 10 × 4 + 5 = 16 + 40 + 5 = 61 mm。

### 常见错误
1. 求不定积分后漏写积分常数 C，导致后续无法利用初始状态求出确定的系统特解。
2. 幂函数积分时误用求导法则：应当幂次加 1 并除以新幂次，而不是幂次减 1 或乘原幂次。
3. 误认为常数 C 必定等于初始条件给定的数值，未将 t = 0 代入表达式进行验算。

## 定积分与面积
定积分用于量化某一连续变化量在有限区间上的累计总效应。在质检站传送带
运动中，若速度 v(t) 随时间连续变化，将时间区间 [a, b] 细分为 n 个微小区间
Δtᵢ，每个小区间内用瞬时速度近似匀速运动，累加求和即得位移近似值。当最大
子区间长度趋近于零时，该和式的极限即为黎曼和，其极限值定义为定积分：
∫ₐᵇ v(t) dt = lim(n→∞) Σ v(ξᵢ) Δtᵢ。

定积分在几何上表示曲线 y = f(t) 与横轴及直线 t = a、t = b 围成的有向面积。
当 f(t) ≥ 0 时面积为正，物理上表示正向位移或系统吸能；当 f(t) < 0 时
面积为负，物理上表示反向运动或系统释能。代数和反映了区间的净积累量。

牛顿–莱布尼茨公式建立了导数与定积分的联系：若 F(t) 是连续函数 f(t) 的
任意一个原函数，则定积分可通过上下限的原函数差值计算：
∫ₐᵇ f(t) dt = F(b) - F(a)。
此外，定积分具有重要的线性性质与区间可加性：常数因子可提出积分号外；两函数
和的积分等于各自积分的和；对于区间内任意点 c，满足
∫ₐᵇ f(t) dt = ∫ₐᶜ f(t) dt + ∫(c→b) f(t) dt。

### 例题
题目：质检站分拣挡板在执行动作时，驱动电机的角速度满足
ω(t) = 3t² - 12t + 9（单位：rad/s），动作周期为 t 从 0 s 到 3 s。
利用牛顿–莱布尼茨公式计算该时段内挡板转过的净角位移 θ。

解答：
第一步，列出净角位移对应的定积分表达式：
θ = ∫₀³ (3t² - 12t + 9) dt。
第二步，求被积函数的原函数：
F(t) = 3 × (1/3) t³ - 12 × (1/2) t² + 9t = t³ - 6t² + 9t。
第三步，应用牛顿–莱布尼茨公式计算上限与下限的原函数差值：
F(3) = 3³ - 6(3)² + 9(3) = 27 - 54 + 27 = 0 rad。
F(0) = 0³ - 6(0)² + 9(0) = 0 rad。
θ = F(3) - F(0) = 0 - 0 = 0 rad。
物理含义：挡板先正向摆动后反向回位，在 3 秒末净角位移为 0 rad，回到原位。

### 常见错误
1. 混淆“净位移（定积分值）”与“实际路程”，在被积函数变号时直接套用定积分求路程。
2. 应用牛顿–莱布尼茨公式时代入次序颠倒，误算为 F(a) - F(b)。
3. 颠倒积分上下限时忽略符号变换，忘记当积分上限小于下限时定积分结果应取相反数。

## 换元积分与分部积分
工程实际中的响应曲线常由复合函数或函数乘积构成，需利用变换技巧求解。
第一类换元积分法（凑微分法）基于复合函数求导链式法则：若被积表达式可写为
f(g(t)) g'(t) dt，设中间变量 u = g(t)，则 du = g'(t) dt，原式转化为
∫ f(u) du。对于定积分换元，换元必须同时换限，即当 t 分别为 a 和 b 时，
新限 u 分别取 g(a) 和 g(b)，计算时直接代入新限，无须在计算后反代原变量。

分部积分法源于函数乘积求导法则 (uv)' = u'v + uv'。两端积分移项后得到
分部积分公式：∫ u dv = uv - ∫ v du。在定积分中表示为
∫ₐᵇ u dv = [uv]ₐᵇ - ∫ₐᵇ v du。

分部积分的关键是选取合适的 u 与 dv：选取原则通常是使 u 求导后结构显著简化
（例如多项式降幂），且 dv 易于直接积分得到 v。在机电系统的阻尼振荡与
衰减响应分析中，多项式与指数函数相乘的形式常用分部积分求解。

### 例题
题目：质检站阻尼吸能机构吸收工件冲击能量时，瞬时功率为
P(t) = 40 t e^(-2t)（单位：W）。求该机构在 t 从 0 s 到 2 s 内吸收的
总能量 E（保留两位小数，已知 e⁻⁴ ≈ 0.0183）。

解答：
第一步，写出能量积分式：
E = ∫₀² 40 t e^(-2t) dt = 40 ∫₀² t e^(-2t) dt。
第二步，利用分部积分法，选取 u = t，dv = e^(-2t) dt。
求导得 du = dt，积分得 v = -(1/2) e^(-2t)。
第三步，代入定积分分部积分公式：
∫₀² t e^(-2t) dt = [ -0.5 t e^(-2t) ]₀² - ∫₀² [ -0.5 e^(-2t) ] dt
                 = [ -e^(-4) - 0 ] + 0.5 ∫₀² e^(-2t) dt
                 = -e^(-4) - 0.25 [ e^(-4) - e⁰ ]
                 = 0.25 - 1.25 e^(-4)。
第四步，代入系数计算吸收总能量：
E = 40 × [ 0.25 - 1.25 e^(-4) ] = 10 - 50 e^(-4)
  ≈ 10 - 50 × 0.0183 = 10 - 0.915 = 9.08 J。

### 常见错误
1. 定积分换元时忘记同步更换上下限，导致上下限与积分变量不匹配。
2. 记错分部积分公式符号，将 uv - ∫ v du 误写为 uv + ∫ v du。
3. 选取 u 和 dv 时主次颠倒，导致积分后被积函数次数升高、表达式更繁琐。

## 数值积分
在桌面质检分拣站的实际控制系统中，传感器采集的数据通常是以固定时间间隔
记录在单片机内存或 CSV 文件中的离散数据序列，缺乏连续解析表达式。此时
必须使用数值积分方法来估算累计位移或电能消耗。

梯形法则（Trapezoidal Rule）是工程中最常用的数值积分算法。其核心思路是
将时间区间 [a, b] 划分为 n 个等宽子区间，采样周期即步长 h = Δt = (b - a)/n。
在每个微小子区间上，用连接两端采样点的弦线替代未知真实曲线，将曲线下面积
近似为一个直角梯形面积。

对所有相邻采样区间的梯形面积进行累加，得到复合梯形法则计算公式：
```
∫ₐᵇ f(t) dt ≈ (h / 2) × [ f(t₀) + 2 f(t₁) + 2 f(t₂) + ... + 2 f(tₙ₋₁) + f(tₙ) ]
```
公式规律表明：首点与末点采样值的权重为 1，所有中间采样点的权重均为 2。

复合梯形法则的截断误差与步长的平方 h² 成正比（二阶精度）。当采样频率
加倍（即采样周期 h 减半）时，理论算法误差将缩小至原来的四分之一。在单片机
资源允许的情况下，提高采样频率能有效提升累计量的估算精度。

### 例题
题目：质检站传送带光电传感器以固定步长 h = 0.5 s 记录工件运行速度，
t 从 0 s 到 2 s 内采集的 5 个时刻速度值（单位：mm/s）依次为：
t₀ = 0.0 s, v₀ = 10；t₁ = 0.5 s, v₁ = 18；t₂ = 1.0 s, v₂ = 24；
t₃ = 1.5 s, v₃ = 22；t₄ = 2.0 s, v₄ = 16。
使用复合梯形法则估算工件在 2 秒内的累计位移 S。

解答：
第一步，明确步长与采样数据权重：
步长 h = 0.5 s。首点 v₀ 与末点 v₄ 权重为 1，中间点 v₁、v₂、v₃ 权重为 2。
第二步，代入复合梯形法则公式：
S ≈ (h / 2) × [ v₀ + 2v₁ + 2v₂ + 2v₃ + v₄ ]
  = (0.5 / 2) × [ 10 + 2 × 18 + 2 × 24 + 2 × 22 + 16 ]
  = 0.25 × [ 10 + 36 + 48 + 44 + 16 ]
  = 0.25 × 154 = 38.5 mm。
工件在 2 秒内的估计累计位移为 38.5 mm。

### 常见错误
1. 累加求和时遗漏中间项系数 2，误将所有采样点直接相加再乘以 (h/2)。
2. 将公式前置系数 (h/2) 误写为 h，导致所有计算结果放大一倍。
3. 混淆截断误差阶数，误以为梯形法则误差与步长 h 呈线性比例关系。

## 单元小结
- 积分是微分的逆运算：不定积分给出含有任意常数 C 的原函数族，结合设备
  初始条件能够唯一确定系统的运动状态特解。
- 定积分量化连续变化的累计量：牛顿–莱布尼茨公式通过原函数差值高效求值，
  其几何意义对应有向面积的代数和。
- 换元法与分部积分拓展了解析求解能力：凑微分实现变量代换（定积分须换限），
  分部积分巧妙化解多项式与指数函数等乘积积分。
- 梯形法则架起离散时序数据与连续数学的桥梁：首末权一、中间权二，误差与
  步长平方成正比，适用于单片机与表格离散求和。
