# 多元函数入门

本单元学习处理多个控制参数与传感器变量的基本工具，包括偏导数的计算与含义、梯度向量与参数调优方向，以及单变量函数的多项式近似（泰勒展开入门），并完成位置与速度采样的综合实作。

## 本单元知识点
- 偏导数：固定其余变量求导，掌握多变量系统的局部变化率与灵敏度分析。
- 梯度与方向：由偏导数构成的向量，指示函数值增长最快的方向与优化思路。
- 泰勒展开入门：在基准工作点附近用多项式近似非线性函数并理解截断误差。
- 位置与速度曲线采样（自评）：用表格计算离散差分并对比区间中点瞬时速度。

## 偏导数
在桌面质检分拣站中，系统性能往往同时取决于多个输入量。例如推杆电机
的功率损耗既受工作电流影响，也受线圈阻值和工作温度影响。当因变量由
两个或更多自变量共同决定时，我们使用多元函数 z = f(x, y) 进行建模。

分析多元函数时最基本的工程思路是“控制变量法”。当我们希望探究自变量 x 
的变化对因变量 z 的瞬时影响率时，假定其他所有自变量（如 y）保持不变，
将其视为常数，然后按照一元函数的求导法则对 x 求导。所得结果称为函数对 x 
的偏导数，记作 ∂z/∂x 或 f_x(x, y)。同理，把 x 看作常数对 y 求导，
即得到函数对 y 的偏导数 ∂z/∂y 或 f_y(x, y)。

偏导数具有明确的几何与物理意义。在曲面 z = f(x, y) 上，∂z/∂x 表示曲面
沿平行于 x 轴截开的剖面线上切线的斜率。在分拣站的工程实践中，偏导数
反映了在其他运行工况固定不变的前提下，某一特定控制参数变动对系统指标的
边际灵敏度。

### 例题
某分拣站推杆电机的功率损耗公式为 P(I, R) = I²·R（单位：W），其中 I 为
驱动电流（单位：A），R 为绕组电阻（单位：Ω）。求偏导数 ∂P/∂I 和 ∂P/∂R，
并计算工作点 I = 3 A，R = 2 Ω 时的偏导数值。

解答：
1. 计算对 I 的偏导数时，将 R 视为常数：
   ∂P/∂I = ∂(I²·R)/∂I = 2I·R
2. 计算对 R 的偏导数时，将 I 视为常数：
   ∂P/∂R = ∂(I²·R)/∂R = I²
3. 将 I = 3 A，R = 2 Ω 代入解析式：
   ∂P/∂I = 2 × 3 × 2 = 12 W/A
   ∂P/∂R = 3² = 9 W/Ω
计算表明：在当前工况下，若电阻保持不变，电流每增加 1 A，功率损耗瞬时
增加 12 W；若电流保持不变，电阻每增加 1 Ω，损耗增加 9 W。

### 常见错误
- 求偏导时忘记将其他变量当作常数，误按全导数或乘积导数引入了未知的导数项。
- 混淆常数乘项与独立常数项，例如把自变量相乘项中的常数因子误当作独立常数求导成 0。

## 梯度与方向
设二元连续可微函数 z = f(x, y)，由其在点 (x, y) 处对两个自变量的偏导数
按坐标顺序排列构成的向量，称为函数在该点的梯度（Gradient），
记作 grad f 或 ∇f(x, y) = (∂f/∂x, ∂f/∂y)。

梯度向量具有重要的几何与物理性质：梯度向量的方向指向函数值在该点增长最快
（即坡度最陡峭）的方向；梯度的模长 ||∇f|| = √((∂f/∂x)² + (∂f/∂y)²) 则等于
沿该最大增长方向的方向导数（最大变化率）。相反，负梯度方向 -∇f(x, y)
则是函数值局部下降最快的方向。

梯度下降思路是现代工程调优与参数标定的核心。例如在分拣站视觉相机的位姿
微调或电机伺服响应优化中，我们定义一个误差函数 E(w₁, w₂)。由于无法直接
解析求解极小值点，控制器从初值出发，每次沿着负梯度的方向修正参数：
新参数 = 旧参数 - 步长 × ∇E。通过多次迭代逐步逼近误差最小的最优工作点。

### 例题
质检相机高度定位底座的误差函数为 E(x, y) = 3x² + 2y²（单位：mm²），
其中 x 和 y 为两个微调手轮的位移偏差（单位：mm）。求误差函数在点 (1, 2)
处的梯度向量 ∇E(1, 2) 以及在该点的最大误差增长率。

解答：
1. 分别求关于坐标变量 x 和 y 的偏导数：
   ∂E/∂x = ∂(3x² + 2y²)/∂x = 6x
   ∂E/∂y = ∂(3x² + 2y²)/∂y = 4y
2. 写出梯度向量形式：
   ∇E(x, y) = (6x, 4y)
3. 代入指定工作点坐标 (1, 2)：
   ∇E(1, 2) = (6 × 1, 4 × 2) = (6, 8)
4. 计算梯度向量的模长：
   ||∇E(1, 2)|| = √(6² + 8²) = √(36 + 64) = 10 mm²/mm
结论：在点 (1, 2) 处，误差增长最快的方向为向量 (6, 8) 的方向，其最大
变化率为 10 mm²/mm。若要最快减小系统误差，应沿负梯度方向 (-6, -8) 调整手轮。

### 常见错误
- 误将梯度向量当成标量数值，混淆了“梯度向量”与“梯度的模长”。
- 在执行参数优化时记错符号，误沿着正梯度方向调节参数，导致系统误差扩大发散。

## 泰勒展开入门
在工程系统建模中，许多传感器特性、电磁响应或热敏规律都是高度非线性的。
为了便于在控制器或单片机中快速计算并分析局部稳定性，我们常用多项式来
逼近非线性函数。泰勒展开提供了一种在基准工作点附近逐阶逼近函数的标准方法。

若函数 f(x) 在基准点 x = 0 处各阶导数均存在，其泰勒公式（麦克劳林展开）为：
f(x) ≈ f(0) + f'(0)·x + [f''(0)/2!]·x² + [f'''(0)/3!]·x³ + ...
其中前两项 f(0) + f'(0)·x 即为前面学过的切线线性近似；二次项和更高阶项
则逐级补充了曲线弯曲度和高阶变化特征。

工程常用的基准函数展开式（在 x = 0 附近）：
- eˣ ≈ 1 + x + x²/2 + x³/6
- sin x ≈ x - x³/6
- cos x ≈ 1 - x²/2

当我们在实际计算中只保留前几项时，被舍弃的其余高阶项总和称为截断误差。
在自变量 x 极其接近展开中心（|x| 较小）时，高次项衰减极快，截断误差
非常小；但当 x 明显偏离基准点时，低阶多项式误差急剧增加，需要增加项数
或重新在新的工作点附近展开。

### 例题
桌面分拣站温度传感器将环境温差 ΔT（单位：°C）转换为响应电流信号，
满足模型 I(ΔT) = 5·e^(0.2·ΔT)（单位：mA）。试利用指数展开式的前三项
eᵘ ≈ 1 + u + u²/2，建立 I(ΔT) 在 ΔT = 0 附近的二阶多项式近似，
并估算 ΔT = 0.5 °C 时的电流值。

解答：
1. 令 u = 0.2·ΔT，在 ΔT 接近 0 时利用展开式：
   e^(0.2·ΔT) ≈ 1 + (0.2·ΔT) + (0.2·ΔT)² / 2 = 1 + 0.2·ΔT + 0.02·(ΔT)²
2. 展开式两端乘以系数 5，得到多项式近似模型：
   I(ΔT) ≈ 5·[1 + 0.2·ΔT + 0.02·(ΔT)²] = 5 + 1·ΔT + 0.1·(ΔT)²
3. 将 ΔT = 0.5 °C 代入多项式求值：
   I(0.5) ≈ 5 + 1 × 0.5 + 0.1 × (0.5)² = 5 + 0.5 + 0.025 = 5.525 mA
真实值 5·e^(0.1) ≈ 5.52585 mA，二阶近似绝对误差仅约 0.00085 mA，
完全满足工业信号采集的快速近似要求。

### 常见错误
- 遗漏高阶项分母中的阶乘，如误把二次项分母 2! = 2 或三次项分母 3! = 6 遗漏。
- 脱离展开中心过远依然使用低阶泰勒多项式，导致截断误差失控。

## 位置与速度曲线采样（自评）
目标：在电子表格中建立离散采样模型，计算工件位移 x(t) = t² 和速度
v(t) = 2t 的采样数据序列，比较相邻采样点的平均速度与对应区间中点的
瞬时速度，直观理解离散差分与连续导数的关系。

材料或准备：具备电子表格软件（如 LibreOffice Calc、Excel 等）的电脑
或能生成表格数据的计算工具。

步骤：
1. 新建工作表，在 A 列建立时间序列 t，自 t = 0.0 s 起，以步长 Δt = 0.5 s
   均匀递增，填写至 t = 3.0 s（共 7 个采样时刻点）。
2. 在 B 列输入公式计算位移 x(t) = t²（单位：mm）；在 C 列输入公式计算理论
   瞬时速度 v(t) = 2t（单位：mm/s）。
3. 在 D 列计算相邻两采样点之间的平均速度：
   v_avg = [x(tₖ₊₁) - x(tₖ)] / Δt
4. 在 E 列计算相邻两采样点对应的时间中点 t_mid = (tₖ + tₖ₊₁)/2，并在
   F 列计算该中点处的瞬时速度 v(t_mid) = 2·t_mid。
5. 对比 D 列与 F 列的数值，观察平均变化率与区间中点瞬时导数的大小关系；
   选中 A 列至 C 列生成折线图，观察抛物线位移与线性速度的变化趋势。

## 单元小结
- 偏导数运用控制变量思想，固定其余自变量，定量评估单输入参数变动对系统的局部影响。
- 梯度向量汇集了所有方向的局部变化率，其方向指向函数值增长最快的路径，其反方向构成了算法寻优与参数调校的基石。
- 泰勒展开是在工作点附近将非线性系统进行多项式简化的强力工具，截断误差取决于展开阶数与偏离中心的距离。
- 离散采样实验直观印证了平均变化率与瞬时导数切线斜率在微小时间尺度上的内在统一。
