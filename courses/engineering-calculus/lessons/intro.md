# 函数与变化率
本单元以桌面质检分拣站为工程背景，学习函数映射模型、平均变化率与采样差商、
极限逼近思想及系统连续性，为后续掌握导数、瞬时速度与设备响应奠定数学基础。

## 本单元知识点
- 函数与常见函数：掌握定义域与值域判定，理解多项式、指数、对数与正弦函数的工程特性及复合规律。
- 平均变化率：掌握自变量与因变量增量比值 Δy/Δx，理解割线斜率，能根据传感器采样表计算平均速度。
- 极限的直观理解：通过数值逼近与图像理解极限趋势与左右极限，掌握常见极限计算及无穷小量概念。
- 连续性：理解连续的极限定义与几何意义，掌握间断点分类，并能判定分段控制函数在分界点的连续性。

## 函数与常见函数
函数是描述自动化工位中不同物理量之间依赖关系的数学工具。如果对于输入变量
x 的每一个合法取值，输出变量 y 都有唯一确定的数值与之对应，则称 y 是 x 的函数，
记作 y = f(x)。其中自变量 x 允许取值的集合为定义域，因变量 y 对应产生的所有数值
的集合为值域。在工程实务中，定义域和值域通常受传感器量程和机构物理行程的严格限制。

工程中常见的四类基础函数具有明确的物理意义：多项式函数常用于描述匀加速或平滑
运动的位置规律；指数函数 y = e⁻ᵏᵗ（k > 0）常用于描述电容放电、温度冷却等一阶
惯性衰减过程；对数函数常用于放大微弱信号并压缩宽动态范围数据；正弦函数 y = A sin(ωt + φ)
则广泛用于描述步进电机旋转编码器输出、机构振动等周期性交变过程。

当一个量的变化通过中间变量间接影响最终输出时，构成复合函数。若 y = f(u) 且
u = g(x)，则 y = f(g(x))。在分拣站中，时间 t 驱动电机转角 θ，转角 θ 再驱动挡板末端
位移 y，整体位移即为时间 t 的复合函数。构成复合函数的充要条件是内层函数的值域必须
落在外层函数的定义域范围内。

### 例题
质检工位使用红外测距传感器监测工件高度。传感器调理电路将测量距离 x（单位：mm）
转换为输出电压 U（单位：V），关系为 U(x) = 200 / (x + 30)。传感器标称有效量程
为 10 mm ≤ x ≤ 70 mm。试求该传感器在此量程下的输出电压范围（值域）。

解答：
第一步，分析函数单调性。对于函数 U(x) = 200 / (x + 30)，当 x 在区间 [10, 70] 内
递增时，分母 (x + 30) 单调递增且大于零，因此 U(x) 在定义域上单调递减。
第二步，计算定义域端点处的函数值：
当 x = 10 mm 时，U(10) = 200 / (10 + 30) = 200 / 40 = 5.0 V。
当 x = 70 mm 时，U(70) = 200 / (70 + 30) = 200 / 100 = 2.0 V。
第三步，确定值域。由于 U(x) 在闭区间 [10, 70] 上单调递减且连续，其输出电压的值域
为 [2.0, 5.0] V。该电压范围即为后端单片机 ADC 采样通道需要匹配的量程区间。

### 常见错误
1. 忽略物理约束直接按纯代数求值域，例如未限制 x ≥ 10，导致得出无穷大等不切实际结论。
2. 在计算复合函数时混淆内外层映射次序，错误地将 f(g(t)) 算成 g(f(t))。
3. 误将单调递减函数两端点的计算结果直接书写为 [5.0, 2.0]，颠倒了区间的上下界次序。

## 平均变化率
在工程系统运行过程中，物理量随时间变化的快慢是监控的核心指标。设变量 y 随变量 x
变化，当自变量由 x₁ 变到 x₂ 时，自变量的增量记作 Δx = x₂ - x₁；因变量的对应增量
记作 Δy = y₂ - y₁ = f(x₂) - f(x₁)。比值 Δy/Δx 称为函数 y = f(x) 在区间 [x₁, x₂] 上的
平均变化率。

平均变化率具有清晰的几何意义与物理意义：在平面直角坐标系中，点 P(x₁, y₁) 与
Q(x₂, y₂) 是函数图像上的两个状态点，比值 Δy/Δx 恰好等于连接两点的割线 PQ 的斜率。
在分拣站输送带场景中，若自变量为运行时间 t（s），因变量为工件位移 s（mm），
则比值 Δs/Δt 即表示工件在时间段 [t₁, t₂] 内的平均速度 v_avg。

实际工业控制中，到位传感器和视觉检测系统通常以固定的时间周期 T（如每隔 0.1 s）
对工件坐标进行采样并记录至 CSV 文件。利用采样表计算相邻两个采样点之间的差商，
是单片机估算设备运行速度、监控传送带是否卡滞堵料的最基础数值算法。

### 例题
质检输送带上的光电测距模块记录了某合格工件的位移数据：在 t₁ = 1.2 s 时，工件距离
初始挡板 s₁ = 144 mm；在 t₂ = 1.6 s 时，工件距离初始挡板 s₂ = 224 mm。试计算工件
在时间区间 [1.2, 1.6] s 内的平均速度，并说明其对应的割线斜率含义。

解答：
第一步，计算时间增量与位移增量：
时间增量 Δt = t₂ - t₁ = 1.6 - 1.2 = 0.4 s。
位移增量 Δs = s₂ - s₁ = 224 - 144 = 80 mm。
第二步，计算平均速度：
v_avg = Δs / Δt = 80 mm / 0.4 s = 200 mm/s。
第三步，解释几何意义：
在 s-t 坐标系中，点 (1.2, 144) 与点 (1.6, 224) 之间的割线斜率等于 200 mm/s。
这表明在该 0.4 s 时间内，无论工件中间是否有微小的加减速抖动，其整体宏观推进
速率等效为每秒向前平移 200 mm。

### 常见错误
1. 增量计算前后颠倒，将 Δs 算成 s₁ - s₂ 导致算出的平均速度带有错误的负号。
2. 混淆平均速度与瞬时速度，误将 0.4 s 区间内的平均速度当作 t = 1.2 s 瞬间的真实速度。
3. 在计算全程平均速度时，直接对多段子区间的平均速度求简单算术平均，忽视了时间权重。

## 极限的直观理解
极限思想是微积分大厦的基石，用于研究变量在无限趋近某一目标时的稳定趋势。
设函数 y = f(x)，当自变量 x 无限接近于常数 x₀ 但不等于 x₀ 时，如果函数值 f(x)
无限接近于一个确定的常数 L，则称常数 L 为函数 f(x) 当 x 趋向于 x₀ 时的极限，
记作 lim(x→x₀) f(x) = L。

极限具有方向性，分为左极限与右极限。当 x 从小于 x₀ 的左侧趋近于 x₀ 时，极限记作
lim(x→x₀⁻) f(x)；当 x 从大于 x₀ 的右侧趋近于 x₀ 时，极限记作 lim(x→x₀⁺) f(x)。
极限存在的充分必要条件是：左极限与右极限都必须存在，且两者的数值严格相等。
如果左右极限不相等，或者趋向于无穷大，则极限不存在。

在初等极限计算中，对于在趋近点处有良好定义的代数式，可直接代入计算；当遇到
分子与分母同时趋近于 0 的 0/0 型未定式时，通常通过因式分解、消去公因式或有理化
分子等方法转化后再代入求值。若变量在某一变化过程中的极限为 0，则该变量称为无穷小量；
若其绝对值无限增大，则称为无穷大量。无穷小量是分析瞬时变化率的核心工具。

### 例题
分拣站工件在定位槽中的位移规律满足二次函数 s(t) = 2t²（单位：mm）。为求解在
t = 3 s 时的瞬时变化趋势，先计算时间增量为 Δt 时的平均速度表达式 Δs/Δt，再求
当时间增量 Δt 趋近于 0 时的极限值 lim(Δt→0) Δs/Δt。

解答：
第一步，写出从 t = 3 到 t = 3 + Δt 的位移增量表达式：
Δs = s(3 + Δt) - s(3) = 2(3 + Δt)² - 2(3)²
展开得：Δs = 2(9 + 6Δt + (Δt)²) - 18 = 18 + 12Δt + 2(Δt)² - 18 = 12Δt + 2(Δt)²。
第二步，建立平均速度的差商表达式（假设 Δt ≠ 0）：
Δs / Δt = [12Δt + 2(Δt)²] / Δt = 12 + 2Δt。
第三步，对差商表达式取 Δt → 0 的极限：
lim(Δt→0) (Δs / Δt) = lim(Δt→0) (12 + 2Δt) = 12 + 2 × 0 = 12 mm/s。
该极限结果表明，当采样时间间隔无限缩小时，割线斜率无限逼近切线斜率 12 mm/s。

### 常见错误
1. 混淆极限值与函数值，误认为如果函数在某点没有定义，该点处的极限就必然不存在。
2. 遇到 0/0 型表达式时未进行因式分解消除零因式，直接断言表达式无意义或结果等于 0。
3. 误将无穷小量当成一个极小的固定常数（如 0.0001），而未理解其本质是趋近于 0 的变量。

## 连续性
在工业控制与机械运动中，连续性表征了物理系统不发生断裂、突跃的平稳状态。
若函数 y = f(x) 在点 x₀ 的某个邻域内有定义，且满足三个条件：函数在 x₀ 处有确定值 f(x₀)；
极限 lim(x→x₀) f(x) 存在；该极限值严格等于函数值 f(x₀)，即 lim(x→x₀) f(x) = f(x₀)，
则称函数 f(x) 在点 x₀ 处连续。若在某区间内每一点都连续，则称该函数在区间上连续。

如果函数在点 x₀ 不满足上述连续条件，则该点称为间断点。在分拣系统中常见的间断点
包括跳跃间断点（如继电器开关导通瞬间电压由 0 V 阶跃至 24 V，左右极限均存在但不相等）
和无穷间断点（如某些传感器反比例放大增益在分母为零时无限发散）。初等函数在其自身
的定义域区间内都是连续的。

分拣站的伺服或步进驱动常常采用分段函数来规划加减速轮廓。在分段函数的分界点处，
必须分别校核左极限、右极限与该点的实际函数值。只有三者完全吻合时，速度或位移
曲线才连续，电机才不会出现剧烈的机械冲击、丢步或电磁噪音。

### 例题
分拣推杆的速度曲线设计为两段规划：当时间 0 ≤ t ≤ 3 s 时，v(t) = 3t（单位：mm/s）；
当 3 < t ≤ 8 s 时，v(t) = -t + 12。请判断推杆速度曲线在切换时刻 t = 3 s 处是否连续，
并给出严格证明。

解答：
第一步，计算在 t = 3 s 处的实际函数值：
根据分段定义，t = 3 属于第一段区间 [0, 3]，因此 v(3) = 3 × 3 = 9 mm/s。
第二步，计算时间趋于 3 s 时的左极限：
lim(t→3⁻) v(t) = lim(t→3⁻) (3t) = 3 × 3 = 9 mm/s。
第三步，计算时间趋于 3 s 时的右极限：
lim(t→3⁺) v(t) = lim(t→3⁺) (-t + 12) = -3 + 12 = 9 mm/s。
第四步，对比结论：
由于左极限等于右极限且等于函数值，即 lim(t→3) v(t) = v(3) = 9 mm/s，故推杆速度
函数在切换点 t = 3 s 处严格连续。推杆在由加速段转入减速段时速度平滑过渡，无速度阶跃。

### 常见错误
1. 仅验证了左极限等于右极限，忽略了检查该点函数值是否存在且是否与极限值相等。
2. 机械地认为分段函数在分段点处一定不连续，没有通过代入端点极限进行定量计算。
3. 在工程应用中将连续性与光滑性混淆，误以为速度曲线连续就代表加速度也必然平滑。

## 单元小结
- 函数映射与工程约束：函数建立了分拣站中各类传感器信号与机械位移的确定对应关系，
  工程应用中必须严格考虑物理行程与测量量程对定义域与值域的限制。
- 割线斜率与平均变化率：平均速度是位移与时间增量的比值 Δs/Δt，对应 s-t 图像上
  割线的斜率，是离散时间采集数据中最基础的设备运动状态评估指标。
- 极限思想与无穷小量：极限描述自变量趋于目标时函数值的演化趋势；左右极限相等是
  极限存在的判据；当时间增量 Δt 趋近于无穷小量 0 时，割线斜率逼近瞬时速度。
- 连续性与系统平稳性：连续性要求极限存在且等于函数值；识别跳跃等间断点、保证
  控制曲线在过渡分界点连续，是消除设备机械冲击和电机失步的关键工程准则。
