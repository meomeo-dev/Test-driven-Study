# 高等数学（工程应用）

从导数、积分和常微分方程理解速度、累计量与设备响应。

## 学习起点

先掌握函数、代数运算与坐标图。建议并行复习三角函数。

- 极限与导数 → 积分与单位 → 一阶微分方程 → 多元函数和梯度。

## 学完能做什么

- 用导数解释瞬时速度和斜率。
- 用定积分解释净位移和累计量。
- 能从一阶动态过程辨认输入、状态和时间变化。

**桌面质检分拣站实作**。用表格画出 x(t) = t² 的位置曲线和 v(t) = 2t 的速度曲线，比较相邻采样点的平均速度。

## 课程内容

1.1.0 版包含七个单元、27 个知识点和 134 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 函数与变化率 | 函数与常见函数；平均变化率；极限的直观理解；连续性 |
| 导数 | 导数的定义与意义；求导法则；复合函数求导；指数、对数与三角函数的导数 |
| 导数的应用 | 单调性与极值；最优化问题；线性近似与微分；速度、加速度与相关变化率 |
| 积分 | 原函数与不定积分；定积分与面积；换元积分与分部积分；数值积分 |
| 积分的应用 | 累计量与净位移；函数的平均值；面积、体积与功 |
| 一阶微分方程 | 微分方程的基本概念；可分离变量方程；一阶线性系统与时间常数；欧拉法数值求解 |
| 多元函数入门 | 偏导数；梯度与方向；泰勒展开入门；位置与速度曲线采样（自评） |

“位置与速度曲线采样”是自评实作，没有练习题。
按[多元函数入门讲义](lessons/multivariable.md)中的自评清单完成后，
在学习路径中标记已会。
