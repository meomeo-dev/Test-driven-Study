# 循环

本单元学习 C 语言中的 while、do-while 与 for 循环结构，以及 break 与
continue 控制语句和嵌套循环，掌握重复执行、状态轮询与批量数据处理的核心方法。

## 本单元知识点

- while 与 do-while：掌握条件循环与先执行后判断的控制逻辑，学会设计退出条件防范死循环。
- for 循环与计数：掌握初始化、条件判定与更新三要素，运用计数器实现定次循环与累加。
- break 与 continue：掌握提前终止循环与跳过当次迭代的机制，实现工位异常处理与过滤。
- 嵌套循环与执行次数：理解多层循环的运行机制与乘法原理，掌握矩阵与批次工件遍历方法。

## while 与 do-while

在单片机分拣工位中，程序常需持续等待某个事件发生（如工件到达传感器）。
循环结构用于在满足特定条件时重复执行一段代码，避免编写冗余重复的语句。

while 循环的语法为 while (条件表达式) { 循环体; }。执行时先评估条件表达式的值：
若条件为非零（真），则执行大括号内的循环体；执行完毕后再次测试条件，直到条件为
零（假）时退出循环。若初始条件即为假，while 循环体一次也不会执行。

do-while 循环的语法为 do { 循环体; } while (条件表达式);。与 while 不同，
do-while 先无条件执行一次循环体，然后再检验条件表达式。因此无论初始条件真假，
其循环体至少执行一次。需要特别注意：do-while 语句末尾的小括号后必须加分号。

当循环条件恒为真且循环体内无法改变判定变量时，程序会陷入死循环，导致系统失去响应。
编写循环时必须确保循环体内存在改变判定条件、使条件最终能够转为假的更新逻辑。

### 例题

【题目】分拣工位的到位传感器信号存放在变量 sensor 中（0 为未到位，1 为到位）。
编写程序模拟轮询过程：每等待一轮循环，轮询计数器 poll_count 加 1；当轮询满 3 次时，
传感器检测到工件到来（sensor 置 1），循环随之结束，最后输出总轮询次数。

【解答】
```c
#include <stdio.h>

int main(void) {
    int sensor = 0;
    int poll_count = 0;
    while (sensor == 0) {
        poll_count++;
        if (poll_count >= 3) {
            sensor = 1;
        }
    }
    printf("轮询结束，总轮询次数: %d\n", poll_count);
    return 0;
}
```
输出结果为：
轮询结束，总轮询次数: 3
分析：初始时 sensor 为 0，while 条件成立进入循环体；前两轮 poll_count 分别自增为
1、2，sensor 保持 0；第 3 轮 poll_count 增至 3，满足 if 条件使 sensor 变为 1；
下一轮判定 sensor == 0 为假，循环退出并输出 3。

### 常见错误

1. 遗漏 do-while 语句末尾的分号：写成 do { ... } while (条件) 缺少结尾分号引发编译错误。
2. 循环体内漏写更新语句：例如在 while (count < 5) 中漏写 count++，导致条件恒为真产生死循环。
3. 误将判等运算符 == 写作赋值符号 =：如 while (sensor = 0) 会先赋值并判定为 0 导致循环直接退出。

## for 循环与计数

当已知确定的重复次数或需要依序遍历区间数值时，for 循环是最规范和常用的结构。
它将控制循环的三个关键动作集中在头部，提高了代码的可读性与维护性。

for 循环的语法格式为：for (初始化表达式; 条件表达式; 步进更新表达式) { 循环体; }。
执行流程遵循固定顺序：
1. 循环开始前，首先执行初始化表达式（仅执行一次），通常用于给计数器赋初值；
2. 评估条件表达式，若结果为真则执行循环体，若为假则直接终止并跳出循环；
3. 循环体执行完毕后，执行步进更新表达式（如自增、自减或步长递加）；
4. 重新返回第 2 步评估条件，如此循环往复。

计数器的闭开区间与循环次数规律：从 0 开始的标准定次循环 for (int i = 0; i < n; i++)
恰好执行 n 次，计数器依次取值 0 到 n - 1；若写为 for (int i = 1; i <= n; i++)，
同样执行 n 次，计数器取值 1 到 n。

数据累加模式：在循环外部定义一个累加器变量并赋初始值 0（如 int sum = 0;），
在循环体内部利用复合赋值运算符（如 sum += value;）逐步累加数据。

### 例题

【题目】分拣工位连续检测 4 个工件的质量读数，工件重量增量刚好与批次序号 i 相同。
使用 for 循环计算这 4 个工件的重量总和，并打印累计值。

【解答】
```c
#include <stdio.h>

int main(void) {
    int total_weight = 0;
    for (int i = 1; i <= 4; i++) {
        total_weight += i;
    }
    printf("4个工件总重量: %d\n", total_weight);
    return 0;
}
```
输出结果为：
4个工件总重量: 10
分析：i 从 1 开始，循环执行 4 轮；各轮累加值分别为 1、2、3、4；
total_weight 依次变为 1、3、6、10；当 i 增至 5 时不满足 i <= 4，退出循环。

### 常见错误

1. 累加器变量未赋初值：声明 int sum; 后直接执行 sum += i;，读取未初始化的内存垃圾值。
2. 边界判定引发差一错误（Off-by-one）：需循环 5 次时写成 i <= 5（从 0 起步）导致多跑一轮。
3. for 头部右括号后误加分号：写成 for (int i = 0; i < 5; i++); 会将空语句循环 5 次。

## break 与 continue

在流水线运行过程中，常需要根据突发事件改变循环流程。C 语言提供了 break 和
continue 两条转向语句来精细控制循环执行。

break 语句的作用是立即跳出并终止当前所在的那一层循环。程序执行到 break 后，
无论循环条件是否依然为真，后续的循环体代码与后续所有迭代轮次都会被全部放弃，
直接跳转到该循环闭合大括号之后的下一条语句。常用于检测到急停信号或严重故障。

continue 语句的作用是提前结束“当前这一次”迭代。程序遇到 continue 时，会跳过
循环体中位于 continue 之后的剩余代码，直接前进到下一次循环周期的准备阶段：
在 for 循环中跳转到步进更新表达式，在 while 循环中跳转到条件表达式判定。
常用于过滤无效数据（如跳过传感器偶发的负数异常噪声）。

对比两者的核心区别：break 是彻底终结循环，不再回头；continue 是跳过本轮剩余操作，
保留后续轮次的执行机会。注意两者都仅对直接包围它们的当前层循环生效。

### 例题

【题目】分拣工位检测 5 个工件，编号为 1 到 5。规则如下：若遇到编号为 2 的工件
（测试件），跳过其数据处理；若遇到编号为 4 的工件触发了停机标志，立即终止分拣。
使用循环统计最终被正常处理的工件数量。

【解答】
```c
#include <stdio.h>

int main(void) {
    int processed = 0;
    for (int id = 1; id <= 5; id++) {
        if (id == 2) {
            continue;
        }
        if (id == 4) {
            break;
        }
        processed++;
    }
    printf("成功处理工件数: %d\n", processed);
    return 0;
}
```
输出结果为：
成功处理工件数: 2
分析：id=1 正常累加（processed 为 1）；id=2 触发 continue 跳过累加；id=3 正常累加
（processed 为 2）；id=4 触发 break 直接终止整个循环，id=5 不会被执行。最终结果为 2。

### 常见错误

1. 混淆 break 与 continue 的业务语义：误将跳过当次异常写成 break，导致工位流水线提早停机。
2. 在 while 循环中使用 continue 时将计数更新写在其后：导致更新被跳过，程序陷入死循环。
3. 误以为 break 能直接退出多层嵌套循环：单层 break 只能退出直接包围它的最内层循环。

## 嵌套循环与执行次数

在实际生产中，工件常按矩阵托盘或多批次存放（例如 3 个料盒，每个料盒放置 4 个工件）。
处理此类多维排布的数据需要使用嵌套循环。

嵌套循环是指在一个循环的循环体内部完整包含另一个循环。处于外部的称为外层循环，
被包含在内部的称为内层循环。外层与内层可以使用相同或不同类型的循环语句。

执行流程与乘法原理：外层循环每执行一次，内层循环就会重新开始，完整经历初始化、
条件判断、循环体执行到退出的全部生命周期。若外层循环执行 M 次，且在每次外层迭代中
内层循环均固定执行 N 次，则内层循环体的总执行次数严格遵循乘法法则：M × N 次。

二维遍历设计规范：通常外层循环变量（如 row、batch）控制宏观行号或批次号，
内层循环变量（如 col、slot）控制微观列号或工件槽位。为防止逻辑混乱，
内外层循环应使用互不相同的变量名（如常见的 i 与 j），避免内层变量遮蔽外层变量。

### 例题

【题目】分拣工位有 2 个料箱，每个料箱包含 3 个检测格位。编写程序使用双重 for 循环
模拟扫描所有格位，并统计扫描的总格位数。

【解答】
```c
#include <stdio.h>

int main(void) {
    int total_slots = 0;
    for (int box = 1; box <= 2; box++) {
        for (int slot = 1; slot <= 3; slot++) {
            total_slots++;
        }
    }
    printf("总扫描格位数: %d\n", total_slots);
    return 0;
}
```
输出结果为：
总扫描格位数: 6
分析：外层 box 取值 1、2（共 2 次）；每次外层迭代中，内层 slot 均依次取 1、2、3
（共 3 次）；内层循环体执行次数为 2 × 3 = 6 次，最终 total_slots 累加值为 6。

### 常见错误

1. 内外层循环共用同一个计数器变量：如先声明 int i; 再在内外层都写 for (i = 0; ...)，
   内层会篡改外层计数器；即使用 int i 分别声明，同名遮蔽也容易引起误读。
2. 误将内外层执行次数按加法计算：混淆了乘法原理，误认为总次数为 M + N。
3. 内层循环临时统计变量在错误位置声明：若要在每行重新统计，应在每轮外层循环开始时清零重置。

## 单元小结

- while 适用于执行次数未知的条件轮询，do-while 保证循环体至少被无条件执行一次。
- for 循环将初始化、条件检测与步进更新集中管理，是定次循环与数据累加的首选结构。
- break 用于立刻跳出当前层循环，continue 仅跳过当前轮次剩余代码并推进到下一轮。
- 嵌套循环的内层总执行次数遵循乘法原理（M × N），设计时务必使用独立的计数器变量名。
