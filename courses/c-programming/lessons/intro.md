# 程序结构与数据
本单元介绍 C 语言程序的基本骨架、编译构建流程、核心数据类型与运算规则，为分拣工位单片机控制程序的编写建立底层代码基础。

## 本单元知识点
- 程序结构与编译运行：掌握 main 入口、预处理指令、语句分号与完整构建流程。
- 变量与基本类型：掌握 int、float、double、char 的声明、初始化与 sizeof 测算。
- 格式化输入输出：掌握 printf 与 scanf 的格式占位符、转义字符及取地址机制。
- 算术运算、整除与取余：掌握四则运算、整除截断、取余及自增自减的运算规则。
- 类型转换与溢出：掌握隐式提升、显式强转、有无符号边界与浮点精度特性。

## 程序结构与编译运行
C 语言是一门编译型结构化程序设计语言。程序的基本构成单元是函数与声明，
其中 main 函数是整个 C 程序执行的唯一入口。单片机系统在上电复位之后，
底层引导代码完成基础寄存器配置，便会跳转至 main 函数开始执行业务逻辑。

源程序通常以 #include 预处理指令开头，用于引入系统标准库或自定义头文件。
例如 <stdio.h> 提供了标准输入输出函数的原型声明。
预处理指令以井号 # 开头，行尾不加英文分号。

C 语言中的每条可执行语句都必须以英文半角分号（;）作为结束标志。
代码注释分为单行注释 // 与多行块注释 /* ... */。
注释主要用于解释分拣逻辑与接口定义，在预处理阶段会被自动剔除。

源文件转为机器可执行程序的流程分为四个步骤：
1. 预处理：展开头文件、替换宏定义并剥离注释；
2. 编译：将预处理后的 C 代码翻译为汇编语言指令；
3. 汇编：将汇编代码转换为机器可识别的二进制目标文件（.o 或 .obj）；
4. 链接：将各个目标文件与标准库、运行时支持库组合链接为最终的可执行程序。

### 例题
【题目】编写一个向控制台输出分拣工位自检就绪信息的最小 C 程序骨架，并解释其核心语句的功能。
```c
#include <stdio.h>

int main(void) {
    // 输出分拣系统就绪提示信息
    printf("Sorting Station Ready\n");
    return 0;
}
```
【解答】
第 1 行使用 #include <stdio.h> 引入标准输入输出库，使程序能够调用 printf；
第 3 行定义了主函数 main，返回值类型为整型 int，参数列表 void 表示无参数；
第 5 行调用 printf 格式化输出字符串，末尾必须包含英文分号；
第 6 行 return 0 向操作系统或运行时环境返回状态码 0，表示程序正常执行完毕。

### 常见错误
1. 遗漏语句末尾的英文分号，或在中文输入法状态下误输入全角分号导致语法错误。
2. 将入口函数拼写为 mian、Main 或 MAIN，导致链接器无法找到程序入口符号。
3. 在 #include 预处理指令末尾多写了英文分号，引发非预期的预处理警告或报错。

## 变量与基本类型
在分拣工位程序中，到位检测状态、合格计数器和工件尺寸等数据均需保存在内存中。
变量就是具有名称并占用固定内存空间的存储单元。C 语言要求变量“先声明后使用”。

C 语言提供了丰富的基本数据类型，满足不同数据的存储需求：
- int（整型）：通常占用 4 字节（32 位），用于存储工件计数、工件 ID 等离散整数；
- float（单精度浮点型）：占用 4 字节，提供约 6–7 位有效数字，用于存储重量或尺寸；
- double（双精度浮点型）：占用 8 字节，提供约 15–17 位有效数字，精度要求更高；
- char（字符型）：占用 1 字节（8 位），用于存储 ASCII 字符或单字节控制指令。

声明变量时指定其类型和名称，并在声明的同时赋予初值的过程称为变量初始化。
函数内部定义的局部变量如果未初始化，其内存中残留的是不确定的随机垃圾值，
若未赋初值直接参与计算，会导致分拣计数或判定逻辑完全失控。

sizeof 是 C 语言的内置编译期运算符，用于测算某种类型或变量所占用的内存字节数。
其操作数既可以是数据类型名称（需用括号包围），也可以是变量表达式。

### 例题
【题目】声明记录合格品数量的整型变量与记录厚度公差的单精度浮点变量，初始化后使用 sizeof 计算它们在内存中占用的字节总数。
```c
#include <stdio.h>

int main(void) {
    int qualified_count = 150;
    float tolerance = 0.05f;
    int total_bytes = sizeof(qualified_count) + sizeof(tolerance);
    printf("%d\n", total_bytes);
    return 0;
}
```
【解答】
在标准 32 位运行环境中，int 占用 4 字节，float 占用 4 字节。
表达式 sizeof(qualified_count) 返回 4，sizeof(tolerance) 返回 4，
二者相加得到 total_bytes 的最终计算结果为 8 字节。

### 常见错误
1. 局部变量未显式赋初值就直接进行累加运算（如 int count; count++;）。
2. 将字符常量误用双引号书写（如 char cmd = "S";），导致类型不匹配。
3. 将 sizeof 误解为普通运行时函数，误以为括号内的表达式会在运行时被执行。

## 格式化输入输出
分拣工位通常需要通过串口或屏幕与操作人员交互数据。C 语言标准库中的 printf
与 scanf 提供了强大的格式化数据输入输出支持。

printf 函数用于向标准输出发送格式化文本。其第一个参数是格式化控制字符串，
内部包含普通字符与格式占位符，后续参数按顺序与占位符对应：
- %d：以有符号十进制整数形式输出；
- %f：以十进制浮点数形式输出，默认保留 6 位小数，写作 %.2f 可指定保留两位小数；
- %c：输出单个字符；
- %s：输出字符串；
- %%：输出一个百分号字符本身。
常用的转义字符包括换行符 \n 和水平制表符 \t。

scanf 函数用于从标准输入读取格式化数据。其基本调用语法与 printf 类似，
但存在一个关键区别：除了数组与指针外，读取基本类型变量时，
参数必须传入变量的内存地址，即在变量名前添加取地址符 &（例如 &input_id）。

scanf 在解析数字占位符（如 %d、%f）时会自动忽略输入流前导的空白字符。
但使用 %c 占位符读取单个字符时，任何字符（包括空格和换行符）都会被原样读取，
在连续读入字符与数值时需特别注意清除输入缓冲区残留的换行符。

### 例题
【题目】编写代码从控制台读入工件编号（整数）与检验测得的长度（浮点数），并按照指定对齐与精度格式打印到串口监控窗口。
```c
#include <stdio.h>

int main(void) {
    int piece_id;
    float length;
    scanf("%d %f", &piece_id, &length);
    printf("PART:%04d, LEN:%.2fmm\n", piece_id, length);
    return 0;
}
```
【解答】
scanf 中使用 %d 和 %f，参数分别提供 &piece_id 和 &length 的地址；
printf 中格式控制符 %04d 表示输出整数占用至少 4 位且不足补前导零；
%.2f 控制浮点数仅保留两位小数输出，后接单位 mm 并换行。

### 常见错误
1. 在 scanf 调用中遗漏取地址运算符 &，导致程序将变量当前值误当内存地址写入崩溃。
2. printf 格式占位符与传入的变量类型不对应（如用 %d 打印 float 变量）。
3. 在 scanf 的格式控制字符串末尾错误地添加了 \n，导致输入必须多按回车才能继续。

## 算术运算、整除与取余
分拣系统中经常需要进行节拍计算、箱装配比以及传感器阈值换算，这些都依赖算术运算。
C 语言提供了五个基本算术运算符：加（+）、减（-）、乘（*）、除（/）和取余（%）。

取余运算符（%）用于计算两个整数相除所得的余数，要求两边的操作数必须均为整数。
例如表达式 25 % 4 的运算结果为 1。取余运算广泛用于周期轮询与工件打包散件统计。

除法运算符（/）的行为取决于操作数的类型：
两端均为整数时执行整数除法向零截断小数（如 9 / 2 结果为 4）；
若两端至少有一个浮点数则执行浮点除法（如 9.0 / 2 结果为 4.5）。

算术运算遵循严格的优先级与结合性规则：
乘法（*）、除法（/）、取余（%）优先级相同，高于加法（+）与减法（-）。
同一优先级的算术运算符自左向右结合。使用圆括号 () 可以显式改变计算顺序。

自增（++）与自减（--）是一元运算符，用于将整型或字符型变量的值增加 1 或减少 1：
- 前缀形式（如 ++a）：变量自身先加 1，再取变量的新值参与表达式求值；
- 后缀形式（如 a++）：先取变量的当前旧值参与表达式求值，变量自身随后加 1。

### 例题
【题目】分拣工位每箱定额装载 12 件工件。当前累计传送了 135 件工件，编写程序计算已装满的标准箱数量以及最后尚未装满的散件数量。
```c
#include <stdio.h>

int main(void) {
    int total_pieces = 135;
    int box_capacity = 12;
    int full_boxes = total_pieces / box_capacity;
    int leftover = total_pieces % box_capacity;
    printf("%d %d\n", full_boxes, leftover);
    return 0;
}
```
【解答】
表达式 total_pieces / box_capacity 为两个整型相除，135 / 12 截断小数得到 11 箱；
表达式 total_pieces % box_capacity 计算 135 除以 12 的余数，得到 3 件散件。

### 常见错误
1. 对浮点数使用取余运算符（例如 10.5 % 3），直接导致编译器报告类型非法。
2. 期望得到精确小数结果，却直接让两个整数相除（如 1 / 2 得到 0 而非 0.5）。
3. 在单个复杂表达式中多次修改同一变量（如 i = i++ + ++i），造成未定义行为。

## 类型转换与溢出
在分拣控制程序中，不同精度的传感器采样值常常需要参与统一运算，这就涉及到类型转换。
类型转换包括由编译器自动完成的隐式类型转换，以及由程序员显式指定的强制类型转换。

隐式类型转换（算术提升）：当不同类型的操作数出现在同一个算术表达式中时，
编译器会自动将精度较低的类型转换为精度较高的类型，以保证计算精度。
char 与 short 先提升为 int；之后按 int -> unsigned int -> long -> float -> double
的大致顺序向更高类型转换。

强制类型转换的语法格式为：(目标类型)表达式。
强制类型转换只对紧随其后的操作数起作用，不会改变原始变量本身的存储值与类型。
例如在计算合格率时，需写作 (double)pass / total，使除法按浮点规则进行。

整型变量有符号类型（signed）与无符号类型（unsigned）之分。
8 位 signed char 范围为 -128 到 127，unsigned char 范围为 0 到 255。
当运算结果超出变量类型所能表示的极限范围时，将发生“整数溢出”。
有符号整数（如 int）运算上溢是未定义行为，不可依赖其结果；把超范围的值存回
signed char 等较窄类型时，结果由实现定义，常见补码机器上会截取低位并发生符号翻转；
无符号整数溢出则按模 2 的位数次方绕回，行为是确定的。

计算机采用二进制浮点数存储，很多十进制小数（如 0.1）无法精确存储。
因此在分拣工位判定工件厚度或重量是否达到阈值时，切忌直接使用 == 进行相等比较，
而应检查两个浮点数差值的绝对值是否小于允许的微小误差门限（如 1e-6）。

### 例题
【题目】分拣站批次质检合格数为 18 件，总检测数为 24 件。编写代码通过强制类型转换精确计算浮点合格率，避免因整数除法截断为 0。
```c
#include <stdio.h>

int main(void) {
    int qualified = 18;
    int total = 24;
    double pass_rate = (double)qualified / total;
    printf("%.2f\n", pass_rate);
    return 0;
}
```
【解答】
(double)qualified 首先将 qualified 的值临时转换为 double 类型的 18.0；
随后 total 在混合运算中被隐式提升为 double 类型的 24.0；
二者进行浮点除法运算，得到精确的合格率 0.75 并赋给 pass_rate。

### 常见错误
1. 误写为 (double)(qualified / total)，括号内先进行了整数除法得到 0，强转后仍为 0.0。
2. 无符号整数在自减循环中递减越过 0 发生下溢，瞬间跳变至极大值导致逻辑异常。
3. 直接使用 float_a == 0.3 比较浮点变量，因二进制精度舍入偏差导致判定条件失效。

## 单元小结
- C 程序以 main 函数为唯一入口，代码需经预处理、编译、汇编与链接才能烧录运行。
- 变量必须先声明后使用且务必初始化，根据分拣数据特征合理选择基本数据类型。
- printf 与 scanf 通过格式占位符实现串口终端交互，读取基本变量务必添加取地址符 &。
- 整数除法向零截断小数，取余运算仅适用于整数，前缀与后缀自增自减具有不同求值时序。
- 混合算术运算存在类型提升，关键计算需合理使用显式强转，注意防范溢出与浮点误差。
