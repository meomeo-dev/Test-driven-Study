# 数组与字符串
本单元系统学习一维数组的内存存储与边界控制、基于循环的常见数据统计算法、
以空字符结尾的 C 风格字符串处理，以及基础查找与冒泡排序算法，为分拣工位的
传感序列缓存与串口报文解析打下坚实基础。

## 本单元知识点
- 数组与下标边界：数组声明与初始化、连续内存、[0, n-1] 下标规则、越界未定义行为与长度计算。
- 数组求和、最值与计数：遍历传感数据实现累加求和、平均值、极值与条件计数，掌握数组传参必须显式传长度。
- 字符数组与字符串：'\0' 结束符机制、sizeof 与 strlen 的本质区别、字符串初始化与 strcmp 报文比较。
- 排序与查找：冒泡排序比较轮次计算、线性查找无序工件尺寸、有序工件参数的二分查找折半原理。

## 数组与下标边界
数组是相同类型元素在内存中连续排列的集合。在 C 语言中，声明如
int sensors[5]; 会在内存栈区连续开辟容纳 5 个 32 位整型变量的空间。
声明时可用花括号赋初值，如 int a[3] = {1, 2, 3};；若初值列表少于元素个数，
例如 int b[5] = {0};，未被显式赋值的元素会自动补 0。

数组下标严格从 0 开始计数。包含 n 个元素的数组，合法下标区间为
0 到 n - 1。第 1 个元素是 a[0]，最后一个元素是 a[n - 1]。

C 语言在编译和运行期均不进行下标边界检查。访问 a[-1] 或 a[n] 会直接
读写未知内存，属于未定义行为（Undefined Behavior），可能引发数据被静默
破坏、单片机死机或硬件异常，在工业控制中必须严格杜绝。

在定义数组的当前作用域内，可通过 sizeof(a) / sizeof(a[0]) 计算出
数组的元素个数。

### 例题
题目：分拣工位需要缓存 5 次红外测距传感器的 AD 采样值。请声明一个容量为 5
的整型数组并清零，然后通过循环写入前 5 次采样数据，最后安全地输出最后一个
采样值。

```c
#include <stdio.h>

int main(void) {
    int adc_buf[5] = {0};
    int count = sizeof(adc_buf) / sizeof(adc_buf[0]);
    for (int i = 0; i < count; i++) {
        adc_buf[i] = (i + 1) * 10;
    }
    printf("末次采样: %d\n", adc_buf[count - 1]);
    return 0;
}
```

解答分析：
1. sizeof(adc_buf) / sizeof(adc_buf[0]) 计算出容量 5。
2. 循环变量 i 从 0 递增到 4，恰好覆盖全部合法下标。
3. 最后一个元素的下标为 count - 1 即 4，避免越界访问 adc_buf[5]。

### 常见错误
- 误将容量 n 作为末尾下标访问 a[n]，引发越界访问未定义行为。
- 声明 int a[5]; 未初始化即直接读取，各元素包含内存残留的垃圾随机值。
- 在被调函数内部对退化为指针的数组形参使用 sizeof(a) / sizeof(a[0]) 计算长度。

## 数组求和、最值与计数
遍历是处理数组元素的核心手法，通常使用 for 循环配合下标逐个访问元素。

累加求和时需声明累加变量并显式初始化为 0（如 int sum = 0;），循环累加
sum += arr[i];。计算平均值时需警惕整数除法截断问题，若需浮点结果，应将
被除数强制转换为浮点型，例如 (double)sum / len。

寻找最值时，通常将初值设为数组首个元素（如 int max = arr[0];），随后从
下标 1 开始循环比较更新。条件计数则需维护一个初值为 0 的计数器，在满足
判定条件（如工件重量合格 weights[i] >= 50）时累加计数。

一维数组作为函数形参时（如 void process(int a[], int len)），数组名退化
为首元素指针，函数内部无法通过 sizeof 获取原数组大小，必须额外显式传入
长度参数 len。

### 例题
题目：编写一个统计函数，接收工件重量数组与长度，统计重量大于等于 50 克的
合格工件数量并在 main 函数中验证。

```c
#include <stdio.h>

int count_pass(int weights[], int len) {
    int count = 0;
    for (int i = 0; i < len; i++) {
        if (weights[i] >= 50) {
            count++;
        }
    }
    return count;
}

int main(void) {
    int batch[4] = {48, 52, 50, 45};
    int passed = count_pass(batch, 4);
    printf("合格件数: %d\n", passed);
    return 0;
}
```

解答分析：
1. count_pass 函数显式接收数组 weights 与长度参数 len。
2. 循环遍历 [0, len - 1] 区间，命中 52 与 50 两件合格品。
3. 计数器累加得到 2 并正确返回。

### 常见错误
- 求极值时将初值误设为 0，当数组元素全为负数时无法求出真实最大值。
- 计算平均值直接使用整数除法 sum / len，导致小数部分被截断丢失。
- 编写函数时省略长度参数，企图在函数内部通过 sizeof 计算数组元素个数。

## 字符数组与字符串
C 语言没有原生的 string 类型，字符串本质是以空字符 '\0'（ASCII 码为 0）
结尾的字符数组（char 数组）。字面量 "OK" 在内存中占用 3 个字节，依次为
'O'、'K' 与 '\0'。

声明存储字符串的字符数组时，容量必须至少为“有效字符数 + 1”，预留给
'\0'。例如存储 4 字符指令应声明 char cmd[5] = "PASS";。若数组空间不足
以容纳结尾的 '\0'，该数组便不能作为合法的 C 字符串使用。

sizeof 与 strlen 有本质区别：sizeof(s) 是编译期运算符，返回该数组在内存
中分配的总字节数；strlen(s) 是库函数（需包含 <string.h>），在运行期从
首地址扫描到第一个 '\0' 为止，返回有效字符个数，不计入 '\0'。

字符串比对绝不能使用关系运算符 cmd == "PASS"（这仅比对内存首地址），必须
调用 strcmp(s1, s2)。当且仅当两字符串内容完全相同时返回 0。

### 例题
题目：分拣工位接收上位机下发的动作指令。请声明字符数组保存指令 "REJECT"，
分别输出其数组内存字节数与有效字符长度，并使用 strcmp 校验是否为 "PASS"。

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char cmd[10] = "REJECT";
    int mem_size = sizeof(cmd);
    int str_len = strlen(cmd);
    printf("内存占用: %d, 字符串长: %d\n", mem_size, str_len);
    if (strcmp(cmd, "PASS") == 0) {
        printf("放行工件\n");
    } else {
        printf("剔除工件\n");
    }
    return 0;
}
```

解答分析：
1. cmd 数组容量为 10，故 sizeof(cmd) 返回 10。
2. "REJECT" 包含 6 个字母后跟 '\0'，strlen(cmd) 返回 6。
3. strcmp(cmd, "PASS") 返回非零值，程序分支正确执行并输出“剔除工件”。

### 常见错误
- 字符数组容量未预留 '\0' 的空间，导致作为字符串处理时发生内存越界越读。
- 误用 s1 == "PASS" 比较字符串内容是否相等。
- 混淆 sizeof 与 strlen，把数组总容量误当成当前接收到的实际字符个数。

## 排序与查找
线性查找按顺序逐个比对元素，适用于任何无序或有序数组。若匹配成功返回目标
下标，遍历结束仍未命中则返回 -1。对于包含 n 个元素的数组，最坏与平均需
比较 n 次。

冒泡排序通过相邻元素的比较与交换，让极值元素逐轮“冒泡”到末尾。对包含 n
个元素的数组进行升序排序，第 1 轮需比较 n - 1 次，第 2 轮比较 n - 2 次，
共需 n - 1 轮。总比较次数公式为 n * (n - 1) / 2。

二分查找要求数组已预先排序。维护区间 [low, high]，每次取中点
mid = low + (high - low) / 2。若 a[mid] 命中目标则返回；若 a[mid] 小于目标，
调整左界 low = mid + 1；反之调整右界 high = mid - 1。直到 low > high
表示区间为空、查找失败。

### 例题
题目：分拣工位有一组已排序的工件公差标称值 {10, 20, 30, 40, 50}。编写二分
查找算法检索目标值 40 所在的下标并输出。

```c
#include <stdio.h>

int binary_search(int a[], int len, int target) {
    int low = 0, high = len - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (a[mid] == target) return mid;
        if (a[mid] < target) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}

int main(void) {
    int std_sizes[5] = {10, 20, 30, 40, 50};
    int idx = binary_search(std_sizes, 5, 40);
    printf("目标下标: %d\n", idx);
    return 0;
}
```

解答分析：
1. 初始区间 low = 0, high = 4。第 1 轮 mid = 2，a[2] = 30 < 40，更新 low = 3。
2. 第 2 轮 mid = 3，a[3] = 40 命中目标，返回下标 3。
3. 折半缩减使检索效率从 O(n) 提升至 O(log n)。

### 常见错误
- 对未排序的无序数组误用二分查找，导致检索结果错误。
- 二分查找循环条件误写为 low < high，导致仅剩一个候选元素时漏检。
- 冒泡排序内层循环边界写错，在访问 a[j + 1] 时引发数组下标越界。

## 单元小结
- 数组是连续内存结构，容量为 n 的数组合法下标为 0 到 n - 1，越界访问是未定义行为。
- 遍历是实现求和、平均、最值和条件计数的通用模式；一维数组作为参数传递必须显式携带长度。
- C 字符串以 '\0' 结尾，sizeof 反映内存总字节数，strlen 反映有效字符数，内容比较必须用 strcmp。
- 线性查找适用任意数组，二分查找要求数组有序；n 个元素的基础冒泡排序总比较次数为 n*(n-1)/2。
