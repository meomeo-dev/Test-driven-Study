# 条件与分支

本单元学习 C 语言的关系运算、逻辑运算与分支控制结构，掌握根据传感检测结果做出工件分拣决策的程序设计方法。

## 本单元知识点

- 关系与逻辑运算：比较传感器数值并组合多重条件，掌握短路求值与赋值/判等区别。
- 条件语句 if / else：实现基于阈值判定的单分支、双分支与多层嵌套分流。
- 多分支 switch：基于离散状态码或通信指令字符高效分发分拣执行动作。

## 关系与逻辑运算

在分拣控制程序中，单片机需要频繁比较传感器读取的物理量（如工件尺寸、
重量与到位开关电平），并根据多个信号的组合决定下一步动作。C 语言提供了
关系运算符与逻辑运算符来构建这些判定条件。

关系运算符包含大于（>）、小于（<）、大于等于（>=）、小于等于（<=）、
等于（==）和不等于（!=）。这些运算符用于比较两个数值的大小或相等性。
在 C 语言中，关系表达式的计算结果为整型（int），当关系成立时结果为 1
（真），不成立时结果为 0（假）。

逻辑运算符用于将多个关系表达式组合为复合条件：
- 逻辑与（&&）：当且仅当两个操作数均非 0 时结果为 1，否则为 0。
- 逻辑或（||）：只要两个操作数中有一个非 0，结果即为 1；全 0 时结果为 0。
- 逻辑非（!）：单目运算符，对操作数取反。操作数为 0 时结果为 1，非 0 时为 0。

逻辑运算具有短路求值（Short-circuit Evaluation）特性：
- 在计算 a && b 时，若左操作数 a 为 0，整个表达式已确定为假，右操作数 b 不会执行。
- 在计算 a || b 时，若左操作数 a 非 0，整个表达式已确定为真，右操作数 b 不会执行。
若右侧表达式包含自增或赋值等运算，短路发生时这些操作将被跳过。

必须严格区分赋值运算符（=）与判等运算符（==）。表达式 a = 5 会将 5 写入变量 a，
且整个表达式的值为 5（在条件判断中视为真）；而 a == 5 仅测试 a 是否等于 5，
不会修改变量的值。误将 == 写作 = 是初学者最常见且隐蔽的错误。

### 例题

编写程序检测到位传感器状态 in_pos（1 表示到位，0 表示无工件）与工件长度
length（毫米）。只有当工件到位且长度在 40 到 60 毫米之间时，判定工件有效。

```c
#include <stdio.h>

int main(void) {
    int in_pos = 1;
    int length = 48;
    int is_valid = 0;

    is_valid = in_pos && (length >= 40 && length <= 60);

    printf("工件有效状态：%d\n", is_valid);
    return 0;
}
```

解答说明：
1. 表达式 length >= 40 结果为 1，length <= 60 结果为 1，二者经 && 运算结果为 1。
2. in_pos 值为 1，与右侧的 1 再次进行 && 运算，最终 is_valid 变量赋值为 1。
3. 若 in_pos 为 0，由于短路求值，右侧区间判断不再执行，直接返回 0。

### 常见错误

1. 连续书写不等式：误写如 40 <= length <= 60。C 语言会先计算 40 <= length
   得到 0 或 1，再拿 0 或 1 与 60 比较，结果恒为 1，失去范围约束作用。
2. 条件中误用赋值符：在条件中写出 if (sensor = 1)，导致变量被意外修改且
   条件恒成立。
3. 依赖被短路的表达式更新变量：在 && 或 || 右侧放置自增操作（如 flag && ++cnt），
   左侧为假时 cnt 不会递增，导致计数遗漏。

## 条件语句 if / else

获得逻辑判断的结果后，程序需要根据结果选择不同的执行路径。if-else 语句是
C 语言中最核心的条件分支控制结构。

if-else 语句的基本执行机制是基于条件表达式的真假分流：
- 单分支：if (条件) 语句；当条件非 0 时执行对应语句，为 0 时跳过。
- 双分支：if (条件) 语句1; else 语句2; 条件非 0 执行语句1，为 0 执行语句2。
- 级联多分支：使用 else if 串联多重互斥条件。程序自上而下依次判断，一旦某个
  分支的条件成立，执行其内部语句后立即跳出整个 if-else 链，后续分支均被跳过。

代码块（复合语句）与大括号的使用规范：
当某个分支需要执行多条语句时，必须使用成对的大括号 {} 将多条语句包围为代码块。
若省略大括号，if 或 else 仅控制紧随其后的第一条语句。为保证程序结构清晰、
避免后期维护引发漏洞，即使分支只有一条语句，也强烈建议书写大括号。

悬空 else（Dangling else）匹配规则：
当 if 语句发生多层嵌套且缺少大括号时，C 语言编译器始终将 else 与前面最近的、
尚未配对的 if 进行绑定，代码缩进对编译器的语法解析没有任何影响。

### 例题

分拣站对检测工件的重量 weight（克）进行等级判定：大于等于 80 克为超重品
（料盒 1），50 到 79 克为标准合格品（料盒 2），小于 50 克为欠重品（料盒 3）。
编写阈值分拣程序。

```c
#include <stdio.h>

int main(void) {
    int weight = 65;
    int target_bin = 0;

    if (weight >= 80) {
        target_bin = 1;
    } else if (weight >= 50) {
        target_bin = 2;
    } else {
        target_bin = 3;
    }

    printf("目标分拣料盒号：%d\n", target_bin);
    return 0;
}
```

解答说明：
1. 程序从上向下依次判定。weight 为 65，首先判断 weight >= 80 为假。
2. 进入 else if 分支，判断 weight >= 50 为真，执行 target_bin = 2。
3. 分支命中后直接跳过末尾的 else 分支，最终输出料盒号 2。

### 常见错误

1. if 条件圆括号后误加分号：例如写成 if (weight > 80);，分号构成了空语句，
   导致后续大括号内的代码脱离条件控制，变成无条件执行。
2. 缺少大括号导致逻辑归属错误：在没有 {} 的情况下写了多条语句，误以为所有语句
   都受 else 管辖，实际上只有第一条受管辖。
3. 级联分支判断顺序颠倒：若先判断 weight >= 50 再判断 weight >= 80，由于 65
   和 90 都满足第一个条件，会导致大于 80 的工件提前进入料盒 2。

## 多分支 switch

当分拣系统需要根据离散的传感器状态编码、料盒编号或上位机下发的单字节通信指令
（如字符 'A'、'B'、'S'）进行多路分支选择时，使用 switch 语句比多重嵌套 if
更加直观且高效。

switch 语句的基本语法与约束：
- 控制表达式：switch (表达式) 中的表达式必须是整型（如 int、short）或字符型
  （char），不能是浮点型（float、double）。
- case 标签：每个 case 标签后紧跟一个整型常量表达式（如数字 1 或字符 'P'）
  和一个冒号。case 后的值必须在编译期确定，不能是变量，且同一 switch 内不能重复。

break 语句与贯穿（Fall-through）机制：
程序进入 switch 后，会计算表达式的值并跳转到匹配的 case 标签处开始向下执行。
若该 case 分支末尾没有 break 语句，程序不会自动退出 switch，而是无视后续的
case 标签，顺次执行下一分支的代码，这种现象称为贯穿。
只有遇到 break 语句，程序才会跳出整个 switch 代码块。

default 分支与分支合并：
- default 分支是可选的。当表达式的值与所有 case 均不匹配时执行 default，通常
  用于处理异常输入或未定义状态。
- 利用贯穿特性，可以有意将多个 case 叠放在一起，让它们共享同一段处理逻辑，
  例如大小写字符共用同一执行分支。

### 例题

分拣站接收上位机下发的单字符动作指令 cmd：字符 'P' 或 'p' 表示合格放行
（舵机转到 45 度），字符 'R' 或 'r' 表示剔除（舵机转到 135 度），其他未知
指令执行复位停止（舵机保持 90 度）。

```c
#include <stdio.h>

int main(void) {
    char cmd = 'p';
    int servo_angle = 90;

    switch (cmd) {
        case 'P':
        case 'p':
            servo_angle = 45;
            break;
        case 'R':
        case 'r':
            servo_angle = 135;
            break;
        default:
            servo_angle = 90;
            break;
    }

    printf("舵机目标转角：%d\n", servo_angle);
    return 0;
}
```

解答说明：
1. cmd 变量值为 'p'，switch 跳转到 case 'p' 标签处。
2. case 'P' 与 case 'p' 叠放，共享 servo_angle = 45 的赋值逻辑。
3. 执行完赋值后遇到 break，跳出 switch，避免继续贯穿到 'R' 分支，最终输出 45。

### 常见错误

1. 漏写 break 语句：由于疏忽在 case 末尾遗漏 break，导致程序继续执行后续分支，
   意外覆盖前面的计算结果。
2. case 标签使用非法类型：在 case 后写变量（如 case var:）或浮点数（如 case 1.5:），
   违反了必须为整型常量表达式的语法规定。
3. 重复的 case 常量：同一个 switch 块内出现了相同值的 case 标签，导致编译报错。

## 单元小结

- 关系与逻辑运算符求值结果为 int 类型的 1（真）或 0（假）；编写条件时切忌混淆
  赋值符号 = 与判等符号 ==，并充分注意 && 与 || 的短路特性。
- if-else 语句支持单分支、双分支与互斥级联多分支；多条件阈值分级时注意判断顺序，
  并务必使用大括号 {} 明确代码块作用域，规避悬空 else 与分号陷阱。
- switch 语句适用于离散整型与字符指令分发；case 必须接整型常量，各分支末尾
  根据设计意图明确添加 break，合理利用贯穿合并共享逻辑。
- 在桌面分拣站项目中，传感器状态整合宜用逻辑运算，连续物理量分级适用 if-else if，
  上位机字符通信指令解析优先采用 switch-case。
