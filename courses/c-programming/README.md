# C 语言程序设计

从变量、分支和循环到可测试的传感数据处理函数。

## 学习起点

会运行电脑程序。可先在桌面编译器练习。

- 读懂变量和条件 → 写循环 → 抽取函数 → 用边界输入验证。

## 学完能做什么

- 用条件、循环和函数表达控制逻辑。
- 理解数组索引、整型除法和边界检查。
- 为计数、阈值和异常输入编写简单测试。

**桌面质检分拣站实作**。写一个函数统计传感器样本中大于阈值的数量，分别测试空数组、等于阈值和高于阈值。

## 课程内容

1.1.0 版包含七个单元、29 个知识点和 144 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成
学习顺序。表中同一单元的知识点以分号分隔。

| 单元 | 知识点 |
| --- | --- |
| 程序结构与数据 | 程序结构与编译运行；变量与基本类型；格式化输入输出；算术运算、整除与取余；类型转换与溢出 |
| 条件与分支 | 关系与逻辑运算；条件语句 if / else；多分支 switch |
| 循环 | while 与 do-while；for 循环与计数；break 与 continue；嵌套循环与执行次数 |
| 函数与测试 | 函数定义、参数与返回值；作用域、生命周期与 static；边界输入与断言测试；递归入门 |
| 数组与字符串 | 数组与下标边界；数组求和、最值与计数；字符数组与字符串；排序与查找 |
| 指针、结构体与位运算 | 指针与地址；指针、数组与传参；结构体；位运算与掩码；常量、宏与头文件 |
| 数据处理项目 | 多文件与模块化；传感器数据处理；调试与常见错误；实作：阈值计数函数与测试（自评） |

“实作：阈值计数函数与测试”是自评实作，没有练习题。
按[数据处理项目讲义](lessons/project.md)中的自评清单完成后，
在学习路径中标记已会。
