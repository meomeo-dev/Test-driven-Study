# 机器视觉与图像处理

用固定光照、阈值和轮廓识别垫片孔位，并学习尺寸标定。

## 学习起点

会用 Python 读取文件和运行函数。可从已有工件照片开始。

- 固定相机与背景 → 采集已知标签照片 → 分割和轮廓 → 标定与对照测量。

## 学完能做什么

- 理解光照、位置和曝光对分割的影响。
- 用阈值和轮廓建立缺孔检测基线。
- 用同平面的参考件将像素换算为毫米。

**桌面质检分拣站实作**。分别拍摄有孔和缺孔样件，从静态图像找孔。改变一次光照，记录阈值法在哪种条件下失效。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 数字图像基础 | 像素、分辨率与坐标；颜色通道与灰度；图像即数组；读写图像 |
| 成像与采集 | 相机、镜头与视场；光照方式；曝光、增益与对焦；固定相机与采集规范 |
| 图像预处理 | 直方图与对比度；平滑滤波与去噪；缩放、旋转与裁剪 |
| 阈值分割与轮廓 | 全局阈值与 Otsu；自适应阈值与光照不均；形态学操作；轮廓提取与层级 |
| 形状特征与孔检测 | 面积、周长与外接框；圆度与形状描述；边缘检测；孔位检测与缺孔判定 |
| 标定与尺寸测量 | 像素与毫米换算；镜头畸变与相机标定；测量误差与验证 |
| 检测流程与评估 | 检测流程与 ROI；鲁棒性与失效分析；检测结果的评估；有孔与缺孔检测实验（自评） |

“有孔与缺孔检测实验”是自评实作，没有练习题。
按[检测流程与评估讲义](lessons/inspection.md)中的自评清单完成后，
在学习路径中标记已会。
