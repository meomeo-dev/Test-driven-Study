# 图像预处理
本单元学习如何通过直方图分析与对比度调整改善工件成像质量，使用平滑滤波消除
传送带振动与传感器噪声，以及利用几何变换定位工件感兴趣区域（ROI），为垫片
孔位检测提供稳定清晰的输入图像。

## 本单元知识点
- 直方图与对比度：掌握灰度直方图统计分布，掌握线性明暗调节与直方图均衡化。
- 平滑滤波与去噪：掌握均值、高斯与中值滤波特性，理解奇数核与椒盐噪声滤除。
- 缩放、旋转与裁剪：掌握图像插值缩放、旋转矩阵变换以及 ROI 坐标换算规则。

## 直方图与对比度
灰度直方图是图像灰度分布的统计图表，横坐标表示灰度级（8 位灰度图取值范围为
0 至 255），纵坐标表示具有该灰度值的像素总数。在桌面分拣站中，相机采集的
金属垫片图像如果直方图整体集中在左侧低灰度区间，说明工件受光不足、整体偏暗；
如果集中在右侧高灰度区间，说明光源过强产生了过曝；如果分布集中在中段极窄的
区间内，则表明垫片与背景的对比度偏低，不利于后续提取孔洞边缘。在 OpenCV
中，通常使用 cv2.calcHist([gray], [0], None, [256], [0, 256]) 计算直方图。

线性对比度与亮度调整通过一元一次线性变换对每个像素的灰度进行缩放与平移：
g(x, y) = α · f(x, y) + β
其中 f(x, y) 为原始像素灰度，g(x, y) 为调整后的像素灰度。斜率系数 α 称为增益，
用于控制对比度：当 α > 1 时，展开灰度范围，对比度增强；当 0 < α < 1 时，压缩
灰度范围，对比度降低。常数项 β 称为偏置，用于控制整体亮度：当 β > 0 时，全图
灰度上移变亮；当 β < 0 时，全图灰度下移变暗。由于变换结果可能超出 0 至 255
范围，计算后必须进行截断保护。OpenCV 提供了 cv2.convertScaleAbs 函数，能够
自动完成线性缩放、取绝对值并饱和截断到 uint8 范围。

直方图均衡化是一种非线性增强方法，其核心思想是通过图像的累积分布函数作为
灰度映射表，把原本狭窄集中的灰度直方图非线性拉伸为接近均匀分布的平坦直方图。
在分拣工位中，若垫片表面反光不足且背景对比度较弱，调用 cv2.equalizeHist(gray)
可以有效扩展灰度的动态范围，凸显孔洞轮廓边缘。需要注意，直方图均衡化仅适用于
单通道 8 位灰度图像；若图像背景本身存在较强的暗部散粒噪声，全局均衡化可能会
同步放大背景噪点。

### 例题
在垫片分拣工位上，相机采得一张 640×480 的单通道灰度图 gray，工件表面略暗且
动态范围狭窄。请编写 Python 代码：首先统计该图像的 256 级灰度直方图；接着使用
对比度系数 α = 1.2、亮度偏置 β = 15 对图像进行线性增强；最后使用直方图均衡化
增强图像对比度。

```python
import cv2
import numpy as np

# 1. 统计灰度直方图
hist = cv2.calcHist([gray], [0], None, [256], [0, 256])

# 2. 线性调整对比度与亮度（自动执行饱和截断）
enhanced_linear = cv2.convertScaleAbs(gray, alpha=1.2, beta=15)

# 3. 直方图均衡化增强对比度
enhanced_equ = cv2.equalizeHist(gray)
```

解答说明：
cv2.calcHist 函数中输入图像与通道必须使用方括号包裹，ranges 参数指定为
[0, 256) 表示包含 0 至 255 的全部灰度级。cv2.convertScaleAbs 内部实现了
饱和截断，有效避免了手动计算导致的数值溢出回绕。cv2.equalizeHist 直接接收
单通道灰度数组，返回均衡化后的增强图像。

### 常见错误
- 直接使用 NumPy 标量加减（如 gray + 20）调整亮度，因 uint8 溢出特性，超过
  255 的像素会回绕为小数值（如 250 + 20 = 14），使高亮区域出现黑色噪斑。
- 对三通道彩色图像直接调用 cv2.equalizeHist，导致 OpenCV 报尺寸与通道错误；
  彩色图像需转换到 YCrCb 或 HSV 色彩空间后仅对亮度分量进行均衡化。
- 将 cv2.calcHist 的取值范围错误写为 [0, 255]，导致灰度级 255 的像素无法被
  统计进直方图，造成亮区像素频次遗漏。

## 平滑滤波与去噪
在桌面分拣系统中，相机传感器受发热、电磁干扰或传送带震动影响，采集的图像
往往包含噪声。平滑滤波通过邻域加权运算来抑制高频噪点。空间滤波器基于卷积核
（或掩模）实现，核尺寸通常选用奇数（如 3×3、5×5、7×7）。选用奇数核的原因是
奇数矩阵具有唯一的正中心像素作为锚点，能够精准对齐输入与输出的像素坐标。

线性滤波包括均值滤波与高斯滤波：
- 均值滤波：使用 cv2.blur(src, (ksize, ksize)) 实现。核内所有像素赋予相同
  权重，输出为邻域像素的算术平均值。均值滤波计算速度快，但会将垫片孔洞边缘
  同步模糊钝化。
- 高斯滤波：使用 cv2.GaussianBlur(src, (ksize, ksize), sigmaX) 实现。根据
  二维高斯正态分布赋予核内像素不同权重，中心像素权重最高，向外围平滑衰减。
  高斯滤波在有效抑制传感器高斯白噪声的同时，比均值滤波能更好地保留边缘轮廓。

非线性滤波的代表是中值滤波，使用 cv2.medianBlur(src, ksize) 实现。中值滤波
将邻域窗口内的像素灰度从小到大排序，取正中间的中位数替换中心像素。在分拣工位
现场，因电机启动脉冲干扰或反光尘埃产生的孤立黑白杂点属于典型的“椒盐噪声”。
均值滤波和高斯滤波会将极值噪点均化为周围的一团模糊污斑，而中值滤波能利用
中位数排序机制将极端黑白值彻底剔除，因此是处理椒盐噪声的首选算法。

### 例题
分拣工位相机因传输线电磁干扰，采集的垫片灰度图像 gray 中出现了许多孤立白色
噪点（椒盐噪声），且夹具边缘伴随轻微高斯白噪声。请编写 Python 代码：分别使用
5×5 的高斯滤波和 5×5 的中值滤波进行去噪处理。

```python
import cv2

# 1. 高斯滤波（适用于传感器连续高斯白噪声）
gaussian_filtered = cv2.GaussianBlur(gray, (5, 5), sigmaX=1.0)

# 2. 中值滤波（适用于剔除孤立椒盐噪点）
median_filtered = cv2.medianBlur(gray, 5)
```

解答说明：
cv2.GaussianBlur 的核尺寸参数为元组 (5, 5)，sigmaX 设为 1.0 用于控制高斯分布
展宽程度。cv2.medianBlur 的核尺寸参数必须是单个奇数整数（如 5），代表正方形
窗口边长。对于椒盐噪声，中值滤波能够彻底抹除极值白点并完整保留孔洞边界。

### 常见错误
- 向 cv2.medianBlur 传递偶数核尺寸（如 4 或 6）或元组参数（如 (5, 5)），导致
  OpenCV 抛出断言异常；中值滤波核尺寸必须为单个奇数整数。
- 在工位去噪时盲目选用过大的滤波核（如 21×21），导致待检垫片的小孔区域被
  周围高亮像素完全侵蚀填平，造成孔特征丢失。
- 试图使用均值滤波消除椒盐噪声，结果孤立噪点并未消失，反而被扩散成半透明的
  灰斑，对后续边缘提取造成更大干扰。

## 缩放、旋转与裁剪
图像几何变换改变图像的像素空间布局。常用几何变换包括缩放、旋转和 ROI 裁剪。
图像缩放使用 cv2.resize(src, dsize, fx=..., fy=..., interpolation=...) 实现。
特别注意 dsize 的传参顺序为 (宽, 高) 即 (w, h)，与 NumPy 数组形状 (h, w)
刚好相反。缩放涉及像素插值计算：
- 图像缩小：推荐选用 cv2.INTER_AREA（区域重采样插值），能有效避免摩尔纹失真。
- 图像放大：推荐选用 cv2.INTER_LINEAR（双线性插值，默认）或 cv2.INTER_CUBIC
  （双三次插值，边缘更平滑但计算开销大）。
- 最近邻插值 cv2.INTER_NEAREST 速度最快，但会引入明显的台阶锯齿感。

在分拣流水线上，当垫片落料角度倾斜时，需要利用旋转进行姿态校正。OpenCV 的
旋转通过仿射变换实现，具体步骤包括：
1. 调用 cv2.getRotationMatrix2D(center, angle, scale) 生成 2×3 仿射变换矩阵 M。
   其中 center 为旋转中心 (cx, cy)，angle 为旋转角度（正值表示逆时针，负值表示
   顺时针），scale 为等比例缩放倍数。
2. 调用 cv2.warpAffine(src, M, (w, h)) 将图像映射至目标画布，画布尺寸同样为
   (宽, 高)。

为了提高检测效率并排除无关背景干扰，通常需要从整图中提取垫片所在的感兴趣
区域（ROI）。裁剪操作直接通过 NumPy 数组切片完成：
roi = image[y1:y2, x1:x2]
注意切片第一维是垂直方向 y（行范围），第二维是水平方向 x（列范围）。
在 ROI 局部图像内检测到孔心坐标 (x_roi, y_roi) 后，必须将其转换回全图坐标系：
x_global = x_roi + x1
y_global = y_roi + y1
若遗漏左上角原点偏移量 (x1, y1)，分拣执行挡板将因坐标偏差而发生误动作。

### 例题
分拣相机采集图像分辨率为 1280×960（宽 1280，高 960）。已知定位夹具区域的
左上角坐标为 (400, 300)，右下角坐标为 (800, 700)。请编写代码截取该 ROI，
并将局部检测出的孔心坐标 (x_roi, y_roi) = (215, 180) 换算为全局图像坐标。

```python
# 1. 数组切片截取 ROI（格式为 [y1:y2, x1:x2]）
x1, y1 = 400, 300
x2, y2 = 800, 700
roi = image[y1:y2, x1:x2]

# 2. 局部坐标换算为全局坐标
x_roi, y_roi = 215, 180
x_global = x_roi + x1
y_global = y_roi + y1
```

计算说明：
x_global = 215 + 400 = 615 像素，y_global = 180 + 300 = 480 像素。
全图坐标为 (615, 480)，该坐标可直接提供给上位机分拣与 CSV 记录模块。

### 常见错误
- 数组切片截取 ROI 时混淆行列顺序，写成 image[x1:x2, y1:y2]，导致图像发生
  转置或因尺寸不符引发下标越界异常。
- 调用 cv2.resize 或 cv2.warpAffine 时传入 (height, width)，导致图像拉伸变形；
  cv2.resize、cv2.warpAffine 的尺寸参数均遵循 (width, height) 顺序。
- 在 ROI 局部图像中提取特征坐标后，未累加 (x1, y1) 偏移直接用于控制 PLC 或
  分拣挡板，造成物理抓取位置产生严重偏差。

## 单元小结
- 灰度直方图反映图像明暗与对比度分布，线性变换可拉伸动态范围，直方图均衡化
  可自适应展开单通道灰度分布。
- 空间滤波核尺寸应为奇数以保证对称中心锚点；高斯滤波适于衰减连续高斯噪声，
  中值滤波则是消除孤立椒盐噪声的首选算法。
- 图像缩小宜选用 cv2.INTER_AREA 避免混叠，放大宜选用 cv2.INTER_LINEAR 或
  cv2.INTER_CUBIC。
- 图像旋转采用 cv2.getRotationMatrix2D 与 cv2.warpAffine，正角度表示逆时针。
- ROI 裁剪遵循 image[y1:y2, x1:x2]，局部检测结果必须加上 (x1, y1) 换算为
  全局坐标后才能用于分拣控制。
