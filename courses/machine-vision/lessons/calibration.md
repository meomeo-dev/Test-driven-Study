# 标定与尺寸测量
本单元学习如何建立图像像素与物理毫米之间的精确换算关系，消除工业相机的
镜头畸变失真，并通过高精度量具对照与统计分析验证分拣站的尺寸测量精度。

## 本单元知识点
- 像素与毫米换算：通过已知尺寸标定件获取空间分辨率，建立同一高度平面测量基准。
- 镜头畸变与相机标定：理解桶形与枕形畸变原理，利用棋盘格获取内参与畸变系数。
- 测量误差与验证：分析边缘离散误差与亚像素技术，结合卡尺真值与重复性评估精度。

## 像素与毫米换算
工业相机采集到的数字图像本质上是离散的二维像素网格矩阵，像素坐标仅代表
感光元件阵列上的离散排列位置。在桌面质检分拣站中，工件图纸要求与分拣判定
均以毫米（mm）为度量单位。为了通过视觉算法精确判断垫片的外径和孔径是否
合格，必须建立图像像素坐标与物理世界坐标的线性比例映射，该系数通常称为
空间分辨率或比例尺系数 s（单位通常为 mm/pixel）。

当相机垂直俯视安装在工作台正上方时，在消除光学畸变的理想正交小孔投影下，
物面与像面保持平行。此时被测平面内的物理长度 L_real 与图像中的轮廓像素
长度 L_pixel 满足正比例线性换算关系：
s = L_real / L_pixel
若已知某系统的空间分辨率为 0.05 mm/pixel，算法检测出垫片外轮廓直径为
440 个像素，则该垫片的实际物理外径即可直接计算为 440 × 0.05 = 22.0 mm。

这种单目线性比例尺在几何光学上具有严格的适用边界，必须同时满足两项前提：
1. 严格处于同一高度平面：根据透镜成像物像相似三角形原理，成像大小与物距成
反比。当工件厚度增加或被定位夹具垫高时，物面更靠近镜头，图像中的成像尺寸
显著增大，此时原标定比例尺立即失效，继续使用会导致测量值偏大。
2. 相机光轴与物面正交对齐：若相机存在倾斜角度，物面上不同区域到镜头光心的
距离不一致，圆形零件在图像中会发生透视梯形形变呈现椭圆，单一全局比例失效。

### 例题
在桌面分拣站夹具承载面上放置一个加工精度为 ±0.01 mm 的标准圆形校准块，
其已知物理外径为 20.00 mm。相机垂直俯视采集图像，经轮廓检测算得校准块的外轮廓
直径为 400 像素。随后在同一高度的夹具内放入待测冲压垫片，测得其中心孔轮廓
像素直径为 150 像素。求：（1）当前机位高度下的空间分辨率 s（mm/pixel）；
（2）待测垫片中心孔的实际物理孔径。

解答：
1. 根据标准参考件的已知物理尺寸和图像像素尺寸，计算空间分辨率比例尺：
s = 真实物理尺寸 / 图像像素尺寸 = 20.00 mm / 400 pixel = 0.05 mm/pixel
2. 利用标定比例尺计算待测中心孔的实际物理孔径：
D_real = 中心孔像素直径 × s = 150 pixel × 0.05 mm/pixel = 7.50 mm
答：当前高度下的空间分辨率为 0.05 mm/pixel，垫片中心孔的实际孔径为 7.50 mm。

### 常见错误
1. 混淆比例尺乘除方向：将 mm/pixel 与 pixel/mm 混为一谈。若比例为 0.05 mm/pixel，
换算实际物理尺寸必须用像素值乘以 0.05；若错误相除会导致测量结果出现 400 倍偏差。
2. 跨高度平面混用标定比例：在工作台底板完成标定后，直接用于测量厚度为 10 mm
的工件上表面特征，忽略了物距缩短导致的图像放大，使计算出的物理尺寸显著虚大。
3. 忽视相机倾斜引起的透视形变：相机镜头未严格垂直于工作台时，零件发生透视
倾斜变形，圆孔变为椭圆，此时若直接套用单一比例尺，长轴与短轴均会出现严重误差。

## 镜头畸变与相机标定
工业相机的光学镜头由多枚球面或非球面玻璃透镜组合而成。受光学制造工艺和透镜
折射物理规律限制，实际成像并不完全符合理想的小孔线性投影，图像边缘的光线
会产生非线性偏移，导致实际物体的直线在图像边缘弯曲，这种现象称为镜头畸变。

工业视觉中最常见的镜头畸变包括径向畸变（Radial Distortion）和切向畸变
（Tangential Distortion）：
1. 径向畸变：光线在透镜边缘的放大率与中心区域不一致所致。若边缘放大率低于
中心，图像向内压缩、边缘直线向外膨胀形成凸弧，称为桶形畸变（常见于短焦、
广角镜头）；若边缘放大率高于中心，图像四周向外拉伸，称为枕形畸变（长焦常见）。
2. 切向畸变：透镜装配时内部各镜片与感光芯片 CMOS 不完全平行引起的偏心位移。

为了消除畸变并进行精确测量，需进行相机标定（Camera Calibration）。标定
算法将求解两组关键参数：
1. 相机内参矩阵：包含水平与垂直方向等效像素焦距（fx, fy）以及图像主点坐标
（cx, cy，即光轴在传感器上的物理中心像素坐标）。
2. 畸变系数向量：通常包含径向畸变系数（k1, k2, k3）和切向畸变系数（p1, p2）。

在 OpenCV 中，广泛采用张正友棋盘格标定法。在工作空间不同角度、位置和倾角下
拍摄多幅已知方格尺寸的棋盘格标定板照片，算法提取黑白交点（亚像素角点），通过
闭式求解与非线性优化计算出内参与畸变系数。标定完成后，使用 cv2.undistort()
函数将变形图像恢复为理想线性图像，再进行轮廓提取与几何尺寸测量。

### 例题
质检站使用短焦广角镜头拍摄垫片夹具，发现图像四周原本笔直的夹具边框弯曲成了
向外膨胀的弧线，且边缘区域垫片尺寸测量值明显偏小。请分析该镜头存在何种畸变，
并给出利用 OpenCV 已标定好的内参矩阵 camera_matrix 和畸变向量 dist_coeffs
对采集图像 img 进行去畸变矫正的核心 Python 代码。

解答：
1. 畸变类型分析：边缘直线向外膨胀弯曲，视场边缘放大率低于中心区域，属于
典型的桶形畸变（径向畸变为主）。
2. 图像去畸变矫正核心代码如下：
```python
import cv2

# 调用内参矩阵与畸变系数矫正图像
undistorted_img = cv2.undistort(img, camera_matrix, dist_coeffs)
```
矫正后图像消除了透镜径向弯曲，原本变形的直线恢复为平直几何线，各区域比例一致。

### 常见错误
1. 误认为只拍单张正面平放棋盘格即可完成标定：单张照片无法解耦相机内参矩阵
与相机空间位姿（外参），必须在不同倾角和距离下采集 10–20 张有效标定图像。
2. 误将内参与外参混淆：内参和畸变系数完全由相机与镜头的光学机械物理结构决定，
相机在机架上移动位置不改变内参；外参（旋转与平移）则随相机的安装位置而改变。
3. 标定完成后转动调焦环：手动微调镜头焦距或对焦环会改变内部镜片间距，导致
等效像素焦距 fx, fy 和畸变系数立即漂移，原有标定参数彻底失效。

## 测量误差与验证
机器视觉系统的尺寸测量值必然伴随一定的不确定度。在自动化分拣站中，若测量
波动超过零件加工公差带，就会导致合格品误剔或缺陷品漏检。必须从图像采样本质
出发分析误差来源，并通过标准量具对比与重复性测试验证系统的实际测量精度。

视觉测量的主要误差来源包括：
1. 像素离散化与边缘过渡带误差：CMOS 传感器将连续空间采样为离散的方形像素，
且由于光学衍射与轻微离焦，物理边缘在图像上表现为跨越 2–4 个像素的渐变灰度
过渡带。常规整像素阈值分割和轮廓提取具有 ±0.5 到 ±1 像素的量化不确定度。
若空间分辨率为 0.05 mm/pixel，整像素边缘跳动将直接带来 ±0.05 mm 的尺寸误差。
引入基于灰度插值、梯度重心或空间矩的亚像素边缘定位算法，可将边缘定位精度
突破至 0.1 甚至 0.02 像素级别。
2. 随机环境噪声与重复性波动：传感器热噪声、环境杂散光微弱闪烁以及机械电机
运转带来的微小振动，会导致静止放置的工件在连续拍摄时轮廓尺寸产生正态微幅跳动。

系统精度的工程验证与评估流程：
1. 高精度真值对照：使用分度值为 0.01 mm 或 0.02 mm 的高精度数显游标卡尺、
千分尺对基准试样进行多点多次精密测量，取平均值作为标称基准真值。
2. 系统误差与随机误差分离：计算视觉测量多次均值与卡尺真值的差值，评估系统
常值偏差（通常由标定比例微小误差或阈值选取引起，可通过参数校准补偿消除）；
计算多次测量的标准差 σ，以 3σ 作为评估系统重复性（Repeatability）的核心指标。

### 例题
某桌面分拣站相机的空间分辨率为 0.05 mm/pixel。质检员使用分度值为 0.01 mm 的
数显千分尺测量一枚标准垫片的外径，实测真值为 25.00 mm。随后将垫片固定在夹具中，
用视觉系统连续重复拍摄测量 5 次，测得的外径像素直径分别为：502, 501, 502, 503,
502 像素。求：（1）这 5 次视觉测量的平均物理外径；（2）视觉系统相对于千分尺
基准真值的平均测量误差。

解答：
1. 计算 5 次测量的平均像素直径：
P_avg = (502 + 501 + 502 + 503 + 502) / 5 = 2510 / 5 = 502.0 pixel
计算对应的平均物理外径：
D_avg = P_avg × s = 502.0 pixel × 0.05 mm/pixel = 25.10 mm
2. 计算平均测量误差（测量均值与基准真值之差）：
Error = D_avg - D_true = 25.10 mm - 25.00 mm = +0.10 mm
答：5 次视觉测量的平均物理外径为 25.10 mm，系统平均测量误差为 +0.10 mm
（相当于存在约 2 个像素的正向系统偏差，可通过微调比例尺或阈值修正）。

### 常见错误
1. 依赖单次测量判定系统精度：单次测试包含未知的偶然光电随机噪声，不能代表
系统真实水平；必须进行 10–30 次重复采样计算标准差以客观评估重复性。
2. 误将算法浮点数显示位数当成物理精度：在未采用亚像素算法的整像素系统中，
将计算结果强行输出为保留 5 位小数属于虚假精度，测量极限受制于离散物理像素。
3. 缺少高精度接触式量具闭环验证：仅以视觉系统自身前后读数是否一致来评估精度，
忽视了系统整体可能存在的常值比例偏差，必须使用经过计量的卡尺进行真值对标。

## 单元小结
- 像素与毫米换算通过已知尺寸参考件建立物理比例尺，但该比例严格受限于固定的
  物距和垂直光轴，工件高度改变或相机倾斜会导致比例尺失效。
- 镜头径向畸变（桶形与枕形）会导致图像边缘发生非线性拉伸与弯曲，需利用棋盘格
  标定获取相机内参与畸变系数，并通过去畸变算法恢复真实几何形态。
- 视觉测量受像素离散网格与边缘灰度过渡带限制，引入亚像素边缘算法可突破整像素
  分辨率瓶颈，有效提升尺寸测量分辨力。
- 工业视觉系统的综合测量精度必须结合数显卡尺真值对照、重复性多轮采样以及
  系统误差与随机误差统计分析进行科学闭环评估。
