# 成像与采集

本单元学习工业相机的成像几何、光源选型、曝光对焦及规范采集流程，
为桌面分拣站稳定识别垫片孔位建立高质量且可复现的图像输入。

## 本单元知识点
- 相机、镜头与视场：分辨率、焦距、工作距离与视场关系，以及像素当量的计算。
- 光照方式：背光、环形光、同轴光与漫射光的照明效果，以及反光与阴影控制。
- 曝光、增益与对焦：曝光时间、传感器增益、景深对焦及过曝与欠曝的调校。
- 固定相机与采集规范：硬件机构固定、锁定自动参数及样本命名与数据记录。

## 相机、镜头与视场
在桌面分拣站中，相机与镜头负责将被测垫片的物理几何特征转换为数字图像。
传感器分辨率指感光芯片横向与纵向的有效像素阵列大小，例如 2048 × 1536。
工作距离（WD）指镜头前端到垫片被测平面的物理距离；视场（FOV）则是
相机在工作距离下能够覆盖的实际物体尺寸范围（宽 FOV_w 与高 FOV_h）。

镜头焦距 f、工作距离 WD 与视场 FOV 遵循光学成像相似三角形近似关系：

```
视场宽度 / 传感器宽度 ≈ 工作距离 / 镜头焦距
```

视场大小与工作距离成正比，与镜头焦距成反比。当工作距离固定在分拣台高度时，
选用焦距越短的镜头，视场范围越大；选用焦距越长的镜头，视场范围越小。

像素当量 s 是连接图像像素坐标与物理尺寸的换算桥梁，定义为视场宽度与
图像水平像素数的比值：

```
像素当量 = 视场宽度 / 水平像素数
```

像素当量的单位通常表示为毫米每像素（mm/pixel）。已知像素当量后，
图像中测得的特征像素距离乘以像素当量，即可换算出实际物理尺寸。

### 例题
分拣工位工作台上放置外径 40 mm 的垫片，选用水平分辨率为 2048 像素的
工业相机。为使固定夹具完全进入视野且留有余量，设定相机视场宽度为 102.4 mm。
求该系统的像素当量。若图像中检测到垫片中心孔直径为 240 像素，求其实际孔径。

解答：
1. 计算像素当量：
s = 102.4 mm / 2048 像素 = 0.05 mm/pixel。
2. 计算中心孔实际物理尺寸：
孔物理直径 = 240 像素 × 0.05 mm/pixel = 12.0 mm。

### 常见错误
1. 误将传感器的像素数直接等同于成像测量精度，忽略了工作距离与视场大小对
每个像素代表的物理尺寸（像素当量）的决定性影响。
2. 计算像素当量时混淆了图像的宽度和高度，用纵向像素数去除了横向视场宽度。
3. 在测量物理尺寸前未标定像素当量，直接在代码中写死经验换算系数。

## 光照方式
机器视觉遵循“优质的光学照明胜过复杂的图像修复算法”原则。合理选择光源
能够增强垫片中心孔与背景的对比度，抑制环境光变化并消除多余阴影干扰。

背光照明（底光）是将面光源放置在被测垫片正下方，相机在正上方俯视拍摄。
光线直接穿透垫片中心孔射入镜头，而实心金属区域阻挡光线。该方式能生成
黑白分明的剪影图像，孔边缘对比度极高且无杂乱反光，是孔位检测的首选方案。

正面照明中常见的光源形态具有不同特点：
环形光围绕镜头四周向下照射，安装方便，但金属冲压表面极易产生高光亮斑并在
孔壁产生阴影；同轴光通过分光镜使光线平行于光轴，适合平整镜面金属表面的
缺陷检测；漫射光（如穹顶光）利用多角度漫反射消除金属表面的高光耀斑。

### 例题
在桌面分拣站中需要快速判定金属垫片是否有冲压中心孔。若使用正面斜射白炽灯，
图像中金属表面出现亮斑，孔壁出现阴影，导致固定灰度阈值经常误分割。
应如何改进照明方案？

解答：
应改用下方均匀透光的背光源。
背光使中心通孔呈现高亮灰度（接近 255），不透光的金属实体呈现低灰度黑色
（接近 0）。图像的灰度直方图呈现明显的双峰分布，阈值分割算法只需设置一个介于
亮暗之间的固定阈值即可稳定提取孔洞，基本避免了金属反光和阴影造成的伪边缘。

### 常见错误
1. 试图在照明反光严重、阴影模糊的糟糕原始图像上堆叠复杂的软件滤波算法，
而没有从物理源头改进打光方式。
2. 在需要测量外轮廓或透光孔径的几何检测任务中盲目选用正面环形光，导致反光失真。
3. 忽视车间环境杂散光的影响，未在工位上方增加遮光罩阻隔日照或顶灯干扰。

## 曝光、增益与对焦
曝光时间决定了图像传感器每个像素累积光子能量的时间长短。曝光时间过短
会导致欠曝，图像整体昏暗且动态范围压缩；曝光时间过长会导致过曝，高光
区域像素值饱和截断为 255，孔边缘细节彻底丢失。

增益（Gain）是对传感器电信号的后级放大倍数。调高增益虽然能提亮欠曝图像，
但会同时放大传感器噪声，在图像中引入大量随机噪点，破坏边缘平滑度。
因此在工业采集中，原则上应优先提高光源亮度和调整曝光，尽可能保持低增益。

对焦与景深决定图像的清晰程度。精准对焦使垫片表面的边缘在传感器上形成最清晰
的像，边缘灰度跃变梯度达到最大。景深是被测物沿光轴方向能保持清晰成像的
厚度范围；光圈越小（f 数越大），景深越大，但进入镜头的光通量会相应减少。

理想采集图像的灰度直方图应当覆盖较宽的动态范围，且前景与背景双峰分离明显，
直方图两端灰度 0 和 255 处不应出现大面积的过饱和截断现象。

### 例题
分拣站相机在测试时采集到的垫片图像偏暗，灰度值全部低于 50，孔边缘对比度差。
现场有一名学员建议直接在软件中把相机数字增益调大 4 倍。分析此建议是否合理。

解答：
该建议不合理。
直接增大增益会放大传感器的本底噪声，使原本平整的背景和垫片表面产生大量
随机噪点，导致阈值分割后产生虚假空洞和毛刺边缘。
正确做法是物理上加大背光源亮度，或在工件静止时适度延长相机曝光时间。

### 常见错误
1. 调焦未达到最佳焦点就急于测试算法，模糊的边缘会导致轮廓拟合与孔径测量
产生多个像素的系统偏差。
2. 用大幅提高增益来代替补光，导致采集的图像噪声过大，无法进行稳定阈值分割。
3. 在开大光圈增加进光量时忽视了景深变浅的问题，导致工件稍有厚度起伏就失焦。

## 固定相机与采集规范
视觉分拣系统的稳定性高度依赖物理环境的一致性。相机必须安装在刚性支架上，
垂直俯视工件平面，杜绝俯仰与左右倾斜。相机晃动或微小位移会改变工作距离，
进而破坏像素当量的标定基准。

工作台上应安装 3D 打印或机械加工的定位夹具，确保每个垫片在传感器视野中的
落点和朝向一致，避免因脱离视野或景深边缘导致误检。

在工业采集软件中，严禁开启自动曝光（AE）、自动增益（AGC）与自动白平衡（AWB）。
自动模式会根据画面整体亮度实时变动相机内部参数，导致有孔样本与缺孔样本的
基准亮度发生漂移，使固定的灰度阈值算法彻底失效。必须手动设定曝光并永久锁定。

建立规范的样本采集流程：按类别严格命名图像文件，并将采集元数据同步写入
CSV 记录文件，示例数据格式如下：

```
filename,label,has_hole,timestamp
part_ok_001.png,OK,1,2026-11-13 10:00:01
part_ng_001.png,NG,0,2026-11-13 10:00:05
```

### 例题
某分拣站采集垫片时未关闭自动曝光。当放上有孔垫片时背光透光多，画面整体偏亮，
相机自动调低曝光；当放上缺孔垫片时，相机由于总透光减少自动拉长曝光，
导致缺孔垫片上的背景灰度大幅上升，阈值判决完全错乱。应采取何种规范纠正？

解答：
必须进入相机控制 SDK 或采集程序，将曝光模式从 Auto 改为 Manual，手动设定
一个固定曝光值并锁定。
同时锁定白平衡和增益，确保视野内无论工件状态如何变化，相机的物理感光参数
都保持恒定，从而使固定灰度阈值在不同批次工件上具有稳定判决能力。

### 常见错误
1. 使用带有自动曝光和自动对焦功能的消费级摄像头进行工业检测，未锁定参数。
2. 样本文件命名随意，缺乏正负样本区分与 CSV 标签文件，无法进行批量回归评测。
3. 支架刚性不足发生机械震动，导致工作距离和光轴角度随传送机构运动发生微移。

## 单元小结
- 视场大小由工作距离与焦距共同决定，像素当量是图像像素坐标与物理尺寸换算的基准尺度。
- 背光照明是垫片通孔检测与边缘轮廓测量的首选方案，能提供最大对比度并消除反光。
- 成像调校应遵循充足打光和合理曝光原则，尽量保持低增益以避免随机噪点劣化边缘。
- 工业采集中必须锁定相机位姿与自动参数，规范样本命名与 CSV 标签记录以确保系统稳定。
- 采集质量是机器视觉算法的前提，优秀的前端光学设计可极大简化后续图像处理与识别难度。
