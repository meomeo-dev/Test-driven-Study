# 检测流程与评估
本单元围绕桌面质检分拣站，学习完整的视觉检测流水线设计与参数配置，
分析环境光照与工件偏移对系统鲁棒性的影响，并通过混淆矩阵客观评估检测指标。

## 本单元知识点
- 检测流程与 ROI：掌握采集、预处理、分割、特征提取、判定与记录的完整流水线，
  利用固定 ROI 提升计算效率并将易变参数写入外部配置。
- 鲁棒性与失效分析：分析车间光照突变、工件位置偏移与表面油污对阈值法的影响，
  掌握排查系统失效机理并规范记录失效边界条件的方法。
- 检测结果的评估：通过真正例、假正例、真反例与假反例构建混淆矩阵，
  计算准确率并分析漏检与误报代价，使用独立带标签样本评估算法。
- 有孔与缺孔检测实验（自评）：在工位上采集正反样本，运行检测流程输出判定并
  保存 CSV 记录，改变光照条件记录阈值法失效的现象与临界参数。

## 检测流程与 ROI
工业视觉检测不是单一的图像算法调用，而是一条紧密衔接的工程流水线。
桌面质检分拣站的典型检测流程包含六个核心阶段：
1. 图像采集：到位传感器触发相机抓拍，获取工件原始图像；
2. 截取 ROI：在定位夹具约束下，只截取包含中心孔的核心矩形区域；
3. 图像预处理：进行灰度转换与必要的高斯平滑，抑制高频随机噪声；
4. 阈值分割与轮廓提取：通过二值化分离孔洞与背景，提取内部孔轮廓；
5. 特征提取与规则判定：计算孔面积与圆度，与合格门限对比输出判决；
6. 结果记录与动作响应：向单片机或 PLC 发送分拣信号，并将工件编号、
   特征测量值、判定结果及时间戳追加写入本地 CSV 文件。

在垫片分拣工位中，机械定位夹具已经将工件的大致物理位置约束在固定视场内。
此时若对全图所有像素进行全局处理，不仅浪费算力，还会将夹具边缘反光与
传送带杂散背景卷入检测。通过设定固定感兴趣区域（Region of Interest, ROI），
利用 NumPy 数组切片 roi = img[y1:y2, x1:x2] 提取局部区域，
能以极低计算成本过滤掉非检测区域干扰，显著提升流水线节拍。

工程落地的另一核心原则是参数解耦。相机的曝光时间与增益、固定 ROI 坐标、
二值化分割阈值、孔面积与圆度的上下限门限等，严禁以硬编码形式写死在
算法逻辑内部。应统一存放在 JSON 或 YAML 外部配置文件中，在程序启动或
工件换型时动态读取，便于产线维护与快速调参。

### 例题
分拣站相机输出 640×480 的单通道灰度图。打印定位夹具将垫片孔位限制在
左上角坐标 (220, 160)、宽度为 200 像素、高度为 160 像素的矩形框内。
请写出截取该 ROI 的 Python 切片代码，并计算 ROI 占全图总像素的百分比。

解答：
NumPy 数组切片规则为先高度（行坐标 y）后宽度（列坐标 x）。
起始行 y1 = 160，终止行 y2 = 160 + 160 = 320；
起始列 x1 = 220，终止列 x2 = 220 + 200 = 420。
截取代码为：
```python
roi = img[160:320, 220:420]
```
全图总像素数为 640 × 480 = 307200。
ROI 区域像素数为 200 × 160 = 32000。
所占比例为：
32000 / 307200 ≈ 0.1042，即 10.4%。
截取固定 ROI 使得后续算法只需处理全图约十分之一的像素，大幅降低了运算耗时。

### 常见错误
1. 混淆 NumPy 数组的轴顺序，误写成 img[x1:x2, y1:y2]，导致图像被旋转翻转
   或触发数组越界报错。
2. 将图像二值化阈值与面积判定门限硬编码在检测函数体内，现场调参时必须
   反复修改源码。

## 鲁棒性与失效分析
视觉系统的鲁棒性（Robustness）是指算法在面对车间现场不可避免的环境扰动时，
依然能够维持稳定、正确判定结论的能力。在理想静态环境下调通的固定阈值，
在动态生产环境中极易失效。

常见物理扰动对阈值法的影响机理包括：
1. 环境光照剧变：车间自然采光变化或车间照明开启会导致视场亮度整体漂移。
   使用固定阈值时，光照过强会导致透光孔洞二值化面积剧烈膨胀甚至与背景连通；
   光照减弱则会导致孔二值化面积收缩甚至孔洞断裂丢失。
2. 机械位置偏移：定位夹具轻微松动或震动会导致工件偏离预设中心。
   若孔位局部滑出固定 ROI 边缘，提取出的轮廓将被截断，面积与圆度失真。
3. 表面油污与反光：冲压加工残留的深色重油污遮挡背光，会使孔洞被分割成
   破碎斑点；金属表面反光斑则可能被误判为多余的高亮通孔。

排查失效时不能盲目随手放大判定容差，而应规范建立失效记录表。
详细记录发生误检时的环境照度（Lux）、曝光时间、工件偏移位移以及二值化
中间图像特征。工程防御应优先采用物理手段（如加装遮光罩、选用透射背光），
其次配合算法补偿（如自适应阈值或局部动态对比度检测）。

### 例题
某透射光检测工位在标准照度下，合格垫片孔的二值化面积在固定阈值 T=130 下
稳定在 3000 像素左右，合格范围设为 [2600, 3400]。正午由于外界阳光直射工位，
背景与孔洞处的灰度整体提升，导致固定阈值分割出的亮孔面积扩大为 3800 像素。
分析此时检测系统的判定结果，并提出两项消除该失效的工程改进措施。

解答：
判定分析：光照增强后提取出的孔面积为 3800 像素，超出了系统设定的合格上限
3400 像素，导致本应合格的有孔垫片被系统判定为不合格（尺寸超差或孔径偏大），
造成良品误废。
工程改进措施：
1. 物理层改进：在相机与工位上方加装封闭式遮光罩，阻断外部车间采光波动；
2. 算法层改进：改用大津法（Otsu）或基于局部灰度对比度的自适应阈值算法，
   使分割门限跟随背景亮度自适应浮动。

### 常见错误
1. 误以为在实验桌调试的一套固定阈值可适应全天候运行，忽略了昼夜与天气变化。
2. 发生光照漂移误判后盲目放宽合格面积区间，导致孔径真正超差的次品漏网流出。

## 检测结果的评估
客观评估视觉检测系统的性能必须引入二分类统计体系。
在垫片质检中，通常将待检目标事件定义为正类（Positive），非目标或缺陷
定义为负类（Negative）。在本工位中，统一约定正常有孔合格品为正类，
缺孔次品为负类。

系统检测输出与工件真实状态的交叉组合构成了混淆矩阵（Confusion Matrix）：
- 真正例（True Positive, TP）：真实为有孔，系统正确判定为有孔；
- 假正例（False Positive, FP）：真实为缺孔，系统误判定为有孔（次品漏网）；
- 真反例（True Negative, TN）：真实为缺孔，系统正确判定为缺孔（次品被拦截）；
- 假反例（False Negative, FN）：真实为有孔，系统误判定为缺孔（良品被误废）。

基于混淆矩阵可以计算核心量化指标：
准确率 Accuracy = (TP + TN) / (TP + FP + TN + FN)，反映整体判定的正确比例。
在工业现场，两类错误的工程代价截然不同：假正例 FP 意味着次品流出进入下一道
装配工序，极易引发严重装配事故甚至召回；假反例 FN 则是良品被剔除，
主要损失是增加人工二次复检成本。

评估工作必须使用带有人工基准标签（Ground Truth）的独立验证集进行。
严禁直接拿调参用过的工件图像来统计指标，否则会产生过拟合虚高假象。

### 例题
质检站使用 120 件独立带标签垫片测试算法，其中包含 100 件有孔件与 20 件缺孔件。
测试结果为：100 件有孔件中 95 件判定为合格，5 件被判定为次品；20 件缺孔件中
18 件判定为次品，2 件被判定为合格。求混淆矩阵各要素值并计算系统准确率 Accuracy
（保留两位小数）。

解答：
根据分类定义：
TP（真实有孔且判定合格）= 95
FN（真实有孔却判定次品）= 5
TN（真实缺孔且判定次品）= 18
FP（真实缺孔却判定合格）= 2
总样本量 N = 95 + 5 + 18 + 2 = 120 件。
系统准确率计算如下：
Accuracy = (TP + TN) / N = (95 + 18) / 120 = 113 / 120 ≈ 0.9417。
保留两位小数为 0.94（即 94%）。

### 常见错误
1. 使用少量调试样本的 100% 检出率直接作为产线验收依据，缺乏统计代表性。
2. 在缺陷占比极低的样本集中只看准确率指标，掩盖了次品完全漏检的重大质量隐患。

## 有孔与缺孔检测实验（自评）
目标：搭建完整的垫片孔位视觉检测流程，自动输出判定结论并保存 CSV 记录；
通过主动改变工位光照，实测并记录阈值法失效的临界现象。

材料或准备：
1. 桌面质检分拣站夹具、USB 相机、辅助光源（透射背光板或条形光源）；
2. 冲压有孔垫片与缺孔垫片各 5–10 件，附带人工编号与标签；
3. 安装有 Python 3、OpenCV 与 NumPy 的计算机，建立配置文件 config.json。

步骤：
1. 将垫片放入定位夹具，固定相机位置、焦距、曝光与光源并锁定自动参数；在
   config.json 中配置截取中心孔的 ROI 矩形区域坐标与二值化初始阈值。
2. 在标准光照下拍摄每件有孔与缺孔样本，保存为带编号和标签的图像文件，如
   ok_01.png、ng_01.png。
3. 编写检测脚本：读取图像，截取 ROI，阈值分割，用 cv2.RETR_CCOMP 提取内轮廓，
   按面积范围统计孔数并判定，将工件编号、孔数、判定结果及时间戳追加写入
   result.csv。
4. 对全部样本图像运行脚本，打开 result.csv 与人工真实标签对比，构建混淆矩阵
   并统计准确率。
5. 改变一次光照（调高或调低光源亮度，或移除遮光罩），重新拍摄同一批样本并
   检测，记录出现首次误判时的光照状态、二值化结果的变化与失效原因。

## 单元小结
- 机器视觉检测流水线涵盖采集、ROI 截取、预处理、分割、特征提取、判定与 CSV 记录
  全流程，参数配置化是工程落地的规范做法。
- 固定 ROI 能够依靠机械定位大幅削减数据计算量，并有效屏蔽视野外围的杂散背景干扰。
- 阈值分割算法对光照波动、工件偏移与表面油污高度敏感，工程上应优先采用遮光罩等
  物理防护，辅以自适应算法提升鲁棒性。
- 系统评估必须基于独立的带标签验证样本，借助混淆矩阵全面权衡假正例（次品漏网）
  与假反例（良品误废）的工程代价。
