# 阈值分割与轮廓

本单元学习将灰度图像分割为目标与背景的全局与自适应阈值化方法、形态学滤波去噪技巧，
以及工件内外轮廓提取与层级解析，为桌面分拣站中的垫片孔位检测构建完整的几何轮廓处理链。

## 本单元知识点
- 全局阈值与 Otsu：掌握固定阈值与 Otsu 双峰自适应二值化原理及 OpenCV 函数调用。
- 自适应阈值与光照不均：掌握局部邻域阈值分割原理、窗口尺寸与常数 C 对阴影与明暗渐变的影响。
- 形态学操作：掌握基于结构元素的腐蚀与膨胀，运用开运算消除孤立毛刺杂点、闭运算桥接填补小孔洞。
- 轮廓提取与层级：掌握二值图像轮廓跟踪算法、外轮廓与内轮廓（孔）的拓扑层级及提取模式。

## 全局阈值与 Otsu

二值化是图像分割中最基础的操作，其目标是将单通道灰度图转换为仅包含 0（黑）
与 255（白）的二值图像。OpenCV 提供了 cv2.threshold 函数，通过设定全局分界
阈值 thresh，将全图像素划分为目标前景与背景两大类。

常用的阈值类型包括 cv2.THRESH_BINARY 与 cv2.THRESH_BINARY_INV。
当像素灰度大于阈值时，THRESH_BINARY 将其赋值为 maxValue（通常设为 255），
其余置为 0；而 THRESH_BINARY_INV 逻辑相反，像素值小于等于阈值时置为 255，
大于阈值时置为 0。在桌面分拣站背光照明下，背景为高亮白光，金属垫片呈现深色，
因此常采用 THRESH_BINARY_INV 将深色垫片转换为白色前景。

当生产现场环境光轻微波动时，人工指定固定阈值容易失效。Otsu 算法（大津法）
通过遍历所有候选灰度级，自动寻找使目标类与背景类之间“类间方差”达到最大的
灰度值作为全局最优阈值。该算法特别适用于灰度直方图呈现明显双峰分布的工况。
在 OpenCV 中，只需在阈值类型参数中叠加 cv2.THRESH_OTSU 标志
（例如 cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU），并将传入阈值参数设为 0
即可启用。

### 例题
在桌面分拣工位中，相机采集到垫片灰度图像 gray。背光照明下背景明亮
（灰度约 210–240），垫片偏暗（灰度约 40–80）。请使用 Otsu 自动阈值算法
将垫片分割为白色前景（255），背景设为黑色（0），并打印计算出的最优阈值。

解：
```python
import cv2

gray = cv2.imread("washer.png", cv2.IMREAD_GRAYSCALE)

# 背光下目标偏暗，使用反二值化配合 Otsu 自动寻优
# 传入阈值设为 0，函数返回值 ret 即为 Otsu 自动计算出的全局阈值
ret, thresh_img = cv2.threshold(
    gray, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU
)
print(f"Otsu 选定的最佳阈值: {ret}")
```

### 常见错误
- 目标与背景极性混淆：OpenCV 轮廓提取默认将白色（255）作为前景目标。若暗色
  垫片误用 THRESH_BINARY，会导致整个高亮背景被当成目标工件。
- 在单峰或低对比度图像上滥用 Otsu：当照明严重不均、直方图没有明显双峰波谷时，
  Otsu 会在单峰斜坡处强行分割，导致大范围误检。

## 自适应阈值与光照不均

在工业分拣现场，侧光照射、机械臂遮挡或光源衰减常导致工作台表面照度不均匀，
出现光斑或渐变阴影。在整幅图像中，阴影区域垫片的灰度往往低于强光区域的背景。
此时单一全局固定阈值必然顾此失彼，导致一侧垫片缺失或另一侧背景过度分割。

自适应阈值算法（cv2.adaptiveThreshold）通过对每个像素独立计算局部阈值来
解决光照不均。对坐标为 (x, y) 的像素，算法以其为中心取大小为
blockSize × blockSize 的邻域窗口，计算该窗口内像素的加权均值，再减去微调
常数 C，作为该像素专属的判定门限 T(x, y)。

该函数的关键参数规则如下：
- adaptiveMethod：可选 cv2.ADAPTIVE_THRESH_MEAN_C（算术均值）或
  cv2.ADAPTIVE_THRESH_GAUSSIAN_C（高斯权重均值）。高斯加权法离中心越近
  权重越高，分割边缘比算术均值法更为平滑自然。
- blockSize：局部邻域边长，必须是大于 1 的奇数（如 11, 21, 31）。其尺寸应
  大于需分割目标的特征宽度（如垫片边框宽度），并小于光照渐变的变化尺度。
- 常数 C：从均值中扣除的偏置数值。若使用 THRESH_BINARY_INV 提取暗目标，
  增大 C 可以过滤背景微弱光影杂点，但 C 过大会造成垫片边缘轮廓萎缩。

### 例题
分拣台右侧存在遮挡形成的局部阴影，导致工作台灰度从左向右渐变变暗。请使用
高斯加权自适应阈值，窗口边长设为 25，微调常数 C 设为 5，将暗色垫片提取为
白色前景。

解：
```python
import cv2

gray = cv2.imread("shadow_washer.png", cv2.IMREAD_GRAYSCALE)

# 采用局部高斯自适应阈值，窗口尺寸必须为奇数（25）
adapt_img = cv2.adaptiveThreshold(
    gray, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C,
    cv2.THRESH_BINARY_INV, 25, 5
)
```

### 常见错误
- blockSize 传入偶数：OpenCV 严格要求 blockSize 为大于 1 的奇数以保证具有
  唯一的中心像素，传入偶数会直接抛出断言错误异常。
- blockSize 尺寸选得过小：若 blockSize 小于垫片实心边框宽度，当窗口完全落入
  垫片内部时，局部均值等于自身灰度，减去 C 后会导致垫片实体中心被掏空镂空。

## 形态学操作

形态学操作是基于集合论的二值图像几何滤波技术，利用预定义形状与尺寸的探针
——“结构元素”（Kernel，核）在二值图像上滑动匹配，根据局部重叠形态修改图像。

最基本的两种操作是腐蚀（Erosion）与膨胀（Dilation）：
- 腐蚀（cv2.erode）：要求结构元素覆盖的所有像素全部为白色（255），输出中心
  像素才保留为 255，否则置为 0。效果是收缩白色前景，消除孤立毛刺与细小杂点。
- 膨胀（cv2.dilate）：只要结构元素覆盖范围内包含任意一个白色（255）像素，
  输出中心点即置为 255。效果是扩张白色前景，桥接边缘裂缝并填补内部黑色孔洞。

在实际工件检测中，常组合使用腐蚀与膨胀：
- 开运算（Opening）：先腐蚀后膨胀（cv2.morphologyEx 使用 cv2.MORPH_OPEN）。
  能有效消除背景上孤立的细小金属反光杂点，平滑工件毛刺，且不改变垫片主尺寸。
- 闭运算（Closing）：先膨胀后腐蚀（cv2.morphologyEx 使用 cv2.MORPH_CLOSE）。
  能填补垫片内部细小黑孔与裂纹，桥接邻近微小缝隙，平滑轮廓边缘。
结构元素通常通过 cv2.getStructuringElement(cv2.MORPH_RECT, (ksize, ksize))
创建，核尺寸一般设为 3×3 或 5×5，尺寸不宜过大以免破坏工件真实孔径。

### 例题
二值化后的垫片图像 binary_img 中，背景传送带上散落有若干 1–2 像素的金属碎屑
白色反光杂点，垫片边缘伴有细微毛刺。请构造 3×3 矩形核，调用开运算清理杂点
并平滑边缘。

解：
```python
import cv2

# 创建 3x3 矩形结构元素
kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))

# 执行形态学开运算：先腐蚀消除细小杂斑，再膨胀恢复垫片轮廓
cleaned_img = cv2.morphologyEx(binary_img, cv2.MORPH_OPEN, kernel)
```

### 常见错误
- 结构元素尺寸超过待检特征尺度：垫片为白色、孔为黑色时，若核尺寸不小于孔径，
  膨胀或闭运算会将中心孔填平；若孔作为白色前景，开运算或腐蚀会将它消除。
- 混淆开运算与闭运算功能：消除孤立白噪点应使用开运算（先腐蚀）；若误用闭运算
  （先膨胀），无法消除孤立白噪点（点仍然保留），邻近的噪点还可能被连成一片。

## 轮廓提取与层级

轮廓是连接所有具有相同像素强度（在二值图中为 255）的连续边界像素点曲线。
OpenCV 4.x 提供 cv2.findContours 函数进行轮廓跟踪，输入图像必须是 8 位
单通道二值图像（目标前景为 255，背景为 0）。

函数原型为 contours, hierarchy = cv2.findContours(image, mode, method)。
其中 method 参数指定轮廓点编码方式：
- cv2.CHAIN_APPROX_NONE：保存边界上每一个像素点的绝对坐标。
- cv2.CHAIN_APPROX_SIMPLE：压缩水平、垂直与对角直线段，仅保留线段端点，
  极大节省内存占用并加速后续几何特征计算。

mode 参数与 hierarchy 层级关系：
- cv2.RETR_EXTERNAL：仅检测最外层轮廓，完全忽略所有内部孔洞。用于快速获取
  工件外轮廓包络尺寸与定位。
- cv2.RETR_CCOMP：建立两级拓扑结构。顶层为工件外边界，次层为工件内部孔洞。
  垫片外圆周为顶层外轮廓，冲压中心孔为次层内轮廓。
返回值 hierarchy 是一个形状为 (1, N, 4) 的三维数组，每个轮廓对应
[Next, Previous, First_Child, Parent] 四个层级指针。若 Parent 等于 -1，
表明该轮廓没有父级，属于最外层边界；若 Parent 不等于 -1，则其数值指明所属
外轮廓的索引，表明该轮廓属于嵌套在工件内部的孔洞。

### 例题
已得到垫片二值图像 bin_img（垫片为白色 255，孔洞与背景为 0）。请提取两层
轮廓层级，统计并输出图像中检测到的所有工件内孔（内轮廓）总数量。

解：
```python
import cv2

# 采用 RETR_CCOMP 提取内外两层拓扑，CHAIN_APPROX_SIMPLE 压缩点集
contours, hierarchy = cv2.findContours(
    bin_img, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE
)

hole_count = 0
if hierarchy is not None:
    # 遍历 hierarchy[0] 中每个轮廓的层级信息
    for h in hierarchy[0]:
        # 第四个元素 h[3] 为 Parent 索引，不为 -1 即代表内部孔洞
        if h[3] != -1:
            hole_count += 1
print(f"检测到的工件孔洞总数: {hole_count}")
```

### 常见错误
- 提取孔洞时错误采用 RETR_EXTERNAL 模式：RETR_EXTERNAL 会彻底丢弃所有内部
  闭合轮廓，导致无法检测到垫片中心孔。
- 传入未二值化的图像：findContours 只接受单通道图，多通道图像会抛出异常；
  未二值化的灰度图不报错，但所有非零像素都会被当作前景，轮廓随之错误。

## 单元小结
- 全局二值化通过统一门限区分前景与背景，Otsu 算法利用最大类间方差准则在双峰
  直方图下自适应确定最优全局阈值。
- 在外界光照不均或存在明暗渐变阴影时全局阈值失效，自适应阈值根据像素局部邻域
  动态计算门限，其窗口尺寸 blockSize 必须为大于 1 的奇数。
- 腐蚀收缩前景消除毛刺，膨胀扩张前景填补微孔；开运算（先腐蚀后膨胀）用于清除
  孤立背景杂点，闭运算（先膨胀后腐蚀）用于弥合工件内部断裂与细小孔洞。
- cv2.findContours 函数中，RETR_EXTERNAL 仅检测工件最外层包络轮廓，而
  RETR_CCOMP 能够建立外边界与内部孔洞的两级父子层级，Parent 索引不等于 -1 即为孔。
