# 形状特征与孔检测

本单元面向桌面质检分拣站场景，系统讲解基于轮廓与边缘的几何特征提取技术，
通过面积、周长、外接框与圆度分析实现垫片孔位精准识别与缺孔判定。

## 本单元知识点
- 面积、周长与外接框：学习轮廓像素面积、弧长周长、正外接矩形与质心坐标的计算。
- 圆度与形状描述：掌握圆度与长宽比公式，利用无量纲几何特征筛选圆形轮廓。
- 边缘检测：理解灰度梯度与 Sobel 算子，掌握 Canny 双阈值边缘提取与边界定位。
- 孔位检测与缺孔判定：提取工件内轮廓并按几何特征计数，完成缺孔判定与信号输出。

## 面积、周长与外接框
在二值化与轮廓提取完成后，工件边界由一组有序坐标点构成。OpenCV 提供了多个
直接从点集计算几何特征的函数，用于定量描述工件的尺寸与空间位置。

cv2.contourArea(cnt) 基于格林公式计算闭合轮廓包围的多边形面积，单位为像素平方。
轮廓点位于边界像素中心，因此面积略小于区域内的像素个数：边长 10 像素的实心
正方形，轮廓面积为 81，周长为 36，而像素个数为 100。
cv2.arcLength(cnt, True) 计算封闭轮廓的周长，参数 True 表示曲线闭合；若参数为
False，则计算开折线的折线长度。

对于工件定位与边界包络，cv2.boundingRect(cnt) 返回与图像坐标轴平行的正外接
矩形参数 (x, y, w, h)，分别代表外接矩形左上角坐标与矩形宽高。
cv2.minEnclosingCircle(cnt) 返回完全包围该轮廓的最小外接圆圆心坐标与半径浮点
数 ((cx, cy), radius)。

轮廓的几何中心（质心）通常借助图像空间矩获取。调用 cv2.moments(cnt) 可计算各阶
几何矩，当零阶矩 M["m00"]（代表面积）非零时，质心坐标公式为：
cx = int(M["m10"] / M["m00"])
cy = int(M["m01"] / M["m00"])
质心坐标反映了工件在视场中的物理定位参考点。

### 例题
题目：已知拍摄到的一枚垫片外轮廓点集存储在变量 cnt 中，请编写一段代码，计算
该轮廓的像素面积、闭合周长、正外接矩形与质心坐标，并格式化输出。
```python
import cv2

# 计算轮廓像素面积与闭合周长
area = cv2.contourArea(cnt)
perimeter = cv2.arcLength(cnt, closed=True)

# 计算正外接矩形
x, y, w, h = cv2.boundingRect(cnt)

# 计算空间矩与质心坐标
m = cv2.moments(cnt)
if m["m00"] != 0:
    cx = int(m["m10"] / m["m00"])
    cy = int(m["m01"] / m["m00"])
else:
    cx, cy = 0, 0

print(f"面积: {area:.1f}, 周长: {perimeter:.1f}")
print(f"正外接矩形: x={x}, y={y}, w={w}, h={h}")
print(f"质心坐标: ({cx}, {cy})")
```

### 常见错误
1. 调用 cv2.arcLength 时误将 closed 参数设为 False，导致算出的仅为开折线长度。
2. 计算质心时未判断零阶矩 m["m00"] 是否为零，在遇到单点噪声轮廓时触发除零异常。
3. 混淆正外接矩形与最小面积外接矩形，正外接矩形边框始终与图像坐标轴平行。

## 圆度与形状描述
获取几何特征后，需要构建无量纲形状描述子，以区分圆形内孔、长条划痕与金属毛刺。

圆度（Circularity）是工业视觉中最经典的圆形度量指标，其定义公式为：
圆度 = 4π × 面积 / 周长²
对于理想的连续圆形，面积 A = πr²，周长 P = 2πr，代入公式后圆度恰好为 1.0。
当形状偏离圆形或边缘凹凸不平时，周长显著增大而面积相对缩减，圆度向 0 趋近。
在像素栅格上，用 contourArea 与 arcLength 计算的圆孔圆度总是低于 1.0，孔越小
偏差越大：直径约 10 像素约为 0.76，20 像素约为 0.83，100 像素约为 0.89。

长宽比（Aspect Ratio）由正外接矩形计算得出：长宽比 = 宽度 / 高度（w / h）。
圆形与正方形工件的长宽比通常接近 1.0，而长条形杂质或传送带划痕的长宽比显著偏离
1.0，可用于辅助快速粗筛。

在分拣质检中，通常采用双门限联合过滤机制：首先设定面积阈值区间 [min_area,
max_area] 过滤细小椒盐噪点与大块背景干扰；其次设定圆度下限 circularity ≥
min_circ 剔除边缘带毛刺或缺损的不规则孔洞。

### 例题
题目：给定图像中提取的候选轮廓列表 contours，编写函数筛选出面积在 500 到 3000
像素之间、且圆度大于等于 0.80 的圆形孔洞轮廓，返回有效孔洞列表。
```python
import cv2
import numpy as np

valid_holes = []
for cnt in contours:
    area = cv2.contourArea(cnt)
    perimeter = cv2.arcLength(cnt, closed=True)
    if perimeter == 0:
        continue
    # 计算圆度: 4π·面积/周长²
    circularity = 4 * np.pi * area / (perimeter ** 2)
    # 按面积与圆度双重条件筛选
    if 500 <= area <= 3000 and circularity >= 0.80:
        valid_holes.append(cnt)

print(f"筛选出的有效圆形孔数量: {len(valid_holes)}")
```

### 常见错误
1. 计算圆度时未判断周长是否为零，导致单像素噪点轮廓引发除零错误。
2. 误将圆度阈值设为绝对严格等于 1.0，忽略离散栅格误差而误杀合格孔洞。
3. 误认为外接矩形长宽比接近 1.0 就必然是圆，忽略了正方形多边形长宽比同样为 1.0。

## 边缘检测
边缘对应图像中灰度发生剧烈跳变的像素集合，通常表征工件物理边界与孔位轮廓。
与阈值分割依赖整体亮度不同，边缘检测完全依赖局部的灰度空间导数与梯度幅值。

Sobel 算子采用一阶微分卷积核分别计算图像水平梯度 Gx 与垂直梯度 Gy。梯度向量
指向灰度变化最剧烈的方向，梯度幅值近似计算为 G = √(Gx² + Gy²)，其数值直接反映
了边界过渡的陡峭程度。

Canny 算法是目前工业检测中最常用的边缘检测算子，包含四个处理阶段：
1. 高斯滤波降噪：滤除图像中的高频随机噪声。
2. 计算梯度幅值与方向：使用 Sobel 卷积核获取全局梯度特征。
3. 非极大值抑制（NMS）：沿梯度方向仅保留局部最大值像素，细化边缘为单像素宽。
4. 双阈值滞后跟踪：采用高阈值 threshold2 与低阈值 threshold1 分类边缘像素。

在双阈值判断中，梯度幅值大于高阈值的确定为强边缘；小于低阈值的判定为假边缘丢弃；
介于高低阈值之间的弱边缘，仅在与强边缘相连通时才作为有效边缘保留。
高低阈值比例通常推荐设定在 2:1 至 3:1 之间。

阈值分割输出的是包含工件内部的二值连通域掩模，适合区域面积统计；边缘检测输出的
是单像素宽的边界线条，更适合高精度边缘测量、间隙检测与微小毛刺识别。

### 例题
题目：读取灰度垫片图像 gasket_gray，先使用 5×5 高斯核平滑滤波，再调用 Canny
算子检测边缘（低阈值设为 50，高阈值设为 150），最后统计边缘像素总数。
```python
import cv2
import numpy as np

# 高斯滤波抑制成像噪声
blurred = cv2.GaussianBlur(gasket_gray, (5, 5), sigmaX=1.0)

# Canny 双阈值边缘提取
edges = cv2.Canny(blurred, threshold1=50, threshold2=150)

# 统计单像素边缘点数量
edge_count = np.count_nonzero(edges)
print(f"检出边缘像素点总数: {edge_count}")
```

### 常见错误
1. 调用 Canny 前未做高斯平滑滤波，导致图像中的椒盐或高频噪声被误检为散碎边缘。
2. 高低阈值设置极端，高阈值过高导致边缘断裂，低阈值过低导致伪边缘连成蛛网。
3. 误将 Canny 提取出的边缘线当成实心孔洞，直接调用 contourArea 计算实心面积。

## 孔位检测与缺孔判定
桌面质检分拣站的核心任务是：从采集到的垫片图像中定位内孔，核验孔的数量与形状
属性，判定工件是否存在缺孔缺陷，并向执行机构发出分流指令。

检测实施流程包括以下四个核心步骤：
1. 图像预处理与二值化：通过滤波与阈值分割获得清晰的工件黑白二值图。
2. 提取分级轮廓：利用 cv2.findContours 搭配 cv2.RETR_CCOMP 模式提取内外轮廓，
   并通过层级数组 hierarchy 锁定位于工件内部的孔洞候选。
3. 几何特征过滤：计算各内轮廓的面积与圆度，剔除不满足规格的孔内污渍与反光噪点。
4. 缺孔判定与信号输出：将有效孔数量与标准期望孔数对比，生成合格或缺孔结论。

在判定逻辑中，设合格垫片的标准期望孔数为 N（如单孔垫片 N = 1，四孔垫片 N = 4）。
当实测有效孔数量等于 N 时，判定为合格工件，控制系统驱动挡板放行；
当实测有效孔数量小于 N 时，判定为缺孔不合格件，挡板动作将工件拨入废料盒；
若实测孔数大于 N，说明存在穿孔或开裂，同样属于不合格产品。

分拣站主程序同时将每个工件的时间戳、实测孔数与最终判定结果保存为 CSV 记录，
形成完整的质量追溯档案。

### 例题
题目：某型金属垫片标准设计应具有 1 个中心圆孔。已知工件二值化图像 binary_img，
编写完整的内孔提取与缺孔判定逻辑，打印最终分拣决策。
```python
import cv2
import numpy as np

# 提取两级轮廓，获取工件外边界与内孔边界
contours, hierarchy = cv2.findContours(
    binary_img, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE
)

valid_hole_count = 0
EXPECTED_HOLES = 1

if hierarchy is not None:
    for i, cnt in enumerate(contours):
        # hierarchy[0][i][3] != -1 表示该轮廓存在父轮廓，即属于内孔
        if hierarchy[0][i][3] != -1:
            area = cv2.contourArea(cnt)
            perimeter = cv2.arcLength(cnt, closed=True)
            if perimeter > 0:
                circ = 4 * np.pi * area / (perimeter ** 2)
                # 依据工位标定参数过滤孔洞
                if 800 <= area <= 4000 and circ >= 0.75:
                    valid_hole_count += 1

# 缺孔与合格判定
if valid_hole_count == EXPECTED_HOLES:
    verdict = "PASS"
else:
    verdict = "FAIL_DEFECT"

print(f"检出有效孔数: {valid_hole_count}, 质检判定: {verdict}")
```

### 常见错误
1. 未分析 hierarchy 层级结构，误将工件最外层轮廓一同计入孔洞数量。
2. 判定逻辑仅写 valid_hole_count > 0，当多孔工件漏冲个别孔时发生漏检。
3. 面积门限未根据相机物距与分辨率标定，使用经验常数导致不同批次工件误判。

## 单元小结
- 轮廓几何度量：利用 contourArea、arcLength、boundingRect 与图像矩确定工件尺度与质心。
- 形状特征描述：结合圆度与长宽比构成无量纲指标，有效实现圆形孔洞与非圆异物的区分。
- 边缘梯度检测：Canny 算子通过高斯滤波、梯度计算、非极大值抑制与双阈值滞后提取边界。
- 闭环质检判定：通过层级轮廓提取与几何筛选统计有效孔数，对比期望孔数输出分拣决策。
