# 数字图像基础
本单元介绍工业视觉分拣场景中数字图像的核心基础，包括像素点阵与坐标系统、
灰度与通道表示、图像在内存中的 NumPy 数组结构以及基础图像文件读写方法。

## 本单元知识点
- 像素、分辨率与坐标：认识图像像素网格、分辨率与以左上角为原点的坐标系。
- 颜色通道与灰度：理解 8 位灰度级以及 RGB 与 OpenCV 的 BGR 通道与灰度转换。
- 图像即数组：掌握 NumPy 数组形状 (高, 宽, 通道)、[y, x] 索引切片与 uint8 溢出。
- 读写图像：掌握使用 cv2.imread 与 cv2.imwrite 安全读写图像与处理空返回值。

## 像素、分辨率与坐标
在桌面质检分拣工位中，待检垫片被放置在 3D 打印的定位夹具内。到位传感器触发
相机曝光后，相机的感光元件将垫片表面反射的光信号转换为离散的二维点阵。点阵中
的每一个基本感光单元称为像素（Pixel），它是构成数字图像的最小单位。

图像分辨率通常用“水平宽度 × 垂直高度”（Width × Height）表示。例如 1280 × 960
的分辨率表示水平方向有 1280 个像素，垂直方向有 960 个像素，图像包含的总像素数
为两者乘积（1,228,800 像素）。在视野范围固定的前提下，分辨率越高，单个像素对应
的实际物理尺寸越小，算法能分辨的垫片边缘和孔位细节就越精细。

机器视觉使用的标准数字图像坐标系与传统平面直角坐标系不同：
- 坐标原点 (0, 0) 严格位于图像的左上角。
- x 轴沿水平方向向右延伸为正，取值范围是 0 到 宽度 - 1。
- y 轴沿垂直方向向下延伸为正，取值范围是 0 到 高度 - 1。
定位夹具中垫片中心若在图像中向下移动，其 y 坐标增大；向右移动，x 坐标增大。

### 例题
题目：分拣工位相机采集到一幅垫片图像，分辨率为 1920 × 1080。请计算该图像
的总像素数，并写出图像最右下角最后一个像素的坐标 (x, y)。

解答：
1. 图像水平宽度 W = 1920，垂直高度 H = 1080。
2. 图像总像素数 = W × H = 1920 × 1080 = 2,073,600 像素。
3. 像素坐标从 0 开始计数，水平范围为 0 到 1919，垂直范围为 0 到 1079。
4. 因此，图像最右下角像素的坐标为 (1919, 1079)。

### 常见错误
1. 坐标轴方向混淆：误把 y 轴当作数学坐标系的“向上为正”，导致工件上下位置颠倒。
2. 越界边界错误：误将右下角坐标当作 (1920, 1080)，忽略了从 0 起算导致数组越界。

## 颜色通道与灰度
在工业分拣中，判断垫片是否有孔主要依据零件轮廓与明暗对比。单通道 8 位灰度图
用一个无符号整数（uint8）表示每个像素的明暗程度，数值范围为 0 到 255。
数值 0 代表无光反射的纯黑色（如无反光背景或深孔中心），数值 255 代表最亮的
纯白色（如金属垫片表面强反光区），中间数值对应不同深浅的灰色。

常规彩色图像由红（R）、绿（G）、蓝（B）三个分量合成。但 OpenCV 默认使用 BGR
顺序存储彩色图像：通道 0 为蓝色（B），通道 1 为绿色（G），通道 2 为红色（R）。
若将 OpenCV 读取的图像直接传入以 RGB 格式解析的绘图库中显示，会发生颜色通道
互换，原本蓝色的背景会呈现为红色。

从彩色图像转换到灰度图像并非简单求三通道平均值。人眼视网膜对不同波长的光敏感度
存在生理差异，对绿光最敏感、对蓝光最迟钝。因此机器视觉采用标准感知加权转换公式：
Gray = 0.299 × R + 0.587 × G + 0.114 × B
在 OpenCV 中，通常调用 cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) 快速完成转换。

### 例题
题目：工件表面某像素在 OpenCV 中的颜色分量为 B = 60，G = 50，R = 190。
请根据标准感知灰度公式计算转换后的灰度值。

解答：
1. 提取各通道分量：R = 190，G = 50，B = 60。
2. 代入感知加权公式：Gray = 0.299 × 190 + 0.587 × 50 + 0.114 × 60。
3. 分项计算：0.299 × 190 = 56.81；0.587 × 50 = 29.35；0.114 × 60 = 6.84。
4. 求和：56.81 + 29.35 + 6.84 = 93。
5. 该像素转换后的灰度值为 93。

### 常见错误
1. 通道顺序错位：误将 OpenCV 彩色图通道 0 当作红色通道提取，导致特征颜色失真。
2. 简单平均求灰度：用 (R+G+B)/3 转换有色工件，在低对比度有色划痕处容易丢失边缘。

## 图像即数组
在 Python 环境中，OpenCV 读取的图像直接存储为 NumPy 的多维数组（ndarray）。
图像数组的 shape 属性定义了各维度大小：
- 彩色图像为三维数组，形状为 (高度, 宽度, 通道数)，即 (height, width, channels)。
- 单通道灰度图为二维数组，形状为 (高度, 宽度)，即 (height, width)。
例如高 600、宽 800 的彩色图像，其 shape 值为 (600, 800, 3)。

NumPy 数组的索引顺序与几何坐标 (x, y) 刚好相反：第一个维度表示垂直方向的行数
（对应 y），第二个维度表示水平方向的列数（对应 x）。因此访问坐标为 (x, y) 的
像素必须使用 img[y, x]。
通过数组切片可以快速提取定位夹具中垫片所在的感兴趣区域（ROI）：
roi = img[y1:y2, x1:x2]
切片范围遵循 Python 的前闭后开规则，垂直范围在前，水平范围在后。

图像数组默认采用 np.uint8 类型，数值范围严格限制在 0 到 255 之间。
当直接对数组使用 Python 原生运算符时，计算会发生模 256 溢出回绕：
- 上溢：210 + 60 计算结果为 14（(210 + 60) - 256 = 14），亮区反而变黑。
- 下溢：30 - 50 计算结果为 236（(30 - 50) + 256 = 236），暗区反而变亮。
进行亮度增减等数值运算时，应使用 cv2.add() 等饱和运算函数，或先转换为 float32。

### 例题
题目：已知灰度图像 img 的 shape 为 (480, 640)，数据类型为 np.uint8。
夹具中垫片中心点坐标为 x = 200，y = 150，当前像素灰度值为 210。
请写出访问该像素的代码，并计算执行 img[150, 200] = img[150, 200] + 60 后的值。

解答：
1. 访问像素遵循先行后列原则（先 y 后 x），访问代码为 img[150, 200]。
2. 计算原生加法：210 + 60 = 270。
3. 数组类型为 np.uint8，结果超出 255 发生模 256 上溢回绕：270 % 256 = 14。
4. 因此赋值后该像素的新值为 14。

### 常见错误
1. 坐标顺序写反：误写成 img[x, y]，导致行列颠倒甚至引发 IndexError 索引越界。
2. 误判 shape 含义：误以为 shape[0] 是图像宽度，实际上 shape[0] 是高度（行数）。
3. 忽略 uint8 溢出：直接用加减法调节图像亮度，导致高光反光面出现大片黑色噪点。

## 读写图像
在自动化检测流程中，程序需要从工控机硬盘加载工件图片，并在检测判定完成后将
带有标注的结果图片保存到磁盘。OpenCV 提供了简洁的读写接口。

读取图像使用 cv2.imread(filepath, flags)：
- filepath 为图像文件路径。如果文件不存在、权限不足或文件已损坏，cv2.imread
  不会抛出 Python 异常，而是静默返回 None。若未判空直接访问 img.shape，将引发
  AttributeError: 'NoneType' object has no attribute 'shape' 异常。
- flags 指定读取模式。默认值为 cv2.IMREAD_COLOR（即 1），始终返回 3 通道 BGR 图像；
  传入 cv2.IMREAD_GRAYSCALE（即 0）可直接以单通道 8 位灰度模式加载，节省内存。

保存图像使用 cv2.imwrite(filepath, img)：
- 函数自动根据 filepath 的扩展名选择编码器（如 .png 或 .jpg）。
- .png 格式为无损压缩，适合保存保留边缘微观细节的质检样张；
  .jpg 为有损压缩，文件体积较小但会产生边缘压缩伪影。
- 保存成功返回 True，目录不存在或无法写入时返回 False；扩展名无法识别时
  会抛出 cv2.error，因此应使用 .png 等明确支持的扩展名。

文件路径编写时，Windows 系统下的反斜杠容易与转义字符混淆（例如 \n、\t 会被转义
导致路径错误）。在编写视觉程序时，建议统一使用正斜杠（如 "images/washer.png"）
或在路径前加上 r 声明为原始字符串（如 r"images\washer.png"）。

### 例题
题目：编写一段 Python 脚本，以单通道灰度模式读取 "sample.png"，若读取成功
则将其另存为无损格式 "sample_gray.png"，读取失败时输出错误提示。

解答：
```python
import cv2

img = cv2.imread("sample.png", cv2.IMREAD_GRAYSCALE)
if img is None:
    print("图像读取失败，请检查文件路径")
else:
    success = cv2.imwrite("sample_gray.png", img)
    if success:
        print("灰度图像保存成功")
```

### 常见错误
1. 缺少 NoneType 检查：调用 cv2.imread 后不作检查，导致后续调用属性时程序崩溃。
2. 参数常数混淆：误把 cv2.COLOR_BGR2GRAY 作为 imread 的参数传入导致读取错误。
3. 路径转义错误：在 Windows 路径中使用未经转义的反斜杠导致文件找不到。

## 单元小结
- 像素是图像的最小单元，分辨率为宽 × 高；坐标系以左上角为原点 (0, 0)，x 向右、y 向下。
- 8 位灰度图亮度范围为 0 到 255；OpenCV 彩色图像默认为 BGR 通道顺序，彩色转灰度采用感知加权公式。
- OpenCV 图像以 NumPy 数组存储，形状为 (高, 宽, 通道)，通过 img[y, x] 访问像素，需防范 uint8 溢出回绕。
- cv2.imread 路径错误时静默返回 None，cv2.imwrite 根据后缀名自动选择压缩编码格式并返回布尔值。
