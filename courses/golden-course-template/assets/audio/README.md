# Listening recordings

`delivery-delay.mp3` was synthesized offline with the `cmu_us_slt` voice from
[CMU Flite 2.2](https://github.com/festvox/flite/tree/v2.2) and encoded as mono
MP3. The course uses an original script, stored in the recording item's
`transcript` field in [the question bank](../../questions/extended-practice.json).
See Flite's [license](https://github.com/festvox/flite/blob/v2.2/COPYING) and the
[voice source notice](https://github.com/festvox/flite/blob/v2.2/lang/cmu_us_slt/cmu_us_slt.c).
