# 零基础阶梯进阶英语（二）

## 课程概述
- **学制与学时**：标准学期制课程，共 9 单元，90 课时（每课时 60 分钟，总计 5,400 教学分钟）。
- **课程定位**：第二学期（90课时）：进阶时态、被动语态、状语从句与定语从句、职场邮件与技术说明文读写。
- **配套大纲**：详见 `syllabus_180h.json`。

## 单元结构
1. **一般将来时与计划预算表达**（10 课时）
2. **现在完成时与质量管控体系**（10 课时）
3. **过去进行时与过去完成时**（10 课时）
4. **被动语态与工程规范写作**（10 课时）
5. **并列句与状语从句系统**（10 课时）
6. **定语从句与工程特征界定**（10 课时）
7. **名词性从句与商务技术沟通**（10 课时）
8. **实用职场、邮件与技术说明文读写**（10 课时）
9. **第二学期综合实战复习与终结考核**（10 课时）
