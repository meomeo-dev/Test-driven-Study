# 单片机与嵌入式开发

用 GPIO、串口和状态机驱动一个可复位的桌面分拣工位。

## 学习起点

先学电路基础与 C 语言的条件、循环和函数。可先用模拟器或一块开发板练习。

- 按键消抖与串口计数 → 读取到位信号 → 非阻塞控制舵机挡板。

## 学完能做什么

- 读取按键和到位传感器，区分稳态与事件。
- 用非阻塞计时和状态机组织检测、分流和故障。
- 通过串口记录状态，并检验超时、复位和掉线。

**桌面质检分拣站实作**。编写等待工件、等待判定、分流、故障四个状态。模拟电脑不回包，并验证设备保持在故障状态直至人工复位。

## 课程内容

1.1.0 版包含七个单元、27 个知识点和 134 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成
学习顺序。表中同一单元的知识点以分号分隔。

| 单元 | 知识点 |
| --- | --- |
| 单片机与开发环境 | 单片机的组成；开发环境、编译与下载；程序结构 setup 与 loop；逻辑电平与引脚电气限制 |
| GPIO 输入与输出 | 数字输出驱动 LED；数字输入与上拉、下拉；按键消抖；边沿检测与事件计数 |
| 计时、中断与 PWM | 阻塞延时与非阻塞计时；外部中断与 volatile；定时器与 PWM |
| 串口通信与调试 | UART 帧与波特率；串口日志与调试；命令协议与解析；通信超时与重试 |
| 传感器与执行器 | ADC 采样与换算；到位传感器与光电开关；舵机 PWM 与角度；负载驱动与隔离供电 |
| 状态机与可靠性 | 状态、事件与转移表；故障状态与人工复位；看门狗与复位原因；实作：四状态分拣工位（自评） |
| 系统集成与测试 | 需求与 IO 分配表；传感器滤波与迟滞；分模块联调与测试记录；上电、掉电与安全默认状态 |

“实作：四状态分拣工位”是自评实作，没有练习题。
按[状态机与可靠性讲义](lessons/state-machines.md)中的自评清单完成后，
在学习路径中标记已会。
