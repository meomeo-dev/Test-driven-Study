# 梯形图基础

本单元学习梯形图的母线结构、触点线圈求值、布尔逻辑组合、自锁与置位复位电路，
以及上升沿与下降沿脉冲的单周期捕获机制。

## 本单元知识点
- 梯形图与触点线圈：左右母线、能流概念、常开常闭触点与线圈从左到右自上而下的执行规则。
- 逻辑组合：触点串联为与、并联为或、常闭为非的布尔映射与动作条件表达。
- 自锁、置位与复位：启保停电路结构、停止优先原则、置位复位指令与双线圈冲突规避。
- 上升沿与下降沿：边沿检测原理、单扫描周期脉冲特性与防重复触发计数应用。

## 梯形图与触点线圈
梯形图（Ladder Diagram, LD）是工业自动化中最常用的图形化编程语言。
梯形图两侧为垂直母线，左侧代表提供信号源的供电母线，右侧为回路参考母线。
程序按照虚拟“能流”（Power Flow）方向自左向右流动，
各逻辑行（Rung）则在 PLC 的扫描周期中按照从上到下的顺序依次扫描执行。

触点用于反映输入信号或内部中间变量的位状态（0 或 1）。
常开触点（Normally Open, NO）在对应变量为 1 时闭合导通，为 0 时断开；
常闭触点（Normally Closed, NC）在对应变量为 0 时保持导通，为 1 时断开。
通过触点的开闭状态组合，决定能流是否可以向后级网络传递。

输出线圈（Coil）置于逻辑行的最右端，代表计算结果的输出赋能。
当左侧能流完整接通至线圈时，线圈对应的存储器位被置为 1；
当能流中断时，该位被置为 0。在标准循环扫描机制中，
线圈运算结果首先写入输出映像寄存器，在扫描周期末尾集中刷新至物理端子。

### 例题
在桌面分拣站中，工件到位光电传感器接入 PLC 输入端 I0.0（工件遮挡时光电输出 1），
相机就绪信号接入 I0.1（相机正常就绪时输出 1）。
要求当工件到位且相机就绪时，工件定位气缸夹紧电磁阀 Q0.0 动作。
请给出该逻辑行的梯形图文字描述与布尔表达式，并说明其扫描执行过程。

解答：
梯形图逻辑行描述：
第 1 行：常开触点 I0.0 与常开触点 I0.1 串联，最右端连接输出线圈 Q0.0。
布尔逻辑表达式：
```
Q0.0 = I0.0 AND I0.1
```
扫描执行说明：
在扫描周期的输入采样阶段，PLC 读取外部端子并刷新 I0.0 与 I0.1 映像位；
进入程序执行阶段，若两者均为 1，则两个常开触点均闭合导通，
能流从左母线流经两个触点驱动线圈 Q0.0，使 Q0.0 映像位置 1；
若任一输入为 0，能流中断，Q0.0 映像位置 0。
扫描周期末尾的输出刷新阶段，PLC 将 Q0.0 的状态写入物理端子驱动夹紧电磁阀。

### 常见错误
- 错误 1：将输出线圈放置在逻辑行中间或最左侧。IEC 规范中能流从左向右，
  输出线圈必须置于逻辑行的最右端。
- 错误 2：误以为线圈得电会瞬间触发外部物理电磁阀。
  PLC 采用集中刷新机制，物理输出只在当前扫描周期结束时统一更新。

## 逻辑组合
梯形图通过触点的拓扑连接实现布尔逻辑代数运算。
触点相互串联对应布尔“与”（AND）逻辑，只有所有串联触点同时导通，能流才能通过。
触点相互并联对应布尔“或”（OR）逻辑，多条并联支路中只要任意一条导通，
即可将能流传递至下游回路。

常闭触点对应布尔“非”（NOT）逻辑，在信号为 0 时导通，信号为 1 时截断能流。
在工业现场中，复杂的设备启动或动作条件均可拆解为与、或、非的组合。
例如分拣挡板既可以由自动检测信号触发，也可以由人工手动调试按钮触发，
同时必须受到全局安全联锁条件的严格串联约束。

在设计逻辑组合网络时，应注意分支与总干路的从属关系。
全局保护条件（如安全门开关、过载保护）必须串联在所有并联分支的总干路上；
若错误串联在某一条并联分支内，其他分支动作时将绕过该安全保护。

### 例题
桌面分拣站的分拣挡板电磁阀由输出线圈 Q0.0 控制。动作要求如下：
条件 1：处于自动运行模式（I0.2 为 1），且视觉检测为不合格（I0.3 为 1），
且工件到达分拣区（I0.4 为 1）；
条件 2：处于手动点动分拣模式（I0.5 为 1）；
同时，防护罩关闭检测开关 I0.6 采用常闭接线（防护罩关闭时为 1，打开或断线时为 0），
防护罩未关闭时严禁动作。
请写出布尔逻辑表达式并给出梯形图文字描述。

解答：
布尔逻辑表达式：
```
Q0.0 = ((I0.2 AND I0.3 AND I0.4) OR I0.5) AND I0.6
```
梯形图文字描述：
支路 1 由常开触点 I0.2、I0.3、I0.4 串联组成；
支路 2 由常开触点 I0.5 组成；
将支路 1 与支路 2 并联，形成复合启动条件块；
该并联块右侧串联常开触点 I0.6，最后连接输出线圈 Q0.0。
无论处于自动还是手动支路，一旦防护罩打开或检测线路断开（I0.6 为 0），
常开触点 I0.6 立即切断通往 Q0.0 的能流，确保设备停机保护。

### 常见错误
- 错误 1：并联分支嵌套层级错误，将安全联锁触点并入局部回路，
  导致某一触发条件跳过安全联锁。
- 错误 2：外部接线与程序逻辑极性混淆。外部采用常闭硬件接入时，
  PLC 输入映像已为 1，程序内应根据真值表选用对应触点，避免二次取反颠倒逻辑。

## 自锁、置位与复位
工业控制中的按钮大多为瞬态点动按钮（按下闭合，松开即断开）。
为了在按钮松开后维持设备连续运转，需使用受控线圈自身的常开触点
与启动按钮并联，这种电路称为自锁电路，亦称“启保停”（Start-Hold-Stop）电路。

启保停电路必须遵循“停止优先”（Stop-Priority）安全原则。
停止按钮触点必须串联在启动与自锁并联回路的总干路上。
当停止按钮按下时，无论启动按钮是否被外力卡阻闭合，
总回路能流均被强制切断，输出线圈失电，自锁状态解除。

置位（SET / S）与复位（RESET / R）是具保持记忆特性的指令。
执行 SET 指令后，目标位保持为 1，即使驱动能流消失也不会复位；
只有执行对应的 RESET 指令，目标位才被清 0。
若在同一周期内 SET 与 RESET 条件同时成立，
位于梯形图下方的指令将在最终扫描中生效，通常将 RESET 置于下方以实现复位优先。

双线圈冲突（Dual-Coil Issue）是初学者最常见的问题。
在同一个程序中对同一个普通输出线圈进行多次赋值输出时，
位于后方逻辑行的运算结果会无条件覆盖前方逻辑行的结果。
因此同一普通线圈在全程序中只能出现一次，多分支驱动应合并为并联网络，
或规范采用成对的置位/复位指令。

### 例题
桌面分拣站传送带电机由输出线圈 Q0.1 控制。
启动按钮接入 I0.0（常开点动），停止按钮接入 I0.1（现场常开按钮，按下为 1）。
请设计停止优先的启保停电路文字描述，并分析启动与停止按钮同时按下时的输出。

解答：
梯形图文字描述：
第 1 行：常开触点 I0.0 与常开触点 Q0.1 并联，构成启动与自锁回路；
该并联回路右侧串联常闭触点 I0.1，末端驱动输出线圈 Q0.1。
动作分析：
按下启动按钮 I0.0 时，能流经过 I0.0 与常闭触点 I0.1 驱动 Q0.1 得电；
Q0.1 置 1 后其并联常开触点闭合；I0.0 松开后，能流通过 Q0.1 自身触点维持；
当 I0.0 与 I0.1 同时按下时，并联支路导通，但常闭触点 I0.1 因输入为 1 而断开，
主干路能流中断，线圈 Q0.1 保持为 0，电机停止运行，满足停止优先。

### 常见错误
- 错误 1：出现双线圈输出。在自动逻辑行写了一次驱动 Q0.1，
  在手动逻辑行又写了一次驱动 Q0.1，导致上方逻辑行的输出被下方完全覆盖。
- 错误 2：启动优先错误接线。将停止触点仅串联在自锁触点支路上，
  当启动按钮卡死时无法紧急停止。

## 上升沿与下降沿
现场机械与检测动作往往是事件驱动的瞬态过程。
由于 PLC 扫描周期通常仅为数毫秒至数十毫秒，
若直接使用持续数百毫秒的电平信号驱动计数器或步进指令，
会导致单次工件通过在连续多个扫描周期内被重复累计数十次。

上升沿检测（Positive Transition, R_TRIG）用于捕捉信号由 0 变 1 的瞬间；
下降沿检测（Negative Transition, F_TRIG）用于捕捉信号由 1 变 0 的瞬间。
边沿检测指令开辟独立的布尔存储位记录上一扫描周期的输入状态，
通过比较“当前周期状态”与“上一周期状态”来判断跳变。

边沿脉冲的有效输出时间严格限制为 1 个扫描周期（Single Scan Cycle）。
当信号由 0 变为 1 时，指令在当前周期输出为 1；
在紧接着的下一个扫描周期中，即使外部输入信号依然维持为 1，
由于历史位已被刷新为 1，边沿触点会自动复位为 0。

边沿检测广泛应用于分拣工位的单件工件到达计数、启动单次拍照脉冲、
模式切换单步触发等场景，是避免电平信号被重复计数、实现单次事件触发的关键。

### 例题
桌面分拣站中，工件遮挡到位光电传感器 I0.0 持续 0.8 秒，
PLC 的平均扫描周期为 10 毫秒。程序中要求在工件到达瞬间产生触发脉冲 M0.0，
用于触发视觉相机采集拍照并让合格品计数器加 1。
请计算工件通过期间：I0.0 维持高电平经历了多少个扫描周期？
利用上升沿指令生成的脉冲 M0.0 输出为 1 的状态维持了多少个扫描周期？

解答：
1. 持续时间计算：0.8 s = 800 ms。
   经历的扫描周期数 = 800 ms ÷ 10 ms = 80 个扫描周期。
2. 边沿脉冲特性分析：
   M0.0 由 I0.0 的上升沿指令驱动。上升沿指令只在信号由 0 跳变为 1 的
   第一个扫描周期产生逻辑 1 输出，在后续的 79 个扫描周期内输出均为 0。
因此，I0.0 保持高电平经历了 80 个扫描周期，
而 M0.0 为 1 的状态仅维持 1 个扫描周期（即 10 ms）。

### 常见错误
- 错误 1：多个边沿检测指令共用同一个内部边沿标志位，
  导致前一个指令刷新状态后后一个指令无法正确捕获跳变。
- 错误 2：在条件跳过或未调用的子程序块中使用边沿指令，
  因扫描中断导致历史状态无法连续更新，再次调用时产生误触发或漏检。

## 单元小结
- 梯形图采用直观的电路拓扑形式，遵循左母线供电、自左向右、自上而下的扫描顺序。
- 触点串联实现布尔与，并联实现布尔或，常闭实现布尔非，安全保护条件需串联在总干路。
- 启保停自锁电路必须遵循停止优先原则，全程序严禁对同一普通线圈多次赋值（双线圈冲突）。
- 上升沿与下降沿检测指令输出严格维持单个扫描周期的瞬态脉冲，是防重计数与单次触发的核心。
