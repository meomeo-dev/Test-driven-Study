# 安全与故障处理

本单元学习工业自动化控制中的急停安全回路设计原则、故障检测与报警自锁恢复机制，
以及手动、自动与回原点模式的互锁切换逻辑。

## 本单元知识点
- 急停与安全回路：急停常闭触点接法、硬件安全继电器与程序分工及复位不自动重启原则。
- 故障检测、报警与复位：超时故障锁存、声光报警输出及人工确认排除后的受控复位。
- 手动与自动模式：手动点动、自动连续与单步运行，模式互锁切换条件及回原点流程。

## 急停与安全回路
工业自动化设备在高速运行时具备机械动能，传感器失效、工件卡死或人员误入
都可能导致人身伤害或设备损坏。安全系统设计的核心目标是实现“故障导向安全”
（Fail-Safe），即系统发生任何单一电气或机械故障时均能自动转移到安全停机状态。

在电气接线中，急停按钮必须使用常闭（NC）触点接入控制系统。当按钮被按下、
信号线松脱或线缆发生折断时，回路物理断开，控制系统立即判定为急停触发。
若错误采用常开（NO）触点，当线缆意外断线时，即使操作员按下急停按钮，触点
闭合信号也无法传递给控制器，导致急停功能彻底失效。

工业标准严格要求“硬件切断优先与冗余控制”原则。急停输入信号必须直接接入专用的
硬件安全继电器。当急停触发时，安全继电器的硬件常开触点立即物理断开电磁阀动力
电源与电机主接触器线圈电源；同时，安全继电器的辅助干触点作为普通数字量输入
（如 I0.0）送入 PLC，供程序感知急停事件并停止步进逻辑。严禁将普通 PLC 程序
作为切断执行机构动力的唯一防线。

当现场险情排除并将急停蘑菇头旋转释放（触点恢复闭合）后，系统严禁立即自动恢复
动作。安全继电器必须经过独立的人工安全复位按钮触发重新吸合，且 PLC 程序必须
保持在安全待机或停机步，必须由操作人员再次按下启动按钮后方可重新启动。

### 例题
桌面质检分拣站中，急停按钮 SB1（常闭触点）与安全复位按钮 SB2（常开触点）配合
硬件安全继电器 K1 工作。请回答：(1) 当急停按钮线缆在端子处松脱断开时，系统
为何能确保停机安全？(2) 操作员旋出急停蘑菇头并按下 SB2 使 K1 重新吸合后，
输送带电机的 PLC 输出线圈 Q0.0 是否应当立即通电启动？为什么？

解答：
(1) 急停回路采用常闭触点串联供电，线缆松脱断线与拍下急停在物理电路上等效，
均导致回路电流中断，使安全继电器 K1 释放并切断动力源，符合故障导向安全原则。
(2) Q0.0 不得立即通电启动。安全继电器吸合仅代表硬件动力回路处于允许通电状态。
为防止机械机构在人员未做好准备时突然动作引发伤害，PLC 状态机必须保持在停机步，
必须由操作员现场确认安全后按下独立启动按钮，PLC 方可驱动输出。

### 常见错误
- 错误 1：将急停按钮的常开触点接入安全继电器或 PLC 输入，导致线路断线时急停失效。
- 错误 2：仅在 PLC 程序内部编写急停停机逻辑，而未在硬件主回路上串联安全继电器。
- 错误 3：将急停释放信号直接作为重新启动信号，旋出急停按钮后设备立即无预警自启动。

## 故障检测、报警与复位
在工件检测与分拣过程中，各气缸与机械机构的行程动作均有确定的时间物理上限。
控制程序通常使用接通延时定时器 TON 对执行机构动作进行超时监控。例如：推料
电磁阀通电输出后，若在设定时间（如 2.5 秒）内到位传感器仍未接通，或工件到位后
上位视觉系统在规定时间内未返回检测结果，即可判定为卡料或传感器故障。

故障状态必须执行锁存（Latch）。由于机械振动或操作扰动，故障发生后传感器信号
可能瞬时恢复，若不进行锁存，故障条件消失会导致系统在隐患未排除时盲目重新启动。
在梯形图中，通常使用置位指令（SET）或自锁逻辑将故障标志位（如 M1.0）保持为 1，
同时立即联锁切断当前动作步的动力输出，并驱动报警蜂鸣器与报警指示灯。

故障处理必须遵循闭环管理流程：系统检测到异常后停机报警并锁存故障，维护人员
查明并消除物理卡料或线路故障，人工按下专用复位按钮清除故障锁存标志，控制
状态机返回初始步或原点待命步。严禁在未排除物理隐患前强行复位，且复位后必须
从安全的受控步序重新开始。

### 例题
桌面质检分拣站的推料气缸伸出电磁阀为 Q0.1（由步进逻辑的推料请求 Push_Request 驱动），伸出到位传感器为 I0.3，故障报警灯为
Q0.7，故障标志位为 M1.0，人工复位按钮为 I0.5。气缸动作正常耗时 1.0 秒，监控
超时阈值设为 2.5 秒。请写出该工序超时故障检测、锁存及复位的梯形图逻辑说明与
结构化文本（ST）代码。

解答：
梯形图控制逻辑说明：
第 1 行：常开触点 Q0.1 与常闭触点 I0.3 串联，接入接通延时定时器 TON_1 的输入端 IN，
定时时间 PT 设定为 T#2.5S。
第 2 行：定时器输出触点 TON_1.Q 接通时，执行置位指令 SET M1.0。
第 3 行：故障标志常开触点 M1.0 接通时，驱动报警输出线圈 Q0.7。
第 4 行：复位按钮常开触点 I0.5 接通时，执行复位指令 RST M1.0。
第 5 行：推料请求 Push_Request 串联常闭触点 M1.0，驱动 Q0.1，故障时立即切断伸出输出。
结构化文本（ST）代码实现：
```pascal
TON_1(IN := Q0.1 AND NOT I0.3, PT := T#2.5S);
IF TON_1.Q THEN M1.0 := TRUE; END_IF;
IF I0.5 THEN M1.0 := FALSE; END_IF;
Q0.7 := M1.0;
Q0.1 := Push_Request AND NOT M1.0;
```

### 常见错误
- 错误 1：未使用故障置位锁存，导致推料气缸卡死时报警灯随传感器抖动闪烁后意外自启。
- 错误 2：复位逻辑直接强行跳转到高速自动主步，未核对现场工件与机构是否在安全位置。
- 错误 3：将故障确认按钮与系统启动按钮合并为一个按钮，导致排除故障按键瞬间设备飞车。

## 手动与自动模式
桌面质检分拣站在日常生产、设备调试和检修维护中需要运行在不同的工作模式下。
工业控制系统常见的三种基本工作模式包括：手动点动（Jog）模式、单步（Single Step）
运行模式以及自动连续（Auto）运行模式。

手动模式主要用于设备检修、机构调试及处理卡料。在手动点动模式下，每个气缸或
电机的动作由操作面板上的对应点动按钮直接控制，其控制原则是“按压动作、松手即停”。
梯形图中直接由输入触点驱动输出线圈，严禁加入自锁支路，确保操作员能够精准控制
微小行程。单步模式则用于工艺调试，每按一次单步启动按钮，系统仅执行顺序控制流程
中的一个动作步，随后自动暂停并等待下一次按键指令，方便观察工序转换是否正常。

自动模式与手动模式在控制逻辑上具有严格的互斥性。在程序设计中，模式选择开关的
触点必须进行逻辑互锁。当切换到手动模式时，自动运行的主步进状态机必须被强制切断
并保持在挂起或复位状态；当在自动运行过程中突然切换到手动模式时，系统必须立即
安全停机，防止两套互斥逻辑同时争夺输出线圈（避免双线圈冲突）。

系统在从手动调试模式切换回自动运行模式前，必须强制执行“回原点”（Homing）程序。
由于手动点动可能使推料气缸、分选挡板或夹具停留在任意不可预知的中间位置，若直接
启动自动循环，极易发生机械干涉碰撞。回原点程序会按照严格的安全先后顺序控制各执行
机构逐一退回初始安全物理位置，在所有原点传感器均有效接通后，才允许置位系统就绪
标志并准许切换进入自动连续运行。

### 例题
桌面质检分拣站配有两档选择开关 SA1（接入 I0.6，接通为自动模式，断开为手动模式）。
推料气缸电磁阀为 Q0.1，手动点动按钮为 I0.7，自动步进送出的推料控制标志为 M2.1。
请说明为何不能在程序中分别编写两行独立的输出梯形图（第 1 行由 I0.7 驱动 Q0.1，
第 2 行由 M2.1 驱动 Q0.1），并给出符合规范的梯形图逻辑设计说明与 ST 语句。

解答：
在 PLC 循环扫描机制下，若对同一个物理输出线圈 Q0.1 编写两次独立输出（双线圈），
后执行的程序行结果将无条件覆盖先执行的程序行结果，导致逻辑失效甚至机构失控。
规范设计应使用互锁逻辑将不同模式的控制条件汇聚到同一线圈驱动支路中：
梯形图控制逻辑说明：
常闭触点 I0.6（手动模式有效）与常开触点 I0.7（点动按钮）串联构成支路 1；
常开触点 I0.6（自动模式有效）与常开触点 M2.1（自动推料步）串联构成支路 2；
支路 1 与支路 2 并联后，统一驱动推料电磁阀输出线圈 Q0.1。
结构化文本（ST）代码实现：
```pascal
Q0.1 := (NOT I0.6 AND I0.7) OR (I0.6 AND M2.1);
```

### 常见错误
- 错误 1：在不同程序段中对同一执行机构输出线圈进行重复赋值（双线圈输出），造成逻辑混乱。
- 错误 2：手动调试后未执行回原点程序，在机构处于行程中间位置时直接开启自动运行导致撞机。
- 错误 3：模式切换开关未做程序防抖与状态互锁，在旋钮切换瞬间引发机构误动作。

## 单元小结
- 急停回路必须采用常闭触点接入硬件安全继电器，切断动力由硬件优先执行，急停解除不自动重启。
- 故障监控通过定时器实现超时判定，故障标志必须置位锁存，排除物理隐患后方可人工复位。
- 故障复位后系统严禁就地飞车动作，必须从受控的安全初始步或原点状态重新启动。
- 手动点动、单步与自动运行必须严格互锁，手动切换自动前必须经过回原点流程确保机械安全。
