# 定时与计数

本单元围绕桌面分拣站的动作节拍控制与执行机构运行保护展开学习，
重点掌握 IEC 61131-3 标准下的通电延时、断电延时与脉冲定时器，
加减计数器的基本原理与时序特性，以及到位超时监控的工程实现。

## 本单元知识点
- 定时器 TON、TOF 与 TP：掌握三种基础定时器的使能时序、预设时间 PT 与当前时间 ET 的刷新行为。
- 计数器 CTU 与 CTD：掌握基于脉冲上升沿的工件数量统计、预设值与复位加载控制逻辑。
- 超时监控：利用定时器实现气缸伸出、物料到位等动作的过程时间监视与异常报警互锁。

## 定时器 TON、TOF 与 TP
在 PLC 顺序控制系统中，定时器是实现动作延时、工件到位消抖以及
脉冲宽度控制的核心工具。IEC 61131-3 标准定义了三种核心定时器功能块：
通电延时定时器 TON、断电延时定时器 TOF 和脉冲定时器 TP。
每个定时器功能块均包含使能输入端 IN、预设时间输入端 PT、
计时完成输出端 Q 以及当前累计流逝时间输出端 ET。

通电延时定时器 TON 的工作规则：
1. 当输入端 IN 变为 TRUE 时开始计时，当前时间 ET 从 0 逐步递增。
2. 当 ET 达到预设时间 PT 时，输出端 Q 变为 TRUE。
3. 此后只要 IN 保持 TRUE，输出 Q 就持续保持 TRUE，ET 保持为 PT。
4. 在任何时刻只要 IN 变为 FALSE，输出 Q 立即复位为 FALSE，ET 立即清零。
TON 常用于工件到位后的平稳消抖确认，以及动作完成后的延时启动。

断电延时定时器 TOF 的工作规则：
1. 当输入端 IN 为 TRUE 时，输出端 Q 立即为 TRUE，ET 清零。
2. 当 IN 由 TRUE 变为 FALSE（产生下降沿）时，启动延时计时，ET 递增。
3. 当 ET 累积达到预设时间 PT 时，输出端 Q 变为 FALSE，ET 停止累计。
4. 若在计时过程中 IN 重新变为 TRUE，计时立即中止，ET 清零，Q 保持 TRUE。
TOF 广泛用于设备停机后的散热延时，或气缸动作完成后的延时复位保持。

脉冲定时器 TP 的工作规则：
1. 当输入端 IN 出现由 FALSE 到 TRUE 的上升沿时，输出端 Q 立即为 TRUE。
2. Q 为 TRUE 期间，当前时间 ET 从 0 开始持续累加至预设值 PT。
3. 在脉冲持续期间，无论输入端 IN 提前断开还是产生新的上升沿，均被忽略。
4. 当 ET 达到预设值 PT 时，输出端 Q 自动变为 FALSE，完成单次脉冲输出。
TP 适用于为工业相机输出固定宽度的拍照触发脉冲（如 T#50ms）。

### 例题
在桌面分拣工位中，工件到位光电传感器 I0.0 接通后，由于工件滑入
定位夹具时可能存在微小弹跳，需要工件稳定保持 500ms 后才触发相机拍照。
若工件在 500ms 内滑出或发生抖动导致 I0.0 断开，必须立即放弃本次拍照。
请选用合适的定时器，编写梯形图控制逻辑并分析其工作过程。

解答：
选用通电延时定时器 TON。
梯形图逻辑设计如下：
```text
第 1 行：常开触点 I0.0 连接到定时器 TON_Stable 的 IN 端，预设时间 PT 设为 T#500ms。
第 2 行：定时器输出 TON_Stable.Q 驱动相机触发线圈 Q0.1。
```
工作过程分析：
1. 当工件滑入夹具使 I0.0 接通时，TON_Stable 开始计时，ET 开始递增。
2. 若工件稳定停留在夹具内达到 500ms，ET 累积达到 PT，输出端 Q 置为 TRUE，
   线圈 Q0.1 得电，驱动工业相机完成高质量拍照。
3. 若工件在 300ms 时因弹跳滑出夹具，I0.0 变为 FALSE，定时器使能解除，
   当前时间 ET 立即清零，输出 Q 始终保持 FALSE，从而有效避免了误拍照。

### 常见错误
1. 误将 TON 当作保持型定时器：误认为 IN 端断开后 ET 会停留在断开时的值，
   实际上标准 TON 的 IN 为 FALSE 时会立即复位清零当前时间。
2. 误以为 TP 脉冲输出期间可被重触发：在 TP 输出脉冲尚未结束前，再次给
   IN 端施加上升沿不会延长脉冲宽度，TP 在计时完成前忽略所有输入变化。
3. 忽略 PLC 扫描周期对定时精度的影响：若定时器预设时间小于单个 PLC 扫描周期，
   输出刷新只能在下一个扫描周期完成，无法实现微秒级的硬件精确度。

## 计数器 CTU 与 CTD
在分拣流水线中，工件计数、批次装箱及废品率统计均依赖计数器。
IEC 61131-3 定义了加计数器 CTU 和减计数器 CTD 两种基本功能块。
计数器是事件驱动型功能块，依靠输入信号的跳变沿来更新计数值。

加计数器 CTU 的工作机制：
1. 计数输入端 CU：每次检测到由 FALSE 变为 TRUE 的有效上升沿，当前值 CV 增加 1。
2. 输出端 Q：当当前计数值 CV 大于或等于预设值 PV 时，输出端 Q 置为 TRUE。
3. 复位输入端 R：当 R 为 TRUE 时，强制将当前值 CV 清零，输出 Q 变为 FALSE。
   复位端 R 具有最高优先级，只要 R 为 TRUE，CU 端的脉冲将全部被忽略。
4. 当 CV 达到 PV 且输出 Q 置位后，若继续输入 CU 脉冲且未复位，CV 仍会继续递增。

减计数器 CTD 的工作机制：
1. 装载输入端 LD：当 LD 为 TRUE 时，强制将预设值 PV 载入当前值 CV，输出 Q 置 FALSE。
2. 计数输入端 CD：每次检测到有效上升沿，当前计数值 CV 减 1。
3. 输出端 Q：当当前计数值 CV 小于或等于 0 时，输出端 Q 置为 TRUE 并保持。
CTD 适合用于倒计时控制或剩余物料配额监控场景。

计数信号的边沿检测与防抖要求：
现场开关量传感器（如光电开关或微动开关）在工件切入边缘时可能产生毫秒级的
接触弹跳抖动。若直接用电平逻辑计数，会导致一个工件被误计多次。
因此，在进入计数器 CU/CD 之前，必须对输入信号进行硬件滤波或程序消抖，
并通过上升沿检测指令（R_TRIG）捕获唯一的跳变边沿。

### 例题
桌面分拣站每收集满 10 个合格工件时，需要触发推箱气缸换料。
合格品到位检测信号为 I0.1，新空料盒到位传感器为 I0.2，
推箱气缸电磁阀由 Q0.3 驱动。请使用 CTU 设计该控制逻辑。

解答：
选用加计数器 CTU。
梯形图逻辑设计如下：
```text
第 1 行：合格品检测常开触点 I0.1 串联上升沿指令，连接到 CTU1 的计数输入端 CU。
第 2 行：预设值 PV 设定为 10，新料盒到位常开触点 I0.2 连接到复位端 R。
第 3 行：计数器输出端 CTU1.Q 驱动推箱气缸线圈 Q0.3。
```
工作过程分析：
1. 每个合格品滑过 I0.1 时，产生一个上升沿脉冲，CTU1 的当前值 CV 加 1。
2. 当第 10 个工件通过时，CV 达到 10，输出端 CTU1.Q 变为 TRUE，Q0.3 得电，
   推箱气缸伸出将满载料盒推走。
3. 当操作人员放入新料盒使 I0.2 接通时，复位端 R 变为 TRUE，CTU1.CV 立即清零，
   输出 CTU1.Q 自动恢复为 FALSE，推箱气缸缩回，开始下一批次计数。

### 常见错误
1. 复位信号持续接通：将到位传感器常开信号直接长接在 R 端，导致物料停留期间
   R 端持续为 TRUE，CV 被死锁在 0，无法记录后续任何进料脉冲。
2. 忽略计数超额后的处理：CV 达到 PV 后若未及时复位，继续计件会导致 CV 继续增加，
   若下一级程序依赖 CV == PV 判定批次，将产生严重的控制脱节。
3. 计数信号未做消抖处理：机械开关触点抖动使单个工件产生多次通断，
   CTU 在几毫秒内接收到多个上升沿，导致计数结果大幅超出实际产量。

## 超时监控
在自动化设备中，输出指令发出后执行机构必须在限定时间内完成动作并反馈到位。
若因气路泄漏、异物卡料、机构卡死或传感器损坏导致机构未在规定时间内到位，
必须由超时监控逻辑及时报警停机，防止设备损坏甚至发生人员伤害事故。

超时监控的基本结构与原理：
1. 使用通电延时定时器 TON 实施过程监控，动作驱动信号作为 TON 的使能条件。
2. 将动作对应的到位传感器常闭触点串联在定时器的使能回路中。
3. 当动作正常完成时，到位传感器变为 TRUE，常闭触点断开，TON 立即复位清零。
4. 若动作受阻未能在规定时间内到位，常闭触点保持闭合，TON 持续累积时间达到 PT，
   输出端 Q 变为 TRUE，触发超时故障报警逻辑。

超时时间的合理设定原则：
1. 必须以执行机构的实测动作时间（含正常工况下的波动）作为基准时间。
2. 超时时间通常取正常动作时间的 1.5 至 2.0 倍：例如气缸正常动作需要 300ms，
   超时预设时间 PT 一般设定在 450ms 至 600ms 之间。
3. 裕量过小会导致现场气压微弱波动时频繁误报警；裕量过大则会导致机构卡死时
   电机或气阀长时间堵转，可能烧毁器件或压损工件。

安全联锁与故障自锁规范：
1. 报警自锁：超时报警必须通过置位指令（Set）锁定，严禁随卡阻物晃动而自动消除。
2. 动力切断：报警标志位的常闭触点必须互锁切断对应执行机构及上游供料的输出。
3. 禁止自动重启：故障排除后，即使到位传感器重新接通，系统也绝不允许自动恢复运行，
   必须由人工现场确认安全并按下复位按钮后，方可解除报警并转入就绪状态。

### 例题
分拣挡板气缸由电磁阀 Q0.2 驱动伸出，到位磁性开关为 I0.3。气缸正常伸出耗时 200ms。
请设计一套超时监控程序：若伸出指令发出 400ms 后仍未检测到到位信号，
置位报警标志 M1.0，并立即强制切断气缸输出 Q0.2，由按钮 I0.5 人工复位。

解答：
选用通电延时定时器 TON，设定 PT = T#400ms（正常耗时的 2.0 倍）。
梯形图逻辑设计如下：
```text
第 1 行：分拣伸出指令接通并自锁 Q0.2，同时常开触点 Q0.2 串联常闭触点 I0.3 驱动 TON1.IN。
第 2 行：定时器输出 TON1.Q 驱动置位指令（Set），将报警标志位 M1.0 置 TRUE。
第 3 行：将报警标志常闭触点 M1.0 串联在 Q0.2 线圈回路中，故障时立即切断 Q0.2。
第 4 行：人工复位常开触点 I0.5 触发复位指令（Reset），将报警标志位 M1.0 清零。
```
工作过程分析：
1. Q0.2 输出时，因气缸未到位，I0.3 为 FALSE，常闭触点闭合，TON1 开始计时。
2. 正常情况下气缸在 200ms 到位，I0.3 变为 TRUE，常闭触点断开，TON1 立即清零，不报警。
3. 若气缸卡死，400ms 内 I0.3 始终未接通，TON1.Q 变为 TRUE，置位 M1.0 并切断 Q0.2。
4. 人工排除异物后，必须按下复位按钮 I0.5 才能解除 M1.0，确保设备与人员安全。

### 常见错误
1. 报警信号未自锁：仅用 TON.Q 直接点亮报警灯，一旦卡料工件晃动触碰到位传感器，
   定时器复位会导致报警突然熄灭且机构重启，存在严重安全隐患。
2. 超时时间裕量过小：将超时阈值设得过于接近正常动作时间，现场气压轻微波动
   便导致频繁误报故障，大幅降低设备综合利用率。
3. 忽略执行动作与动力切断的互锁：报警发出后未联动切断输出，导致执行机构
   持续顶撞卡滞物料，造成气缸活塞弯曲或电机烧毁。

## 单元小结
- 通电延时 TON 用于到位滤波与顺序延时，断电延时 TOF 用于停机延后处理，脉冲 TP 用于恒宽控制。
- 计数器 CTU 与 CTD 依靠输入信号的上升沿工作，实际工程中必须配合防抖滤波与规范复位逻辑。
- 超时监控是执行机构安全运行的核心防线，预设时间通常设定为正常物理动作时间的 1.5 至 2.0 倍。
- 超时故障处理必须严格遵守三原则：故障自锁保持、动力立即互锁切断、人工确认后手动复位恢复。
