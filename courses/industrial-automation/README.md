# 工业自动化与 PLC

用扫描周期、定时和互锁表达工位顺序与故障恢复。

## 学习起点

建议先完成单片机状态机。入门可用控制逻辑仿真。

- 输入输出表 → 顺序控制 → 定时和计数 → 互锁与异常复位仿真。

## 学完能做什么

- 理解 PLC 输入、程序和输出的基本扫描顺序。
- 为送料、拍照和分流设计互锁与超时。
- 验证设备停机后等待明确复位的行为。

**桌面质检分拣站实作**。模拟送料、检测和分流，分别测试传感器超时、结果缺失与人工复位。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 工业控制系统 | 自动化系统组成；PLC 硬件与 I/O 模块；扫描周期；I/O 分配表与数据类型；节拍与产量 |
| 现场器件 | 开关量传感器；电磁阀、气缸与继电器；模拟量信号与量程换算 |
| 梯形图基础 | 梯形图与触点线圈；逻辑组合；自锁、置位与复位；上升沿与下降沿 |
| 定时与计数 | 定时器 TON、TOF 与 TP；计数器 CTU 与 CTD；超时监控 |
| 顺序控制 | 顺序功能图 SFC；用状态字实现顺序控制；互锁与联锁 |
| 安全与故障处理 | 急停与安全回路；故障检测、报警与复位；手动与自动模式 |
| 编程与调试 | 结构化文本 ST 入门；功能块与程序组织；仿真与测试用例；HMI 与通信；送料检测分流仿真（自评） |

“送料检测分流仿真”是自评实作，没有练习题。
按[编程与调试讲义](lessons/programming.md)中的自评清单完成后，
在学习路径中标记已会。
