# 向量与坐标

本单元学习平面与空间中向量的概念、分量表示、代数运算、模长距离及点积，
为桌面质检分拣站中定位夹具与相机视野的坐标对齐打下数学基础。

## 本单元知识点
- 向量与分量：掌握有向线段几何意义、平面与三维坐标分量、位移向量与零向量。
- 向量加减与数乘：掌握按分量加减规则、数乘的伸缩与反向意义及平行四边形法则。
- 向量长度与距离：掌握向量模长公式、工位两点间距离计算以及单位向量归一化。
- 点积与夹角：掌握点积代数与几何公式、正交垂直判定及沿特定方向的投影计算。

## 向量与分量
向量是同时具有大小和方向的几何量。在工业自动化中，它常用于描述位移、速度与力。
例如在桌面质检分拣站中，工件从到位传感器滑移到定位夹具的过程，
可以用一条带箭头的有向线段表示：线段长度代表移动距离，箭头指向移动方向。
在不改变大小和方向的前提下平移有向线段，表示的是同一个自由向量。

建立直角坐标系后，向量可以用有序数对（分量）来定量描述。
若起点为 P₁(x₁, y₁)，终点为 P₂(x₂, y₂)，则位移向量 v = P₁P₂ 的分量为：
v = (x₂ - x₁, y₂ - y₁)
即用终点坐标减去起点坐标。
在包含高度信息的三维质检场景中，增加垂直于台面的 z 轴，
空间位移向量表示为三元组 v = (x₂ - x₁, y₂ - y₁, z₂ - z₁)。

大小为 0 的特殊向量称为零向量，记作 0。
二维平面中零向量的分量为 (0, 0)，三维空间中为 (0, 0, 0)。
零向量的方向在数学上可以视为任意方向。当工件实际位置与基准位置完全重合时，
两者之间的位移偏差向量即为零向量。

### 例题
【例题】在分拣工位平面坐标系中，到位传感器安装在 S(15, 20) mm 处，
工件定位夹具中心位于 F(65, 80) mm 处。
(1) 求工件从传感器滑移至夹具中心的位移向量 v；
(2) 若质检相机以夹具中心为基准，安装在高度 z = 120 mm 处且平面投影重合，
写出从夹具中心到相机的三维位移向量 c。

【解答】
(1) 位移向量等于终点坐标减去起点坐标：
v = SF = (65 - 15, 80 - 20) = (50, 60) mm。
(2) 夹具中心三维坐标为 (65, 80, 0) mm，相机坐标为 (65, 80, 120) mm。
从夹具中心到相机的三维位移向量为：
c = (65 - 65, 80 - 80, 120 - 0) = (0, 0, 120) mm。

### 常见错误
- 颠倒减法次序：误用起点坐标减去终点坐标，导致计算出的位移向量方向完全反向。
- 混淆位置点与向量：把点坐标当作位移向量。点表示空间具体位置，
  而向量表示两点之间的相对位移，平移后分量不变。

## 向量加减与数乘
向量加法是多个连续位移或多外力合成的数学描述。
代数上，向量相加只需将对应分量分别相加。
对于平面向量 u = (u₁, u₂) 与 v = (v₁, v₂)，其和向量为：
u + v = (u₁ + v₁, u₂ + v₂)
几何上，向量加法遵循平行四边形法则：以 u 和 v 为邻边作平行四边形，
由公共起点出发的对角线有向线段即表示和向量 u + v。

向量减法是加法的逆运算，对应分量分别相减：
u - v = (u₁ - v₁, u₂ - v₂)
在几何上，向量 u - v 表示从向量 v 的终点指向向量 u 终点的有向线段。
在分拣控制中，若已测出工件当前位置向量 p 与目标基准位置向量 r，
则将工件移到基准点所需的纠偏位移向量正是 r - p。

实数 k 与向量 v 的乘积称为数乘，运算规则为将实数与每个分量相乘：
kv = (k·v₁, k·v₂)
数乘在几何上改变向量的长度与方向：
当 k > 0 时，向量方向不变，长度伸缩为原长度的 k 倍；
当 k < 0 时，向量方向反向，长度变为原长度的 |k| 倍；
当 k = 0 时，结果为零向量 (0, 0)。

### 例题
【例题】质检视觉检测到夹具上工件的中心相对标定点存在偏差向量 e = (4, -2) mm。
控制系统设定补偿推杆的单次纠偏系数为 k = -1.5。
同时，输送带滑动造成工件产生附加位移 w = (-2, 5) mm。
求推杆执行纠偏并叠加输送带位移后的合成位移向量 c = ke + w 的分量。

【解答】
首先计算数乘 ke：
ke = -1.5 × (4, -2) = (-1.5 × 4, -1.5 × (-2)) = (-6, 3) mm。
然后进行向量加法，对应分量相加：
c = ke + w = (-6 + (-2), 3 + 5) = (-8, 8) mm。

### 常见错误
- 数乘时漏乘分量：只对第一个分量乘以系数，例如将 -1.5 × (4, -2) 误算为 (-6, -2)。
- 符号处理错误：负数相乘时出现变号失误，例如误将 -1.5 × (-2) 算作 -3。

## 向量长度与距离
向量的大小称为向量的长度或模，记作 ‖v‖。
平面向量 v = (x, y) 的模长由勾股定理给出：
‖v‖ = √(x² + y²)
模长是非负实数。当且仅当 v 为零向量时，‖v‖ = 0。
对于空间三维向量 v = (x, y, z)，其模长公式扩展为：
‖v‖ = √(x² + y² + z²)

在工位坐标系中，两个几何点 P₁(x₁, y₁) 与 P₂(x₂, y₂) 之间的直线距离 d，
等于连接两点的位移向量 v = P₁P₂ 的模长：
d = ‖P₁P₂‖ = √((x₂ - x₁)² + (y₂ - y₁)²)
利用该公式，质检系统可精确计算工件孔距、装配公差及偏差距离。

模长等于 1 的向量称为单位向量。
对于任意非零向量 v，将其各分量除以模长 ‖v‖ 的操作称为向量归一化：
u = v / ‖v‖ = (x / ‖v‖, y / ‖v‖)
归一化得到的向量 u 模长为 1，方向与原向量 v 完全相同。
在机械臂路径规划与图像特征匹配中，单位向量用于纯粹指示运动方向或法线方向。

### 例题
【例题】质检相机检测到工件表面两个装配标记孔在图像坐标系中的位置分别为
A(10, 20) mm 与 B(40, 60) mm。
(1) 计算两标记孔之间的实际直线距离 d；
(2) 求从标记孔 A 指向标记孔 B 的单位方向向量 u。

【解答】
(1) 计算由 A 指向 B 的位移向量 AB：
AB = (40 - 10, 60 - 20) = (30, 40) mm。
两孔之间的距离等于向量 AB 的模长：
d = ‖AB‖ = √(30² + 40²) = √(900 + 1600) = √2500 = 50 mm。
(2) 将位移向量 AB 归一化求单位向量：
u = AB / ‖AB‖ = (30 / 50, 40 / 50) = (0.6, 0.8)。
验证其模长：√(0.6² + 0.8²) = √(0.36 + 0.64) = √1 = 1。

### 常见错误
- 误把绝对值之和当成模长：误写为 ‖(x, y)‖ = |x| + |y|，混淆欧氏距离与坐标差之和。
- 归一化时除错量：误除以模长的平方，或归一化时忽略了负号导致方向改变。

## 点积与夹角
两个向量的点积（又称数量积或内积）用符号 · 表示。
对于平面向量 a = (a₁, a₂) 与 b = (b₁, b₂)，其代数定义为对应分量乘积之和：
a·b = a₁b₁ + a₂b₂
对于三维向量 a = (a₁, a₂, a₃) 与 b = (b₁, b₂, b₃)，点积为：
a·b = a₁b₁ + a₂b₂ + a₃b₃
必须注意：点积运算的结果是一个实数（标量），而不是向量。

点积具有鲜明的几何意义，它与两向量的夹角 θ（0° ≤ θ ≤ 180°）密切相关：
a·b = ‖a‖‖b‖cosθ
由此可导出两向量夹角余弦的计算公式：
cosθ = (a·b) / (‖a‖‖b‖)
若 a·b > 0，则 cosθ > 0，两向量夹角为锐角（0° ≤ θ < 90°）；
若 a·b < 0，则 cosθ < 0，两向量夹角为钝角（90° < θ ≤ 180°）；
若 a·b = 0 且 a, b 为非零向量，则 cosθ = 0，夹角 θ = 90°，即两向量相互垂直（正交）。

点积在质检分拣工程中有两大核心应用：
1. 正交性检验：通过检验 a·b 是否为 0，快速判断夹具边缘、推杆轴线是否垂直装配。
2. 投影长度计算：向量 a 在非零向量 b 方向上的有向投影长度为：
p = ‖a‖cosθ = (a·b) / ‖b‖
该投影量可直接用于分解机械推力或测量沿导轨方向的有效位移量。

### 例题
【例题】在分拣工位上，夹具基准轴方向向量为 b = (4, 3) mm，
传感器测得工件边缘轮廓位移向量为 a = (6, 2) mm。
(1) 计算点积 a·b，并判断两向量夹角是锐角还是钝角；
(2) 计算向量 a 在基准轴 b 方向上的投影长度 p。

【解答】
(1) 代入平面向量点积公式：
a·b = 6 × 4 + 2 × 3 = 24 + 6 = 30。
因为 a·b = 30 > 0，且两向量非零，所以两向量夹角为锐角。
(2) 计算向量 b 的模长：
‖b‖ = √(4² + 3²) = √(16 + 9) = √25 = 5 mm。
代入投影长度公式：
p = (a·b) / ‖b‖ = 30 / 5 = 6 mm。
这说明向量 a 沿基准轴 b 方向有效延伸了 6 mm。

### 常见错误
- 误将点积结果写成向量：例如将 a·b 误算为 (a₁b₁, a₂b₂)；点积是各分量乘积的累加值。
- 投影公式分母颠倒：求 a 在 b 上的投影时，误除以 ‖a‖ 而非 ‖b‖。

## 单元小结
- 向量是有大小和方向的量，坐标系下用分量表示；两点间位移向量等于终点坐标减起点坐标。
- 向量加减法按分量直接运算，几何上对应平行四边形法则；数乘缩放模长并决定指向。
- 向量模长由坐标平方和开方求得，两点距离即位移向量的模长，除以模长可得单位方向向量。
- 点积是对应分量相乘之和，其数值等于模长之积乘夹角余弦；点积为零判定正交垂直，
  点积除以目标模长可求方向投影。
