# 矩阵运算

本单元学习矩阵的基本记号与代数运算，建立矩阵乘向量与矩阵乘法的几何直观，
为桌面质检分拣工位中坐标变换与数据处理奠定数学基础。

## 本单元知识点
- 矩阵与记号：矩阵的行列维度、元素表示、特殊矩阵及加法数乘与转置。
- 矩阵乘向量：矩阵乘列向量的计算规则、列向量线性组合的视角及维度约束。
- 矩阵乘法：矩阵乘积的行乘列计算、结合律与一般不满足交换律的特性。
- 转置与对称矩阵：转置运算对乘积的展开规律与对称矩阵的核心特性。

## 矩阵与记号
矩阵是由 m 行 n 列数字排列而成的矩形数表，记为 m × n 矩阵。
位于第 i 行第 j 列的元素记为 aᵢⱼ。当行数等于列数（m = n）时称为方阵。
在桌面质检分拣站中，图像像素阵列、传感器离散读数表及夹具安装参数均以矩阵组织。

本课程在行文中把矩阵按行书写，例如 [[1, 2], [3, 4]] 表示第一行 1、2，第二行 3、4。
特殊矩阵包括所有元素均为 0 的零矩阵 O，以及主对角线全为 1、其余全为 0 的单位矩阵 I。
同维度的两个矩阵可以对应位置元素相加；常数 k 与矩阵相乘则是对所有元素逐一数乘。
将矩阵 A 的行与列互换得到的新矩阵称为转置矩阵，记为 Aᵀ。若 A 为 m × n，则 Aᵀ 为 n × m。

### 例题
工位记录夹具基准点位置偏差矩阵 A 与补偿系数矩阵 B 如下：
```
A = [[ 2, -1], [ 0,  3]]
B = [[ 1,  4], [ 5, -2]]
```
求 2A - B 以及矩阵 A 的转置矩阵 Aᵀ。

解答：
计算数乘 2A：将 A 中每个元素乘以 2，得：
```
2A = [[ 4, -2], [ 0,  6]]
```
将 2A 与 B 对应元素相减得到 2A - B：
```
2A - B = [[ 4 - 1, -2 - 4], [ 0 - 5, 6 - (-2)]] = [[ 3, -6], [-5,  8]]
```
将 A 的第一行写为第一列、第二行写为第二列，得到转置矩阵 Aᵀ：
```
Aᵀ = [[ 2, 0], [-1, 3]]
```

### 常见错误
- 混淆行列次序：把 m × n 误记为 n 行 m 列，或误将 a₂₁ 当作第 1 行第 2 列。
- 不同维度的矩阵直接相加：加法要求两个矩阵行数与列数完全一致。
- 转置时仅反转对角线或漏转负号：转置是沿主对角线对称互换位置 aᵢⱼ 与 aⱼᵢ。

## 矩阵乘向量
若矩阵 A 是 m × n 矩阵，x 是 n × 1 的列向量，则乘积 Ax 是一个 m × 1 的列向量。
Ax 的第 i 个分量等于矩阵 A 的第 i 行与列向量 x 的点积。
其维度匹配的核心要求是：A 的列数必须严格等于列向量 x 的行数。

若把 A 按列分成 n 个列向量 [a₁, a₂, ..., aₙ]，则 Ax 正是各列向量以 x 的各分量为权重的线性组合：
Ax = x₁a₁ + x₂a₂ + ... + xₙaₙ。
该视角揭示了变换的几何本质：矩阵乘向量是用输入向量分量合成基向量变换后的新向量。

### 例题
相机坐标系下检测到工件特征点位移向量 x = (3, -2)ᵀ，坐标变换矩阵 A 为：
```
A = [[ 1, 2], [-3, 4]]
```
分别用行点积法和列线性组合法计算 Ax。

解答：
方法一（行点积法）：
第一行与 x 点积：1 × 3 + 2 × (-2) = 3 - 4 = -1。
第二行与 x 点积：(-3) × 3 + 4 × (-2) = -9 - 8 = -17。
得到 Ax = (-1, -17)ᵀ。

方法二（列线性组合法）：
A 的第一列为 a₁ = (1, -3)ᵀ，第二列为 a₂ = (2, 4)ᵀ。按 x 的分量线性组合：
Ax = 3 × (1, -3)ᵀ + (-2) × (2, 4)ᵀ = (3, -9)ᵀ + (-4, -8)ᵀ = (-1, -17)ᵀ。
两种算法结果完全吻合。

### 常见错误
- 维度不匹配强行相乘：例如试图用 2 × 3 的矩阵乘 2 维向量。记住 A 的列数须等于 x 的维数。
- 混淆结果维度：m × n 矩阵乘 n 维列向量，得到的是 m 维列向量，而非标量或行向量。

## 矩阵乘法
如果矩阵 A 的维度为 m × k，矩阵 B 的维度为 k × n，则它们的乘积 C = AB 是一个 m × n 矩阵。
只有当左矩阵 A 的列数等于右矩阵 B 的行数时，乘法才有定义。
乘积矩阵 C 中第 i 行第 j 列的元素 cᵢⱼ，等于 A 的第 i 行与 B 的第 j 列对应元素乘积之和。

矩阵乘法满足结合律 A(BC) = (AB)C 与分配律 A(B + C) = AB + AC。
对于同阶方阵，单位矩阵 I 满足 AI = IA = A。
关键工程特性：矩阵乘法一般不满足交换律，即一般情况下 AB ≠ BA。
在分拣工件位姿控制中，“先旋转后剪切”与“先剪切后旋转”的结果一般不同，其本质正是矩阵不可交换。

### 例题
工件在分拣工位先后经历两道标定变换，对应矩阵为：
```
A = [[1, 2], [3, 0]]
B = [[2, -1], [1, 4]]
```
计算复合变换矩阵 C = AB。

解答：
A 与 B 均为 2 × 2 矩阵，乘积 C 也是 2 × 2 矩阵。逐项计算元素：
c₁₁ = 1 × 2 + 2 × 1 = 2 + 2 = 4
c₁₂ = 1 × (-1) + 2 × 4 = -1 + 8 = 7
c₂₁ = 3 × 2 + 0 × 1 = 6 + 0 = 6
c₂₂ = 3 × (-1) + 0 × 4 = -3 + 0 = -3
得到乘积矩阵：
```
C = AB = [[4, 7], [6, -3]]
```

### 常见错误
- 误将矩阵乘法做成对应元素相乘：对应相乘是逐元素乘积，矩阵相乘是“行乘列”。
- 默认交换律成立：计算中擅自颠倒 AB 为 BA，导致变换结果完全错误。
- 忽视中间维度匹配：若两矩阵维度为 3 × 2 与 3 × 2，则无法直接相乘。

## 转置与对称矩阵
矩阵乘积的转置公式要求调换相乘次序，即 (AB)ᵀ = BᵀAᵀ。
若直接写成 AᵀBᵀ，中间对齐的维度将不匹配，导致乘积无定义或结果错误。

若方阵 A 满足 Aᵀ = A，则称 A 为对称矩阵。对称矩阵的所有元素沿主对角线对称，即 aᵢⱼ = aⱼᵢ。
在分拣站传感器协方差分析与最小二乘拟合中，构造出的法矩阵均具有对称性。
对任意形状的实矩阵 A，乘积 AᵀA 与 AAᵀ 必然是对称方阵。
其数学证明为：(AᵀA)ᵀ = Aᵀ(Aᵀ)ᵀ = AᵀA，完全符合对称矩阵定义。

### 例题
视觉定位标定矩阵 A 如下：
```
A = [[ 1, 2], [-1, 0], [ 2, 1]]
```
写出转置矩阵 Aᵀ，计算法矩阵 S = AᵀA，并验证 S 是否为对称矩阵。

解答：
A 为 3 × 2 矩阵，其转置 Aᵀ 为 2 × 3 矩阵：
```
Aᵀ = [[1, -1, 2], [2, 0, 1]]
```
计算 S = AᵀA，其维度为 2 × 2：
s₁₁ = 1 × 1 + (-1) × (-1) + 2 × 2 = 1 + 1 + 4 = 6
s₁₂ = 1 × 2 + (-1) × 0 + 2 × 1 = 2 + 0 + 2 = 4
s₂₁ = 2 × 1 + 0 × (-1) + 1 × 2 = 2 + 0 + 2 = 4
s₂₂ = 2 × 2 + 0 × 0 + 1 × 1 = 4 + 0 + 1 = 5
得到矩阵：
```
S = [[6, 4], [4, 5]]
```
由于 s₁₂ = s₂₁ = 4 且 Sᵀ = S，验证了 S 必然是对称矩阵。

### 常见错误
- 展开转置时漏调顺序：将 (AB)ᵀ 错误写为 AᵀBᵀ。
- 误以为任意非方阵也能对称：对称矩阵的前提必须是方阵。
- 认为对称矩阵要求主对角线全为 1：对角线可以是任意实数，关键是对称位置相等。

## 单元小结
- 矩阵是行与列构成的数表，同型矩阵可逐元素相加减，数乘缩放全局，转置行列对调。
- 矩阵乘向量 Ax 本质是矩阵各列向量以 x 各分量为权重的线性组合，列数须等于向量维数。
- 矩阵乘法遵循行乘列规则，满足结合律但一般不满足交换律，在复合工序中顺序关键。
- 乘积转置须反转顺序 (AB)ᵀ = BᵀAᵀ；对称矩阵满足 Aᵀ = A，实矩阵的 AᵀA 必对称。
- 矩阵可以表示几何变换，为后续工位相机坐标映射奠定基础。
