# 线性组合与基

本单元学习平面向量的线性组合、张成空间与线性无关判定，以及基与坐标表示，
为分析桌面质检分拣站中双轴驱动位移与工件夹具坐标转换奠定代数基础。

## 本单元知识点
- 线性组合：掌握 c₁v₁ + c₂v₂ 的合成形式与方程求解，用基准向量表示平面位移。
- 张成与线性无关：理解向量集合张成的空间形态，掌握二维向量共线即相关的几何判据。
- 基与坐标表示：理解标准基与一般基的条件，掌握同一向量在不同参考基下的坐标转换。

## 线性组合

在桌面质检分拣工位中，到位传感器触发后，机械执行机构通常由两个不同方向的
驱动轴（例如同步带滑台与气缸推杆）协同驱动。当两个驱动轴分别提供单位步进
位移向量 v₁ 和 v₂ 时，各自运行 c₁ 与 c₂ 步产生的总复合位移可以表示为
c₁v₁ + c₂v₂。这种通过数乘与向量加法构造新向量的数学形式，就称为线性组合。

形式化地，给定二维平面中的向量 v₁ = (x₁, y₁) 和 v₂ = (x₂, y₂)，以及两个
实数标量 c₁ 和 c₂，向量 p = c₁v₁ + c₂v₂ 称为 v₁ 与 v₂ 的线性组合，标量
c₁ 和 c₂ 称为该组合的系数或权值。按分量展开计算规则如下：
```
p = c₁(x₁, y₁) + c₂(x₂, y₂)
  = (c₁x₁ + c₂x₂, c₁y₁ + c₂y₂)
```

若已知目标位移向量 p = (x, y) 以及两个基准方向向量 v₁、v₂，求解所需的组合
系数 c₁ 和 c₂ 时，只需将其按横坐标与纵坐标拆分为二元一次方程组：
```
c₁x₁ + c₂x₂ = x
c₁y₁ + c₂y₂ = y
```
只要两个基准向量不平行，就可以通过代入消元法或加减消元法求出唯一的系数标量。

### 例题

质检分拣站的滑台由两台步进电机驱动。第一台电机的单步位移向量为
v₁ = (2, 1) mm，第二台电机的单步位移向量为 v₂ = (1, 2) mm。视觉相机检测到
工件当前需要产生总位移 p = (8, 7) mm 才能对准合格料盒中心。求两台电机各自
需要行进的步数系数 c₁ 与 c₂，使得 c₁v₁ + c₂v₂ = p。

解：
根据线性组合的分量展开式，列出二元一次方程组：
```
2c₁ + 1c₂ = 8
1c₁ + 2c₂ = 7
```
由第一个方程可得 c₂ = 8 - 2c₁。将该式代入第二个方程：
c₁ + 2(8 - 2c₁) = 7
展开化简得：
c₁ + 16 - 4c₁ = 7
-3c₁ = -9
解得 c₁ = 3。
将 c₁ = 3 代回 c₂ 的表达式：
c₂ = 8 - 2 * 3 = 2。
验算：
3 * (2, 1) + 2 * (1, 2) = (6, 3) + (2, 4) = (8, 7) mm，与目标向量完全吻合。
因此，第一台电机需要驱动 3 步，第二台电机需要驱动 2 步。

### 常见错误

- 混淆标量乘法与向量加法的运算优先级，未将标量分别乘入向量的各个分量，就
  直接把两向量分量相加。
- 误以为任意选取的两个基准向量都能合成平面上的任意位移，忽略了两个方向共线
  时只能在单一直线上位移的物理限制。
- 列二元一次方程组时横纵分量混淆，把 x 分量与 y 分量相加在同一个方程中。

## 张成与线性无关

向量集合的张成（Span）描述了该集合通过所有可能线性组合所能“触达”的空间范围。
对于向量集合 {v₁, v₂}，其张成空间记作 span(v₁, v₂)，由所有满足 c₁v₁ + c₂v₂
（c₁、c₂ 为任意实数）的向量汇集而成。
在二维平面中，张成空间的几何形态完全取决于向量之间的方向关系：
- 单个非零向量 v₁ 的张成空间 span(v₁) 是一条穿过坐标原点的无限延伸直线；
- 若两个非零向量 v₁ 与 v₂ 不共线，其线性组合可以覆盖整个二维平面 R²；
- 若两个非零向量 v₁ 与 v₂ 共线，则它们的线性组合仍只能停留在同一条直线上。

线性相关（Linear Dependence）刻画了向量集合内部是否存在“多余”或“冗余”的方向。
如果在向量集合中存在一组不全为零的标量系数 c₁、c₂，使得
c₁v₁ + c₂v₂ = 0
则称向量组 {v₁, v₂} 线性相关；反之，若只有在 c₁ = 0 且 c₂ = 0 时该等式才成立，
则称该向量组线性无关（Linearly Independent）。

在二维平面几何中，两个向量线性相关与否有一个极其简明直观的充要条件：
两个向量线性相关等价于它们共线（互相平行或反向平行）。代数上，非零向量
v₁ = (x₁, y₁) 与 v₂ = (x₂, y₂) 线性相关，等价于存在非零实数 k 使得 v₂ = kv₁，
或者交叉相乘差值为零：x₁y₂ - x₂y₁ = 0。此外，任何包含零向量 (0, 0) 的向量集合
都必定线性相关。

### 例题

在分拣工作台上，推杆机械臂的运动方向向量为 u = (3, -2)，分拣挡板滑轨的
方向向量为 v = (-6, 4)。请判断向量组 {u, v} 是线性相关还是线性无关，并说明
它们所能张成的空间几何形态。

解：
计算两向量对应分量的比例关系：
-6 / 3 = -2，且 4 / (-2) = -2。
显然有 v = -2u。将该等式移至等号同一侧，可得：
2u + 1v = (0, 0)
在这组组合系数中，c₁ = 2，c₂ = 1，显然不全为零。
根据定义，存在非全零组合系数使得线性组合为零向量，因此向量组 {u, v} 线性相关。
几何上，由于 u 与 v 共线，它们在二维平面内指向完全相反的方向。由这两个向量
构造的所有线性组合 c₁u + c₂v 均落在通过原点且斜率为 -2/3 的唯一直线上，
因此它们张成的空间是一条直线，而非整个二维平面。

### 常见错误

- 误将“方向相反”理解为“线性无关”。事实上，反向向量互为负数倍数，依然共线
  并线性相关。
- 误以为只要向量组包含零向量，还能通过调整系数使其线性无关。实际上只要包含
  零向量，给零向量赋予非零系数即得零组合，必线性相关。
- 混淆张成空间与具体向量本身，把连续无限延伸的直线或平面误认为有限线段。

## 基与坐标表示

在质检分拣站中，视觉相机的像素平面有自己的直角轴，而安装在工作台上的 3D 打印
定位夹具往往带有倾斜的定位槽与导轨。要准确描述同一个工件在不同参考系下的位置，
必须建立基（Basis）与坐标（Coordinates）的概念。

二维向量空间的一组基，是指一个能够张成整个平面且自身线性无关的向量集合。
构成二维空间基的条件非常明确：任何两个不共线（线性无关）的非零二维向量
{b₁, b₂} 都可以作为一组基。标准直角坐标系所使用的就是标准基
e₁ = (1, 0) 与 e₂ = (0, 1)。由于 e₁ 与 e₂ 互相垂直且不共线，它们是二维空间
最自然的一组基。

一旦选定了一组基 B = {b₁, b₂}，二维平面内的任意向量 p 都可以被唯一地表示为
该基向量的线性组合：
p = c₁b₁ + c₂b₂
此时，这一对唯一确定的实数标量 (c₁, c₂) 就称为向量 p 在基 B 下的坐标。
日常所用的平面坐标 (x, y) 实际上是标准基下的坐标，因为 (x, y) = x*e₁ + y*e₂。

若已知一组非标准基 b₁ = (x₁, y₁)、b₂ = (x₂, y₂)，要求已知向量 p = (x, y)
在该基下的新坐标 (c₁, c₂)，本质上就是求解待定系数的二元一次方程组：
```
c₁x₁ + c₂x₂ = x
c₁y₁ + c₂y₂ = y
```
因为基向量线性无关，该方程组保证有且仅有唯一解。这为后续单元中夹具坐标与相机
坐标之间的矩阵坐标变换奠定了核心计算模型。

### 例题

在分拣站工位中，定位夹具沿着倾斜导轨安装，工程师设定夹具基向量为
b₁ = (1, 1) mm 与 b₂ = (-1, 1) mm。上位机视觉系统在工作台标准坐标系下检测到
待分拣工件的特征点位置向量为 p = (2, 6) mm。求该工件特征点在夹具基
{b₁, b₂} 下的坐标 (c₁, c₂)。

解：
根据基下坐标的定义，需要求标量 c₁ 与 c₂ 满足：
c₁b₁ + c₂b₂ = p
将分量代入表达式：
c₁(1, 1) + c₂(-1, 1) = (2, 6)
展开为二元一次方程组：
```
c₁ - c₂ = 2
c₁ + c₂ = 6
```
解法如下：
两式直接相加消去 c₂：
2c₁ = 8，解得 c₁ = 4。
将 c₁ = 4 代入第二个方程：
4 + c₂ = 6，解得 c₂ = 2。
验算：
4 * (1, 1) + 2 * (-1, 1) = (4, 4) + (-2, 2) = (2, 6) mm，与标准坐标完全吻合。
因此，该特征点在夹具基下的坐标为 (4, 2)。

### 常见错误

- 脱离基底孤立谈论坐标数值，忽视了坐标数值与基向量绑定的本质。
- 误选用共线向量作为二维平面的基，导致无法合成面内所有点，破坏了基的完备性。
- 在一般基下计算坐标时，错误地套用标准基的点积投影公式，而未按定义求解方程组。

## 单元小结

- 线性组合是向量数乘与加法的统一表示形式 c₁v₁ + c₂v₂，分拣站中双轴电机的
  复合位移本质就是基准方向向量的线性组合。
- 张成空间描述了向量所有可能组合覆盖的空间集合；二维空间中两非零向量共线
  仅张成一条直线，不共线则能张成整个二维平面。
- 线性无关保证了空间描述的无冗余性；二维平面中两向量共线即相关，且包含
  零向量的任何向量组必定线性相关。
- 二维平面的基由任意两个线性无关的向量构成，基向量张成全空间且系数唯一。
- 向量在基下的坐标就是其线性组合的唯一系数，通过解二元一次方程组可实现
  标准坐标向夹具基坐标的转换。
