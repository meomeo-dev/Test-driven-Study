# 线性方程组
本单元学习如何把多传感器测量与工程约束写成矩阵方程 Ax = b，运用高斯消元法求解，分析解的唯一性、无穷多解与无解，并掌握用逆矩阵直接求解未知状态的方法。

## 本单元知识点
- 方程组与矩阵形式：将联立线性方程组转化为矩阵方程 Ax = b 与增广矩阵 [A | b]。
- 高斯消元：利用三种初等行变换将增广矩阵化为行阶梯形，并通过回代求解未知数。
- 解的情况与秩：通过矩阵的秩判断线性方程组具有唯一解、无解还是无穷多解。
- 逆矩阵：理解方阵可逆条件与 2×2 求逆公式，运用 x = A⁻¹b 直接计算方程组的解。

## 方程组与矩阵形式
在桌面质检分拣工位中，相机像素坐标与机械定位夹具坐标之间往往存在线性换算关系。
当需要从多个传感器读数或标定点反推工件的真实物理位置 (x₁, x₂) 时，就会形成联立的
线性方程组。例如：
a₁₁ x₁ + a₁₂ x₂ = b₁
a₂₁ x₁ + a₂₂ x₂ = b₂

将未知数的系数提炼出来组成系数矩阵 A，未知数排成列向量 x，等号右端常数排成向量 b，
整个方程组就可以紧凑地写成矩阵形式 Ax = b。以 2 个未知数和 2 个方程为例展开为：
```text
[ a₁₁  a₁₂ ] [ x₁ ]   [ b₁ ]
[ a₂₁  a₂₂ ] [ x₂ ] = [ b₂ ]
```
从向量视角看，Ax 是各列向量以 x 分量为权重的线性组合：
x₁ · (a₁₁, a₂₁) + x₂ · (a₁₂, a₂₂) = (b₁, b₂)

为了在消元过程中同时追踪常数项，通常把矩阵 A 与列向量 b 拼合在一起，构成增广矩阵
（Augmented Matrix），记为 [A | b]：
```text
[ a₁₁  a₁₂ | b₁ ]
[ a₂₁  a₂₂ | b₂ ]
```
增广矩阵的每一行代表一个方程，前两列对应未知数的系数，最右侧一列为常数项。

### 例题
质检相机对固定在夹具上的工件进行双通道标定，测得坐标 (x₁, x₂) 满足：
2x₁ + 3x₂ = 8
4x₁ - x₂ = 2
请写出该系统的系数矩阵 A、未知数向量 x、常数向量 b 以及增广矩阵 [A | b]。

解：
1. 提取未知数 x₁ 与 x₂ 的系数，得到系数矩阵 A：
```text
A = [ 2   3 ]
    [ 4  -1 ]
```
2. 未知数向量为列向量 x = (x₁, x₂)，常数向量为列向量 b = (8, 2)。
3. 方程组的矩阵形式为 Ax = b。
4. 将常数向量 b 拼接到 A 的右侧，得到增广矩阵：
```text
[A | b] = [ 2   3 | 8 ]
          [ 4  -1 | 2 ]
```

### 常见错误
1. 漏写零系数：当某方程缺少某个未知数（如只有 3x₁ = 6）时，对应系数应填 0，
   不能将整列省略或写成 1。
2. 移项符号错误：常数项必须全部移至等号右侧再填入 b，若将 2x₁ + 3x₂ - 8 = 0
   直接写入增广矩阵，容易误把常数记为 -8。

## 高斯消元
高斯消元法是求解线性方程组的核心算法。其核心思路是：对增广矩阵执行一系列不改变
解集的初等行变换，将矩阵逐步化简为行阶梯形，最后通过回代求出所有未知数。

初等行变换共有三种：
1. 交换两行（记作 R_i ↔ R_j）：调换两个方程的上下位置。
2. 某行乘以非零数（记作 R_i ← k·R_i，k ≠ 0）：方程两边同乘以非零常数。
3. 某行的倍数加到另一行（记作 R_j ← R_j + k·R_i）：用一个方程消去另一个方程的未知数。

行阶梯形矩阵具有以下特征：
- 全为 0 的行（若有）排在矩阵的最下方。
- 每个非零行的第一个非零元素称为主元（Pivot）。
- 下一行主元的位置严格位于上一行主元的右侧。

化为阶梯形后，从最下方的非零方程直接解出最后一个未知数；然后依次向上代入各个方程，
步步求出其余未知数，这个逆向计算过程称为回代求解（Back-substitution）。

### 例题
桌面分拣站的 PLC 记录了两个分拣气缸的工作压力参数 x₁ 与 x₂，满足方程组：
x₁ + 2x₂ = 5
3x₁ + 4x₂ = 9
请用高斯消元法求解未知数向量 (x₁, x₂)。

解：
1. 写出增广矩阵：
```text
[ 1  2 | 5 ]
[ 3  4 | 9 ]
```
2. 消元化为行阶梯形：
第一行主元为 1，执行行变换 R₂ ← R₂ - 3R₁：
```text
[ 1   2 |  5 ]
[ 0  -2 | -6 ]
```
3. 回代求解：
第二行对应方程为 -2x₂ = -6，解得 x₂ = 3。
将 x₂ = 3 代入第一行方程 x₁ + 2(3) = 5，解得 x₁ = -1。
4. 验证：代入第二方程 3(-1) + 4(3) = 9，计算吻合。方程组的解为 (x₁, x₂) = (-1, 3)。

### 常见错误
1. 只对系数消元而遗漏增广列：做行变换时忘记对最右侧的常数项进行同步乘加计算。
2. 减法符号混淆：在执行 R₂ - k·R₁ 时，遇到负数相减（如 5 - (-6)）容易算错符号。

## 解的情况与秩
工程中的线性方程组并不总是恰好有一个解。根据传感器布置与方程约束，解有三种情况：
1. 唯一解：所有未知数都有唯一确定的数值。
2. 无穷多解：传感器信息存在冗余或欠约束，部分未知数可自由取值（自由变量）。
3. 无解（不相容）：传感器数据互相矛盾，不存在满足所有方程的数值。

矩阵的“秩”（Rank）是判定解的情况的关键工具。
矩阵 A 的秩记为 rank(A)，定义为将矩阵化为行阶梯形后非零行的行数，它代表了矩阵中
包含的线性无关方程（或有效信息）的最大数量。

秩与线性方程组 Ax = b（设未知数个数为 n）解的关系判定规则如下：
1. 若 rank(A) < rank([A | b])：阶梯形中会出现形如 [0  0  ...  0 | d]（d ≠ 0）的一行，
   对应矛盾方程 0 = d，此时方程组无解。
2. 若 rank(A) = rank([A | b]) = r：方程组有解（相容）：
   - 当 r = n 时：每个未知数列都有主元，方程组有唯一解。
   - 当 r < n 时：存在 n - r 个自由未知数，方程组有无穷多解。

### 例题
分拣站两个光电开关检测工件位移 x₁ 与 x₂，测得以下两组数据构成的方程组：
x₁ + 2x₂ = 4
2x₁ + 4x₂ = 8
分析该方程组的解的情况；若第二组数据的常数项变为 7，解的情况如何变化？

解：
1. 情况一增广矩阵为：
```text
[ 1  2 | 4 ]
[ 2  4 | 8 ]
```
执行 R₂ ← R₂ - 2R₁ 得：
```text
[ 1  2 | 4 ]
[ 0  0 | 0 ]
```
阶梯形非零行为 1 行，因此 rank(A) = 1，rank([A | b]) = 1。
由于 rank(A) = rank([A | b]) = 1 < n = 2，存在 1 个自由未知数，方程组有无穷多解。
2. 情况二（常数项变为 7）增广矩阵为：
```text
[ 1  2 | 4 ]
[ 2  4 | 7 ]
```
执行 R₂ ← R₂ - 2R₁ 得：
```text
[ 1  2 |  4 ]
[ 0  0 | -1 ]
```
第二行对应方程 0x₁ + 0x₂ = -1，即 0 = -1，产生矛盾。
此时 rank(A) = 1，rank([A | b]) = 2，rank(A) < rank([A | b])，方程组无解。

### 常见错误
1. 未化简直接数非零行：必须在初等行变换化为阶梯形后再统计非零行数，未化简矩阵中
   看似独立的非零行可能互为倍数。
2. 误认为未知数多于方程数就一定有解：方程组可能本身包含矛盾，此时依然无解。

## 逆矩阵
对于普通数字方程 ax = b，当 a ≠ 0 时两边乘以 a⁻¹ 即可求得 x = a⁻¹b。
矩阵代数中也有类似的工具——逆矩阵（Inverse Matrix）。

设 A 是一个 n×n 的方阵，若存在同规格方阵 B 使得：
AB = BA = I
其中 I 为单位矩阵（主对角线全为 1，其余全为 0），则称方阵 A 可逆（Invertible），
B 称为 A 的逆矩阵，记作 A⁻¹。此时 A 与 A⁻¹ 互为逆矩阵。

对于 2×2 矩阵：
```text
A = [ a  b ]
    [ c  d ]
```
其可逆的充要条件是交叉相乘之差 ad - bc ≠ 0。求逆公式为：
```text
A⁻¹ = (1 / (ad - bc)) · [  d  -b ]
                        [ -c   a ]
```
口诀是：“主对角线互换，副对角线变号，前面除以 ad - bc”。若 ad - bc = 0 则不可逆。

使用逆矩阵求解线性方程组：
若系数矩阵 A 是可逆方阵，对于方程组 Ax = b，我们在等式两边同时从左侧乘以 A⁻¹：
A⁻¹(Ax) = A⁻¹b  =>  (A⁻¹A)x = A⁻¹b  =>  Ix = A⁻¹b  =>  x = A⁻¹b
无需逐步消元回代，只需一次矩阵与向量的乘法即可直接解出未知数向量 x。

### 例题
分拣站控制器需要求解相机校正向量 x = (x₁, x₂)，系统满足 Ax = b，其中：
```text
A = [ 3  1 ] ,  b = [  7 ]
    [ 5  2 ]        [ 12 ]
```
判断 A 是否可逆；若可逆，求出 A⁻¹ 并用 x = A⁻¹b 求解未知数向量 x。

解：
1. 检查可逆条件：ad - bc = 3 × 2 - 1 × 5 = 6 - 5 = 1 ≠ 0，故矩阵 A 可逆。
2. 应用求逆公式：主对角线对调，副对角线变号：
```text
A⁻¹ = [  2  -1 ]
      [ -5   3 ]
```
3. 求解 x = A⁻¹b：
```text
x = [  2  -1 ] [  7 ] = [  14 - 12 ] = [ 2 ]
    [ -5   3 ] [ 12 ]   [ -35 + 36 ]   [ 1 ]
```
解得未知数向量为 (x₁, x₂) = (2, 1)。
4. 验证：3(2) + 1(1) = 7，5(2) + 2(1) = 12，结果完全吻合。

### 常见错误
1. 乘法顺序颠倒：必须从左侧乘 A⁻¹ 得到 x = A⁻¹b；写成 bA⁻¹ 乘法未定义且错误。
2. 混淆求逆公式中的位置与符号：常错将副对角线互换而主对角线变号，应牢记“主互换、副变号”。
3. 对非方阵求逆：只有行数等于列数的方阵才能定义逆矩阵，不可对长方形矩阵套用公式。

## 单元小结
- 矩阵形式统一表达：线性方程组可紧凑写为 Ax = b 与增广矩阵 [A | b]，便于算法自动化处理。
- 高斯消元普适解法：通过三种初等行变换将增广矩阵化为行阶梯形，并自下而上回代求解。
- 秩揭示解的本质：比较系数矩阵的秩与增广矩阵的秩，能明确判定系统是唯一解、无穷多解还是无解。
- 逆矩阵一步求解：对于可逆方阵（2×2 满足 ad - bc ≠ 0），利用 x = A⁻¹b 可直接计算出系统的解。
