# 线性变换与坐标变换

本单元学习线性变换的判定准则与矩阵表示，掌握平面旋转、缩放与剪切变换，引入
齐次坐标统一刚体运动计算，并实现工件在夹具与相机坐标系之间的位姿转换。

## 本单元知识点
- 线性变换：掌握线性变换的加法与数乘条件，由基向量的像构造变换矩阵，理解平移非线性变换。
- 旋转、缩放与剪切：掌握二维旋转矩阵、对角缩放与剪切矩阵，理解变换复合顺序与行列式意义。
- 齐次坐标与平移：引入三维齐次坐标统一表达平移与旋转，掌握二维刚体变换矩阵的构造。
- 坐标系变换：掌握工件在夹具系与相机系间的坐标转换方程，理解正交旋转矩阵的逆变换求法。

## 线性变换
在分拣工位的视觉定位与运动控制中，坐标映射无处不在。一个将二维平面向量映射
为二维平面向量的函数 T 称为线性变换，当且仅当它严格满足以下两条基本性质：
1. 可加性：对任意向量 u 和 v，满足 T(u + v) = T(u) + T(v)；
2. 齐次性（数乘相容性）：对任意实数标量 c 和向量 u，满足 T(c · u) = c · T(u)。

由齐次性可知，当取标量 c = 0 时，必然有 T(0) = 0，即任何线性变换都必须将坐标
原点映射为坐标原点。工业中常见的固定平移操作将向量 v 映射为 v + d（其中位移
向量 d 为非零常数向量），由于 T(0) = d ≠ 0，且不满足可加性，因此平移变换不是
线性变换。

线性变换的映射规律完全由它对平面标准基向量的作用唯一确定。设平面直角坐标系的
标准基向量为 e1 = (1, 0) 与 e2 = (0, 1)。若已知 T(e1) = (a, c) 且 T(e2) = (b, d)，
则该变换对应的标准矩阵 A 的第一列为 T(e1)，第二列为 T(e2)：
```text
A = [ T(e1)  T(e2) ] = [[a, b],
                        [c, d]]
```
对平面上任意待测特征点向量 v = (x, y)，该点变换后的像均可通过矩阵与向量乘法
直接求得：T(v) = A · v。

### 例题
分拣相机校准算法中，已知标准基向量 e1 = (1, 0) 变换后成为 (3, 1)，标准基向量
e2 = (0, 1) 变换后成为 (-2, 4)。求该线性变换矩阵 A，以及工件边缘特征点
p = (2, 5) 经该变换后的新坐标。

解答：
1. 根据基向量的像构造变换矩阵 A。A 的第一列为 (3, 1)，第二列为 (-2, 4)，按行书
   写为 [[3, -2], [1, 4]]。
2. 计算矩阵与向量的乘积 T(p) = A · p：
   x' = 3 · 2 + (-2) · 5 = 6 - 10 = -4
   y' = 1 · 2 + 4 · 5 = 2 + 20 = 22
所以工件特征点变换后的新坐标为 (-4, 22)。

### 常见错误
1. 误将含有常数位移的仿射映射（如 T(x, y) = (x + 2, y + 3)）当成线性变换，忽略
   了线性变换必过原点（T(0) = 0）的先决条件。
2. 构造变换矩阵时，误将基向量的像按行填充，导致矩阵被转置，后续计算产生错误。

## 旋转、缩放与剪切
在二维平面上，常用的几何变换都可以用 2×2 矩阵统一表达：
1. 绕原点逆时针旋转 θ 度的旋转矩阵 R(θ) 为：
```text
R(θ) = [[cos θ, -sin θ],
        [sin θ,  cos θ]]
```
当绕原点逆时针旋转 90 度时，cos 90° = 0，sin 90° = 1，矩阵为 [[0, -1], [1, 0]]。
2. 沿坐标轴的缩放矩阵 S 为对角矩阵 [[kx, 0], [0, ky]]。当 kx = ky > 0 时为均匀
   缩放；若 kx = -1, ky = 1，则表示关于 y 轴的镜像变换。
3. 水平剪切矩阵形式为 [[1, k], [0, 1]]，它使纵坐标保持不变，横坐标产生与纵坐标
   成正比的偏移。

当对工件坐标连续施加多个变换时，必须通过矩阵相乘进行复合。若先对向量 v 实施
变换 A，再实施变换 B，其结果为 B · (A · v) = (B · A) · v。因为矩阵乘法通常不满足
交换律（B · A ≠ A · B），所以先旋转后缩放与先缩放后旋转的结果往往不同。此外，
变换矩阵行列式的绝对值代表面积放大倍数，正负号反映图形的手征性是否保持。

### 例题
工件图像需先绕原点逆时针旋转 90 度，再在 x 方向缩放 2 倍（y 方向保持 1 倍）。
求复合变换矩阵 M，以及点 (1, 2) 变换后的坐标。

解答：
1. 逆时针旋转 90 度矩阵 R = [[0, -1], [1, 0]]。
2. x 方向缩放 2 倍矩阵 S = [[2, 0], [0, 1]]。
3. 按照“先旋转后缩放”顺序计算复合矩阵 M = S · R：
   M = [[2, 0], [0, 1]] · [[0, -1], [1, 0]] = [[0, -2], [1, 0]]。
4. 计算点 (1, 2) 变换后的坐标：
   x' = 0 · 1 + (-2) · 2 = -4
   y' = 1 · 1 + 0 · 2 = 1
所以变换后的点坐标为 (-4, 1)。

### 常见错误
1. 颠倒复合矩阵乘法的相乘顺序，误将“先 A 后 B”写为 A · B，导致执行结果错误。
2. 混淆旋转矩阵正负号，误将右上角记为 +sin θ、左下角记为 -sin θ（顺时针矩阵）。

## 齐次坐标与平移
平移变换由于不满足线性条件，无法直接写成 2×2 矩阵乘法。为了把平移与旋转、缩放
纳入统一的矩阵乘法体系，工程中普遍采用齐次坐标表示法。

二维平面点 (x, y) 的齐次坐标定义为在其末尾添加标量 1，写成三维列向量 (x, y, 1)。
引入齐次坐标后，沿 x 轴平移 tx、沿 y 轴平移 ty 的平移操作可由 3×3 矩阵表示：
```text
T(tx, ty) = [[1, 0, tx],
             [0, 1, ty],
             [0, 0,  1]]
```
将该矩阵与齐次点 (x, y, 1) 相乘，得到 (x + tx, y + ty, 1)，提取前两个分量即
为平移后的二维笛卡尔坐标。

利用齐次坐标，我们可以将 2×2 旋转矩阵 R 与二维平移向量 t 融合成统一的 3×3 刚体
变换矩阵：
```text
T_rigid = [[cos θ, -sin θ, tx],
           [sin θ,  cos θ, ty],
           [    0,      0,  1]]
```
刚体变换只改变工件在平面上的位置与朝向，严格保持工件本身的几何形状与点间距离
不变。复杂的工件运动序列均可化简为 3×3 矩阵连乘，极大简化了单片机的数据计算。

### 例题
分拣站挡板机构需要将工件先绕原点逆时针旋转 90 度，随后向 x 轴正方向平移 10 mm，
向 y 轴正方向平移 5 mm。写出对应的 3×3 齐次变换矩阵，并求原点 (0, 0) 变换后的位置。

解答：
1. 旋转部分为 R(90°) = [[0, -1], [1, 0]]，平移向量 tx = 10, ty = 5。
2. 组合为 3×3 齐次变换矩阵：
   T = [[0, -1, 10], [1, 0, 5], [0, 0, 1]]。
3. 作用于原点齐次坐标 (0, 0, 1)：
   x' = 0 · 0 + (-1) · 0 + 10 · 1 = 10
   y' = 1 · 0 + 0 · 0 + 5 · 1 = 5
   z' = 0 · 0 + 0 · 0 + 1 · 1 = 1
因此变换后的平面坐标为 (10, 5) mm。

### 常见错误
1. 计算完成后忘记剥离末位的齐次扩增分量 1，或者漏补末位 1 导致矩阵维度无法相乘。
2. 误以为刚体矩阵左上角旋转与最后一列平移可以随意调换相乘顺序，忽略了刚体变换
   “先旋转再平移”与“先平移再旋转”的矩阵构造差异。

## 坐标系变换
在分拣检测系统中，同一个物理点在夹具坐标系 {F} 与相机坐标系 {C} 下拥有不同的
数值坐标。建立两坐标系间的换算关系是视觉引导抓取与尺寸判定的核心。

设某工件特征点在夹具系下的坐标为 P_F，在相机系下的坐标为 P_C。若已知夹具系相对于
相机系的旋转矩阵为 R_FC，夹具系原点在相机系中的坐标向量为 t_FC，则变换方程为：
```text
P_C = R_FC · P_F + t_FC
```
写为 3×3 齐次形式即为 P_C = T_C_from_F · P_F。

若已知相机系测得的点坐标 P_C，需要反求该点在夹具系中的坐标 P_F 时，需利用逆变换：
```text
P_F = (R_FC)⁻¹ · (P_C - t_FC)
```
由于二维旋转矩阵是标准正交矩阵，满足转置等于逆，即 (R_FC)⁻¹ = (R_FC)ᵀ。因此
逆变换中的旋转运算可直接通过矩阵转置完成，无需繁琐的高斯消元求逆。在工程实务
中，必须时刻分清变换矩阵的上标与下标，明确当前数据转换的出发系与目标系。

### 例题
夹具坐标系 {F} 相对于相机坐标系 {C} 绕原点逆时针旋转了 90 度，夹具原点在相机系中
的坐标为 (20, 30) mm。若夹具上某固定销的坐标为 P_F = (4, -2) mm，求该固定销在相机
坐标系下的坐标 P_C。

解答：
1. 旋转矩阵为 R_FC = [[0, -1], [1, 0]]，平移向量 t_FC = (20, 30)。
2. 代入坐标系变换公式 P_C = R_FC · P_F + t_FC：
   x_C = 0 · 4 + (-1) · (-2) + 20 = 2 + 20 = 22
   y_C = 1 · 4 + 0 · (-2) + 30 = 4 + 30 = 34
因此该销在相机坐标系下的坐标为 (22, 34) mm。

### 常见错误
1. 混淆坐标系旋转与物体旋转的方向性，在坐标转换中将旋转角正负号弄反。
2. 求解逆变换时直接写成 P_F = Rᵀ · P_C - t，遗漏了平移向量也必须左乘 Rᵀ 的规则。

## 单元小结
1. 线性变换满足可加性与齐次性并保持原点不变，平移变换因无法通过原点而不属于线性变换。
2. 线性变换由标准基向量的像完全确定，复合变换对应矩阵连乘，其乘法顺序不可随意颠倒。
3. 齐次坐标通过扩展末位分量 1，成功将平移与旋转统一为单一的 3×3 矩阵乘法运算。
4. 坐标系变换描述同一空间点在不同基准下的表示，利用旋转矩阵的正交性可高效求取逆变换。
