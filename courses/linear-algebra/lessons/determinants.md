# 行列式

本单元围绕桌面质检分拣站的相机标定与坐标变换，系统学习二阶与三阶
行列式的计算规则、几何面积缩放与空间降维本质，以及行列式代数性质与
逆变换可解性判定准则。

## 本单元知识点
- 二阶与三阶行列式：掌握二阶交叉相乘与三阶首行展开法，熟练完成位姿变换矩阵的数值求解。
- 行列式的几何意义：理解行列式绝对值作为面积缩放倍数、正负号代表定向手性、等于零代表降维。
- 行列式性质与可逆性：掌握乘积性质 det(AB) = det A · det B、行变换变号与矩阵可逆性充要条件。

## 二阶与三阶行列式

在桌面质检分拣站中，相机抓拍图像后需要将像素坐标映射到传送带夹具坐标。
这一坐标变换通常使用二阶或三阶方阵来描述。行列式是一个将方阵映射为标量
数值的运算，它反映了变换矩阵的核心内在代数特征。

对于按行书写的 2×2 矩阵，二阶行列式采用十字交叉相乘法计算：主对角线
两个元素的乘积，减去副对角线两个元素的乘积。其标准计算形式如下：

```
| a  b |
| c  d | = a · d - b · c
```

当处理包含齐次坐标或三维空间位姿的 3×3 矩阵时，三阶行列式可以通过
“按第一行展开法”分解为三个二阶行列式的代数和。在展开过程中，必须严格
遵循正负符号交替出现的规则，即第一项取正号、第二项取负号、第三项取正号：

```
| a11  a12  a13 |
| a21  a22  a23 | =   a11 · | a22  a23 |
| a31  a32  a33 |           | a32  a33 |
                    - a12 · | a21  a23 |
                            | a31  a33 |
                    + a13 · | a21  a22 |
                            | a31  a32 |
```

每个提取出的二阶行列式称为对应元素在该行中的余子式。分别求出这三个
二阶行列式的值后，与对应系数相乘并求代数和，即可得出三阶行列式的终值。

### 例题

分拣站视觉系统在标定相机倾角时，采集到一个按行书写的 3×3 标定矩阵：
[[2, 1, 3], [0, 4, 1], [1, 2, 0]]。请按第一行展开法求该矩阵的行列式。

解答步骤：
1. 确定展开式中第一行元素及其对应正负符号：
   a11 = 2（正项）、a12 = 1（负项）、a13 = 3（正项）。
2. 写出按第一行展开的子行列式表达式：
   det = 2 · | 4  1 | - 1 · | 0  1 | + 3 · | 0  4 |
             | 2  0 |       | 1  0 |       | 1  2 |
3. 分别计算三个二阶行列式：
   子式 1 = 4 · 0 - 1 · 2 = 0 - 2 = -2
   子式 2 = 0 · 0 - 1 · 1 = 0 - 1 = -1
   子式 3 = 0 · 2 - 4 · 1 = 0 - 4 = -4
4. 代入系数并求代数和：
   det = 2 · (-2) - 1 · (-1) + 3 · (-4)
       = -4 + 1 - 12
       = -15
计算得出该标定矩阵的行列式为 -15。

### 常见错误
- 主副对角线减法顺序颠倒：误将二阶行列式算成 b · c - a · d。
- 三阶首行展开遗漏中间负号：将第二项误写为 + a12，导致符号错误。
- 划掉行列提取子式时看错位置：划除第 1 行第 2 列时抄错剩余元素。

## 行列式的几何意义

在线性代数中，行列式不仅是一组代数公式，更具备直观的几何意义。在分拣站
工作台中，传送带上的工件区域经过线性变换后，其图形面积将被整体缩放。
变换矩阵行列式的绝对值 |det A|，恰好等于几何图形变换前后的面积缩放倍数。

行列式的代数符号揭示了坐标系的定向与手性是否发生改变：
- 当 det A > 0 时，变换保持空间定向不变，坐标轴相对转向与原系统一致。
- 当 det A < 0 时，变换使空间发生镜像翻转（例如相机反光镜成像或背光倒置），
  虽然图形依然存在，但手性被反转。计算实际物理面积时必须取绝对值 |det A|。

对 3×3 矩阵，|det A| 是三维体积的缩放倍数，符号含义相同。

当 det A = 0 时，具有极其关键的几何含义：它意味着二维平面被完全压扁
坍缩为一条直线或一个单点。此时图形的面积被缩放为 0，原平面上原本分离的
不同点在变换后会重叠在一起，导致空间位置信息永久丢失且无法还原。

### 例题

分拣站相机检测到一个位于夹具基准面的矩形条码区域，原设计面积为 20 mm²。
相机矫正矩阵按行书写为 [[-3, 0], [1, 2]]。请计算变换后的条码面积，
并判断其手性定向是否发生翻转。

解答步骤：
1. 计算变换矩阵的行列式：
   det = (-3) · 2 - 0 · 1 = -6 - 0 = -6。
2. 分析定向与手性：
   因为 det = -6 < 0，所以该变换包含了镜像反射，坐标定向发生翻转。
3. 计算实际缩放倍数与变换后面积：
   面积缩放倍数为行列式的绝对值，即 |-6| = 6。
   变换后面积 = 原面积 · 缩放倍数 = 20 · 6 = 120 mm²。
结论：变换后的条码区域面积为 120 mm²，且几何定向发生了镜像翻转。

### 常见错误
- 认为面积可以为负数：看到 det < 0 便得出负面积结论，未取绝对值。
- 误解 det = 0 的后果：以为 det = 0 只是微小形变，未认识到降维坍缩。
- 混淆纯旋转与镜像变换：误将包含反射翻转的负行列式当成纯角度旋转。

## 行列式性质与可逆性

在自动化流水线中，工件往往连续经过夹具装配、传送带位移与镜头透视等多重
级联变换。如果变换分别由矩阵 A 和 B 表示，则复合变换矩阵为乘积 AB。
根据行列式的乘积性质，复合矩阵的行列式等于各自矩阵行列式的乘积：

```
det(AB) = det A · det B
```

初等行变换对行列式的值有着确定的影响规则：
- 互换矩阵的任意两行，行列式的值变为原来的相反数，即 det(A') = -det A。
- 某一行所有元素乘以常数 k，行列式的值扩大为 k · det A。
- 将某一行的 k 倍加到另一行上，行列式的值保持不变。
- 若矩阵中存在两行对应元素完全相同或成比例，则其行列式恒等于 0。

在工程控制中，最重要的性质是行列式与矩阵可逆性之间的等价关系：方阵 A
可逆（存在逆矩阵 A⁻¹）的充分必要条件是 det A ≠ 0。在分拣系统中，控制器
必须求解逆矩阵才能将图像像素逆推为机械挡板的物理动作。一旦 det A = 0，
矩阵即陷入奇异状态不可求逆，系统将无法解算出唯一确定的物理坐标。

### 例题

工控机控制程序中存在相机标定矩阵 A = [[3, 2], [1, 2]] 与执行机构变换
矩阵 B = [[4, 1], [2, 1]]（两者均为按行书写的矩阵）。
（1）判断矩阵 A 是否可逆；
（2）利用行列式性质求解乘积矩阵 AB 的行列式 det(AB)。

解答步骤：
1. 校验矩阵 A 的行列式与可逆性：
   det A = 3 · 2 - 2 · 1 = 6 - 2 = 4。
   因为 det A = 4 ≠ 0，所以矩阵 A 确定可逆，允许进行坐标逆解。
2. 计算矩阵 B 的行列式：
   det B = 4 · 1 - 1 · 2 = 4 - 2 = 2。
3. 利用乘积性质计算 det(AB)：
   det(AB) = det A · det B = 4 · 2 = 8。
结论：矩阵 A 满足可逆条件，复合变换矩阵的行列式为 8。

### 常见错误
- 误套加法分配律：错误臆造 det(A + B) = det A + det B（该等式不成立）。
- 行变换调换忘变号：交换两行位置后，遗漏负号而导致计算偏差。
- 混淆可逆判定门槛：误以为 det A > 0 才能求逆，忽略了负数行列式同样可逆。

## 单元小结
- 二阶行列式按十字交叉相乘相减计算，三阶按首行展开并注意符号正负交替。
- 行列式的绝对值代表面积或体积的缩放比例，负号代表坐标系发生手性镜像翻转。
- 行列式为零在几何上意味着空间被压扁降维，导致图形位置信息永久丢失。
- 乘积矩阵的行列式等于各自分离行列式的乘积，互换两行会导致行列式值变号。
- 方阵可逆的充要条件是 det A ≠ 0，这是质检系统逆解夹具坐标的数学基石。
