# 特征值与工程应用

本单元介绍特征值与特征向量、最小二乘拟合及相机标定方程，并结合分拣站夹具完成旋转实作。

## 本单元知识点

- 特征值与特征向量入门：掌握 Av = λv、特征多项式与缩放主方向。
- 最小二乘拟合：掌握超定方程组的正规方程 AᵀAx = Aᵀb 及直线拟合。
- 标定约束方程：建立像素与毫米坐标转换方程并利用多组点估计参数。

## 特征值与特征向量入门

在工程控制与图像处理中，方阵 A 作用于平面向量通常会改变其长度与方向。
若非零向量 v 经 A 变换后方向保持在同一直线上，仅发生纯伸缩，
即满足关系式 Av = λv，则称标量 λ 为特征值，非零向量 v 为对应的特征向量。
特征向量指明了变换的主方向，而特征值给出了该方向上的拉伸或压缩倍率。

求解 2×2 矩阵的特征值时，将 Av = λv 移项整理为齐次方程 (A − λI)v = 0。
因为特征向量 v 必须为非零向量，所以系数矩阵 A − λI 必须不可逆，
即其行列式必须为零：det(A − λI) = 0。这一元二次方程称为特征方程。
对于按行书写的矩阵 A = [[a, b], [c, d]]，展开行列式可得：
λ² − (a + d)λ + (ad − bc) = 0。解出方程的根即可得到全部特征值。

若变换矩阵为对角矩阵 A = [[d₁, 0], [0, d₂]]，其特征值直接就是对角线元素 d₁ 和 d₂。
对应的特征向量分别落在水平轴方向 (1, 0)ᵀ 与垂直轴方向 (0, 1)ᵀ 上。
在自动化质检中，这对应于相机或传送带在两垂直主轴上互不干扰的独立缩放。

### 例题

已知工件形变分析矩阵为按行书写的矩阵 A = [[3, 1], [0, 2]]。
求矩阵 A 的全部特征值，并求出对应于较小特征值的特征向量。

解题步骤：
1. 写出特征方程 det(A − λI) = 0：
   det([[3 − λ, 1], [0, 2 − λ]]) = (3 − λ)(2 − λ) − 0 = 0。
2. 解一元二次方程，得到特征值 λ₁ = 3，λ₂ = 2。较小特征值为 λ = 2。
3. 将 λ = 2 代入齐次方程 (A − 2I)v = 0，设 v = (x, y)ᵀ：
   [[1, 1], [0, 0]] · [x, y]ᵀ = [0, 0]ᵀ。
   展开得到线性方程 x + y = 0，即 x = −y。
4. 取自由变量 y = 1，可得对应特征向量为 v = (−1, 1)ᵀ（或其任意非零常数倍）。

### 常见错误

- 误把零向量作为特征向量：特征向量在数学定义上必须是非零向量。
- 误以为任意矩阵的特征值都等于对角线元素：只有上三角、下三角或对角矩阵的特征值
  才直接对应主对角线元素，一般矩阵必须求解特征方程。

## 最小二乘拟合

在桌面分拣站中，视觉传感器测量工件边缘常获取多个离散点 (xᵢ, yᵢ)。
若希望拟合直线 y = kx + b，每个测量点提供一个线性方程 k·xᵢ + b = yᵢ。
当测量点数量大于 2 时，方程个数大于未知参数个数（2 个），形成超定方程组 Ax = b。
由于测量抖动和图像离散化误差，这些方程通常相互冲突，无精确解。

为获得最优工程近似，最小二乘法寻找使残差向量 r = b − Ax 的模长平方
‖b − Ax‖² 达到最小的解向量 x̂ = (k, b)ᵀ。
几何上，残差向量 r 必须与系数矩阵 A 的列空间垂直，即满足 Aᵀ(b − Ax) = 0。

将上式移项整理，即得到著名的正规方程：AᵀAx = Aᵀb。
当测量点横坐标不全相同时，矩阵 A 的列向量线性无关，AᵀA 是对称且可逆的方阵。
两端左乘逆矩阵，即可直接解出唯一最优参数：x̂ = (AᵀA)⁻¹Aᵀb。

### 例题

相机在工件边缘测得 3 个数据点：(−1, 0)、(0, 1)、(1, 5)。
试利用正规方程拟合直线 y = kx + b。

解题步骤：
1. 根据点坐标构建系数矩阵 A 与观测向量 b：
```
A = [[-1,  1],
     [ 0,  1],
     [ 1,  1]],   b = [0, 1, 5]ᵀ
```
2. 计算对称矩阵 AᵀA：
   第一行第一列：(-1)² + 0² + 1² = 2。
   非对角元素：(-1)×1 + 0×1 + 1×1 = 0。
   第二行第二列：1 + 1 + 1 = 3。
   得到 AᵀA = [[2, 0], [0, 3]]。
3. 计算向量 Aᵀb：
   第一行：(-1)×0 + 0×1 + 1×5 = 5。
   第二行：0 + 1 + 5 = 6。
   得到 Aᵀb = [5, 6]ᵀ。
4. 解方程 AᵀAx = Aᵀb：
   2k = 5 ⇒ k = 2.5；3b = 6 ⇒ b = 2。
   得到最优拟合直线方程为 y = 2.5x + 2。

### 常见错误

- 遗漏常数项全 1 列：在构造 A 时，漏写偏置项 b 对应的列向量 (1, 1, ..., 1)ᵀ。
- 颠倒矩阵相乘次序：正规方程左边是 AᵀA 而不是 AAᵀ。

## 标定约束方程

分拣站相机拍摄的图像使用像素坐标 (u, v)，而机械手或分拣推杆工作在毫米坐标 (X, Y)。
两套坐标系之间通常存在比例缩放、偏置平移与轴向倾斜。
在单轴对齐的直线传动机构中，物理位置与像素读数满足一维线性标定模型：
X = s·u + t，其中 s 为比例因子（毫米/像素），t 为安装偏置（毫米）。

若仅采集两组理想特征点，可通过二元一次方程组直接解出 s 与 t。
然而单次采样易受光源反射、边缘毛刺或传感器噪声干扰。
工程实务中，通常测量 m 组（m ≥ 3）已知标准物理间距的标定孔像素位置 (uᵢ, Xᵢ)，
进而写成多组线性约束方程：
```
[[u₁, 1],
 [u₂, 1],
 ...,
 [uₘ, 1]] · [s, t]ᵀ = [X₁, X₂, ..., Xₘ]ᵀ
```

将该方程组写为矩阵形式 Ku = X，利用正规方程 KᵀKu = KᵀX 求最小二乘解。
通过多点数据拟合，可以有效平滑测量噪声，得到高精度的比例因子 s 与平移量 t。

### 例题

分拣站标定板上有 3 个精密孔，其像素读数与实际毫米坐标如下：
孔 1 为 u₁ = 100 像素，X₁ = 20 mm；
孔 2 为 u₂ = 200 像素，X₂ = 40 mm；
孔 3 为 u₃ = 300 像素，X₃ = 62 mm。
写出标定约束矩阵方程，并求解正规方程得到比例因子 s（保留两位小数）。

解题步骤：
1. 建立超定方程组 Ku = X：
   K = [[100, 1], [200, 1], [300, 1]]，X = [20, 40, 62]ᵀ。
2. 计算 KᵀK：
   KᵀK = [[140000, 600], [600, 3]]。
3. 计算 KᵀX：
   第一分量：100×20 + 200×40 + 300×62 = 2000 + 8000 + 18600 = 28600。
   第二分量：20 + 40 + 62 = 122。
   得到 KᵀX = [28600, 122]ᵀ。
4. 解方程 (KᵀK)[s, t]ᵀ = KᵀX：
   由第二行得 600s + 3t = 122 ⇒ t = (122 − 600s) / 3。
   代入第一行：140000s + 600(122 − 600s)/3 = 28600。
   化简：140000s + 200(122 − 600s) = 28600。
   140000s + 24400 − 120000s = 28600 ⇒ 20000s = 4200 ⇒ s = 4200 / 20000 = 0.21。
   代回得 t = (122 − 126) / 3 ≈ −1.33 mm。比例因子 s = 0.21 mm/像素。

### 常见错误

- 比例倒置：混淆毫米/像素与像素/毫米，导致将图像距离换算为物理距离时出现乘除倒置。
- 忽略平移偏置 t：直接用 X = s·u 假设两坐标系原点重合，导致定位整体跑偏。

## 夹具点旋转验证（自评）

目标：
针对分拣站安装工位旋转调整需求，将 3D 打印定位夹具上的 3 个基准定位孔坐标
绕原点逆时针旋转 90°，写出旋转变换矩阵并手算验证，确保刚体形状保距保角。

材料或准备：
方格纸或坐标纸 1 张、直尺、铅笔。
已知夹具上 3 个特征点的原始坐标为：P₁ = (2, 1)、P₂ = (4, 1)、P₃ = (2, 3)（单位：cm）。

步骤：
1. 依据平面逆时针旋转变换公式，代入角度 θ = 90°，写出 2×2 旋转矩阵：
   R = [[cos 90°, −sin 90°], [sin 90°, cos 90°]] = [[0, −1], [1, 0]]。
2. 将三个点分别写为列向量，计算旋转后的新坐标向量 P' = R · P：
   P₁' = [[0, −1], [1, 0]] · [2, 1]ᵀ = [−1, 2]ᵀ；
   P₂' = [[0, −1], [1, 0]] · [4, 1]ᵀ = [−1, 4]ᵀ；
   P₃' = [[0, −1], [1, 0]] · [2, 3]ᵀ = [−3, 2]ᵀ。
3. 在方格纸上建立直角坐标系，用铅笔准确标出原始点 P₁、P₂、P₃，顺次连成三角形；
   随后标出变换后的点 P₁'、P₂'、P₃'，顺次连成旋转后的三角形。
4. 用直尺量取或利用勾股定理计算边长：
   原始边长 |P₁P₂| = 2 cm，|P₁P₃| = 2 cm；
   变换后边长 |P₁'P₂'| = 2 cm，|P₁'P₃'| = 2 cm。
   再算向量 P₁'P₂' = (0, 2) 与 P₁'P₃' = (−2, 0) 的点积为 0，说明直角保持，
   确认刚体旋转未发生缩放或形变。

## 单元小结

- 特征值与特征向量反映了方阵变换中保持方向不变的纯缩放主轴，由 det(A − λI) = 0 求解。
- 针对传感器噪声引入的超定方程组，正规方程 AᵀAx = Aᵀb 提供了残差平方和最小的最优工程解。
- 视觉与机械标定通过多点建立线性约束方程组，借助最小二乘法消除测量偶然误差。
- 平面旋转矩阵属于正交矩阵，能够保持工件夹具的距离与角度特征在刚体变换中严格不变。
