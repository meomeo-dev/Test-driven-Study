# 线性代数

用向量、矩阵和线性变换理解夹具坐标与相机坐标。

## 学习起点

会解简单方程，会读平面坐标和向量分量。

- 向量与线性组合 → 矩阵乘法 → 线性方程组 → 坐标变换。

## 学完能做什么

- 将位移、方向和测量值表示为向量。
- 理解矩阵乘法、旋转与坐标表示。
- 能用简单线性方程描述标定约束。

**桌面质检分拣站实作**。把夹具上三个二维点逆时针旋转 90°，写出矩阵并用手算结果验证。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 向量与坐标 | 向量与分量；向量加减与数乘；向量长度与距离；点积与夹角 |
| 线性组合与基 | 线性组合；张成与线性无关；基与坐标表示 |
| 矩阵运算 | 矩阵与记号；矩阵乘向量；矩阵乘法；转置与对称矩阵 |
| 线性方程组 | 方程组与矩阵形式；高斯消元；解的情况与秩；逆矩阵 |
| 行列式 | 二阶与三阶行列式；行列式的几何意义；行列式性质与可逆性 |
| 线性变换与坐标变换 | 线性变换；旋转、缩放与剪切；齐次坐标与平移；坐标系变换 |
| 特征值与工程应用 | 特征值与特征向量入门；最小二乘拟合；标定约束方程；夹具点旋转验证（自评） |

“夹具点旋转验证”是自评实作，没有练习题。
按[特征值与工程应用讲义](lessons/applications.md)中的自评清单完成后，
在学习路径中标记已会。
