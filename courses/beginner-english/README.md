# 零基础英语（听说与基础语法）

从自我介绍、数字和简短指令开始，逐步衔接工程英语。

## 学习起点

适合词汇量约 300 或更少、需要从发音、语法和口语基础开始的成人。课程说明以中文呈现。
从 USA Learns 的 *1st English Course* 第一单元开始。

- 自我介绍与拼读 → 数字、位置和时间 → 简短请求 → 工位动作与单位 → 作息与班次 →
  描述零件与质量 → 安全与问题报告 → 交接班汇报。
- 第一周每天 30 分钟、每周 5 天。每天用 10 分钟听读、10 分钟跟读替换、
  5 分钟语法和 5 分钟关字幕录音。

## 学完能做什么

- 用 I am、You are 和简短问句介绍自己。
- 在慢速录音中听出地点、动作和数量。
- 关字幕录一段 20–30 秒的简单自我介绍。
- 描述零件的颜色、尺寸和缺陷，报告故障并读懂常见安全标志。
- 用过去时做一段 1 分钟的口头交接班汇报。

**口语实作**。先读 `My name is …`、`I live in …` 和 `I am learning English.`，
换成自己的信息再脱稿说一遍。能听懂慢速短句后，练习说 `Press the button to stop.`。

## 课程内容

2.3.0 版（协议版本 `protocol_version: 2`）包含十个单元、41 个知识点（合计 2,240 分钟 / 37.33 学时）和 424 道练习题（涵盖全部 9 类 v2 题型：`single_choice` 76、`multiple_choice` 38、`true_false` 38、`numeric` 19、`cloze` 65、`listening` 59、`reading_comprehension` 39、`translation` 51、`writing` 39）。讲义小节通过 `<!-- concepts: ... -->` / `effort-lab` 锚点与多题型配额自底向上对齐，全面通过 `course:check`、`audit-course-tts` 与 `audit-course-effort --strict` 质量门。表中同一单元的知识点以分号分隔。

背题模式为全部 39 道阅读理解和 59 道听力题提供英中对照，涵盖阅读段落、
听力逐字稿以及英文小题与选项。听力播放器下可展开逐字稿，
并使用「仅原文」切回英文材料。

在背题工具栏打开「生词本」，可查看本题相关词条，或按单元和全课程复习。
[课程词表](assets/vocabulary/english.json)含 71 条词汇，覆盖十个单元，
提供中文释义、英中例句和词类筛选。

| 单元 | 知识点 |
| --- | --- |
| 自我介绍与问候 | 问候与告别；be 动词 am / is / are；字母与拼读；自我介绍句型；口语自我介绍（自评） |
| 数字、位置与时间 | 数字 0–100；There is / There are；方位介词；钟点与时间 |
| 简短请求与指令 | 祈使句指令；一般疑问句；礼貌请求 |
| 工位动作与单位 | 工具与零件词汇；长度与重量单位；工位动作现在时；听懂工位指令 |
| 日常作息与班次 | 星期、月份与日期；特殊疑问句；频率副词；班次与日程 |
| 描述零件与质量 | 颜色与形状；质量形容词；指示代词 this / that / these / those；形容词比较级 |
| 安全与问题报告 | 必须与禁止 must；安全标志与警示语；能力与许可 can；报告故障与问题 |
| 交接班汇报 | 一般过去时 was / were；规则动词过去式；常用不规则动词过去式；过去时疑问与否定 did；口头交接班汇报（自评） |
| 工具与设备操作 | 工具与劳保词句；检测量具与读数；设备安全规程与指令；工具点检与维护听力 |
| 车间日常沟通与协作 | 工位求助与礼貌应答；现在进行时描述工位状态；通信与对讲机规范；调度协调与交接听力 |

“礼貌请求”可以在学完祈使句或一般疑问句中的任意一项后开始，演示了“满足任一组先修即可”
的规则。“口语自我介绍”和“口头交接班汇报”没有练习题，分别按
[自我介绍讲义](lessons/intro.md)和[交接班讲义](lessons/past-reports.md)的自评清单
录音自评后标记已会。

“桌上有几个零件”听力题使用 DeepSeek TTS 语音合成，练习时可点击题干中的发音按钮收听工位汇报，亦可展开逐字稿进行对照。
