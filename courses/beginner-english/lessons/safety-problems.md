# 安全与问题报告

本单元面向桌面质检分拣工位操作人员，系统学习表达必须与禁止的安全规程、
识别车间与工位核心安全标志、使用 can 表达操作技能与申请许可，以及在设备
发生故障卡滞时使用标准句型向班长与技术员准确汇报。

## 本单元知识点

- 必须与禁止 must：掌握 must、must not 及 have to 的表意与句型结构。
- 安全标志与警示语：识读危险等级标识、工位通行限制与设备警示用语。
- 能力与许可 can：运用 can / can't 表达操作技能并礼貌申请工位许可。
- 报告故障与问题：掌握 There is a problem with... 及设备卡滞等故障汇报。

## 必须与禁止 must

在桌面质检分拣工位操作中，严格遵守安全规程是防范工伤事故的前提。英语中
常用情态动词 must 与短语 have to 来表达强制性规定与绝对禁止要求。

1. 表达“必须做某事”（强制安全规则）：
   - 使用 `must + 动词原形`，强调安全规程或指令要求的强制性。
   - 句型结构：`主语 + must + 动词原形`。
   - 例如：`You must wear gloves.`（你必须佩戴手套。）
   - 在表达工厂通用制度、外部规章要求时，也常用 `have to`：
     `We have to wear safety shoes.`（我们在车间必须穿安全鞋。）

2. 表达“严禁做某事”（绝对禁止指令）：
   - 使用 `must not`（缩写为 `mustn't`），表示强烈的“严禁、绝不可”。
   - 句型结构：`主语 + must not (mustn't) + 动词原形`。
   - 例如：`You must not touch the belt.`（你绝对不可触碰传送带。）
   - 注意：`must not` 表示“禁止做”，绝不可理解为“可以不做”。

3. 语法关键点：
   - 情态动词 must 后面永远跟随动词原形，不加 to，也不发生任何词尾变化。
   - 不管主语是第几人称（I, you, he, they），must 的形式始终保持不变。

### 例题

**题目**：
桌面分拣站接通电源后，传送带开始运转。班长强调两项工位纪律：第一，操作前
必须戴好护目镜；第二，分拣舵机工作时严禁将手伸入分拣挡板活动区域。请用
本节句型给出规范的英文表述。

**解答**：
1. 第一句（必须佩戴）：`You must wear safety glasses.`
2. 第二句（严禁触碰）：`You must not touch the sorting flap.`
3. 解析：
   表达规程强制要求时，使用 `must + 动词原形 wear`；表达严禁触碰危险活动
   部件时，使用 `must not + 动词原形 touch`。两句均不可在 must 后添加 to。

### 常见错误

1. 误把 `must not` 当作“不必”：在车间安全规程中，`must not` 代表违规会
   造成伤害的严厉禁止，而“不必/不需要”应使用 `don't have to`。
2. 在 must 后面误加 to 或动词变形：如写成 `*You must to wear gloves`
   或 `*He must wears glasses`，正确形式必须直接接动词原形。

## 安全标志与警示语

分拣工位与周边车间张贴有各类醒目的安全标识与文字标签。快速识读这些英文
警示语，有助于工人准确规避触电、机械夹伤与表面烫伤风险。

1. 危险等级标志（按严重程度划分）：
   - `Danger`（危险）：最高警示级别，表示不避开将导致重大伤害或死亡。
   - `Warning`（警告）：中度警示级别，提示存在可能导致严重伤害的潜在危害。
   - `Caution`（注意/小心）：提醒防范轻微擦伤、绊倒或设备碰撞。

2. 工位限制与动作警示标志：
   - `No entry`：禁止入内；`Keep out`：闲人免进 / 请勿靠近。
   - `Do not touch`：请勿触碰（禁止徒手触摸测试工件或运动连杆）。
   - `Hot surface`：高温表面（分拣工位大功率补光灯外壳的防烫警示）。

3. 防护指令与应急设施标志：
   - `Wear safety glasses`：必须佩戴护目镜（指令性防护标识）。
   - `Emergency stop`：紧急停止（标在工位红色蘑菇头急停按钮旁）。
   - `Exit`：安全出口（紧急疏散通道引导标识）。

### 例题

**题目**：
质检员在分拣工作台上看到三个标识：总控箱红色凸起按钮旁标注着
`Emergency stop`；检测相机光源外壳上贴有 `Hot surface`；传送带侧面
贴有 `Do not touch`。请说明这三个标识的含义及应对动作。

**解答**：
1. `Emergency stop`：紧急停止。当舵机卡阻或传动异响时，立即拍下切断电源。
2. `Hot surface`：高温表面。测试灯箱发热严重，严禁徒手触碰以防烫伤。
3. `Do not touch`：请勿触碰。传送带及传动部件运转期间，严禁伸手摸碰。
4. 解析：三个标识分别对应“应急制动设施”、“物理防烫警示”与“动作禁止指令”。

### 常见错误

1. 遇到机械卡死险情时误找 `Caution`：`Caution` 仅是提示小心的牌子，
   发生机械卡阻碰撞时必须立刻寻找并拍下红色 `Emergency stop` 按钮。
2. 混淆 `Exit` 与 `No entry`：`Exit` 是安全出口通道，而 `No entry` 是严禁
   人员入内的危险区域管制标志。

## 能力与许可 can

在桌面分拣工位上，工人需要向班长陈述自己已经掌握的检测技能，同时也需要
在身体不适、工件物料用尽或离岗时礼貌申请许可。

1. 表达个人操作能力（Ability）：
   - 肯定句：`主语 + can + 动词原形`，表示“能/会做某事”。
     例如：`I can use the scanner.`（我会使用扫码枪。）
   - 否定句：`主语 + cannot / can't + 动词原形`，表示“不会/不能做某事”。
     例如：`I can't fix the servo.`（我不会修舵机。）

2. 申请与给予许可（Permission）：
   - 向上级申请许可问句：`Can I + 动词原形 ...?`，意为“我可以……吗？”。
     例如：`Can I take a break?`（我可以休息一下吗？）
   - 答复许可：`Yes, you can.`（可以。）或 `Sorry, not now.`（抱歉，现在不行。）

3. 表达现场规则限制（无许可 / 不允许）：
   - 句型：`主语 + can't + 动词原形`，表示“按规定不可以/不能在此做某事”。
     例如：`You can't stand here.`（你不能站在这里——挡住了物流通道。）

### 例题

**题目**：
新质检员已经完成了工位串口通信软件培训，想要向工段长说明自己“会使用扫码枪”，
并且连续质检两小时后礼貌询问“我能休息一下吗？”。请写出两句工位英文。

**解答**：
1. 表达操作能力：`I can use the scanner.`
2. 礼貌申请许可：`Can I take a break?`
3. 解析：表达个人技能与能力使用陈述句 `I can + 动词原形`；向管理人员申请
   离岗休息等许可时，使用一般疑问句型 `Can I + 动词原形 ...?`。

### 常见错误

1. 在情态动词 can 后面误加 to：写成 `*I can to use the scanner`。can 属于
   情态动词，后接动词原形，绝不可添加 to。
2. 第三人称单数误加 -s：错误地写成 `*He cans check parts`。can 没有第三
   人称单数形式，无论主语是谁均写作 `He can check parts.`。

## 报告故障与问题

质检分拣站由到位传感器、相机、传送带与单片机舵机构成，运行中可能发生零件
卡死、光照失效或通信中断。规范、准确地向维修技术员汇报是排除故障的关键。

1. 报告设备存在问题（总括句型）：
   - 常用句型：`There is a problem with + 故障部件/设备.`
   - 例如：`There is a problem with the camera.`（摄像头出问题了。）
   - 例如：`There is a problem with the sensor.`（到位传感器出问题了。）

2. 描述具体故障现象：
   - 部件不运转/不工作：`The light doesn't work.`（光源/指示灯不亮。）
   - 部件完全无动作：`The machine is not moving.`（机器没有动作/不走动。）
   - 机械卡死/物料阻塞：`The belt is stuck.`（传送带卡住了。）
     `The part is stuck.`（工件卡在料道中了。）
   - 说明：`stuck` 是形容词（卡住的），与 be 动词连用构成系表结构。

3. 呼叫技术员协助（工位祈使句）：
   - `Please call the technician.`（请呼叫技术员。）
   - `Please check the sensor.`（请检查传感器。）

### 例题

**题目**：
分拣站在检测工件时，舵机挡板刚旋转一半便发生机械卡阻，补光灯也随之熄灭。
质检员向赶来的技术员说明两点：第一，“传送带卡住了”；第二，“灯不工作了”。
请写出标准英文。

**解答**：
1. 第一点（机械卡死）：`The belt is stuck.`
2. 第二点（灯光失效）：`The light doesn't work.`
3. 呼叫协助：`There is a problem with the station. Please call the technician.`
4. 解析：描述机械卡阻使用 `is stuck`；描述电气元件不工作使用助动词否定形式
   `doesn't work`；汇报整机故障使用 `There is a problem with...`。

### 常见错误

1. 介词搭配错误：误说成 `*There is a problem of the camera`。表示“某物
   出问题了”必须使用固定介词 `with`。
2. 否定形式混淆：误把不工作说成 `*The light no work` 或 `*The light is not work`。
   work 是实义动词，第三人称单数的一般现在时否定必须使用 `doesn't work`。

## 单元小结

- 规程必须与禁止：掌握 `must + 动词原形` 表示强制要求，`must not + 动词原形`
  表示严厉禁止，客观规则常使用 `have to`。
- 车间标志识读：认清 `Danger`、`Warning`、`Caution` 的危害级别，熟记
  `Emergency stop` 急停开关与 `Hot surface`、`Do not touch` 等操作禁忌。
- 能力与请示表达：运用 `I can...` 明确表达工位技能，使用 `Can I...?`
  规范向上级申请离岗或操作许可。
- 故障精准汇报：熟练运用 `There is a problem with...`、`The belt is stuck.`
  与 `doesn't work` 描述异常，并使用 `Please call the technician.` 及时求助。
