# 测量数据分析

本单元系统讲解测量重复性与再现性评定、靠近公差边界时的合格判定与保护带设置，
以及桌面质检分拣站装配中的尺寸链与公差累积计算。

## 本单元知识点
- 重复性与再现性：用极差和样本标准差评估同条件重复测量与变条件对比测量的波动。
- 合格判定与测量不确定度：分析边界测量值的误收与误废风险，通过保护带划分验收区。
- 尺寸链与公差累积：辨识组成环与封闭环，掌握极值法极限计算与统计法RSS累积思路。

## 重复性与再现性
1. 重复性（Repeatability）：同一操作者在相同测量工位，使用同一把测量工具
（如数显卡尺），对同一工件的同一几何特征在短时间内连续重复测量多次时，
各次测量结果之间的一致程度。它反映了测量系统固有的随机波动与装夹稳定性。
在桌面分拣站中，卡尺重复性决定了单次检测结果的可信区间。

2. 再现性（Reproducibility）：在改变测量条件后，对同一工件的同一几何特征
进行测量时，测量结果之间的一致程度。常见的变动条件包括：更换不同操作人员
（如白班与夜班检验员）、更换不同测量工具、在不同环境温度或不同时间段复测。
再现性反映了测量系统面对外界条件变动时的稳健性。

3. 波动评价指标：
- 极差 R：一组重复测量数据中最大值与最小值之差，即 R = Xmax - Xmin。
极差计算直观简捷，适合质检分拣现场对短序列测量波动进行快速粗略估算。
- 样本标准差 s：表征测量数据围绕算术平均值离散程度的标准统计量，计算公式为：
```
s = √[ Σ(xi - x̄)² / (n - 1) ]
```
式中 n 为测量次数，n - 1 为自由度，x̄ 为样本算术平均值。与极差相比，
样本标准差综合考虑了全部测量数据，更能稳健反映测量过程的随机分散性。

4. 分拣站应用联系：若3D打印定位夹具卡槽存在松动磨损，同一操作者重复放置工件
测量时读数极差会显著增大；若两名检验员操作手法或测力控制不一致，则会导致
显著的再现性偏差，进而导致分拣记录CSV中的测量数据出现系统性跳变。

### 例题
检验员在分拣工位用数显卡尺对同一3D打印滑块的外宽连续测量5次，读数记录分别为：
32.02 mm、32.06 mm、32.04 mm、32.08 mm、32.05 mm。
试求这组测量数据的极差 R 与样本标准差 s（标准差计算结果保留三位小数）。

解答过程：
1. 计算算术平均值 x̄：
x̄ = (32.02 + 32.06 + 32.04 + 32.08 + 32.05) / 5 = 160.25 / 5 = 32.050 mm。
2. 计算极差 R：
读数最大值 Xmax = 32.08 mm，最小值 Xmin = 32.02 mm。
R = Xmax - Xmin = 32.08 - 32.02 = 0.060 mm。
3. 计算各测得值与平均值的离差平方和 Σ(xi - x̄)²：
(32.02 - 32.05)² = (-0.03)² = 0.0009 mm²
(32.06 - 32.05)² = (+0.01)² = 0.0001 mm²
(32.04 - 32.05)² = (-0.01)² = 0.0001 mm²
(32.08 - 32.05)² = (+0.03)² = 0.0009 mm²
(32.05 - 32.05)² = (0.00)² = 0.0000 mm²
离差平方和 = 0.0009 + 0.0001 + 0.0001 + 0.0009 + 0 = 0.0020 mm²。
4. 计算样本标准差 s：
s = √[ 0.0020 / (5 - 1) ] = √[ 0.0005 ] ≈ 0.022 mm。

### 常见错误
- 混淆重复性与再现性：将换班后不同人员测量产生的差异当成重复性问题，
忽视了人员手法与视差变动属于再现性范畴。
- 计算标准差时分母错除以 n：在有限次测量样本计算中未采用自由度 n - 1，
导致低估了测量系统的实际分散度。
- 误将重复性好等同于测量准确：多次读数高度集中仅代表随机误差小；
若卡尺零位未校准或存在恒定测力变形，测量均值仍偏离真值。

## 合格判定与测量不确定度
1. 不确定度与边界判定风险：任何实际测量结果都不可避免地存在测量不确定度 U。
当工件实测值落在公差极限附近时，受测量随机误差与微小系统误差的影响，
实测读数与工件实际真值可能分居极限边界两侧，导致分拣站发出错误的执行指令。

2. 误收与误废：
- 误收（漏判）：工件实际尺寸超出图纸极限，但因测量负向误差使读数落在
合格区内，工件被分拣站送入良品盒。误收会导致不良品流入装配或用户端，
引发装配干涉、功能失效或质量追溯，危害极大。
- 误废（误判）：工件实际尺寸完全符合图纸要求，但因测量正向误差使读数超出
公差极限，工件被分拣挡板打入废品盒。误废导致制造方承担不必要的报废与返工损失。

3. 保护带（Guard Band）原理与设置：
- 为严控高风险的误收现象，工业质检常在图纸公差带极限内侧缩进一定安全裕度 w，
形成收紧的合格验收区。保护带宽度 w 通常根据测量不确定度 U 确定（常取 w = U）。
- 验收极限计算规则：
```
验收上限 = 上极限尺寸 (USL) - w
验收下限 = 下极限尺寸 (LSL) + w
```
- 实测尺寸落入 [LSL + w, USL - w] 判为合格放行；落入保护带区间
[LSL, LSL + w) 或 (USL - w, USL] 则标记为存疑边缘件，分拣至复检料盒，
采用更高精度量具重新测量。

### 例题
分拣站待测的3D打印圆柱销外径图纸标注为 20.00 mm，上偏差为 +0.03 mm，
下偏差为 -0.01 mm。测量系统的扩展不确定度经评定为 U = 0.008 mm。
质检规程要求采用保护带宽度 w = U 向公差带内侧缩进。
试求该销轴图纸公差带与合格验收区，并判断实测值 20.026 mm 的处置方案。

解答过程：
1. 计算图纸极限尺寸与原始公差带：
上极限尺寸 USL = 20.00 + 0.03 = 20.030 mm。
下极限尺寸 LSL = 20.00 - 0.01 = 19.990 mm。
原始图纸公差带为 [19.990, 20.030] mm。
2. 计算内缩保护带后的合格验收区：
验收上限 = USL - w = 20.030 - 0.008 = 20.022 mm。
验收下限 = LSL + w = 19.990 + 0.008 = 19.998 mm。
合格验收区间为 [19.998, 20.022] mm。
3. 工件判定与分拣决策：
工件实测值为 20.026 mm，虽然小于图纸极限 20.030 mm，但大于验收上限 20.022 mm，
处于上保护带区域 (20.022, 20.030] mm 内。该尺寸存在较大的误收风险，
分拣系统不应将其直接排入良品盒，而应将其分流至待复检料盒进行二次核验。

### 常见错误
- 忽略不确定度做绝对判别：将靠近极限尺寸的实测读数盲目视为绝对合格，
导致超差件因测量随机分散而频繁误流入成品料盒。
- 保护带方向搞反：错误地向公差带外侧扩展保护带，导致实际验收范围变大，
进一步放大了误收超差件的概率。
- 忽视误收与误废的非对称成本：未根据下游装配严酷度制定验收策略，
忽略了误收缺陷件引发批量返工的损失往往大于误废单件的成本。

## 尺寸链与公差累积
1. 尺寸链的基本概念：在机器装配或零件加工过程中，由一组按特定顺序首尾相接、
形成封闭几何图形的尺寸系统称为尺寸链。
- 封闭环：在加工或装配过程最后自然形成、不能直接由单独工序加工保证的尺寸。
每个尺寸链有且仅有一个封闭环。
- 组成环：尺寸链中除封闭环之外的其余所有尺寸，每个组成环均可独立加工测量。
- 增环与减环：当其余组成环尺寸固定不变时，自身尺寸增大引起封闭环尺寸
相应增大的组成环为增环；自身尺寸增大引起封闭环尺寸反而缩小的组成环为减环。

2. 极值法（Worst-Case Method）计算规则：
极值法假设所有组成环同时处于最不利的极端公差状态，用于保证 100% 互换性。
```
封闭环基本尺寸 = 增环基本尺寸之和 - 减环基本尺寸之和
封闭环最大极限尺寸 = 增环最大极限尺寸之和 - 减环最小极限尺寸之和
封闭环最小极限尺寸 = 增环最小极限尺寸之和 - 减环最大极限尺寸之和
封闭环公差 T0 = 所有组成环公差之和 (Σ Ti)
```

3. 统计法（平方和开根法 / RSS）思路：
- 在大批量加工中，各个组成环的实际加工尺寸通常独立服从正态分布，
所有组成环同时达到最恶劣极限偏差的概率极小。
- 统计法基于方差合成定律估算封闭环公差：
```
T0_rss = √(Σ Ti²)
```
- 统计法计算出的封闭环公差显著小于极值法公差（T0_rss < T0）。
这允许工程设计中适度放宽单个零件的制造公差，大幅降低 3D 打印与加工成本，
仅需承担可控的极小装配超差风险。

### 例题
分拣站导轨推料机构中，导轨槽总装配间隙 A0 为装配后形成的封闭环。
已知滑槽内宽为增环 A1 = 40.00 mm（上偏差 +0.08 mm，下偏差 0 mm）；
滑块基体宽度为减环 A2 = 25.00 mm（上偏差 0 mm，下偏差 -0.06 mm）；
侧限位垫片厚度为减环 A3 = 14.00 mm（上偏差 +0.02 mm，下偏差 -0.04 mm）。
试用极值法计算间隙 A0 的极限尺寸与公差，并求统计公差 T0_rss（保留三位小数）。

解答过程：
1. 确定各组成环的极限尺寸与公差：
A1（增环）：最大 40.08 mm，最小 40.00 mm，公差 T1 = 0.08 mm。
A2（减环）：最大 25.00 mm，最小 24.94 mm，公差 T2 = 0.06 mm。
A3（减环）：最大 14.02 mm，最小 13.96 mm，公差 T3 = 0.06 mm。
2. 极值法计算封闭环 A0 的尺寸特征：
基本尺寸 A0 = 40.00 - 25.00 - 14.00 = 1.00 mm。
最大极限尺寸 A0_max = A1_max - A2_min - A3_min
                     = 40.08 - 24.94 - 13.96 = 1.18 mm。
最小极限尺寸 A0_min = A1_min - A2_max - A3_max
                     = 40.00 - 25.00 - 14.02 = 0.98 mm。
封闭环极值公差 T0 = A0_max - A0_min = 1.18 - 0.98 = 0.20 mm。
核算公差累加：T1 + T2 + T3 = 0.08 + 0.06 + 0.06 = 0.20 mm，结果一致。
3. 统计法 RSS 计算公差：
T0_rss = √(T1² + T2² + T3²) = √(0.08² + 0.06² + 0.06²)
       = √(0.0064 + 0.0036 + 0.0036) = √0.0136 ≈ 0.117 mm。

### 常见错误
- 增减环极值搭配颠倒：计算封闭环最小值时错误地用“增环最小减去减环最小”，
违背了极值最恶劣累积原则。
- 误以为减环公差可以在极值计算中抵消：封闭环公差是所有组成环公差的绝对和，
制造误差只会累积增大，不可相互抵消。
- 脱离批量前提盲目应用 RSS：在单件试制或小批量 3D 打印装配中强行套用 RSS，
忽视了 RSS 依赖大样本正态分布的统计前提。

## 单元小结
- 测量波动评估：重复性反映同人同量具同工位下的随机离散度，
再现性反映不同人或量具条件下的测量稳健性，常用极差和样本标准差量化。
- 合格边界控制：测量不确定度导致公差边界存在误收与误废风险；
内缩保护带可有效封堵误收缺陷，为分拣机构提供稳妥的执行依据。
- 尺寸累积分析：封闭环由装配间接形成，极值法通过算术极值累加保证 100% 互换，
统计法 RSS 借助方差合成原理为批量制造争取更经济的公差余量。
- 质检闭环应用：在桌面分拣站运行中，多次读数测定重复性、设置保护带判定良品、
依据尺寸链追查定位卡阻，构成了严密的测量数据工程分析闭环。
