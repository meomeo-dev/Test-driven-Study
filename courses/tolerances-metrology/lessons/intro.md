# 尺寸与公差

本单元围绕桌面质检分拣站工件的尺寸检测需求，系统讲解名义尺寸、极限尺寸、
极限偏差与公差带的定义、计算规则与图样标注方法，并阐明一般公差的工程含义。

## 本单元知识点
- 名义尺寸与尺寸标注：掌握名义尺寸定义，识别线性、直径 ⌀ 和半径 R，确定基准边。
- 极限尺寸与极限偏差：掌握上/下极限尺寸及偏差计算，能依据实测数据判定合格性。
- 公差标注与公差带：掌握对称公差、单向公差及极限尺寸标注，熟练计算尺寸公差。
- 一般公差：理解图纸未注公差管控原则，掌握精密（f）、中等（m）、粗糙（c）等级含义。

## 名义尺寸与尺寸标注

名义尺寸（又称基本尺寸）是设计时根据零件功能与强度要求确定的基准几何尺寸。
在桌面质检分拣站的定位夹具与打印工件中，图纸上的名义尺寸是计算极限尺寸和
检验偏差的理论起点，加工所得的实际物理尺寸通常围绕名义尺寸波动。

图样中的标注符号规定了被测要素的几何特征：
- 线性尺寸：直接标注数值，用于表示长、宽、高或孔距，单位默认为毫米（mm）。
- 直径符号 ⌀：用于整圆或大于半圆的圆弧，如分拣站定位销孔“⌀10”。
- 半径符号 R：用于半圆或小于半圆的过渡圆弧与倒角，如定位导向槽圆角“R4”。

尺寸起点的确立依赖基准边或基准面。零件在图样中通常以关键定位面或安装面作为
设计基准，质检人员在测量和分拣工件时，必须使测量量具与定位夹具的基准边对齐，
严禁随意变更加工与检验起点，以防基准不重合产生附加测量误差。

### 例题
【例题】在质检分拣站的 3D 打印滑块图纸上，底面为基准边，从底面至中心定位孔
标注线性尺寸 28 mm，定位孔标注为 ⌀12 mm，滑块顶部圆弧角标注为 R3 mm。
请说明上述三个标注的几何含义与测量基准。
【解答】
1. 28 mm 为线性名义尺寸，表示孔中心轴线到底面基准边的理论设计距离为 28 mm；
2. ⌀12 mm 中“⌀”表示圆形要素，孔的名义直径为 12 mm（名义半径为 6 mm）；
3. R3 mm 中“R”表示圆弧半径，说明顶部倒角圆弧的名义曲率半径为 3 mm；
4. 测量孔距时必须严格以底面作为基准边引出起始点进行量测。

### 常见错误
1. 混淆直径 ⌀ 与半径 R：误将 ⌀20 的圆孔当成半径 20 mm 测量，导致严重误判。
2. 误把名义尺寸当成实测合格值：名义尺寸是理想参数，实际打印件不可能绝对等于它。
3. 测量起点脱离基准边：检验时未从图纸规定的基准面测量，造成多重尺寸累积偏差。

## 极限尺寸与极限偏差

由于加工过程存在打印步进波动、热胀冷缩与刀具磨损，工件的实际尺寸（da 或 Da）
不可能绝对等于名义尺寸。为了保证互换性，设计图样规定了尺寸允许变动的两个极端，
即最大极限尺寸（上极限尺寸）和最小极限尺寸（下极限尺寸）。

极限偏差是极限尺寸减去名义尺寸的代数差：
- 上偏差：上极限尺寸减名义尺寸。孔用大写字母 ES 表示，轴用小写字母 es 表示。
  公式为：ES = Dmax − D 或 es = dmax − d。
- 下偏差：下极限尺寸减名义尺寸。孔用大写字母 EI 表示，轴用小写字母 ei 表示。
  公式为：EI = Dmin − D 或 ei = dmin − d。
- 极限偏差为代数差，其数值可以为正数、负数或零。

质检分拣判定准则：工件合格的充要条件是实际尺寸处于上极限尺寸与下极限尺寸之间，
即下极限尺寸 ≤ 实际尺寸 ≤ 上极限尺寸；或者实际偏差在上偏差与下偏差之间。
分拣站控制程序（PLC 或上位机）根据传感器和量具上传的实测数值执行此区间比对。

### 例题
【例题】分拣站待测销轴的名义尺寸 d = 20 mm，设计要求上极限尺寸 dmax = 20.02 mm，
下极限尺寸 dmin = 19.95 mm。分拣站传感器测得三个工件的实际尺寸分别为 20.01 mm、
19.94 mm 与 20.02 mm。求该轴的上偏差与下偏差，并判定三个工件是否合格。
【解答】
1. 计算上偏差 es = dmax − d = 20.02 − 20 = +0.02 mm；
2. 计算下偏差 ei = dmin − d = 19.95 − 20 = −0.05 mm；
3. 工件合格范围为 [19.95, 20.02] mm；
4. 实测 20.01 mm 处于合格区间内，合格；
5. 实测 19.94 mm 小于下极限尺寸 19.95 mm，超差不合格；
6. 实测 20.02 mm 恰好等于上极限尺寸，属于合格边界，判定合格。

### 常见错误
1. 偏差符号颠倒：错误地用名义尺寸减极限尺寸，将负偏差错算为正偏差。
2. 误判边界值：误以为等于上、下极限尺寸的工件是不合格品（闭区间边界仍合格）。
3. 混淆大小写代号：在标注或记录时将孔的偏差（ES/EI）与轴的偏差（es/ei）混用。

## 公差标注与公差带

尺寸公差（简称公差，用 T 表示）是允许尺寸的变动量。公差在数值上等于上极限尺寸
减去下极限尺寸，也等于上偏差减去下偏差。其计算公式为：
T = Dmax − Dmin = ES − EI（孔）或 T = dmax − dmin = es − ei（轴）。
因为上极限尺寸恒大于下极限尺寸，所以公差恒为绝对正值，绝不能为负数或零。

图样中常见的尺寸公差标注方式包括：
- 对称偏差标注：如 25 ± 0.05 mm，表示上偏差为 +0.05 mm，下偏差为 −0.05 mm，
  公差 T = 0.05 − (−0.05) = 0.10 mm。
- 非对称极限偏差标注：如 50 (+0.03, −0.01) mm，表示上偏差为 +0.03 mm，
  下偏差为 −0.01 mm，公差 T = 0.03 − (−0.01) = 0.04 mm。
- 极限尺寸直接标注：直接在图纸上标出尺寸最大值与最小值，如 19.98 ~ 20.05 mm。

公差带是指在公差带图解中，由代表上偏差和下偏差的两条直线所限定的区域。
公差带具有“大小”与“位置”两个基本要素：公差带的宽度由公差值决定，反映加工精度；
公差带相对于零线的位置由基本偏差决定。公差越小，加工与质检要求越高。

### 例题
【例题】分拣站定位夹具的安装凹槽宽度标注为 30 (+0.08, +0.02) mm。
请计算该尺寸的上极限尺寸、下极限尺寸及尺寸公差 T。
【解答】
1. 名义尺寸 D = 30 mm，上偏差 ES = +0.08 mm，下偏差 EI = +0.02 mm；
2. 上极限尺寸 Dmax = D + ES = 30 + 0.08 = 30.08 mm；
3. 下极限尺寸 Dmin = D + EI = 30 + 0.02 = 30.02 mm；
4. 尺寸公差 T = Dmax − Dmin = 30.08 − 30.02 = 0.06 mm
   （或验算 T = ES − EI = 0.08 − 0.02 = 0.06 mm）。

### 常见错误
1. 对称公差取值减半错误：将 20 ± 0.05 mm 的公差误算为 0.05 mm（实际是 0.10 mm）。
2. 误认为公差可以为负数：当上下偏差均为负数时，误将公差算成负值。
3. 混淆单向偏差与对称偏差：把单向偏差 (+0.05, 0) 误当作对称正负公差对待。

## 一般公差

一般公差是指在车间普通工艺条件下可以保证的公差，通常在图样上对单个尺寸不单独
逐个标注公差值，因此历史上常被称为“未注公差”。国家标准（GB/T 1804）规定了
线性尺寸的一般公差等级与极限偏差数值。

线性尺寸的一般公差分为四个精度等级：
- 精密级（代号 f，fine）：适用于精密仪器、高精模具等高精度非配合尺寸。
- 中等级（代号 m，medium）：机械加工与 3D 打印结构件中最常用的标准等级。
- 粗糙级（代号 c，coarse）：用于冲压、铸造、粗加工或次要外形轮廓。
- 最粗级（代号 v，very coarse）：用于粗放制作或精度要求极低的基础构件。

未注公差决不等于“没有公差”或“允许随意加工”。图样技术要求中若写明
“未注公差按 GB/T 1804-m 执行”，则图纸上所有未单独标注公差的线性尺寸，
必须依据其名义尺寸所在区间，严格执行标准中对应中等级（m）的极限偏差。
分拣站在判断未注公差零件时，CSV 质检日志应自动根据一般公差表调用合格判定门限。

### 例题
【例题】分拣站外壳一块挡板的长度名义尺寸为 80 mm，图样未注公差，技术要求注明
“未注公差按 GB/T 1804-m 执行”。已知在 GB/T 1804 中，>30~120 mm 尺寸段的
m 级极限偏差为 ±0.3 mm。求该挡板长度的上极限尺寸、下极限尺寸及公差 T。
【解答】
1. 查表得极限偏差为 ±0.3 mm，即上偏差为 +0.3 mm，下偏差为 −0.3 mm；
2. 上极限尺寸 = 80 + 0.3 = 80.3 mm；
3. 下极限尺寸 = 80 − 0.3 = 79.7 mm；
4. 尺寸公差 T = 80.3 − 79.7 = 0.6 mm（或 T = 0.3 − (−0.3) = 0.6 mm）。

### 常见错误
1. 误认为未注公差就是无限制加工：认为零件未注公差尺寸偏差几毫米均属合格。
2. 误解等级代号次序：误将粗糙级（c）当成比精密级（f）更高精度的等级。
3. 忽略名义尺寸分段：查找一般公差表时未区分尺寸所属分段，导致查错公差值。

## 单元小结
- 名义尺寸是尺寸计算的基础基准，图纸用线性数值、直径 ⌀ 与半径 R 明确要素特征。
- 极限尺寸是尺寸变动的允许边界，实际尺寸处于上、下极限尺寸闭区间内即判定合格。
- 极限偏差是极限尺寸与名义尺寸的代数差（可正、负、零）；公差恒为正值且等于上、下偏差之差。
- 一般公差（未注公差）分为 f、m、c、v 四个等级，确保图纸未单注尺寸依然有法可依。
- 质检分拣站的核心逻辑就是将各测点的实测数据与设定的极限尺寸比对，输出合格与超差信号。
