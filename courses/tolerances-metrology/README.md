# 公差配合与测量

从名义尺寸、上下限到卡尺测量和重复性检查。

## 学习起点

会读毫米、小数和区间。建议与参数化建模并行。

- 读尺寸标注 → 量试片 → 复测同一件 → 判断是否满足尺寸要求。

## 学完能做什么

- 从尺寸标注推导上下限。
- 区分名义尺寸、制造公差与测量波动。
- 用重复测量与基准件判断测量方法是否稳定。

**桌面质检分拣站实作**。用同一把卡尺重复测量一块打印件的同一特征 10 次，记录最大值、最小值和测量位置。

## 课程内容

1.1.0 版包含七个单元、26 个知识点和 129 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 尺寸与公差 | 名义尺寸与尺寸标注；极限尺寸与极限偏差；公差标注与公差带；一般公差 |
| 孔轴配合 | 孔、轴与基孔制；间隙、过盈与过渡配合；公差等级与配合代号；配合的选用 |
| 量具与读数 | 游标卡尺与数显卡尺；千分尺读数；塞规、量块与半径规；百分表与比较测量；分辨力、准确度与精密度 |
| 测量方法与误差 | 测量误差的来源；测量位置与操作方法；测量记录与数值修约；基准件与零点校准 |
| 几何公差 | 基准与基准体系；形状公差；方向与位置公差；跳动与表面粗糙度 |
| 测量数据分析 | 重复性与再现性；合格判定与测量不确定度；尺寸链与公差累积 |
| 检验实作 | 检验计划与记录表；卡尺重复测量（自评） |

“卡尺重复测量”是自评实作，没有练习题。
按[检验实作讲义](lessons/inspection.md)中的自评清单完成后，
在学习路径中标记已会。
