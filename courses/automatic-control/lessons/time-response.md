# 时域响应
本单元以桌面质检分拣站的电机与挡板控制为对象，系统学习时域响应特征、动态性能指标与稳态误差消除方法。

## 本单元知识点
- 一阶阶跃响应：掌握一阶系统阶跃响应数学模型、时间常数物理意义及响应进入误差带的动态规律。
- 二阶系统与超调：理解阻尼比和自然频率对响应形态的决定作用，掌握欠阻尼振荡与超调特性。
- 性能指标：掌握上升时间、峰值时间、调节时间、超调量与稳态误差的时域定义与图谱读取方法。
- 稳态误差：掌握终值定理的计算应用，理解比例控制的有差调节局限性及积分控制消除静差的机理。

## 一阶阶跃响应
在分拣站的传送带直流电机速度响应或温控模块中，动态特性通常可简化为一阶惯性环节。
其标准传递函数形式为：
G(s) = K / (τs + 1)
式中，K 为系统静态增益，τ 为时间常数。
当系统输入幅值为 A 的阶跃指令 r(t) = A·1(t) 时，零初始条件下的时域输出响应表达式为：
y(t) = K·A·(1 − e^(−t/τ)) (t ≥ 0)
响应曲线从原点单调上升，变化率逐步放缓，最终平稳趋近于稳态终值 y(∞) = K·A。

时间常数 τ 是决定一阶系统过渡过程快慢的核心参数：
当经过时间 t = τ 时，响应值为 y(τ) = K·A·(1 − e^(−1)) ≈ 0.632·K·A，
即实际输出达到最终稳态值的 63.2%；
当经过时间 t = 3τ 时，响应值达到稳态值的 95.0%，进入 ±5% 允许误差带；
当经过时间 t = 4τ 时，响应值为 y(4τ) = K·A·(1 − e^(−4)) ≈ 0.982·K·A，
即输出达到稳态值的 98.2%，此时正式进入 ±2% 的稳态误差带。
在工程实践中，通常以 4τ 作为一阶系统过渡过程结束的时间判据。

一阶响应在初始时刻 t = 0 的切线斜率等于 K·A/τ。
若系统始终维持初始变化速率，仅需经过时间 τ 即可到达稳态值。
时间常数 τ 越小，说明电机的电枢电感与机械转动惯量越小，转速建立过程越快。

### 例题
【例题】分拣站传送带电机的速度开环传递函数为 G(s) = 2.0 / (0.25s + 1)，单位为 (rad/s)/V。
电机初始处于静止状态，在 t = 0 时控制器输出幅值为 12 V 的阶跃控制电压。求：
1. 电机转速的时域响应表达式及稳态转速；
2. 电机转速达到稳态值 63.2% 所需的时间；
3. 电机转速进入 ±2% 稳态误差带所需的时间。
【解答】
根据一阶阶跃响应规律，输入幅值 A = 12 V，增益 K = 2.0，时间常数 τ = 0.25 s。
1. 电机转速时域响应表达式为：
   y(t) = 2.0 × 12 × (1 − e^(−t/0.25)) = 24·(1 − e^(−4t)) rad/s
   当时间趋于无穷大时，稳态转速为 y(∞) = 24 rad/s。
2. 当响应达到稳态终值的 63.2% 时，对应时间恰好为一个时间常数，
   即 t = τ = 0.25 s。
3. 当响应进入 ±2% 误差带时，对应输出达到 0.982·y(∞)，
   所需时间约为 t = 4τ = 4 × 0.25 s = 1.0 s。

### 常见错误
- 混淆时间常数与过渡时间：误以为 t = τ 时电机就已经完成提速过程。
  实际上此时转速仅达到终值的 63.2%，必须等待约 4τ 才能达到 2% 稳定运行精度。
- 遗漏对象增益系数 K：计算稳态终值时仅以输入信号幅值 A 作为输出终值，
  忽略了静态增益 K 的比例缩放作用导致终值计算错误。
- 误认为一阶系统存在超调：一阶惯性环节特征方程只有一个负实根，
  阶跃响应严格单调递增，绝不会出现超调或振荡现象。

## 二阶系统与超调
质检工位中的翻转分拣挡板和定位机构包含转动惯量与复位弹性，
其闭环动态过程通常呈现二阶系统特征。
标准二阶闭环传递函数通常表述为：
Φ(s) = ωn² / (s² + 2ζωn s + ωn²)
式中，ζ 为阻尼比，ωn 为无阻尼自然振荡角频率。
这两个特征参数决定了闭环特征根在复平面上的位置分布，并直接决定了系统的动态形态。

根据阻尼比 ζ 的取值范围，二阶系统的阶跃响应分为四种典型状态：
1. 欠阻尼（0 < ζ < 1）：特征根为具有负实部的共轭复根，
   阶跃响应呈现伴随超调的衰减振荡过程，是工程上应用最广的快速响应状态。
2. 临界阻尼（ζ = 1）：特征根为两个相等的负实根，
   阶跃响应单调上升且无任何超调，是在无超调前提下过渡时间最短的理想边界。
3. 过阻尼（ζ > 1）：特征根为两个不相等的负实根，
   系统动作迟钝缓慢，过渡过程漫长且无超调。
4. 无阻尼（ζ = 0）：特征根位于虚轴上，
   系统输出呈现永不衰减的等幅简谐振荡，无法自发稳定。

在分拣工作站中，翻转挡板若阻尼比过小（如 ζ < 0.4），挡板动作虽快但伴随剧烈晃动，
易撞击分拣料盒产生噪音与疲劳磨损；若阻尼比过大（如 ζ > 1.2），挡板动作迟滞，
无法跟上零件输送节奏。工程上通常折中选取 ζ 在 0.6 至 0.8 之间，兼顾响应速度与平稳性。

### 例题
【例题】分拣挡板位置伺服系统的闭环传递函数为 Φ(s) = 64 / (s² + 9.6s + 64)。
判断系统的阻尼状态，并求解系统的自然频率 ωn 与阻尼比 ζ。
【解答】
对比标准二阶闭环传递函数 Φ(s) = ωn² / (s² + 2ζωn s + ωn²)：
1. 分母常数项 ωn² = 64，解得自然振荡角频率 ωn = 8 rad/s。
2. 分母一阶项系数 2ζωn = 9.6，代入 ωn = 8 得：
   2 × ζ × 8 = 9.6，即 16ζ = 9.6，解得阻尼比 ζ = 0.6。
3. 由于 0 < ζ = 0.6 < 1，该系统处于欠阻尼状态，
   其位置响应将表现为伴随适度超调的衰减振荡过程。

### 常见错误
- 阻尼比与超调趋势反向判断：误认为阻尼比 ζ 越大超调越大。
  实际上阻尼比反映阻尼吸收振荡能量的能力，ζ 越小超调量越大，增大 ζ 会抑制超调。
- 自然频率与衰减系数混淆：误把一阶项系数 2ζωn 直接当作自然频率，
  计算阻尼比时漏除了系数 2，导致参数辨识错误。
- 混淆临界阻尼与过阻尼：误以为只要阶跃响应没有振荡就是临界阻尼，
  忽略了阻尼比过大（ζ > 1）时系统动态响应严重迟缓的过阻尼缺陷。

## 性能指标
为了定量评估分拣控制系统对指令的跟踪品质，工程中采用一组明确的时域性能指标。
这些指标通常直接从系统的阶跃响应曲线上提取，涵盖响应敏捷度、平稳性及最终精度。

常见阶跃响应性能指标定义如下：
1. 上升时间 tr：响应曲线从终值的 10% 上升到 90% 所需的时间
   （欠阻尼系统也常定义为响应曲线首次达到 100% 稳态终值所需的时间），表征初始敏捷度。
2. 峰值时间 tp：响应曲线越过稳态终值并达到第一个最大峰值点所对应的时间。
3. 超调量 σ%：响应的最大峰值 y(tp) 高出稳态终值 y(∞) 的百分比，即：
   σ% = [y(tp) − y(∞)] / y(∞) × 100%
   超调量反映了执行机构越过目标位置的剧烈程度，关系到机械限位与工件保护。
4. 调节时间 ts：响应曲线进入并在此后不再超出允许误差带
   （通常规定为稳态终值的 ±2% 或 ±5%）所需的最小时间。
   二阶欠阻尼系统进入 ±2% 误差带的调节时间估算公式为 ts ≈ 4 / (ζωn)。
5. 稳态误差 ess：当时间 t 趋于无穷大时，期望设定值与实际输出响应之差，
   即 ess = r(∞) − y(∞)。

在桌面分拣站中，要求挡板定位机构的调节时间 ts 严格小于相邻工件的传输间距时间，
同时超调量 σ% 必须受到严格限制，防止挡板撞损 3D 打印的定位夹具。

### 例题
【例题】测试分拣挡板的位置阶跃响应，目标位置设定为 50 mm。
挡板启动后在 t = 0.15 s 首次达到最大位移 60 mm，随后振荡衰减，
在 t = 0.40 s 后位移永久保持在 49 mm 至 51 mm 之间（±2% 误差带），稳态位移为 50 mm。
求该系统的峰值时间 tp、最大超调量 σ% 以及 ±2% 误差带下的调节时间 ts。
【解答】
根据定义从曲线特征数据读取：
1. 响应首次达到峰值的时间为 tp = 0.15 s。
2. 稳态终值 y(∞) = 50 mm，峰值 y(tp) = 60 mm，超调量为：
   σ% = (60 − 50) / 50 × 100% = 10 / 50 × 100% = 20%。
3. 响应曲线进入且不再超出 [49 mm, 51 mm] 误差带的最早时间点为 t = 0.40 s，
   因此调节时间 ts = 0.40 s。

### 常见错误
- 超调量计算基准错误：误将峰值直接除以终值作为超调量（如计算为 60/50 = 120%），
  遗漏了分子中的终值相减步骤。
- 调节时间早判误读：误把曲线第一次进入误差带的时间当成调节时间，
  忽略了欠阻尼振荡可能再次冲出误差带，调节时间必须以永久进入且不再超出为准。
- 混淆上升时间与峰值时间：将达到峰值的时间当成上升时间，
  忽略了上升时间仅衡量响应从 0 或 10% 上升到 90% 或 100% 的初始时间区间。

## 稳态误差
控制系统的瞬时误差定义为期望设定值与实际测量值之差：e(t) = r(t) − y(t)。
当过渡过程衰减结束、系统进入稳态后残留的恒定误差称为稳态误差 ess = lim(t→∞) e(t)。
若闭环系统稳定（即误差传递函数 E(s) 的所有极点均严格位于复平面左半开平面），
可直接运用拉普拉斯变换终值定理计算稳态误差：
ess = lim(s→0) [s · E(s)]

对于分拣传送带电机的速度控制，开环对象通常为一阶系统 G(s) = K / (τs + 1)。
若采用单位负反馈纯比例控制器（增益为 Kp），开环传递函数为 Gk(s) = Kp·K / (τs + 1)。
当施加幅值为 A 的阶跃设定指令 r(t) = A·1(t) 时，误差传递函数为：
E(s) = R(s) / (1 + Gk(s)) = (A/s) / [1 + Kp·K/(τs + 1)]
由终值定理求得其阶跃稳态误差为：
ess = lim(s→0) [s · E(s)] = A / (1 + Kp·K)
这说明：纯比例控制下一阶系统对阶跃输入的稳态误差为设定值的 1/(1 + K0) 倍
（其中 K0 = Kp·K 为开环直流增益）。纯比例控制器必须依靠误差存在才能产生控制电压，
因此系统始终存在固有静差。

为了彻底消除阶跃输入的稳态误差，必须在控制器中引入积分作用（I 控制）。
积分环节在前向通道中引入位于原点 s = 0 的极点，使系统类型提升为 1 型系统。
只要存在微小的稳态残差，积分器就会对误差随时间持续累加，驱动执行器输出不断加大，
直到实际输出严格等于设定值，实现阶跃输入下的零稳态误差。

### 例题
【例题】分拣电机速度系统开环传递函数为 G(s) = 2.0 / (0.1s + 1)。
控制器采用比例调节器 Kp = 4 构成单位负反馈闭环控制。
当给定幅值为 50 rad/s 的转速阶跃指令时，求系统的阶跃稳态误差 ess。
若要求稳态误差为零，应如何调整控制策略？
【解答】
1. 系统的开环直流增益为 K0 = Kp · K = 4 × 2.0 = 8。
2. 根据一阶系统比例控制在阶跃输入下的稳态误差公式：
   ess = A / (1 + K0) = 50 / (1 + 8) = 50 / 9 ≈ 5.56 rad/s。
3. 纯比例控制无论增益多大都无法在理论上彻底消除静差。
   若要求稳态误差完全为零，应在控制器中引入积分作用（构成 PI 控制器），
   利用积分累加效应使系统成为 1 型系统，从而在阶跃输入下彻底消除稳态误差。

### 常见错误
- 盲目增大比例增益：误以为只要无限提高比例增益 Kp 就能消除静差，
  忽略了高增益会导致系统超调激增甚至失稳，且物理驱动器存在电压饱和上限。
- 忽略终值定理稳定性前提：在系统闭环发散失稳的情况下依然机械套用终值定理计算，
  得出完全脱离实际物理过程的虚假稳态结果。
- 混淆输入类型对误差的影响：误以为引入积分后对任何输入（如斜坡输入）误差都能为零，
  实际上 1 型系统仅能完全消除阶跃输入的稳态误差。

## 单元小结
- 一阶系统的阶跃响应单调平稳无超调，时间常数 τ 决定响应快慢；t = τ 时完成 63.2%，约 4τ 时进入 ±2% 误差带并结束过渡过程。
- 二阶系统的动态特性由阻尼比 ζ 与自然频率 ωn 决定；欠阻尼（0 < ζ < 1）产生超调衰减振荡，工程中多取 0.6 至 0.8 实现兼顾平稳与速度的良好品质。
- 时域性能指标全面刻画控制质量：上升时间与峰值时间反映响应敏捷性，超调量度量冲击剧烈度，调节时间表征过渡期长度，稳态误差表征终态精度。
- 纯比例控制下一阶系统的阶跃稳态误差为 1/(1 + K) 倍设定值，存在固有静差；引入积分作用可在阶跃输入下彻底消除静差，实现高精度跟踪。
