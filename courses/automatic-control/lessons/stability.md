# 稳定性

本单元学习控制系统稳定性的数学定义与物理本质，掌握由闭环极点分布判定系统稳定性的基本方法，运用劳斯判据求解高阶系统及闭环稳定增益范围，
并深入剖析分拣站中控制器增益过大与传感器测量延迟引发机构抖动振荡的物理机理。

## 本单元知识点
- 稳定性与极点：理解渐近稳定与有界输入有界输出稳定，掌握闭环极点实部决定系统收敛性及一阶、二阶系统稳定的充要条件。
- 劳斯判据：掌握高阶特征方程劳斯表的构建法则、首列符号与右半平面极点关系，以及控制器稳定增益范围的代数计算。
- 增益、延迟与振荡：剖析比例增益过大对阻尼特性的劣化，理解传感器滤波滞后与数字控制采样延迟诱发闭环振荡的动力学成因。

## 稳定性与极点

控制系统的稳定性是系统正常工作并执行控制任务的首要前提。在桌面质检分拣站中，挡板电机接收定位指令后，不可避免会受到工件滑动碰撞或供电电压微小波动的瞬态扰动。
若系统在扰动撤销后能依靠自身负反馈机制自动恢复到原设定位置，则称该系统是渐近稳定的；若系统在任何有界输入信号驱动下，输出响应始终保持有界而不会发散到无穷大，
则称为有界输入有界输出（BIBO）稳定。反之，若扰动导致挡板持续失控晃动或剧烈撞击机械限位，则系统处于不稳定状态。

线性定常系统的稳定性完全由其闭环传递函数 T(s) 的极点位置决定。设系统的闭环特征方程为 A(s) = 0，方程的根即为闭环极点。若某个闭环极点为复数 p = σ + jω，
其对应的时域自由响应模态正比于 e^(pt) = e^(σt) × (cos(ωt) + j·sin(ωt))。极点的实部 σ 决定了该模态随时间的变化趋势：
- 当所有极点的实部均严格小于零（σ < 0，即极点全部严格位于复平面虚轴左侧的左半开平面）时，所有瞬态模态中的指数项 e^(σt) 随时间趋于无穷大时衰减至零，
  闭环系统是渐近稳定的。
- 若存在至少一个极点的实部大于零（σ > 0，位于右半复平面），该模态将随时间呈指数爆炸式发散，闭环系统不稳定。
- 若存在位于虚轴上的简单极点（σ = 0，如一对纯虚根），且其余极点均在左半平面，系统将产生等幅持续振荡，称为临界稳定（工程上不能保证输出衰减收敛，不属于渐近稳定）。

对于常见的一阶与二阶系统，稳定条件可直接由特征多项式系数直观判定：
- 一阶惯性系统：传递函数为 G(s) = K / (τs + 1)，特征方程为 τs + 1 = 0，极点为 s = -1/τ。系统稳定的充要条件是时间常数 τ > 0。
- 二阶系统：特征方程展开为 s² + a1·s + a0 = 0，与标准型 s² + 2ζωn·s + ωn² = 0 对应。根据二次方程求根公式与韦达定理，
  所有根均具有严格负实部的充要条件是：系数全部严格同号且大于零，即 a1 > 0 且 a0 > 0（对应阻尼比 ζ > 0 且自然频率 ωn > 0）。
  若任一系数小于或等于零，系统必然失稳或进入等幅振荡。

### 例题
分拣站挡板步进电机驱动板设计了位置闭环控制器，其闭环传递函数为：
T(s) = 25 / (s² + 6s + 25)
试求系统的闭环极点，判断系统是否渐近稳定，并计算其无阻尼自然振荡角频率 ωn 与阻尼比 ζ。

【解】
1. 令闭环传递函数的分母多项式等于零，得到特征方程：
   s² + 6s + 25 = 0
2. 利用一元二次方程求根公式计算闭环极点：
   s = (-6 ± √(6² - 4 × 1 × 25)) / 2 = (-6 ± √(-64)) / 2 = -3 ± j4
3. 闭环极点为一对共轭复数，其实部为 σ = -3。因为实部严格小于零（极点全部位于左半复平面），所以该闭环系统是渐近稳定的。
4. 对照标准二阶特征多项式 s² + 2ζωn·s + ωn² = 0：
   ωn² = 25，解得 ωn = 5 rad/s；
   2ζωn = 6，将 ωn = 5 代入得 10ζ = 6，解得阻尼比 ζ = 0.6。由于 0 < ζ < 1，系统的时域阶跃响应表现为衰减振荡并平稳收敛于目标设定值。

### 常见错误
- 混淆开环极点与闭环极点：误认为只要被控对象开环不稳定，闭环就无法稳定。实际上，负反馈的作用正是通过控制器重构闭环极点分布，
  能够将右半平面的开环不稳定极点拉入左半平面构建稳定的闭环系统；反之，开环稳定的对象若反馈增益设置不当也会导致闭环失稳。
- 误把传递函数零点作为稳定性依据：闭环零点仅改变各时域模态叠加时的振幅分配和相位差，完全不改变指数因子 e^(σt) 的衰减速率，稳定性严格由闭环极点决定。

## 劳斯判据

当分拣系统综合考虑了电机绕组电感、机械传动惯量及低通滤波环节时，闭环系统的特征方程往往达到三阶或更高阶。直接代数求解三阶及以上方程的高次根不仅计算极其繁琐，
且在包含未知控制器增益参数时难以直观显式表达。劳斯判据（Routh's Stability Criterion）提供了一种无需直接解方程、
仅通过特征多项式系数排列代数表格即可快速判定是否存在右半平面极点的方法。

设系统的闭环特征方程为：
a3·s³ + a2·s² + a1·s + a0 = 0，其中最高次系数满足 a3 > 0。
构建三阶系统的劳斯表如下：
```
s³ | a3   a1
s² | a2   a0
s¹ | b1    0
s⁰ | c1
```
其中各行新生元素的递推计算公式为：
b1 = (a2·a1 - a3·a0) / a2
c1 = (b1·a0 - a2·0) / b1 = a0

劳斯稳定性判据的核心结论为：
- 闭环系统渐近稳定的充要条件是劳斯表第一列的所有系数均严格大于零（与 a3 同号）。
- 若第一列元素出现符号改变，第一列元素符号改变的次数恰好等于特征方程在右半复平面（实部为正）的根的个数。
- 对于三阶系统，系统稳定的充要条件可以简化为：所有系数全部大于零（a3 > 0, a2 > 0, a1 > 0, a0 > 0），
  且满足交叉乘积不等式 a1·a2 > a0·a3。若控制器增益参数 Kp 包含在这些系数中，联立求解不等式组即可确定系统闭环稳定的增益取值范围。

### 例题
分拣输送带调速系统中，电机与负载的开环传递函数为 G(s) = Kp / (s·(s + 2)·(s + 4))，采用单位负反馈控制回路。
试用劳斯判据确定闭环系统保持渐近稳定时比例增益 Kp 的取值范围。

【解】
1. 闭环系统的特征方程由 1 + G(s) = 0 导出：
   s·(s + 2)·(s + 4) + Kp = 0
   展开并按 s 的降幂排列得：
   s³ + 6s² + 8s + Kp = 0
   对应系数为：a3 = 1，a2 = 6，a1 = 8，a0 = Kp。
2. 列出劳斯表：
```
s³ | 1       8
s² | 6      Kp
s¹ | b1      0
s⁰ | c1
```
   计算 s¹ 行元素：b1 = (6 × 8 - 1 × Kp) / 6 = (48 - Kp) / 6
   计算 s⁰ 行元素：c1 = Kp
3. 根据劳斯判据，闭环系统稳定要求劳斯表第一列元素全部严格大于零：
   a3 = 1 > 0（天然满足）
   a2 = 6 > 0（天然满足）
   b1 = (48 - Kp) / 6 > 0，解得 Kp < 48
   c1 = Kp > 0，解得 Kp > 0
4. 综合以上不等式，系统闭环稳定的比例增益范围为：0 < Kp < 48。

### 常见错误
- 仅计算增益上限而遗漏增益下限：部分学习者算出 b1 > 0 得到 Kp < 48，却忽视了 s⁰ 行对应常数项系数 Kp > 0 的要求。
- 颠倒交叉相乘的计算次序：劳斯表元素计算公式为主对角交叉减去副对角交叉并除以主元，容易误写成 (a3·a0 - a2·a1) / a2 导致分子正负号反转，
  得出完全错误的判决。

## 增益、延迟与振荡

在桌面质检工位的调试过程中，工程师常试图通过增大比例增益 Kp 来提高挡板动作的响应速度并消除机械摩擦引起的静差。然而，增益的提高直接影响了闭环特征根在复平面上的轨迹。
对于二阶及高阶系统，随着 Kp 增大，闭环主导极点的虚部增大而实部绝对值相对减小，等效阻尼比 ζ 显著下降。这在时域上表现为挡板到位时的超调量剧增、伴随明显的往复机械抖动；
一旦 Kp 超过临界稳定阈值，共轭极点越过虚轴进入右半平面，抖动将恶化为持续发散的剧烈撞击。

除了增益过大外，物理回路中的测量与传输延迟是诱发闭环振荡的另一大根源：
- 传感器滤波滞后：分拣光电传感器或霍尔测速编码器前端常接入 RC 滤波电路以抑制电气噪声，这引入了一阶惯性滞后 1 / (Ts + 1)。
- 纯时间延迟：视觉相机的曝光与目标识别算法处理、PLC 与执行器之间的总线通信，均会产生纯时间延迟 e^(-τd·s)。纯时间延迟不改变通过信号的幅值大小，
  但会带来随频率线性增加的相位滞后 -ω·τd。

延迟导致振荡与失稳的动力学机理在于“时效错位”。负反馈控制的有效性建立在反馈量能实时代表当前状态的前提下。当回路中存在显著延迟时，控制器依据接收到的“过时误差”下达纠偏指令。
当挡板实际上已加速越过目标中位线时，滞后的反馈仍报告“未到位”，驱使电机继续全速施力推进，造成严重的过度冲程；随后滞后的传感器终于测到过冲，控制器又以过大力度反向刹车回拉，
再次因为延迟过冲反转，最终使挡板陷入周而复始的极限环振荡或失稳崩溃。

在基于微控制器（如 STM32 或 PLC）的数字控制系统中，连续信号必须通过 ADC 周期性采样并经离散算法输出。ADC 离散采样与零阶保持器（ZOH）
在控制理论上等效于引入了大约半个采样周期的平均纯时间延迟（τd ≈ Ts / 2）。若为了降低 CPU 负载而将采样周期 Ts 设得过大，
由此引入的等效纯延迟将严重侵蚀系统的相位裕度，使得在模拟仿真中原本稳定的控制器增益在实际数字硬件上引发高频抖动。

### 例题
分拣工位传送带采用单片机进行电机闭环调速。在模拟域设计时，闭环系统的临界稳定增益为 Kp_max = 30。实际硬件实现时，
工程师分别测试了 Ts = 1 ms 和 Ts = 40 ms 两种采样周期。在保持比例增益不变的情况下，
发现 Ts = 40 ms 时电机速度在设定值附近产生强烈振荡无法停稳，而 Ts = 1 ms 时运行平稳。试运用采样延迟原理解释此工程现象，并给出硬件与算法层面的改善方案。

【解】
1. 微控制器离散控制中的采样周期 Ts 与零阶保持器在反馈回路中等效引入了大小约为 τd = Ts / 2 的纯时间延迟。
2. 当 Ts = 1 ms 时，等效延迟仅为 0.5 ms，其在系统工作频段内引入的附加相位滞后极小，对闭环极点分布影响微弱，系统保持足够的阻尼和稳定性。
3. 当 Ts = 40 ms 时，等效延迟剧增至 20 ms。延迟带来的严重相位滞后将原本位于左半平面的闭环主导共轭极点向虚轴推移甚至推入右半平面，
   表现为系统阻尼急剧恶化并产生持续的闭环振荡。
4. 工程改善方案：
   - 硬件与软件优化：缩短定时器中断采样周期 Ts（例如降至 2 ms 以下），减小等效延迟。
   - 控制算法调整：若硬件算力受限无法提升采样速率，则必须降低比例增益 Kp，或引入超前校正（如微分控制 Kd）来补偿相位滞后。

### 常见错误
- 误认为纯延迟仅平移波形而不影响稳定性：开环传输中纯延迟确实仅体现为波形滞后输出；但在闭环负反馈回路中，该滞后直接叠加到特征方程的相位中，会彻底改变闭环特征根轨迹，
  极易诱发振荡。
- 忽视微控制器数字化的隐藏延迟：误以为将连续传递函数直接用软件离散写出即可完全复现模拟性能，忽略了 ADC 采样、
  算法运算耗时以及零阶保持器引入的纯延迟对闭环稳定裕度的削弱效应。

## 单元小结
- 稳定性是控制系统可靠运行的绝对底线，闭环极点全部严格位于复平面左半开平面（实部为负）是线性定常系统渐近稳定的充要条件。
- 一阶和二阶系统只需特征多项式系数全正即可保证稳定；三阶及以上系统需借助劳斯判据，通过劳斯表第一列元素的符号判定右半平面极点数量及稳定增益范围。
- 比例增益过大会降低系统的等效阻尼比，导致阶跃响应出现强烈超调与往复振荡，超过临界极限将导致发散失稳。
- 传感器滤波滞后、图像运算耗时以及微控制器离散采样的等效保持延迟，会在反馈回路中引入显著的相位滞后，是工程中导致系统闭环振荡的常见根源。
