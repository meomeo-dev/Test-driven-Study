# 系统建模

本单元围绕桌面质检分拣站的执行机构与电机驱动，建立一阶系统的微分方程与传递函数模型，为后续分析系统动态响应与设计控制器提供数学与物理基础。

## 本单元知识点
- 一阶系统模型：掌握标准一阶微分方程形式、静态增益 K 与时间常数 τ 的物理本质及阶跃响应规律。
- 传递函数入门：理解复变量 s 的微分算子意义、一阶传递函数标准型及极点对动态快慢的影响。
- 直流电机速度模型：掌握电枢电压到转速的一阶近似推导、机械时间常数及负载转矩扰动的作用机制。

## 一阶系统模型
在桌面质检分拣站中，无论是贴标检测前的加热板升温过程，还是输送带电机的加速启动
过程，输出物理量都无法瞬时突变，而是受到物理惯性阻力而逐渐逼近目标。这类系统最典
型的简化描述就是一阶线性常微分方程模型。

一阶系统的标准时域微分方程表达为：
τ · dy(t)/dt + y(t) = K · u(t)
其中 u(t) 为系统的输入控制量（如驱动电压、加热功率），y(t) 为输出响应量（如皮带
线速度、表面温度）。
- 静态增益 K：表示系统达到稳定平衡时，输出变化量与输入变化量的比值，即
  K = Δy_ss / Δu。它衡量系统在稳态下的放大能力，量纲为输出量纲除以输入量纲。
- 时间常数 τ：量纲为时间（秒），表征系统响应的固有惯性与迟缓程度。τ 越大，系统
  抵抗变化的能力越强，过渡过程越慢；τ 越小，系统动态响应越敏捷。

当初始状态为零的一阶系统受到幅值为 U0 的阶跃输入时，其时域解析响应规律为：
y(t) = K · U0 · (1 − e^(−t/τ))
根据指数衰减特性，该响应曲线具备以下关键特征点：
- 当 t = τ 时，y(τ) = K·U0·(1 − e⁻¹) ≈ 0.632·K·U0，输出达到稳态值的 63.2%；
- 当 t = 3τ 时，y(3τ) ≈ 0.950·K·U0，响应达到稳态值的 95.0%；
- 当 t = 4τ 时，y(4τ) ≈ 0.982·K·U0，响应达到稳态值的 98.2%。
工程上普遍将 3τ 到 4τ 作为系统基本完成动态过渡、进入稳态的判断依据。

### 例题
质检分拣工位的物料进料皮带由直流驱动模块拖动。设定电机驱动电压从 0 V 阶跃增加至
10 V，通过光电编码器测得输送带稳定运行线速度为 0.8 m/s；从通电启动到线速度达到
0.506 m/s 耗时 0.4 秒。
(1) 求该进料皮带速度系统的静态增益 K 与时间常数 τ；
(2) 写出线速度 v(t) 随输入电压 u(t) 变化的标准微分方程。

【解】
1. 稳态线速度变化量 Δv_ss = 0.8 m/s，输入电压阶跃量 Δu = 10 V。静态增益为：
   K = Δv_ss / Δu = 0.8 / 10 = 0.08 (m/s)/V。
2. 测得线速度达到 0.506 m/s 时，刚好为稳态速度的 0.506 / 0.8 = 63.25% ≈ 63.2%。
   根据一阶系统阶跃响应规律，达到稳态值 63.2% 所需的时间即为时间常数，
   故 τ = 0.4 s。
3. 将 K 与 τ 代入一阶标准微分方程 τ·dv/dt + v = K·u，得到系统方程为：
   0.4 · dv(t)/dt + v(t) = 0.08 · u(t)。

### 常见错误
1. 混淆稳态增益与响应速度：误以为静态增益 K 越大的系统启动越快。实际上响应快慢
完全由时间常数 τ 决定，K 仅决定最终稳定时的幅值放大倍数。
2. 误认达到稳态的时间为 τ：误以为经过 1 个时间常数系统就完全进入稳态。实际上
经历 1 个时间常数输出仅完成约 63.2% 的过渡，工程上通常需要 3τ 至 4τ 才能达到
95% 以上的稳态。

## 传递函数入门
微分方程直接描述了物理量的时域导数关系，但在多环节串联、并联及包含负反馈的复杂
控制系统中，反复求解微分方程极为繁琐。拉普拉斯变换提供了一种将微积分运算转化为
复频域代数运算的强力工具。

在零初始条件下（即分析前系统处于静止平衡状态），拉普拉斯变换具有清晰直观的运算
对应关系：
- 对时间的一阶导数 d/dt 对应于复频域算子乘以 s；
- 对时间的一阶积分 ∫dt 对应于复频域算子乘以 1/s。

传递函数 G(s) 定义为：零初始条件下，系统输出信号的拉普拉斯变换 Y(s) 与输入信号
的拉普拉斯变换 U(s) 之比，即 G(s) = Y(s) / U(s)。
对一阶标准微分方程 τ·dy/dt + y = K·u 两端取拉普拉斯变换：
τ · s · Y(s) + Y(s) = K · U(s)
提取公因式得 (τs + 1) Y(s) = K U(s)，整理可得标准一阶传递函数：
G(s) = Y(s) / U(s) = K / (τs + 1)

令传递函数分母多项式等于零的复数根称为系统的极点（Pole）。对于一阶系统，极点
方程为 τs + 1 = 0，解得极点为 p = −1/τ。
极点的物理意义：
- 极点均位于复平面的负实轴上（当 τ > 0 时），决定了系统零输入响应的自由衰减
  模式 e^(p·t) = e^(−t/τ)；
- 极点距离虚轴越远（即 p 越负，τ 越小），系统的固有响应衰减越迅速，动态响应
  越快；
- 极点越靠近虚轴原点（即 p 接近 0，τ 越大），衰减过程越拖沓，系统动态响应
  越迟缓。

### 例题
桌面分拣站中的剔除气动执行挡板经线性化后，其传递函数为 G(s) = 12 / (0.6s + 3)，
输入为驱动控制信号 u(t)（单位：V），输出为挡板位移 y(t)（单位：mm）。
(1) 将传递函数化为标准一阶形式 G(s) = K / (τs + 1)，并求出静态增益 K 与时间常数 τ；
(2) 求该系统的极点位置；
(3) 若施加 2 V 的恒定阶跃电压，求挡板最终稳定的位移量。

【解】
1. 标准一阶传递函数分母常数项必须为 1。将分子与分母同时除以 3：
   G(s) = (12 / 3) / ((0.6 / 3)s + (3 / 3)) = 4 / (0.2s + 1)。
   对照标准形式可得：静态增益 K = 4 mm/V，时间常数 τ = 0.2 s。
2. 令分母为零：0.2s + 1 = 0，解得系统极点为 p = −1 / 0.2 = −5 rad/s。极点位于
   复平面的负实轴 −5 处。
3. 在恒定阶跃输入下（s = 0 处），稳态位移为：
   y_ss = G(0) · U0 = K · U0 = 4 mm/V × 2 V = 8 mm。

### 常见错误
1. 忽视传递函数定义的零初始条件前提：传递函数表征的是系统本身的固有传输动态，
在有非零初始状态时不能直接用 Y(s) = G(s)U(s) 计算全响应。
2. 未归一化分母常数项直接读取增益：对于形如 G(s) = A / (Bs + C) 的传递函数，
误将 A 当成静态增益 K。必须先将分母常数项 C 归一化为 1，此时分子 A/C 才是真正
的静态增益 K。

## 直流电机速度模型
在桌面质检分拣站中，传送带拖动与分流拨轮均采用小功率永磁直流电机。电机的输入为
电枢驱动电压 u(t)，输出为转子旋转角速度 ω(t)。直流电机由电枢电路与转子机械运动
两个子系统耦合构成：
- 电枢回路电压平衡方程：u(t) = R · i(t) + L · di(t)/dt + e_b(t)，其中感应反电动势
  e_b(t) = K_e · ω(t)，R 为电枢电阻，L 为电枢电感，K_e 为反电动势常数；
- 转子轴机械动力平衡方程：J · dω(t)/dt + B · ω(t) = T_e(t) − T_L(t)，其中电磁驱动
  转矩 T_e(t) = K_t · i(t)，J 为转子及负载的转动惯量，B 为机械粘性摩擦阻尼，
  K_t 为转矩常数，T_L(t) 为外部负载阻力矩。

对于中小功率电机，电枢电感 L 极小，电气时间常数 τ_e = L/R（通常为 1 毫秒以内）远
小于机械时间常数 τ_m（通常为数十毫秒至数秒，视惯量和阻尼而定）。因此在转速动态分析中，可忽略电感
动态项 L·di/dt，即电流近似为瞬时建立：
i(t) ≈ [u(t) − K_e · ω(t)] / R

将电流表达式代入转矩平衡方程并整理，得到：
J · dω/dt + B · ω = (K_t / R) · u − (K_t · K_e / R) · ω − T_L
合并角速度项：
J · dω/dt + (B + K_t·K_e / R) · ω = (K_t / R) · u − T_L
定义综合等效阻尼 B_eq = B + (K_t·K_e)/R。两端同除以 B_eq，得到电机速度的一阶标准
微分方程：
τ_m · dω/dt + ω = K_m · u − K_d · T_L
其中：
- 机械时间常数 τ_m = J / B_eq；
- 稳态速度增益 K_m = (K_t / R) / B_eq；
- 负载扰动灵敏度 K_d = 1 / B_eq。

负载变化作为扰动量：
在质检工位中，当相机判定不合格工件后推板介入，分拣拨轮受到工件冲击摩擦，相当于在
电机轴上施加了一个阻力矩阶跃 ΔT_L。在开环控制下，该扰动会导致稳态转速下跌
Δω = −K_d · ΔT_L。为克服负载扰动引起的降速，必须引入测速传感器并构成闭环负反馈
控制。

### 例题
桌面分拣拨轮电机的实测参数为：转动惯量 J = 0.008 kg·m²，机械粘性摩擦阻尼
B = 0.002 N·m·s/rad，电枢回路电阻 R = 2.5 Ω，转矩常数 K_t = 0.1 N·m/A，反电动势
常数 K_e = 0.1 V/(rad/s)。忽略微小的电枢电感。
(1) 计算电机系统的等效阻尼系数 B_eq；
(2) 计算电机的机械时间常数 τ_m 与稳态速度增益 K_m；
(3) 若施加 12 V 的恒定电枢驱动电压，在无外部负载转矩（T_L = 0）时，电机的稳态空载转速是多少？

【解】
1. 等效阻尼系数由机械粘性摩擦阻尼与反电动势电磁阻尼合成：
   B_eq = B + (K_t · K_e) / R = 0.002 + (0.1 × 0.1) / 2.5
        = 0.002 + 0.01 / 2.5 = 0.002 + 0.004 = 0.006 N·m·s/rad。
2. 计算机械时间常数与稳态速度增益：
   机械时间常数 τ_m = J / B_eq = 0.008 / 0.006 ≈ 1.33 s；
   稳态速度增益 K_m = (K_t / R) / B_eq = (0.1 / 2.5) / 0.006 = 0.04 / 0.006 ≈ 6.67 (rad/s)/V。
3. 在无负载阻矩且电压恒定为 12 V 时，稳态转速为：
   ω_ss = K_m · u = (0.04 / 0.006) × 12 = 0.04 × 2000 = 80 rad/s。

### 常见错误
1. 遗漏反电动势产生的电磁制动阻尼：误以为系统阻尼仅来自机械摩擦 B，忽略了
(K_t·K_e)/R 项。在很多直流电机中，反电动势电磁阻尼甚至显著大于机械摩擦本身。
2. 混淆控制输入与外部扰动：将负载转矩 T_L 当作受控输入。实际上电压 u 是控制器
主动施加的操纵量，而 T_L 是分拣工况中随机发生的外部机械负载扰动，它对转速产生
抑制跌落效应。

## 单元小结
- 物理系统的惯性使得输出响应无法瞬时突变，一阶标准微分方程 τ·dy/dt + y = K·u 中，
  静态增益 K 决定稳态放大能力，时间常数 τ 决定过渡快慢，经过 3τ 至 4τ 系统基本完成
  阶跃响应。
- 在零初始条件下，微分算子 d/dt 对应拉普拉斯算子 s，一阶传递函数 G(s) = K/(τs + 1)
  的极点为 p = −1/τ；极点位于复平面负实轴，离虚轴越远则系统动态衰减越快。
- 直流电机在忽略微小电枢电感后可近似为一阶速度系统；转动惯量与电磁阻尼共同决定了
  机械时间常数 τ_m。
- 分拣工序中的工件碰撞、滑动摩擦等工况变化构成了电机轴上的外部负载转矩扰动，会
  导致开环转速跌落，凸显了后续设计闭环负反馈控制器的必要性。
