# 频率特性与应用
本单元探讨系统在正弦输入下的频率响应与截止频率，解析伺服系统经典的三环串级架构，并通过阶跃响应数值仿真掌握电机速度控制的调参规律。

## 本单元知识点
- 频率响应入门：正弦稳态响应的幅值缩放与相位滞后，系统带宽及一阶系统截止频率。
- 速度环与位置环：串级控制思想、内快外慢频域解耦原则与伺服三环嵌套结构。
- 电机速度阶跃仿真（自评）：使用 Python 仿真一阶电机与离散 PI 控制器并对比参数响应。

## 频率响应入门
频率响应研究线性定常系统在正弦信号激励下的稳态输出特性。当给系统输入角频率为
ω 的正弦信号 u(t) = A·sin(ωt) 时，经过初始瞬态过程衰减后，系统的稳态输出仍是
同角频率的正弦信号 y(t) = B·sin(ωt + φ)。这表明线性系统不改变正弦信号的频率。

稳态输出幅值与输入幅值的比值称为幅频特性 M(ω) = B/A = |G(jω)|；输出信号相对于
输入信号的时间超前或落后换算成的角度称为相频特性 φ(ω) = ∠G(jω)。若 φ(ω) < 0，
则表明输出波形在时间上落后于输入波形，称为相位滞后。

对于分拣站电机常见的一阶速度传递函数 G(s) = K/(τs + 1)，其频率响应表达式为
G(jω) = K/(1 + jωτ)。其幅频特性为 |G(jω)| = K/√(1 + (ωτ)²)，相频特性为
φ(ω) = −arctan(ωτ)。当输入角频率增大时，幅值比持续衰减，相位滞后逐渐增加。

工程上定义幅值比衰减到直流增益 K 的 1/√2（约 0.707 倍）时所对应的角频率为截止
频率或带宽角频率 ωb。对于一阶系统，当 ω = 1/τ 时，ωτ = 1，此时幅值比恰为
|G(j(1/τ))| = K/√2 ≈ 0.707K，相位滞后恰为 45 度。带宽决定了系统能无失真复现输入
信号的最高频率范围；在分拣工位中，挡板快速启闭的指令主频必须处于系统带宽内。

在桌面质检分拣站的实际测试中，工程师通常利用信号发生器向电机驱动器注入不同频率
的正弦速度指令，通过编码器采集实际转速，绘制出幅值比与相位随频率变化的曲线。
这有助于在投入使用前评估机械连杆与减速箱是否存在共振风险。

### 例题
桌面质检分拣站的摆动挡板电机速度开环模型为 G(s) = 2/(0.05s + 1)。
求该电机的转折角频率（截止频率）ωb；若输入正弦测试信号 u(t) = sin(20t)，
求系统进入稳态后的速度输出表达式 y(t)。

解答步骤：
1. 确定系统参数：直流增益 K = 2，时间常数 τ = 0.05 s。
2. 计算截止角频率：由 ωb = 1/τ，得 ωb = 1/0.05 = 20 rad/s。
3. 计算在输入角频率 ω = 20 rad/s 时的幅值比：
   此时 ωτ = 20 × 0.05 = 1。
   幅值比 |G(j20)| = 2 / √(1 + 1²) = 2/√2 = √2 ≈ 1.414。
4. 计算稳态相位差：
   φ = −arctan(ωτ) = −arctan(1) = −45°（即滞后 45 度或 −π/4 rad）。
5. 稳态输出表达式为：
   y(t) = 1.414·sin(20t − 45°)。

### 常见错误
1. 误认为正弦输入经过线性系统后，稳态输出的角频率会加倍或衰减。线性定常系统
   在正弦激励下的稳态输出频率严格与输入频率相同。
2. 混淆截止频率与时间常数的关系，误将截止频率写为 ωb = τ，而正确的物理关系
   是两者互为倒数，即 ωb = 1/τ。
3. 计算输出幅值时，遗漏了系统的直流增益 K，只计算了标准化模型 1/√(1 + (ωτ)²)。

## 速度环与位置环
在桌面质检分拣站中，挡板机构不仅要求快速运行到位，还要求在到位瞬间平稳无晃动、
接触工件时不产生刚性冲击。单回路控制难以兼顾抗力矩扰动与精密定位的要求，
工业伺服驱动普遍采用串级控制（Cascade Control）架构。

伺服系统的经典三环结构自内向外依次为：
1. 电流环（转矩环）：最内环。直接控制电机电枢电流，快速抵消反电动势与电感迟滞，
   决定了电机的输出转矩动态。
2. 速度环：中间环。根据位置环给出的速度指令调节电机转速，实时抑制负载变化、
   机械摩擦突变对转速平稳性的干扰。
3. 位置环：最外环。根据工件分拣的目标角度指令生成速度目标，精确消除静态位置误差。

串级控制的核心准则是“内快外慢”。内环的响应速度必须显著快于外环，通常电流环的
控制带宽与采样频率是速度环的 3 至 5 倍以上，而速度环又是位置环的 3 至 5 倍以上。
当内环极快时，外环控制器在计算控制作用时可近似将整个内环视为无延迟的理想执行机构，
从而实现各控制回路在时域和频域上的解耦。

在分拣工位发生意外卡料时，串级结构表现出极高的安全性：电流环具有独立的饱和限幅，
可以直接限制电机的最大输出转矩，防止挡板打碎工件或烧毁电机绕组。
如果违反“内快外慢”原则而盲目加大外环增益，外环发出的剧烈变动指令将超出内环的
跟踪能力，导致内环饱和或严重相位滞后，引发整个机械结构的剧烈振颤甚至失稳。

### 例题
某分拣站挡板伺服电机配置了电流环、速度环和位置环。已知电流环控制周期为 50 μs，
速度环控制周期为 250 μs。位置环采用比例控制器，比例增益 Kp = 20 s⁻¹。
若挡板当前目标位置为 60 度，位置传感器检测到实际位置为 57 度，求此时位置环
输出给速度环的转速指令值，并说明为什么整定该系统时必须由内环向外环依次进行。

解答步骤：
1. 计算位置误差：
   e = 设定值 − 测量值 = 60° − 57° = 3°。
2. 计算转速指令：
   位置环为比例控制，输出指令 v_ref = Kp·e = 20 s⁻¹ × 3° = 60°/s。
3. 整定顺序的原因：
   整定外环必须建立在内环已经获得良好阻尼与快速跟踪特性的前提下。若先整定
   外环，内环参数尚未确定，其动态延迟与振荡会直接叠加到外环回路中，导致外环
   无法辨识对象模型并诱发系统发散。因此必须由内向外依次整定。

### 常见错误
1. 现场调试时先调节位置环参数，试图一步到位消除定位误差，造成电机剧烈抖动发热。
2. 认为三环的采样周期应设置完全相同；实际上内环动态快，需要更高的采样频率。
3. 误以为速度环能够直接消除位置稳态误差：速度环只调节转速，位置误差由位置环
   依据位置反馈修正。

## 电机速度阶跃仿真（自评）
目标：在计算机上通过数值仿真实现一阶直流电机速度模型与离散 PI 控制器，
观察在阶跃速度目标下系统的响应曲线，分析比例增益与积分增益对超调量与调节时间的影响。

材料或准备：配置 Python 3 环境并安装 matplotlib 绘图库，或者使用电子表格软件。
设定电机速度模型传递函数 G(s) = K/(τs + 1)，取增益 K = 1.0 (rad/s)/V，
时间常数 τ = 0.1 s；仿真步长取 Δt = 0.01 s，仿真时长 2.0 s，目标阶跃为 10 rad/s。

步骤：
1. 建立差分方程：利用前向或后向欧拉法离散化电机微分方程 τ·(dy/dt) + y(t) = K·u(t)，
   得到单步递推公式 y[k] = y[k−1] + (Δt/τ)·(K·u[k] − y[k−1])，其中 u[k] 由上一拍测量值
   y[k−1] 算出。
2. 实现离散 PI 算法：计算误差 e[k] = r[k] − y[k−1]；累加积分项
   I[k] = I[k−1] + e[k]·Δt；计算控制电压 u[k] = Kp·e[k] + Ki·I[k]，
   并加入驱动器输出限幅 [−12V, 12V]。
3. 运行第一组参数仿真（平稳响应）：设定 Kp = 1.5，Ki = 5.0，记录 0 到 2.0 秒内
   每一步的时间、目标值、电机实际速度、误差和控制电压。
4. 运行第二组参数仿真（快速激进）：设定 Kp = 4.0，Ki = 25.0，保持其余模型条件
   完全一致，重新运行数值仿真并记录数据。
5. 绘制并对比响应曲线：在同一张图表上分别绘制两组参数下的速度响应 y(t) 与控制量
   u(t) 曲线，对比两者的上升时间、超调量以及进入 ±2% 误差带的调节时间。

仿真核心算法代码参考：
```python
dt = 0.01          # 仿真步长 0.01 秒
tau, K = 0.1, 1.0  # 电机参数
Kp, Ki = 1.5, 5.0  # 离散 PI 参数
r = 10.0           # 目标阶跃速度 10 rad/s

y, integral = 0.0, 0.0
for step in range(200):
    e = r - y                         # 计算误差
    integral += e * dt                # 积分累加
    u = Kp * e + Ki * integral        # 控制量
    u = max(-12.0, min(12.0, u))      # 电压限幅
    y += (dt / tau) * (K * u - y)     # 欧拉差分更新模型速度
```

## 单元小结
- 线性系统对正弦输入的稳态输出同频，幅值比和相位差分别对应频率响应的模与相角。
- 一阶系统的转折频率为 ω = 1/τ，在此频率下幅值降为直流增益的 0.707 倍，相角滞后 45 度。
- 串级控制遵循“内快外慢”原则，伺服电机三环自内向外为电流环、速度环、位置环。
- 数值仿真直观展现了闭环系统的时域动态，合理的 PI 参数组合可在响应速度与超调量之间取得平衡。
