# PID 控制

本单元以桌面质检分拣站的驱动电机为对象，系统学习比例、积分、微分控制规律，掌握工程整定方法与抗积分饱和策略。

## 本单元知识点
- 比例控制：掌握控制量与误差成正比的规律，理解增大比例增益加快响应但加剧超调且存在残余稳态误差。
- 积分作用：掌握对误差历程累加的积分规律，理解消除稳态误差的机理及积分过强引发超调振荡的原因。
- 微分作用：掌握依据误差变化率提前预判的阻尼规律，理解抑制超调与改善动态响应及放大噪声的特性。
- PID 整定：掌握工程试凑流程与齐格勒–尼科尔斯临界比例度法，建立规范完整的参数整定记录。
- 积分饱和与执行器限幅：理解驱动器输出受限引发积分深度饱和的机理，掌握积分限幅与停止积分等抗饱和算法。

## 比例控制
比例控制（P 控制）是控制系统中最直观、基础的反馈控制规律。
定义系统误差为设定目标值与测量值之差：e(t) = r(t) − y(t)。
比例控制器的输出与当前瞬时误差成严格正比：
```
u(t) = Kp · e(t)
```
式中 Kp 称为比例增益。误差为零时比例项输出为零，误差越大输出控制量越大。
在分拣站输送带与挡板驱动电机调速中，增大 Kp 能显著提高开环增益，
加快系统响应速度并减小上升时间。然而过大的 Kp 会降低系统阻尼，
导致超调量增大、振荡加剧，甚至破坏闭环系统的稳定性。
对于一阶惯性或零型系统（如直流电机速度环），纯比例控制必然存在残余稳态误差。
电机为克服负载摩擦阻力维持转速必须有非零输出 u(t) > 0；
由 u = Kp · e 可知稳态误差 e 绝不可能收敛至零。
若电机速度静态增益为 K，闭环阶跃稳态误差为 ess = r / (1 + Kp · K)。
增大 Kp 可以减小稳态误差，但无法彻底将其消除。

### 例题
【题目】分拣站电机转速传递函数简化为 G(s) = 2/(0.1s + 1)，输入为控制电压 u(V)，
输出为转速 y(r/min)。系统采用纯比例控制器 u(t) = Kp · e(t)，
设定转速为 r = 600 r/min 的阶跃输入。当设置 Kp = 2 V/(r/min) 时，
求系统稳态时的电机转速 y(∞) 与残余稳态误差 ess。
【解答】
第一步：电机的直流静态增益为 K = G(0) = 2 (r/min)/V。
第二步：开环传递函数为 G_open(s) = Kp · G(s) = 4/(0.1s + 1)。
闭环传递函数为：
```
Φ(s) = 4 / (0.1s + 5) = 0.8 / (0.02s + 1)
```
第三步：对阶跃输入 r = 600 r/min，应用终值定理得稳态转速：
y(∞) = Φ(0) · r = 0.8 × 600 = 480 r/min。
第四步：计算残余稳态误差：
ess = r − y(∞) = 600 − 480 = 120 r/min。
也可直接由公式计算：ess = r / (1 + Kp · K) = 600 / (1 + 4) = 120 r/min。

### 常见错误
1. 误以为只要比例增益 Kp 足够大，就能在没有积分项的情况下彻底消除零型系统的稳态误差。
2. 混淆比例控制与位式开关控制，误将线性比例输出当成全开全关状态。

## 积分作用
积分控制（I 控制）通常与比例控制配合构成 PI 控制器，连续时域表达式为：
```
u(t) = Kp · e(t) + Ki · ∫ e(τ) dτ
```
式中 Ki 为积分增益，也可表示为 Kp/Ti，Ti 为积分时间常数。
积分项对误差的历史累积量进行连续累加。只要系统存在哪怕极微小的静差，
积分项输出就会持续增长，迫使执行器加大动作力度。
当测量值完全达到设定值、误差归零（e = 0）时，积分项停止变化并保持当前输出，
恰好维持克服负载阻力所需的恒定控制量，从而从根本上消除稳态误差。
积分环节在开环传递函数中引入了一个原点极点 1/s，提升了系统型别。
但积分作用会带来 90° 的相位滞后，降低系统的相位裕度与阻尼比。
如果积分增益 Ki 设定过大，会导致系统阶跃响应超调剧烈甚至产生发散振荡。

### 例题
【题目】在桌面分拣站的电机数字调速程序中，采样周期为 Δt = 0.01 s。
PI 控制器采用离散积分累加形式：u_I(k) = u_I(k-1) + Ki · e(k) · Δt。
已知 Ki = 15 V/(r/min·s)，上一时刻积分项历史累计值为 u_I(k-1) = 3.2 V。
若当前时刻检测到转速误差为 e(k) = 40 r/min，求当前时刻的积分项输出 u_I(k)。
【解答】
第一步：计算当前采样周期的积分单步增量：
Δu_I = Ki · e(k) · Δt = 15 × 40 × 0.01 = 6.0 V。
第二步：将增量加至上一时刻的历史累加值上：
u_I(k) = u_I(k-1) + Δu_I = 3.2 + 6.0 = 9.2 V。
说明只要误差保持为正，积分项就会在原有水平上持续累加，迫使误差归零。

### 常见错误
1. 误以为积分控制是根据误差的变化速度来反应，实际上积分项反映的是误差的历史累积总量。
2. 误以为引入积分作用能改善系统稳定性，忽视了积分环节带来的 90° 相位滞后与振荡风险。

## 微分作用
微分控制（D 控制）通常与比例、积分控制结合使用。PD 控制器的表达式为：
```
u(t) = Kp · e(t) + Kd · (de(t)/dt)
```
式中 Kd 为微分增益，也可写为 Kd = Kp · Td，Td 为微分时间常数。
微分项反映的是误差的变化趋势（变化率）。
当转速快速逼近目标值时，输出快速爬升，误差迅速缩减，de/dt 为负值。
此时微分项输出负的控制量，提前施加阻尼制动，
从而显著减小超调量并缩短调节时间，有效增加了系统的相对稳定性和相位裕度。
但微分项不能单独使用，也无法消除稳态误差。
当系统达到稳态时误差为常数，de/dt = 0，微分输出完全为零。
在工程中，微分环节对高频噪声具有强烈的放大效应。
编码器量化噪声和电磁干扰经微分后会产生尖锐脉冲，导致执行器抖动发热。
因此工业实务中必须配合低通滤波器使用不完全微分。

### 例题
【题目】分拣站挡板驱动电机转角调节中，设定目标为 90°。
在 t = 0.5 s 时误差随时间变化关系为 e(t) = 20 − 100t（单位为度，t 为秒）。
PD 控制器参数为 Kp = 0.5 V/°，Kd = 0.02 V·s/°。
计算在 t = 0.5 s 时刻，比例项输出、微分项输出及 PD 总控制输出量 u(0.5)。
【解答】
第一步：计算 t = 0.5 s 时的瞬时误差：
e(0.5) = 20 − 100 × 0.5 = −30°。
第二步：计算误差的一阶导数：
de/dt = d(20 − 100t)/dt = −100 °/s。
第三步：分别计算比例项和微分项的输出量：
比例项输出：u_P = Kp · e(0.5) = 0.5 × (−30) = −15 V。
微分项输出：u_D = Kd · (de/dt) = 0.02 × (−100) = −2 V。
第四步：计算总控制量：
u = u_P + u_D = −15 + (−2) = −17 V。
说明微分项在误差向负向恶化时提前产生反向制动作用。

### 常见错误
1. 误以为微分项可以消除常值静态误差，忽视了稳态时误差变化率为零的事实。
2. 在传感器信号包含较强未滤波噪声时盲目调大 Kd，导致执行器剧烈震颤损耗机构。

## PID 整定
全功能 PID 控制器将三种作用结合：
```
u(t) = Kp · e(t) + Ki · ∫ e(τ) dτ + Kd · (de(t)/dt)
```
PID 参数整定是指确定最优的 Kp、Ki、Kd 参数组以兼顾响应速度与稳定性。
工程最常用的经验调参方法是“先 P 后 I 再 D”的试凑法：
1. 先置 Ki = 0，Kd = 0，逐步增大 Kp，直到响应速度满意且有轻微超调。
2. 保持 Kp，由小到大引入 Ki，消除残余稳态误差，直到稳态误差完全归零。
3. 引入 Kd，抑制超调并平抑振荡，最后对三者综合微调。
齐格勒–尼科尔斯（Ziegler–Nichols）临界比例度法是经典的工程方法：
闭环下置 Ki = 0、Kd = 0，逐渐增大 Kp 直至系统输出呈现等幅持续振荡。
记录临界增益 Ku 与振荡周期 Tu，按经典经验公式整定：
```
Kp = 0.6 · Ku,   Ti = 0.5 · Tu (Ki = 1.2 · Ku / Tu),   Td = 0.125 · Tu (Kd = 0.075 · Ku · Tu)
```
整定过程中必须完整记录每次调试的阶跃幅值、上升时间、超调量与调节时间。

### 例题
【题目】在桌面分拣站电机调速实验中，置 Ki = 0，Kd = 0。
增大比例增益至 Kp = 8.0 V/(r/min) 时，电机转速呈现等幅持续正弦振荡，
测得相邻波峰间隔时间为 0.50 s。采用经典齐格勒–尼科尔斯临界比例度法，
求整定出的 PID 参数 Kp、Ki 与 Kd。
【解答】
第一步：识别临界参数：Ku = 8.0 V/(r/min)，Tu = 0.50 s。
第二步：代入经典公式计算：
比例增益：Kp = 0.6 × Ku = 0.6 × 8.0 = 4.8 V/(r/min)。
积分增益：Ki = 1.2 × Ku / Tu = 1.2 × 8.0 / 0.50 = 19.2 V/(r/min·s)。
微分增益：Kd = 0.075 × Ku × Tu = 0.075 × 8.0 × 0.50 = 0.3 V·s/(r/min)。
第三步：整定参数组为 Kp = 4.8，Ki = 19.2，Kd = 0.3。

### 常见错误
1. 试凑整定时没有遵循顺序，同时任意变动多个参数，导致调试方向混乱。
2. 在临界法测试中，将执行器机械限幅削顶的非线性振荡误判为线性系统的临界等幅振荡。

## 积分饱和与执行器限幅
所有实际物理执行器都存在输出能力上限（如驱动板电源最大只能输出 24 V）。
在系统受到大阶跃输入或负载突变时，算法计算出的输出 u(t) 会远超物理上限，
执行器实际输出只能被动卡在饱和极限。
若此时积分项仍在对大误差无休止累加，积分值会膨胀到极大数值，称为积分饱和。
当测量值追赶上设定目标、误差转为负值时，由于内部积分量极度庞大，
必须经历漫长的负误差反向积分才能退出饱和，导致电机转速产生巨大的超调与调节滞后。
解决积分饱和的常用抗饱和（Anti-windup）策略包括：
1. 积分限幅法：对积分项内部累加值施加人为设定的上下限数值钳位。
2. 积分分离与积分冻结：误差较大时切除积分仅用 PD；
当执行器进入物理饱和且误差方向加剧饱和时，立即冻结积分累加。

### 例题
【题目】分拣电机驱动板最大输出限制为 24 V。启动阶段由于未配置抗饱和，
内部积分项累加到了 54 V。当电机转速追平目标值后，转速继续上升，
产生平均为 e = −15 r/min 的反向误差。已知 Ki = 4 V/(r/min·s)。
求内部积分项从 54 V 退饱和至允许退出的边界 24 V 所需的时间。
【解答】
第一步：计算需要回退的积分电压差量：
Δu_I = 54 − 24 = 30 V。
第二步：计算在反向误差下积分项回退速率：
|du_I/dt| = Ki × |e| = 4 × 15 = 60 V/s。
第三步：计算退饱和所需时间：
t = Δu_I / 60 = 30 / 60 = 0.5 s。
说明执行器在这 0.5 s 内仍被死死按在最大输出，造成严重超调。

### 常见错误
1. 仅在控制算法输出端进行软件限幅截断，误以为这样就能阻止内部积分项的过度累加。
2. 误以为抗积分饱和算法会牺牲系统的稳态精度，实际上它仅在大信号饱和期间介入。

## 单元小结
- 比例控制依据当前误差成比例快速动作，但零型系统在负载干扰下必有残余稳态误差。
- 积分控制利用对历史误差的累加彻底消除稳态误差，但带来相位滞后，增益过大会诱发剧烈振荡。
- 微分控制依据误差变化趋势提前实施反向阻尼制动，抑制超调并加速收敛，但易受高频噪声干扰。
- 工程整定应严格遵循先 P 后 I 再 D 的科学顺序，或借助临界比例度法确定基准并规范记录。
- 面对物理执行器输出限幅，必须配置积分限幅或积分冻结等抗饱和策略以防止大超调。
