# 离散采样与数字控制

本单元学习微控制器如何通过固定周期采集连续物理信号、用差分与累加实现离散 PID 算法，以及利用一阶低通滤波消除测量噪声并权衡控制延迟。

## 本单元知识点
- 采样周期与混叠：掌握采样周期与采样频率的换算、针对系统时间常数的周期选取经验法则，以及欠采样引发的信号混叠现象与防范措施。
- 离散 PID 实现：掌握位置式与增量式 PID 的离散差分公式、定时中断调用的必要性，以及工程实现中的注意事项。
- 测量噪声与滤波：掌握一阶低通滤波算法的数学形式、加权系数 α 对噪声抑制与相位延迟的影响，以及滤波对闭环稳定性的制约。

## 采样周期与混叠
连续物理世界与微控制器数字处理之间的核心桥梁是周期性采样。
单片机通过模数转换器（ADC）或光电编码器接口，每隔固定时间间隔 T
读取一次传感器输出的物理量。时间间隔 T 称为采样周期（单位为秒 s），
其倒数 fs = 1/T 称为采样频率（单位为赫兹 Hz）。
在分拣站的输送电机调速系统中，若测速编码器每隔 10 ms 读取一次计数值，
则采样周期 T = 0.01 s，对应的采样频率 fs = 100 Hz。

采样周期 T 的选取必须与受控对象的动态响应速度严格匹配。
对于直流电机等可以用一阶惯性模型描述的系统（传递函数为 K/(τs + 1)），
其响应快慢由时间常数 τ 决定。
在工程实践中，为保证离散控制能够平滑逼近连续控制效果，
通常按照经验法则选取采样周期：
T 应该取系统时间常数 τ 的 1/10 到 1/20，即 T ≤ τ/10。
如果采样周期 T 选得过大（例如接近或超过时间常数 τ），
微控制器在两次采样之间无法感知系统的动态演化，
在控制回路中等效引入了显著的纯时间滞后，
极易导致原本稳定的闭环系统产生大幅超调甚至发散失稳。
反之，若采样周期 T 选得过小，不仅会成倍增加微处理器的运算负担，
还会因相邻采样值差值极小而放大数值量化误差。

混叠（Aliasing）是离散采样系统中由于采样频率不足而产生的典型失真现象。
根据奈奎斯特-香农采样定理，要无失真地重构或识别最高频率为 f_max 的连续信号，
采样频率 fs 必须大于信号最高频率的两倍，即 fs > 2·f_max。
频率上限 fn = fs/2 称为奈奎斯特频率。
当传感器检测信号中混入高于 fn 的高频干扰（如传送带电机机械振动、电网噪声）时，
这些高频信号在采样后会“折叠”假冒为低于 fn 的低频信号。
例如采样频率为 100 Hz 时，奈奎斯特频率为 50 Hz；
若现场存在 85 Hz 的传送带机械振动，由于 85 Hz 高于 50 Hz，
采样后将被混叠为 |85 − 100| = 15 Hz 的假低频波动。
控制器会把该假低频波动误当作真实的电机转速波动进行反向补偿，
造成分拣电机转速莫名晃动甚至执行器机构严重磨损。
防止混叠的根本方法是提高采样频率，或在 ADC 采样前串接模拟硬件抗混叠滤波器。

### 例题
桌面分拣站的分拣挡板驱动电机速度回路可近似为一阶系统，时间常数 τ = 80 ms（0.08 s）。
（1）若按照工程经验法则 T ≤ τ/10，控制器允许的最大采样周期是多少毫秒？
对应采样频率至少为多少赫兹？
（2）若分拣工位处传送带运行产生 75 Hz 的机械振动，
为了避免该机械振动被误采混叠为假低频扰动，微控制器的采样频率最低需达到多少赫兹？

解答：
（1）根据经验法则，采样周期最大允许值为：
T_max = τ / 10 = 80 ms / 10 = 8 ms。
将其换算为采样频率：
fs_min = 1 / T_max = 1 / 0.008 s = 125 Hz。
因此采样周期应不超过 8 ms，采样频率至少应为 125 Hz。
（2）根据采样定理，为避免 75 Hz 的高频振动发生频谱混叠，
采样频率必须严格大于信号最高频率的 2 倍：
fs > 2 × f_vibration = 2 × 75 Hz = 150 Hz。
因此微控制器测速采样的频率最低必须达到 150 Hz（对应采样周期 T < 6.67 ms）。

### 常见错误
1. 误以为“采样周期越小越好”，盲目将采样频率推到极高，
导致单片机 CPU 负载过重，并在计算差分微分时因浮点或整型截断误差放大噪声。
2. 误将采样周期 T 选得过大（例如设为与系统时间常数 τ 接近），
导致数字控制回路产生严重的相位滞后，引发电机转速剧烈振荡。
3. 忽略采样定理与混叠现象，直接对受高频振动干扰的传感器信号以较低频率采样，
把高频噪声错当成低频速度误差去调节。

## 离散 PID 实现
连续时间 PID 控制器的标准时域表达式为：
u(t) = Kp · e(t) + Ki · ∫ e(τ) dτ + Kd · (de(t) / dt)。
在单片机或 PLC 等数字控制系统中，连续的时间积分与导数无法直接计算，
必须在等间隔采样周期 T 下进行数值离散化。
常用的离散化方法为：
积分项用矩形数值积分（误差累加）逼近，即 ∫ e(τ) dτ ≈ Σ eᵢ · T；
微分项用一阶后向差商逼近，即 de(t) / dt ≈ (eₖ − eₖ₋₁) / T。
其中 eₖ 为当前第 k 拍的误差（eₖ = 设定值 − 测量值），eₖ₋₁ 为前一拍误差。

位置式 PID 直接计算当前拍执行机构所需的绝对控制输出量 uₖ：
```
uₖ = Kp · eₖ + Ki · T · Σ eᵢ + Kd · (eₖ − eₖ₋₁) / T
```
在代码实现中，积分部分通常维护一个全局累加变量：
sum_error = sum_error + eₖ，
然后输出 uₖ = Kp · eₖ + Ki · T · sum_error + Kd · (eₖ − eₖ₋₁) / T。
位置式 PID 的输出直接对应执行机构的实际控制物理量，
例如输出对应电机驱动驱动桥的 PWM 占空比或施加给电机的控制电压。
其局限在于：由于每次输出都依赖历史所有误差的累加和，
当执行机构遇到物理饱和（如电机驱动达到最大 100% 占空比）时，
若不增加抗积分饱和算法，累加和会持续无限增长，
在目标反向调整时产生极长时间的迟滞和巨大的超调。

增量式 PID 则专注于计算当前拍控制量相对于前一拍的增量 Δuₖ = uₖ − uₖ₋₁：
```
Δuₖ = Kp · (eₖ − eₖ₋₁) + Ki · T · eₖ + Kd · (eₖ − 2eₖ₋₁ + eₖ₋₂) / T
```
控制器输出增量 Δuₖ 后，实际控制量可通过软件自累加 uₖ = uₖ₋₁ + Δuₖ 获取，
或者直接输出给步进电机驱动器、电动调节阀等天然具备步进积分特性的执行机构。
增量式 PID 的优势十分突出：
计算时仅需要记忆最近三拍的误差值（eₖ、eₖ₋₁、eₖ₋₂），无需保存历史所有误差总和；
算法内部不包含全局误差累加项，容易进行限幅和抗积分饱和处理；
当系统在手动控制与自动控制之间相互切换时，输出不会发生突变跳变，能实现平滑无扰切换。

无论是位置式还是增量式 PID，算法代码都必须置于严格等间隔的硬件定时中断中执行。
严禁将 PID 计算程序随意放置在未经时间锁定的主循环（while 循环）中执行。
因为公式中的积分系数因子 (Ki · T) 和微分除数因子 (Kd / T) 都默认 T 是绝对恒定值。
如果循环调用时间不稳定（存在抖动），相当于每次执行时等效的 Ki 和 Kd 都在随机漂移，
不仅会导致系统动态特性无法预测，还会严重恶化控制品质甚至导致闭环失稳。

### 例题
在桌面分拣站的输送电机速度控制系统中采用位置式 PID 算法，
单片机通过硬件定时器中断每隔 T = 0.02 s 执行一次 PID 计算。
设定控制器增益参数为 Kp = 2.0，Ki = 5.0 s⁻¹，Kd = 0.04 s。
系统记录到上一采样拍误差 eₖ₋₁ = 1.0 V，当前拍误差 eₖ = 1.5 V，
从控制启动到当前拍的所有采样误差累加和 Σᵢ₌₁ᵏ eᵢ = 20.0 V。
求当前采样拍控制器计算出的控制输出电压 uₖ。

解答：
根据位置式 PID 离散计算公式，分项计算比例、积分和微分贡献：
比例项贡献：
P_out = Kp · eₖ = 2.0 × 1.5 V = 3.0 V。
积分项贡献（误差累加乘以采样周期与积分增益）：
I_out = Ki · T · (Σ eᵢ) = 5.0 s⁻¹ × 0.02 s × 20.0 V = 2.0 V。
微分项贡献（后向差商乘以微分增益）：
D_out = Kd · (eₖ − eₖ₋₁) / T = 0.04 s × (1.5 V − 1.0 V) / 0.02 s
D_out = 0.04 s × 0.5 V / 0.02 s = 1.0 V。
将三项相加得到当前拍总输出电压：
uₖ = P_out + I_out + D_out = 3.0 V + 2.0 V + 1.0 V = 6.0 V。

### 常见错误
1. 在裸机开发中将 PID 控制函数直接放在 main 函数的 while(1) 循环内执行，
未配合定时器中断，导致每次运行的时间间隔随代码分支改变而剧烈抖动。
2. 编写代码时忽略了采样周期 T 对积分和微分的影响，
误将离散公式中的 Ki·T 当成 Ki、Kd/T 当成 Kd 编写，
使得现场一旦调整采样频率，原本整定好的 PID 参数完全失效。
3. 使用位置式 PID 时未对累加项设置上下限保护（未作抗积分饱和），
当分拣机构受到堵转等强扰动时累加和爆表，导致电机在恢复时严重失控超调。

## 测量噪声与滤波
在工业现场与桌面分拣站中，传感器测量信号不可避免地会混入各种高频随机噪声。
例如光电编码器的测速量化脉冲抖动、电磁干扰以及机械微小震颤。
这种高频测量噪声在微分控制项 Kd · (eₖ − eₖ₋₁) / T 中具有灾难性的破坏力。
当采样周期 T 很短时（如 5 ms），哪怕传感器读数仅出现微小的随机单拍跳动，
差分 (eₖ − eₖ₋₁) 除以微小的 T 也会被巨额放大成巨大的剧烈冲击尖峰。
这种剧烈跳变的控制量输出不仅无法提供有效阻尼，
还会导致执行器（如直流电机、分拣舵机）剧烈发抖、发出刺耳啸叫，
加速机械齿轮磨损并引起电机驱动芯片异常发热。

一阶数字低通滤波是工业数字控制中最经典且计算开销极小的降噪算法。
其离散时域递推差分方程为：
```
yₖ = α · xₖ + (1 − α) · yₖ₋₁
```
其中 xₖ 为当前时刻传感器采集到的原始带噪数据，
yₖ₋₁ 为上一时刻滤波器计算出的滤波输出，
yₖ 为当前时刻更新后的滤波输出值，
α 为滤波系数（加权因子），其取值范围严格限定在 0 < α ≤ 1 之间。
该差分方程在物理本质上等价于连续域一阶低通惯性滤波器 1 / (τ_f · s + 1)。
嵌入式微处理器仅需执行一次浮点或定点乘加计算，即可高效抑制高频噪声。

滤波系数 α 的数值决定了系统在“平滑度”与“实时性”之间的平衡：
α 代表当前采样测量值在滤波结果中所占的权重。
当 α 较小（如 α = 0.1 或 0.05）时：
滤波输出主要由历史状态 yₖ₋₁ 主导，高频随机波动被深度滤除，输出波形极为平滑；
但代价是输出对真实输入物理量变化的响应显著滞后，引入了明显的时间延迟。
当 α 较大（如 α = 0.8 或 0.9）时：
滤波输出能迅速跟随原始输入信号的变化，时间延迟极小；
但高频随机噪声仍有相当大部分穿透滤波器进入控制回路。
若取 α = 1，则 yₖ = xₖ，相当于完全不执行滤波。

低通滤波带来的时间延迟对闭环控制系统的稳定性具有不可忽视的负面影响。
根据控制理论，任何在反馈回路中额外引入的惯性环节或时间滞后，
都会在频域上带来明显的相位滞后，从而削弱闭环系统的相位裕度。
如果为了追求极其平滑的测速波形而将 α 选取得过小，
过大的滤波延迟会使得控制器无法及时感知电机的真实速度变化。
当控制器做出纠偏反应时，电机实际状态可能已经越过目标，
导致闭环控制系统产生严重超调甚至陷入持续的等幅自激振荡。
因此，工程整定的一条核心准则是在确保消除破坏性高频噪声的前提下，
尽可能选择较大的 α，将滤波延迟限制在闭环系统可承受的动态响应范围之内。

### 例题
在桌面分拣站中，采用光电编码器测定传送带驱动电机的转速，并使用一阶低通滤波器滤除测速噪声。
前一采样拍滤波输出转速为 yₖ₋₁ = 1200 rpm，
当前采样拍测得的原始含噪转速为 xₖ = 1280 rpm。
控制器设定的滤波系数为 α = 0.25。
（1）计算当前采样拍经过一阶低通滤波后的转速输出值 yₖ。
（2）若转速在之后稳定保持在 1300 rpm 不变，计算该一阶低通滤波算法的稳态输出值。

解答：
（1）将已知参数直接代入一阶低通滤波离散递推公式：
yₖ = α · xₖ + (1 − α) · yₖ₋₁
yₖ = 0.25 × 1280 rpm + (1 − 0.25) × 1200 rpm
yₖ = 320 rpm + 0.75 × 1200 rpm
yₖ = 320 rpm + 900 rpm = 1220 rpm。
因此当前拍滤波输出值为 1220 rpm。
（2）当系统达到稳态时，输入恒定为 xₖ = x_ss = 1300 rpm，
滤波输出也趋于稳定恒定值，即 yₖ = yₖ₋₁ = y_ss。
代入递推公式可得：
y_ss = α · x_ss + (1 − α) · y_ss
移项化简得到：
α · y_ss = α · x_ss，即 y_ss = x_ss = 1300 rpm。
这表明一阶低通滤波算法对于直流（恒定）输入具有无静差的稳态跟随特性。

### 常见错误
1. 盲目追求测量曲线的光滑度而将 α 设得极小（例如 α = 0.01），
导致滤波带来的纯时间延迟过大，破坏了闭环系统的相位裕度并引发剧烈振荡。
2. 对微分项 Kd 作用的误差信号直接求差分而不加任何滤波，
使高频量化噪声被巨额放大，造成电机发热和齿轮机械抖动。
3. 误以为低通滤波能够消除所有频段的干扰，
忽略了如果噪声频率低于奈奎斯特频率或者本身就是低频波动，低通滤波无法将其与真实信号区分开。

## 单元小结
- 采样周期 T 与采样频率 fs = 1/T 决定了离散控制系统的时间分辨率；根据工程经验法则，
  采样周期通常选取为受控对象时间常数 τ 的 1/10 到 1/20（T ≤ τ/10），以避免引入过大的控制延迟；若输入信号频率超过奈奎斯特频率 fs/2，
  则会产生混叠现象。
- 连续 PID 在数字系统中通过数值积分（误差累加）和数值微分（后向差商）实现；位置式 PID 直接输出绝对控制量，容易发生积分饱和；增量式 PID 仅输出控制量变化量，
  无需历史全累加且便于手动自动无扰切换。
- 离散 PID 算法必须放置在严格等间隔的硬件定时中断中执行，严禁在执行时间不固定的主循环中随意调用，以保证离散参数物理意义恒定。
- 传感器高频噪声会通过微分项除以小周期 T 被急剧放大，一阶低通滤波递推式 yₖ = α·xₖ + (1 − α)·yₖ₋₁ 能有效平滑信号，
  但滤波系数 α 的减小会带来额外的相位滞后，必须在噪声抑制与闭环系统稳定性之间仔细权衡。
