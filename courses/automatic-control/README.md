# 自动控制原理

用反馈、阶跃响应和 PID 理解速度和位置控制。

## 学习起点

先了解传感器和执行器。深入分析前学习导数、积分和一阶微分方程。

- 反馈与误差 → 一阶模型与阶跃响应 → 稳定性 → 离散采样与 PID。

## 学完能做什么

- 区分开环和闭环。
- 计算跟踪误差，读懂阶跃响应。
- 理解超调、稳态误差与采样的影响。

**桌面质检分拣站实作**。先用仿真给电机模型一个速度阶跃，画出速度、误差和控制量随时间的曲线。

## 课程内容

1.1.0 版包含七个单元、25 个知识点和 124 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 控制系统基础 | 控制系统的组成；开环与闭环；误差与负反馈；方框图 |
| 系统建模 | 一阶系统模型；传递函数入门；直流电机速度模型 |
| 时域响应 | 一阶阶跃响应；二阶系统与超调；性能指标；稳态误差 |
| 稳定性 | 稳定性与极点；劳斯判据；增益、延迟与振荡 |
| PID 控制 | 比例控制；积分作用；微分作用；PID 整定；积分饱和与执行器限幅 |
| 离散采样与数字控制 | 采样周期与混叠；离散 PID 实现；测量噪声与滤波 |
| 频率特性与应用 | 频率响应入门；速度环与位置环；电机速度阶跃仿真（自评） |

“电机速度阶跃仿真”是自评实作，没有练习题。
按[频率特性与应用讲义](lessons/applications.md)中的自评清单完成后，
在学习路径中标记已会。
