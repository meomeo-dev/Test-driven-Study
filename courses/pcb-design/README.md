# PCB 设计与调试

将已验证的低压传感器接口从原理图做成可装配的电路板。

## 学习起点

选修。建议先完成电路基础与单片机样机，并确认器件和接线方案。

- 复核面包板电路 → 原理图 → 封装与布线 → 制板前检查。

## 学完能做什么

- 区分原理图符号、网络与 PCB 封装。
- 执行电气规则检查与设计规则检查。
- 按器件手册核对引脚、电源和安装尺寸。

**桌面质检分拣站实作**。在 KiCad 画一块低压传感器接口板，用器件手册核对插座脚序，并查看板框和安装孔。

## 课程内容

1.1.0 版包含七个单元、25 个知识点和 124 道原创练习题。
知识点建议学时合计 1,800 分钟（约 30 小时），每个计分知识点至少 5 题，
每个单元配一篇讲义。知识点之间声明了先修关系，可在应用的“学习路径”中按目标生成学习顺序。

| 单元 | 知识点 |
| --- | --- |
| 从面包板到 PCB | PCB 设计流程；PCB 结构与层；面包板电路复核 |
| 原理图 | 符号、网络与网络标签；电源符号与接地；电气规则检查 ERC；位号、元件值与 BOM |
| 封装与器件资料 | 封装与焊盘；按手册核对引脚；符号与封装关联 |
| 布局 | 板框与安装孔；元件布局原则；接地与电源分配 |
| 布线 | 线宽与电流；间距与设计规则；布线方法；设计规则检查 DRC |
| 噪声与接口保护 | 去耦电容；噪声与 EMC 基础；接口保护 |
| 制造与调试 | Gerber 与钻孔文件；制板工艺与成本；焊接与装配；首板上电与调试；传感器接口板设计（自评） |

“传感器接口板设计”是自评实作，没有练习题。
按[制造与调试讲义](lessons/fabrication.md)中的自评清单完成后，
在学习路径中标记已会。
