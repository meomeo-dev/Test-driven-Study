## 一、CEFR A1+ 数量词核心定位与两步判定流程

当说话人不需或无法说出精确基数词（如 `three apples`、`two cups of coffee`），而要表达**“一些 / 任何 / 很多 / 少量”**等相对数量时，英语使用**数量词（quantifiers）**放在名词（或“形容词 + 名词”）之前。

在 A1+ 阶段，选对数量词必须按顺序完成**两步判定**（直接承接第 1 讲 `countable-articles`）：

1. **第一步：判定名词类型（可数性 + 单复数）**
   - **复数可数名词**（如 `apples`, `eggs`, `chairs`, `notebooks`, `emails`, `questions`, `bottles`）：可使用 `some`, `any`, `a lot of / lots of`, `many`, `a few`。
   - **不可数名词**（如 `water`, `milk`, `coffee`, `bread`, `rice`, `sugar`, `paper`, `time`, `money`, `information`, `advice`, `work`）：永远保持单数形式（不加 `-s`），可使用 `some`, `any`, `a lot of / lots of`, `much`, `a little`。
   - **单数可数名词的排除边界**：本讲核心数量词（`some`, `any`, `much`, `many`, `a lot of`, `a few`, `a little`）在表数量时**均不能直接修饰单数可数名词**；单个物体必须用不定冠词 `a / an` 或数字 `one`（如 `a pen`、`an apple`，不能说 `*some pen` 或 `*any chair`）。
2. **第二步：判定句式与交际意图**
   - **肯定陈述句（`+`）**、**否定陈述句（`-`）**、**普通信息疑问句（`?`）**，以及**礼貌提议/请求问句（Offers / Requests）**分别对应不同的首选词项与语域惯例。

## 二、`some` 与 `any` 的句式规则与语用特例

### 1. 基础句式分工规则

`some` 与 `any` 均表示不确定的“一些 / 若干 / 任何”，且都**同时兼容复数可数名词与不可数名词**；二者的核心差异在于**句式极性与语用意图**：

| 句式 / 语用功能 | 首选词项 | 复数可数名词例句 | 不可数名词例句 | 语法与语用要点 |
| --- | --- | --- | --- | --- |
| **肯定陈述句（`+`）** | `some` | `There are some apples in the fridge.`（冰箱里有一些苹果。） | `We need some printer paper.`（我们需要一些打印纸。） | 表达存在一定数量；不强调多或少 |
| **否定陈述句（`-`）** | `any` | `I don't have any meetings this afternoon.`（我今天下午没有会议。） | `There isn't any milk left.`（一点牛奶也没剩了。） | 与 `not`（`don't / doesn't / didn't / isn't / aren't / haven't`）连用表“完全没有” |
| **普通信息疑问句（`?`）** | `any` | `Do you have any questions about the schedule?`（你对日程有什么问题吗？） | `Is there any coffee in the kitchen?`（厨房里还有咖啡吗？） | 开放式核查，说话人**不确定**对方有没有 |
| **礼貌提议问句（Offer）** | `some` | `Would you like some cookies?`（你要来点饼干吗？） | `Would you like some tea or water?`（你想喝点茶还是水？） | 热情款待，说话人**期待/欢迎**对方说 `Yes` |
| **礼貌请求问句（Request）** | `some` | `Could I borrow some folders?`（我能借几个文件夹吗？） | `Can I have some water, please?`（请给我一点水好吗？） | 礼貌索取，说话人**默认物品存在**并期待肯定回复 |

### 2. 重点语用特例：为什么提议和请求问句要用 `some`？

在 A1+→A2 真实交际中，不能机械记住“问句一律用 `any`”。在以下两类问句中，英语母语者几乎总是用 `some`：

1. **提供帮助或招待物品（Offers）**
   - 核心句型：
     - `Would you like some + 复数可数 / 不可数名词?`（最礼貌、通用，适用于接待客户、同事或餐厅服务）
       - `Would you like some milk in your coffee?`（你的咖啡里要加点牛奶吗？）
       - `Would you like some fresh fruit?`（想吃点新鲜水果吗？）
     - `Do you want some + 名词?`（更口语，适用于家人、朋友或熟识同事）
       - `Do you want some snacks for the trip?`（路上要带点零食吗？）
     - `How about some + 名词?`（轻松提议）
       - `How about some noodles for lunch?`（午饭吃点面条怎么样？）
   - 配套地道应答：
     - 接受：`Yes, please.` / `Sure, thank you.` / `Just a little, please.`（不可数）/ `Just a few, please.`（可数）
     - 婉拒：`No, thank you. I'm fine.` / `No, thanks. I just had some.`
2. **礼貌请求物品或协助（Requests）**
   - 核心句型：
     - `Can I have some + 名词, please?`（日常与点单高频）
       - `Can I have some hot water, please?`（请给我来点热水好吗？）
     - `Could I have / get some + 名词, please?`（更委婉，职场/餐厅首选）
       - `Could I get some extra napkins, please?`（能再给我拿几张餐巾纸吗？）
     - `Could you send / give / pass me some + 名词?`（职场沟通高频）
       - `Could you send me some information about the training?`（能发我一些培训相关的信息吗？）
3. **同场景对比（精准体会 `any` 与 `some` 的语用差别）**
   - 普通询问（不知有无）：`Do you have any sugar at home?`（你家里有糖吗？）
   - 礼貌请求（默认桌上有并想借用）：`Can I have some sugar for my tea, please?`（能给我一点糖放茶里吗？）
   - 普通询问（核查茶水间库存）：`Is there any coffee left in the pot?`（壶里还剩咖啡吗？）
   - 热情款待（邀请访客饮用）：`Would you like some coffee?`（要喝点咖啡吗？）

### 3. `some / any` 的 A1+ 实用结构延伸（严格控制范围）

1. **`There be` 与 `some / any` 的主谓一致**
   - 不可数名词永远配单数动词 `is / isn't`：`There is some bread on the table.` / `There isn't any rice left.` / `Is there any juice?`
   - 复数可数名词永远配复数动词 `are / aren't`：`There are some pens in the drawer.` / `There aren't any chairs in Room 3.` / `Are there any eggs?`
2. **等价否定结构：`not ... any` = `no + 名词`**
   - 英语中可用肯定动词 + `no` 替代 `not ... any`，语气更干脆，在日常和职场盘点中极常见：
     - `There isn't any paper in the printer.` = `There is no paper in the printer.`
     - `We don't have any empty seats.` = `We have no empty seats.`
   - **强制禁区**：绝不可双重否定（不可说 `*There isn't no paper.` 或 `*I don't have no time.`）。
3. **代词化简答（不重复已知名词）**
   - 当上下文已明确物品时，`some` 与 `any` 可单独使用，不再重复名词：
     - `A: Do we have any batteries?` — `B: Yes, there are some in the top drawer.` / `No, there aren't any.`
     - `A: Did you buy any coffee?` — `B: Yes, I bought some on my way to the office.`
4. **超纲边界提示（供教师与作者规避干扰项）**
   - `any` 在肯定句中表“任何一个都行”（如 `You can choose any color.`）与 `some` + 单数可数名词表“某一个”均属更高阶扩展，本 A1+ 课程不作考核重点，避免与“数量表达”核心规则混淆。

## 三、`much / many / a lot of / a few / a little` 完整搭配矩阵

### 1. 全维数量词搭配矩阵总表

| 数量词 | 数量等级 | 复数可数名词 | 不可数名词 | 肯定句（`+`） | 否定句（`-`） | 疑问句（`?`） | 语域与核心使用规则 | 生活 / 职场地道例句 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| `some` | 不定适量（一些） | 支持 | 支持 | **首选** | 不用 | 仅提议/请求用 | 肯定陈述默认项；问句仅用于 Offer / Request | `We bought some oranges and some milk.` |
| `any` | 零 / 任意数量 | 支持 | 支持 | 暂不作数量重点 | **首选** | **首选** | 否定句配 `not` 表“一点也没有”；普通问句核查有无 | `Are there any notebooks on the shelf?` |
| `a lot of` | 大量（许多） | 支持 | 支持 | **首选（最自然）** | 可用 | 可用 | 中性通用，口语与日常书面均自然；必须带 `of` 接名词 | `She gets a lot of emails every morning.` / `There is a lot of rain in summer.` |
| `lots of` | 大量（许多） | 支持 | 支持 | **常用（口语）** | 可用 | 可用 | 语法同 `a lot of`，语域更轻松非正式；同样须带 `of` 接名词 | `We have lots of snacks for the team lunch.` |
| `many` | 大量（许多） | **仅支持** | 不可用 | 少用（偏正式书面，作主语较自然） | **首选** | **首选** | 否定与疑问高频；日常肯定宾语优先换 `a lot of`；与 `how / too / so` 必配 | `There aren't many buses after 10 p.m.` / `How many people are in the meeting?` |
| `much` | 大量（许多） | 不可用 | **仅支持** | **日常不用**（除非前接 `too / so / as`） | **首选** | **首选** | 否定、疑问及 `How much` 高频；单独用于日常肯定句极不自然 | `I don't have much free time this week.` / `Is there much traffic today?` |
| `a few` | 少量（几个） | **仅支持** | 不可用 | **首选** | 较少用 | 可用（常含期待） | 偏积极含义“还有一些、够用”；不可漏掉 `a` | `I have a few questions about the invoice.` / `There are a few cafes near the station.` |
| `a little` | 少量（一点儿） | 不可用 | **仅支持** | **首选** | 较少用 | 可用（含提议/请求） | 偏积极含义“还有一点、够用”；不可漏掉 `a` | `We still have a little time before the train leaves.` / `Can I have a little honey?` |

### 2. 大量表达精细规范：`a lot of / lots of` vs `much` vs `many`

1. **肯定句中的自然选择（核心语用规范）**
   - 现代英语日常对话与一般职场沟通中，肯定句表达“很多”统一优先使用 **`a lot of`**（或更口语的 **`lots of`**）：
     - 自然：`We have a lot of work today.` / `He drinks a lot of green tea.` / `There are a lot of shops on this street.`
     - 不自然（须避免）：`*We have much work today.` / `*He drinks much green tea.`
   - `many` 在肯定句中作**主语**或用于**偏正式报告/通知**时可接受（如 `Many customers pay by card.`、`Many people commute by subway.`），但在日常口语宾语位置仍普遍首选 `a lot of`（如 `I made a lot of notes.`）。
2. **肯定句中必须用 `much / many` 的常见例外（衔接 A2）**
   - 当数量词前面带有程度词 **`too`（太）**、**`so`（如此）**、**`as`（同样）** 或疑问词 **`how`（多少）** 时，**必须使用 `much`（不可数）或 `many`（可数复数），绝不能用 `a lot of`**：
     - `There is too much salt in this soup.`（这汤太咸了 / 盐太多了。）
     - `We have too many meetings on Monday.`（我们周一会议太多了。）
     - `There are so many people at the supermarket today.`（今天超市人真多。）
     - `Thank you so much for your help.`（非常感谢你的帮助。）
     - 错误写法：`*too a lot of salt`、`*so a lot of people`。
3. **`a lot of` 与 `a lot` 的形式区别**
   - **后面紧跟名词时，必须带 `of`**：`a lot of time`、`a lot of emails`（不能写成 `*a lot time`）。
   - **后面不跟名词（作副词修饰动词，或作代词用于简答）时，必须去掉 `of`**：
     - 副词：`She travels a lot for work.`（她因公经常出差。）/ `Thanks a lot!`
     - 简答代词：`A: Do you drink much coffee?` — `B: Yes, a lot.`（不能答 `*Yes, a lot of.`）

### 3. 少量表达精细规范：`a few` vs `a little`

1. **严格按可数性二选一**
   - `a few + 复数可数名词`：`a few minutes`（几分钟）、`a few emails`（几封邮件）、`a few apples`（几个苹果）、`a few colleagues`（几位同事）。
   - `a little + 不可数名词`：`a little time`（一点时间）、`a little money`（一点钱）、`a little milk`（一点牛奶）、`a little help`（一点帮助）。
2. **语义色彩与 `few / little` 区分边界**
   - **`a few` / `a little` 带积极/中性含义**，指“虽然不多，但有一些，基本够用”：
     - `Don't worry, we still have a little time.`（别担心，我们还有一点时间。）
     - `I bought a few notebooks for the new interns.`（我给新实习生买了几本笔记本。）
   - **去冠词的 `few` / `little`** 表示“几乎没有，不够用”（否定倾向，偏正式，属 A2+→B1 深化内容；日常口语通常更常用 `not many` / `not much` 来表达这一意思，如 `We don't have much time.`）。A1+ 讲义只需简短提示“不要漏掉 `a`”，防止学生把 `a few` / `a little` 误写为 `few` / `little`。
3. **搭配 `only / just` 与独立简答**
   - 常与 `only` 或 `just` 搭配，语气更柔和自然：
     - `There are only a few seats left.`（只剩几个座位了。）
     - `Could I have just a little sugar, please?`（请只要一点点糖。）
   - 可省略名词作简短回答：
     - `A: Do you speak English?` — `B: Yes, a little.`
     - `A: How many boxes of tea do we need?` — `B: Just a few.`

### 4. 主谓一致速查（`There be` 与动词单复数）

`some`、`any`、`a lot of`、`lots of` **本身不改变主谓一致**，动词单复数完全取决于其后的**中心名词**：

| 中心名词类型 | 存在句肯定 / 否定 / 疑问 | 例句 |
| --- | --- | --- |
| **不可数名词**（永远视作单数） | `There is` / `There isn't` / `Is there` | `There is a lot of space in the meeting room.`<br>`There is a little juice in the bottle.`<br>`Is there much paper left?` |
| **复数可数名词**（永远视作复数） | `There are` / `There aren't` / `Are there` | `There are a lot of emails in my inbox.`<br>`There are a few markers on the whiteboard.`<br>`Are there many restaurants nearby?` |

## 四、核心句型结构模板（通用日常与现代职场）

以下结构可直接作为第 2 讲讲义句型表、翻译题与造句题（`writing: sentence_making`）的骨架模板：

1. **盘点现有库存与状态（陈述句）**
   - `There is some / a lot of / a little + 不可数名词 + 地点.`
     - `There is some cold water in the fridge.`
     - `There is a lot of paper in the supply cabinet.`
   - `There are some / a lot of / a few + 复数可数名词 + 地点.`
     - `There are a few clean mugs in the pantry.`
     - `There are a lot of fresh vegetables at the market.`
   - `We have some / a lot of / a few / a little + 名词.`
     - `We have a few minutes before the client arrives.`
2. **说明短缺与不足（否定句）**
   - `There isn't any / much + 不可数名词 (+ left).`
     - `There isn't much milk left for breakfast.`
   - `There aren't any / many + 复数可数名词 (+ left).`
     - `There aren't many folders left in the office.`
   - `I / We don't have any / much / many + 名词.`
     - `I don't have much cash with me today.`
     - `We don't have many extra chairs in this room.`
3. **询问有无与精准数量（疑问句，衔接 `wh-questions`）**
   - 确认有无：`Is there any + 不可数名词?` / `Are there any + 复数可数名词?` / `Do we have any + 名词?`
     - `Do we have any green tea in the kitchen?`
   - 询问大体数量：`Is there much + 不可数名词?` / `Are there many + 复数可数名词?`
     - `Is there much traffic near the airport?`
   - 询问具体数量（呼应第 5 单元 `wh-questions` 与第 3 讲价格询价）：
     - `How many + 复数可数名词 + do we need / are there?`（`How many notebooks do we need for the team?`）
     - `How much + 不可数名词 + do we need / is there?`（`How much coffee do you drink every day?`）
     - 语用区隔提示：`How much` 接不可数名词问“多少量”（`How much water?`），接 `is / are + 物品` 则问“多少钱”（`How much is this umbrella?`，为第 3 讲做好自然伏笔）。
4. **礼貌招待与请求（语用重点）**
   - 提议：`Would you like some + 复数可数 / 不可数名词?`
     - `Would you like some water before the meeting starts?`
   - 请求：`Can / Could I have some + 复数可数 / 不可数名词, please?`
     - `Could I have some extra tissues, please?`
5. **与本讲场景高频搭配的补充量词边界（衔接 Topic 2）**
   - **`enough + 复数可数 / 不可数名词`**（A1+→A2 高频，表“足够的”，置于名词前）：
     - `Do we have enough chairs for everyone?`（复数可数）
     - `We don't have enough time to finish the report today.`（不可数）
   - **`too much + 不可数名词` / `too many + 复数可数名词`**（表“过多、超出需要”）：
     - `Don't put too much sugar in the iced tea.`
     - `We bought too many snacks for five people.`

## 五、三步选词决策树（便于学员快速内化）

在讲义总结或错题解析中，可用以下三步口诀帮零基础进阶学员一次选对：

1. **先看名词能不能数**：
   - 单数可数 → 回退用 `a / an / one`（不用本讲数量词）。
   - 复数可数 → 候选池：`some, any, a lot of / lots of, many, a few`。
   - 不可数 → 候选池：`some, any, a lot of / lots of, much, a little`。
2. **再看表达的数量等级**：
   - “不确定一些 / 有没有” → 在 `some` 与 `any` 中选。
   - “很多” → 在 `a lot of / lots of`、`many`、`much` 中选。
   - “少量（够用）” → 可数复数选 `a few`，不可数选 `a little`。
3. **最后看句式与礼貌语用**：
   - 肯定句表“一些”用 `some`；表“很多”首选 `a lot of`（仅遇 `too / so / as` 时换 `much / many`）。
   - 否定句与普通疑问句表“任何/没有”用 `any`；表“不多/多吗”用 `many`（可数）或 `much`（不可数）。
   - **提议（`Would you like…?`）或请求（`Can / Could I have…?`）问句** → 用 **`some`**（或具体少量 `a little / a few`）。

## 六、供讲义主笔、题库与生词本作者参考的语料库与对齐建议

### 1. 通用日常与现代职场高频名词词池

为避免跨主题词汇超纲并紧扣第 1 讲 `countable-articles` 与第 11 单元 `everyday-shopping`，建议讲义例句与练习优先在以下两类 A1+ 高频词中选材：

- **高频复数可数名词**：
  - 生活消费/饮食：`apples`, `bananas`, `oranges`, `eggs`, `tomatoes`, `cookies`, `sandwiches`, `bottles`, `cups`, `bags`, `coins`, `receipts`
  - 现代办公/通用：`pens`, `notebooks`, `folders`, `sticky notes`, `markers`, `chairs`, `mugs`, `emails`, `questions`, `meetings`, `minutes`, `colleagues`
- **高频不可数名词**：
  - 生活消费/饮食：`water`, `milk`, `coffee`, `tea`, `juice`, `bread`, `rice`, `sugar`, `salt`, `fruit`, `food`, `ice`
  - 现代办公/通用：`paper`, `ink`, `time`, `money`, `cash`, `information`, `advice`, `work`, `space`, `traffic`, `help`, `furniture`

### 2. 讲义与题库（`budget_plan.json`）教学映射要点

- **讲义阅读量与结构**：本讲为单知识点 `quantifiers-amounts`（40 分钟，目标等效阅读量 `1944` 单位，至少 2 道例题）。建议将上述「`some / any` 规则与礼貌提议特例」与「`much / many / a lot of / a few / a little` 搭配矩阵」组织为两张清晰表格，配一组自然双语情景对话（如茶水间招待访客或超市采购清单核对），并在例题中覆盖“普通问句用 `any` vs 提议用 `some`”和“`a lot of` vs `much / many` 肯定/否定切换”。
- **分题型语法考点覆盖建议**：
  - `single_choice`（2 题）：一题考礼貌提议/请求特例（`Would you like some tea?` / `Can I have some water?`），一题考可数/不可数搭配（`a few` vs `a little` 或 `much` vs `many`）。
  - `multiple_choice`（1 题）：考同一不可数或复数可数语境下哪些数量词合法（如肯定句修饰不可数名词 `milk` 可选 `some`、`a lot of`、`a little`，排除 `many`、`a few`、`any`）。
  - `true_false`（1 题）：考易错规则正误判断（例如判断“`Would you like …?` 属于疑问句，因此必须用 `any`”为错，或判断“日常肯定句应优先用 `a lot of` 而非单独的 `much`”为对）。
  - `cloze`（1 题）：一段日常或办公补货小短文，连续填入 `some / any / much / many / a lot of / a few / a little`。
  - `translation`（2 题）：一句英译中（如含 `Would you like some…?` 或 `There isn't much…`）与一句中译英（如“我们还有一点时间和几个问题” `We still have a little time and a few questions.`）。
  - `writing`（`sentence_making`，1 题）：给定场景（如办公室茶水间或周末采购），要求造出包含 `some / any / a lot of / a few / a little` 中指定词的完整句子。
  - `listening`（1 题）：双人日常采购或茶水间接待对话，自然融入 `Do we have any…?`、`There aren't many…`、`Would you like some…?`、`Just a little, please.` 等真实语用切换。
- **生词本候选词条建议（本讲 `vocab_target: 2`）**：
  - 优先收录具有明确语法边界与搭配价值的词块，例如：
    1. `a lot of`（`category: "phrase"`，省略 `pos`；`grammar_note` 可提醒：后接复数可数名词或不可数名词，肯定句中比 `much`/`many` 更自然；句末不接名词时去掉 `of` 用 `a lot`。）
    2. `a few` 或 `a little` 或 `Would you like some …?`（如选用 `Would you like some …?` 须遵循 `design-course-tts` 规范配 `term_tts.text` 去掉省略号；如选用 `a few` / `a little`，属于 `phrase`，省略 `pos`，`grammar_note` 简明点出所接名词可数性差异）。
