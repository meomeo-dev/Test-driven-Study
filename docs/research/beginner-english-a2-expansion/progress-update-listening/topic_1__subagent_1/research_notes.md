## 一、CEFR A2 听力语法定位与教学边界

参照 **Cambridge EGP**、**Cambridge *English Grammar Today***、**British Council** 与 **BBC Learning English**，本讲将第 11–13 讲学过的现在完成时形态、进度副词与 `for / since` 全面转入**真实连读听辨**，核心落实三项能力：

1. **弱读辨音**：在自然语流中听辨缩写/弱读助动词（`'ve / 's / have / has`）及过去分词的省音、连读与弱读，不因听不清 `have / has` 或 `-ed` 而误判时态。
2. **信号词锁态**：凭 `so far`、`not yet`、`still waiting for`、`just finished` 等信号词，实时区分**已完成 / 刚完成 / 进行中与卡点等待 / 尚未完成**四类状态。
3. **跨时态切换**：听懂同一轮进度汇报中“完成时（成果）→ 进行时（等待/处理中）→ `will`（下一步）”的连贯转换。

### 与相邻讲次及同讲子主题的分工边界
- **衔接第 11–13 讲**：不再重讲不规则三态表（第 11 讲）、`ever / never`（第 12 讲）及 `for / since` 基础定义（第 13 讲），专攻听觉解码与进度信号归类。
- **同讲分工**：完整晨会对话、搬家/旅行语音留言及英中逐字稿归 **Topic 2**；听辨干扰陷阱与多小题测评归 **Topic 3**；本笔记聚焦语法、辨音机制、信号词规范与模板。

## 二、听力缩写 `'ve / 's` 与助动词弱读辨音技巧

英语属于**重音计时语言（stress-timed language）**：自然语流中，传达核心语义的实义词（过去分词、名词、进度副词）被重读，而语法助动词 `have / has` 在肯定句中几乎总是**缩写或高度弱读**，导致初学者“听漏助动词”。

### 1. 现在完成时助动词：强读、弱读与缩写辨音总表

| 形式类别 | 书面形式 | 自然语流发音（IPA） | 听辨关键特征与典型例句 |
| --- | --- | --- | --- |
| **肯定缩写（非三单）** | `I've / you've / we've / they've` | `/aɪv/ /juːv/ /wiːv/ /ðeɪv/` | 紧贴代词末尾发极轻的唇齿浊摩擦音 `/v/`，时长极短；*We**'ve** sent the link.* → `/wiːv ˈsent ðə lɪŋk/` |
| **肯定缩写（三单）** | `he's / she's / it's`；单数名词 + `'s` | `/hiːz/ /ʃiːz/ /ɪts/`；浊音后 `/z/`、清音后 `/s/` | 与 `is` 缩写完全同音，**必须看/听紧随其后的词形**定性；*Mark**'s** booked the room.* → `/mɑː(r)ks ˈbʊkt.../` |
| **未缩写肯定弱读** | `have` / `has`（句中非重读） | `/həv/ → /əv/`<br>`/həz/ → /əz/` | 元音 `/æ/` 弱化为央元音 `/ə/`，词首 `/h/` 常脱落；*My colleagues **have** arrived.* 听感接近 `colleagues-əv arrived` |
| **否定缩写（高重读）** | `haven't` / `hasn't` | `/ˈhævnt/` / `/ˈhæznt/` | 否定助动词通常**保持重读**（保留清晰 `/æ/`），但辅音前词尾 `/t/` 常省音或不完全爆破（*haven't checked* → `/ˈhævn(t) tʃekt/`），听辨须抓住重读的 **`havn- / hazn-`** 音节而非死等 `/t/` |
| **疑问句与简答** | `Have you...?` / `Yes, I have.` | 句首常弱读 `/həv jə/`；<br>句尾简答必强读 `/hæv/ /hæz/` | 疑问句靠**句尾升调**与后续过去分词识别；肯定简答永远强读且**禁缩**（`*Yes, I've.` ✗） |

### 2. 听觉一秒辨析：`'s` 是 `has` 还是 `is`？（直接决定任务状态）

在工作晨会或朋友聊天中，`He's / She's / It's` 高频出现，听清 **`'s` 后面第一个实词**即可瞬间区分“已完成”还是“正在做/当前状态”：

| 听到的后续成分 | `'s` 的语法还原 | 对应时态与进度状态 | 地道听力例句（日常与职场） |
| --- | --- | --- | --- |
| **`'s` + 过去分词（V3）**<br>或 **`'s + just/already + V3`** | **`has`** | 现在完成时 → **已完成** | *She**'s sent** the updated slides.*（她已经发了更新后的幻灯片。）<br>*He**'s just finished** the budget.*（他刚做完预算。） |
| **`'s` + `been` (`/bɪn/`)** | **`has`**（绝非 `is`） | 现在完成时 → **持续状态/经历** | *He**'s been** in Shanghai since Tuesday.*（他从周二起一直在上海。） |
| **`'s` + `V-ing`**<br>或 **`'s + still + V-ing`** | **`is`** | 现在进行时 → **进行中 / 等待中** | *She**'s sending** the slides right now.*（她现在正在发幻灯片。）<br>*He**'s still waiting** for the reply.*（他还在等回复。） |
| **`'s` + 形容词 / 名词 / 介词短语** | **`is`** | 一般现在时 → **当前静态状态** | *The meeting room**'s ready**.*（会议室准备好了。）<br>*Anna**'s on vacation** this week.*（安娜这周休假。） |

### 3. 避免 `'ve` 漏听导致“现在完成时 vs. 一般过去时”误判
当 `I've / we've` 后接以辅音开头的规则动词（如 *I've booked* vs. *I booked*）时，轻读 `/v/` 极易被掩盖。听力中采用**双轨锁定法**：
1. **看动词形态**：不规则动词 ABC 型本身就是强信号（听到 `written / seen / done / spoken / taken / gone / been`，即便没听清 `'ve`，也必为完成时）。
2. **抓时间/进度信号词**：听到 `so far / already / just / yet / since / for` 锁定当前进度汇总；听到 `yesterday / last Friday / at 9 a.m. / two days ago` 锁定过去某个已结束时间点。

## 三、过去分词（V3）弱读、省音与连读辨音技巧

### 1. 规则过去分词 `-ed` 的三类语流音变（基于 BBC / Cambridge 连读规律）

规则动词过去分词沿用 `/t/ /d/ /ɪd/` 三种词尾读音，但在自然句中随**后接词首音素**产生规律性变化：

| 语流位置 | 语音现象 | 发音变化示例（IPA） | 听力解码策略 |
| --- | --- | --- | --- |
| **后接辅音**<br>（易误判为原形） | **辅音省略（Elision）**：夹在两辅音间的 `/t/` 或 `/d/` 常脱落或弱化 | *I've finish**ed** the report.* → `/ˈfɪnɪʃ(t) ðə rɪˈpɔː(r)t/`<br>*We've book**ed** two rooms.* → `/bʊk(t) tuː/`<br>*She's call**ed** the hotel.* → `/kɔːl(d) ðə/` | **不死等清脆 `/t/ /d/`**：凭前文 `'ve / 's / already / just` 与语境锁态 |
| **后接元音**<br>（易听成陌生词） | **辅元连读（Linking）**：词尾 `/t/ /d/` 滑向后词词首元音 | *check**ed** it* → `/tʃekt‿ɪt/`<br>*pack**ed** up* → `/pækt‿ʌp/`<br>*sent out* → `/sent‿aʊt/` | 把后词开头的 `/t- / d-/` 还原归属为前词的过去分词尾音 |
| **`/t/ /d/` 词干 + `-ed`**<br>（清晰稳定） | **保留音节 `/ɪd/`**：独立成音节，不易省略 | `updat**ed**` `/ʌpˈdeɪtɪd/`、`print**ed**` `/ˈprɪntɪd/`、<br>`start**ed**` `/ˈstɑː(r)tɪd/`、`decid**ed**` `/dɪˈsaɪdɪd/` | 最稳定的完成态听觉锚点，可优先作定位词 |

### 2. 高频不规则过去分词与动词词组弱读清单
1. **`been` 的弱读 `/bɪn/`（重灾区）**：字典强读为 `/biːn/`（同 `bean`），但日常 95% 以上的句中位置均弱读为短音 **`/bɪn/`**（同 `bin`）：
   - *I've **been** `/bɪn/` really busy since Monday.*（我从周一到现在一直很忙。）
   - *We've **been** `/bɪn/` to three apartments so far.*（截至目前我们已经看了三套公寓。）
2. **高频动词短语中的 `/t/` 省音**：
   - `just finished` → `/dʒʌs(t) ˈfɪnɪʃt/`（`just` 尾音 `/t/` 在 `/f/` 前几乎必省，听成 `jus' finished`）。
   - `sent the / left the` → `/sen(t) ðə/`、`/lef(t) ðə/`（依靠 `sent / left` 的短元音 `/e/` 区别于原形 `send` 和 `leave` `/iː/`）。
3. **读音变、拼写不变的高频陷阱**：`read` 的过去分词读 **`/red/`**（同 `red`），如 *Have you **read** `/red/` my message?*；`said` 读 `/sed/`；`heard` 读 `/hɜː(r)d/`；`done` 读 `/dʌn/`。

## 四、进度核对核心信号词：语法规则、语序与语用规范

在办公室晨会（check-in）或朋友近况分享中，听众的核心任务是迅速给每件事贴上状态标签。以下四大核心信号词及高频辅助短语构成 A2 进度听力的“状态雷达”：

### 1. 四大核心信号词全景对照表

| 信号词 | 对应任务状态 | 必配时态与语法结构 | 句中位置规则 | 地道例句（日常与职场） |
| --- | --- | --- | --- | --- |
| **`so far`**<br>（截至目前） | **阶段已完成**（数量/范围汇总，暗示后续未完） | **现在完成时**（`have/has + V3`）；可配现状短语 *So far, so good.*；**禁用一般过去时** | **句首**（加逗号）或**句末**（最常用） | ***So far**, we've interviewed four candidates.*<br>*We've packed six boxes **so far**.*<br>（错：`*So far I packed six boxes.`） |
| **`just finished`**<br>（刚刚完成） | **刚刚完成**（已完成，可进入下一步） | A2 标准用**现在完成时**：`主语 + 've/'s + just + finished (+ 名词 / V-ing)` | `just` 置于 `'ve/'s` 与 `finished` 之间 | *I've **just finished** the weekly report.*<br>*She's **just finished** writing the email.*<br>（注意：`finish` 后接名词或 `V-ing`，禁用 `*finish to write`） |
| **`still waiting for`**<br>（仍在等待） | **进行中 / 外部卡点**（尚未办结，耗时超预期） | **现在进行时**：`主语 + am/is/are ('m/'s/'re) + still + waiting for + 名词/代词` | `still` 置于 **`be` 动词之后、`waiting` 之前**；介词 **`for` 不可省略** | *We're **still waiting for** the client's reply.*<br>*I'm **still waiting for** my new passport.*<br>（错：`*still waiting the reply`） |
| **`not yet`**<br>（尚未完成） | **尚未完成**（待办，但预期很快会做） | ① 独立简答：**`Not yet.`**；<br>② 完整否定句：`haven't/hasn't + V3 ... yet` 或 `be not + adj + yet` | 完整句中 `yet` 固定置**句末**；简答固定说 `Not yet.`（禁用 `*No, yet.`） | *— Have you booked the train tickets?*<br>*— **Not yet.** I'll book them tonight.*<br>*The slides aren't ready **yet**.* |

### 2. 高频语用细辨与听力状态警示

1. **美式口语 `just finished` 的听力宽容原则**：
   - 在国际 A2 标准与英式英语中，`just` 搭配现在完成时（*I've just finished lunch.*）；但在日常美式英语录音中，母语者也常直接使用一般过去时（*I just finished the slides.*），加之 `'ve` 本身弱读，听感几乎一致。
   - **教学规范**：听力中听到 *I've just finished* 与 *I just finished* **均判为“刚刚完成”**；语法填空与写作产出仍统一使用标准现在完成时 `have/has + just + V3`。
2. **`wait for` 的三条介词边界（防中式直译）**：
   - 后接等待的**人或事物**：必加 `for`（*waiting **for** the designer / **for** the delivery*）。
   - 后接**“等某人做某事”**：`waiting for + 人 + to do`（*We're still waiting **for** Lisa **to confirm** the time.*）。
   - 后接**自己将要做的动作（`to do`）**：**不加 `for`**（*I'm still waiting **to hear** back from the hotel.*）。
3. **半途与延误信号词（听力状态预警）**：
   - **`almost done` / `nearly finished`**（快做完了）→ 属**进行中 / 尚未完全完成**，不可误归 Completed！
   - **`still working on`**（仍在处理中，推进在自己手里）vs. **`still waiting for`**（卡在外部回复/交付），二者均为**未完结**。
   - **识听扩展 `still haven't / hasn't + V3`**（衔接第 12 讲边界）：口语中偶见 *I **still haven't** heard back.*（`still` 置于否定助动词前，表达更强焦急/延误感），听力中判为“至今未完成”，A2 产出仍优先使用 `haven't ... yet` 与 `still waiting for`。
4. **进度汇报经典“双段转折结构”**：
   晨会与近况分享常在同一轮内打包多个状态，典型骨架为**“已完成 + `but` / 句尾 `though` + 未完成/等待 + `will` 下一步”**：
   - *So far, I've updated the budget and sent the invites, **but** I'm still waiting for the venue to reply. I'll call them this afternoon.*
   - *I've unpacked the bedroom boxes. I haven't cleaned the kitchen yet, **though**.*

## 五、通用日常与现代职场核心句型模板库

| 交际功能 | A2 核心句型骨架 | 地道例句（弱读/信号词标注） |
| --- | --- | --- |
| **1. 晨会开场核对进度** | `How's [项目/事情] going so far?` / `Have you [V3] ... yet?` | *— How's the event plan going **so far**? Have you booked the room **yet**?*<br>*— Yes, we**'ve already** booked it.* |
| **2. 汇报刚完成的成果** | `I've just finished [名词 / V-ing], so I'll [下一步].` | *I**'ve just finished** checking the slides, so I**'ll** share the link right now.* |
| **3. 汇总阶段进度 + 转折待办** | `So far, we've [已完成], but we haven't [未完成] yet.` | ***So far**, we**'ve** chosen the hotel, **but** we **haven't** bought the flight tickets **yet**.* |
| **4. 说明外部等待卡点** | `I'm / We're still waiting for [人/事] (to do ...).` | *We**'re still waiting for** the design team **to send** the final poster.*<br>*I**'m still waiting for** the courier to deliver my new desk.* |
| **5. 简短回应未完成 + 承诺时间** | `Not yet. I'm still working on it, and I'll [动作] by [时间].` | *— Has David sent the notes yet?*<br>*— **Not yet.** He**'s still working on** them, and he**'ll** email us by 4:00.* |
