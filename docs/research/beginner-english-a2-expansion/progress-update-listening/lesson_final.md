# 日常分享与工作进度同步听力

本讲承接现在完成时、进度副词、`for / since` 与 `will`，训练在日常与职场同步中听辨弱读、锁定状态并换算时长。

## 日常分享与工作进度同步听力
<!-- concepts: progress-update-listening -->

英语重读实义词，助动词常缩写或弱读，过去分词尾音常省音或连读。晨会碰头（`check-in`）与语音留言常一轮打包“已完成 → 进行中 → 未完成 / 待办 → 下一步”，须借辨音、信号词与换算归类。

### 核心规则与句型表

#### 1. 弱读助动词（`'ve / 's`）与过去分词辨音

| 听辨项目 | 书面与发音 | 听辨关键与例句 |
| --- | --- | --- |
| 缩写 `'ve` | `I've / we've`（`/aɪv/ /wiːv/`） | 尾音 `/v/` 极轻，须借信号词锁定状态：`We've already sent it.` |
| `'s` 辨析 | `he's / she's`（`/hiːz/ /ʃiːz/`） | 接过去分词或 `been` 表 `has`（`She's sent it.`）；接 `-ing` 或形容词表 `is`（`She's sending it.`） |
| 否定与弱读 | `haven't` `/ˈhævn(t)/`、`hasn't` `/ˈhæzn(t)/`；`have / has` `/əv/ /əz/` | 否定重读 `/æ/`，辅音前常省 `/t/`；句中非重读的完整肯定助动词 `have / has` 常省 `/h/` |
| 过去分词 | `-ed`、`been` `/bɪn/` | 辅音前常省 `/t/ /d/`（`finished the`），元音前连读（`checked it`）；词干尾音为 `/t/ /d/` 时保留 `/ɪd/`（`updated`）；`just finished` 常省 `just` 尾音 `/t/`；`been` 句中常弱读短音 `/bɪn/`（`He's been busy.`） |

- **简答规范**：肯定简答不可缩写（`Yes, I have.`，不可说 `Yes, I've.`）。
- **特殊读音与口语变体**：`read` 过去分词读 `/red/`，`left`（`/e/`）区别于 `leave`（`/iː/`）。美式口语常见 `just` 直接配一般过去时（`I just finished.`），加之 `'ve` 弱读难辨，听力均判刚完成，本课书面与产出统一用现在完成时。

#### 2. 进度四态与核心信号词

| 任务状态 | 语法与信号词 | 例句与要点 |
| --- | --- | --- |
| **已完成** | `have / has + 过去分词`；`already`、`just`、`so far` | `I've just finished it.` |
| **进行中** | `be + -ing`；`still working on`、`almost done`、`half ... so far` | `She's still working on it.`；`almost done / half ... so far` 均表尚未全部完成 |
| **未完成 / 待办（含等待）** | `haven't / hasn't ... yet`；`not yet`、`still waiting for` | `I haven't checked it yet.`（`wait` 接对象带 `for`） |
| **推翻旧计划 / 下一步** | `planned to ... but`、`actually`；`will / be going to`、`on track` | `I planned to call today, but I'll call tomorrow.` |

- **搭配要点**：`so far`（截至目前）放句首加逗号或句末，配现在完成时；否定简答用 `Not yet.`。`finish` 接名词或 `-ing`；`wait for` 接等待对象或 `人 + to do`（如 `waiting for Mia to reply`），接 `to + 动词原形` 表等自己做某事时不加 `for`（`waiting to hear back`）；`on track` 表按计划推进；`progress` 不可数（`make progress` 取得进展）。

#### 3. 听力时间换算与“三步三栏”法

| 时间标记 | 核心指向 | 换算规则与示例 |
| --- | --- | --- |
| **`for`** | 持续时长（接时段） | 直接给时长，勿混将来 `in`：`for two weeks` |
| **`since`** | 起始点（接时间点） | 当前减起点，不重复计算首尾两天：周四 `since Monday` 为三天 |
| **`ago`** | 过去动作点（过去时） | 延续至今可换算为 `for`：`started two days ago` 相当于 `for two days` |
| **`in / by`** | 将来之后 / 截止节点 | `in + 时段` 配 `will` 表将来（`in two hours` 两小时后）；`by + 时间点` 表截止期限（`by four` 四点前），均提示未完成 |

**三步三栏法**：① 听前圈人物、状态与时间；② 听中划出“已完成 / 进行中 / 待办”三栏，记“关键词 + 时间”，遇 `but / actually` 立刻划掉旧计划；③ 听后核查未完信号，复算 `since` 减法。

### 自然双语情景对话

#### 情景 1：周三项目晨会（职场对话）

周三上午，汉娜与卢卡斯同步周五活动进度（`check-in` 碰头会）。

- **汉娜**：`Hi Lucas, let's do a quick check-in. We've prepared for Friday's event for two weeks now. How's your part going?`（嗨卢卡斯，快速同步下进度。周五活动已筹备两周，你这边进展如何？）
- **卢卡斯**：`Hi Hannah! Pretty well. So far, I've finished the report. I emailed it yesterday. I've worked on the photos since Monday, and I'm still editing them.`（嗨汉娜！挺顺利的。目前已完成报告，昨天发了。照片从周一一直修到现在，目前还在继续修。）
- **汉娜**：`Great! I've just sent the event link, and I've already confirmed twenty guests. Have you checked the prices yet?`（太好了！刚发了活动链接，也已经确认二十位来宾。价格核对了吗？）
- **卢卡斯**：`Not yet. Actually, I planned to check them this morning, but I'm still waiting for Mia's email.`（还没。其实原计划今天上午核对，但还在等米娅的邮件。）
- **汉娜**：`Okay, I'll message her right now. Also, I haven't printed the welcome cards yet, so I'm going to print them tomorrow.`（好的，我马上联系她。另外，欢迎卡还没打印，所以我打算明天打。）
- **卢卡斯**：`Sounds good! I'll send the photos by four, so we're on track.`（好的！我四点前发照片，一切按计划推进。）

#### 情景 2：新公寓近况分享（日常语音留言与回电）

周三晚，克洛伊给艾玛留语音（`unpack` 拆箱、`settle in` 安顿、`catch up` 叙旧），艾玛稍后回电。

- **克洛伊（语音）**：`Hi Emma, it's Chloe! I moved into my new apartment last week, and I've lived here for five days now. So far, I've unpacked the kitchen boxes, and I've just set up my desk.`（嗨艾玛，我是克洛伊！我上周搬进了新公寓，到现在住了五天。目前拆完了厨房箱子，也刚摆好书桌。）
- **克洛伊（续）**：`I'm still unpacking my books. Good news—the Wi-Fi has worked since Tuesday! I haven't bought curtains yet, and I'm still waiting for my sofa. Call me back tonight!`（我还在整理我的书。好消息——无线网从周二起就一直能正常用了！还没买窗帘，也还在等沙发。今晚记得回电话！）
- **艾玛（回电）**：`Hi Chloe! I've just listened to your message. Glad you're settling in! When will the sofa arrive?`（嗨克洛伊！刚听完你的语音，真高兴你正慢慢安顿下来！沙发什么时候到？）
- **克洛伊**：`On Friday morning. Come over on Sunday to catch up!`（周五上午。周日过来玩，叙叙旧！）

### 例题 1：弱读 `'s` 与任务状态辨析

**题目**：判断下列 3 组属**已完成**、**进行中**或**待办**，并还原第 1–2 组的 `'s`：

1. `She's sent the slides.`
2. `He's still checking the budget. It's almost done.`
3. `I planned to call him this morning, but I haven't called yet.`

**解答**：1. **已完成**（`has`）；2. **进行中**（均为 `is`）；3. **待办**。

**解析**：第 1 组接过去分词 `sent` 为 `has`；第 2 组 `He's` 接 `-ing`（`checking`），`It's almost done.` 中 `done` 作形容词表状态（“快完成了”），故两处 `'s` 均为 `is`（`It's = It is`）；第 3 组 `planned to ... but` 推翻旧计划，`haven't ... yet` 表还没打电话。

### 例题 2：`for / since / in` 听力时间换算

**题目**：假设**现在是周四上午 11 点**，换算时长或发送时间：

1. `He's been on a client call since nine a.m.`（持续几小时？）
2. `She's worked on it since Monday.`（做了几天？）
3. `We haven't sent the report yet, and we'll share it in two hours.`（完成了吗？几点发？）

**解答**：1. **2 小时**；2. **3 天**；3. **未完成，下午 1 点发**。

**解析**：第 1 题 `11 − 9 = 2` 小时（对应 `for two hours`），勿抄 `9`；第 2 题周一至周四间隔 `3` 天（对应 `for three days`），勿算 `4` 天；第 3 题 `in two hours` 表两小时后（下午 1 点），非持续时长。

### 例题 3：微型进度同步听辨与干扰排雷

**题目**：阅读周五下午同步录音稿，回答两问：

- **玛雅**：`Have you updated the schedule yet?`
- **本**：`Yes, I finished it yesterday. I've finished half of the slides so far, and I'm still waiting for Sara's notes. I've waited for them since Wednesday.`

1. 哪项任务已全部完成？
2. 截至周五，本等萨拉的笔记（`notes`）等了几天？

**解答**：1. **更新日程**；2. **2 天**。

**解析**：第 1 题 `finished it yesterday` 锁定“更新日程”已完成，幻灯片带 `half of ... so far` 仅完成一半；第 2 题周三至周五间隔 `2` 天，勿算 `3` 天。

### 常见错误

受汉语习惯影响，须严防以下 5 类偏误（`*` 标错句或错搭）：

1. **漏听否定与 `yet`**：`haven't / hasn't` 尾音 `/t/` 常省音，须盯重读音节 `/ˈhævn/`、`/ˈhæzn/` 与句末 `yet`（均属待办）。
2. **混淆 `'s` 或把部分完成当成全部完成**：辨清 `He's finished`（已完成）与 `He's finishing`（进行中）；`almost done`、`half ... so far` 均未完成。
3. **盲从旧计划**：遇 `planned to ...` 保持警觉，以转折后的状态为准。
4. **`for / since / in` 换算错位**：`since` 算间隔不重复计算首尾两天、不抄起点；`in` 配 `will` 表将来，勿混 `for`。
5. **中式直译**：
   - 汇总至今进度时 `so far` 禁配过去时：`*So far I packed three boxes.` → `So far, I've packed three boxes.`
   - `wait for` 禁漏 `for`：`*waiting the reply` → `waiting for the reply`
   - 否定简答禁 `*No, yet.` → `Not yet.`
   - `finish` 禁接 `to do`：`*finished to write` → `finished writing`
   - `progress` 不可数：`*a progress` → `progress`

**听辨三查**：① 查 `'s` 后词形与否定；② 查未完信号（`almost done / half ... so far`）与转折；③ 查 `for / since / in` 方向与减法。
