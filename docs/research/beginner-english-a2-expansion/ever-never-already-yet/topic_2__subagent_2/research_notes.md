# 第12讲「经历与进度副词（ever / never / just / already / yet）」日常与职场语料及语法笔记

## 1. 语境定位与 A2 语料边界

- **课程定位**：`beginner-english` 第 13 单元「个人经历与进度追踪（`experiences-progress`）」→ 第 12 讲「经历与进度副词（`ever-never-already-yet`）」，目标级别 **CEFR A2**，`skill_focus: grammar_core`（预算 45 分钟；配额 `listening: 1`、`reading_comprehension: 1`、`cloze: 1`、`translation: 1`、`writing (sentence_making): 1`、`single_choice: 2`、`multiple_choice: 1`、`true_false: 1`、`vocab_target: 2`）。
- **体系衔接**：保留现有第 1–10 单元（37.33 小时、41 个知识点）与全部既有 ID 不变，弱化车间背景，按通用 CEFR A1+→A2 听说读写体系扩展第 11–16 单元（+23.00 小时、+30 个微知识点，总课时 60.33 小时）。本讲紧承先修第 11 讲 `present-perfect-forms`（`have/has + 过去分词`、缩写 `'ve/'s/haven't/hasn't` 与 `have been to`），自然复现第 11–12 单元的美食、旅行与 `I'll` 即时响应。
- **场景与语法边界**：
  - 全部语料聚焦**① 朋友畅聊旅行与美食经历**、**② 现代职场与团队事项核对清单**两大通用场景，**严格不含任何车间或工位术语**。

## 2. 两大核心场景高频词块库与地道例句

### 2.1 朋友畅聊旅行与美食经历（`ever / never`）

| 语用功能 | 高频地道英文词块 | 中文释义 | 搭配与语序提示 | A2 地道例句 |
| :--- | :--- | :--- | :--- | :--- |
| 问美食经历 | `Have you ever tried ...?` / `spicy hot pot` / `street food` | 你曾尝过……吗？ / 麻辣火锅 / 街头小吃 | `ever` 放主语与过去分词之间；`try → tried` | ***Have** you **ever tried** spicy hot pot?* |
| 问旅行足迹 | `Have you ever been to ...?` / `visited a night market` | 你曾去过……吗？ / 逛过夜市 | 问“去过且已回”必用 `been to`，不用 `gone to` | ***Have** you **ever been to** Chengdu?* |
| 问特色体验 | `seen snow` / `taken a night train` / `cooked Thai food` | 见过雪 / 坐过夜班火车 / 做过泰餐 | 复现高频不规则过去分词 `seen / taken / eaten` | ***Has** she **ever taken** a night train?* |
| 述零经历 | `I've never been abroad.` / `never eaten raw fish` | 我从未出过国 / 从没吃过生鱼 | `never` 自带否定，助动词保持肯定 `have/has` | *I**'ve never been** abroad, so I'm excited.* |
| 自然互动 | `Yes, I have! It's delicious.` / `No, never.` | 尝过，超好吃！ / 没有，从没试过。 | 简答常用 `No, never.`，可顺接愿望 `I'd love to...` | *No, **never**—I'd love to try it this weekend!* |

### 2.2 团队事项核对清单与即时同步（`just / already / yet`）

| 语用功能 | 高频地道英文词块 | 中文释义 | 搭配与语序提示 | A2 地道例句 |
| :--- | :--- | :--- | :--- | :--- |
| 刚刚完成 | `just sent the email` / `just uploaded the file` | 刚发完邮件 / 刚上传文件 | `have/has + just + 过去分词`，表几分钟前刚发生 | *I**'ve just sent** the updated price list to the client.* |
| 已经完成 | `already updated the slides` / `already booked Room Two` | 已经更新幻灯片 / 已经订好二号会议室 | 肯定句中常放助动词与过去分词之间（也可放句末） | *She**'s already booked** Meeting Room Two.* |
| 尚未完成 | `haven't printed the handouts yet` / `hasn't replied yet` | 还没打印讲义 / 还没回复 | `yet` 固定放否定句末，提示“预计很快会做” | *I **haven't printed** the handouts **yet**.* |
| 例行核对 | `Have you checked the budget yet?` / `shared the notes yet` | 你核对好预算了吗？ / 分享纪要了吗？ | 疑问句末用 `yet`，语气中性礼貌 | ***Have** you **emailed** the client **yet**?* |
| 清单对照 | `I've already ..., but I haven't ... yet.` | 我已经……，但还没…… | 团队会前核对万能结构，一正一反汇报最清晰 | *I**'ve already updated** the slides, but I **haven't printed** them **yet**.* |
| 简答补救 | `Not yet. I'll do it right now.` | 还没，我马上就办。 | `Not yet.` 替代完整否定句，衔接第 8 讲 `I'll` | *—Have you tested the screen **yet**? —**Not yet.** I'll check it now.* |

## 3. 五副词对比矩阵与地道口语速查

### 3.1 语用、句型与位置速查表

| 副词 | 核心语义 | 典型句型 | 句中位置 | 典型例句 |
| :--- | :--- | :--- | :--- | :--- |
| **`ever`** | 曾经（迄今任意时刻） | 疑问句（`?`） | `Have/Has + 主语 + ever + 过去分词` | *Have you **ever** tried Thai curry?* |
| **`never`** | 从未（零经历） | 肯定形态表否定（`-`） | `have/has + never + 过去分词` | *I've **never** visited Singapore.* |
| **`just`** | 刚刚（极短时间前） | 肯定句（`+`） | `have/has + just + 过去分词` | *The waiter has **just** brought our tea.* |
| **`already`** | 已经（早于预期） | 肯定句（`+`）；表惊讶疑问 | `have/has + already + 过去分词` 或句末 | *I've **already** sent the calendar invite.* |
| **`yet`** | 尚未（否）；已经（问） | 否定句（`-`）与疑问句（`?`） | 固定置于**句末** | *We haven't ordered lunch **yet**.* |

### 3.2 四条高频交际与口语要点

1. **中性询问用 `yet`，表达惊讶才在疑问句用 `already`**：常规进度确认说 *Have you printed the handouts **yet**?*；若惊讶对方完成得极快，才说 *Have you finished the slides **already**?*（“你这么快就改完了？”）。
2. **`already` 支持中置与句末两处位置**：A2 首选助动词后（*I've **already** booked the hotel.*）；口语强调“早就办妥”时也可置句末（*I've booked the hotel **already**.*）。
3. **短答固定形式**：答 `Have you ever...?` 用 `Yes, I have.` / `No, never.`；答 `Have you ... yet?` 用 `Yes, I have.` / `Not yet.`（绝不说 ~~No, yet.~~）。
4. **英美口语听辨提示**：CEFR A2 规范与国际通用测试将 `just / already / yet` 统一搭配现在完成时；美式日常口语偶见配一般过去时（*I just sent it.* / *Did you eat yet?*），泛听能理解即可，本讲作答统一用 `have/has + 过去分词`。

## 4. 三组完整双语情景对话（TTS 与逐字稿就绪）

> **适配说明**：每组均为一女（`stella`）一男（`tide`），无舞台括号，钟点采用纯英文拼写，可直接用于 `listening` 题型及 `study_translation.material` 逐行对齐。

### 对话 1：咖啡馆畅聊旅行与美食经历（Travel and Food Experiences）

- **角色**：`Sophie`（女声 `stella`）/ `Daniel`（男声 `tide`）
- **逻辑核验**：两人翻看成都旅游指南 → Daniel 从未去过成都、也未吃过麻辣火锅，但去过西安 → Sophie 在夜市尝过烤海鲜与炒面，但从未做过泰餐 → 服务员刚端来咖啡，Sophie 还没尝过新柠檬蛋糕，决定下次试。

| 轮次 | 英文台词 | 中文对照 | 语法焦点 |
| :--- | :--- | :--- | :--- |
| 1 | **Sophie:** Hey Daniel, I'm reading a travel guide for Chengdu. Have you ever been there? | 苏菲：嘿，丹尼尔，我在看成都旅游指南。你去过那里吗？ | `Have you ever been` 问足迹 |
| 2 | **Daniel:** No, I've never been to Chengdu, but I've visited Xi'an. | 丹尼尔：没有，我从未去过成都，但我去过西安。 | `never been to` 零经历 |
| 3 | **Sophie:** Nice! Have you ever tried spicy hot pot? | 苏菲：真不错！你尝过麻辣火锅吗？ | `Have you ever tried` 问美食 |
| 4 | **Daniel:** No, never! I like spicy food, so I really want to try it. What about you? Have you ever eaten at a night market? | 丹尼尔：没有，从没试过！我喜欢辣味，所以很想尝尝。你呢？你逛过夜市吃东西吗？ | `No, never` 简答 + 反问 |
| 5 | **Sophie:** Yes, I have! I've tried grilled seafood and fried noodles at night markets. | 苏菲：吃过呀！我在夜市尝过烤海鲜和炒面。 | 肯定简答 + 完成时 |
| 6 | **Daniel:** That sounds delicious! Have you ever cooked Thai food at home? | 丹尼尔：听起来好香！你在家自己做过泰餐吗？ | `ever + 过去分词` |
| 7 | **Sophie:** No, I've never cooked Thai food. Oh, look—the waiter has just brought our coffee! | 苏菲：没有，我从没做过泰餐。哎，快看——服务员刚把我们的咖啡端过来了！ | `never` + `has just brought` |
| 8 | **Daniel:** Great! By the way, have you tried their new lemon cake yet? | 丹尼尔：太好了！顺便问下，你尝过他们家的新款柠檬蛋糕了吗？ | `yet` 疑问句末核对 |
| 9 | **Sophie:** Not yet. I've already had a big lunch, so I'll try it next time! | 苏菲：还没有。我已经吃过丰盛的午饭了，所以下次再尝吧！ | `Not yet` + `already` + `I'll` |

| 单选 2（经历 `ever / never`） | *"Have you ______ tried Thai curry?" — "No, I've ______ eaten it."* | 正答：`ever; never`（干扰项：`yet; never` / `ever; not never` / `never; ever`） |
| 多选 1（语序与句型综合） | 选出语法正确且自然的 A2 表达 | 正答：`She has just sent the email.` / `Have you booked Room Two yet?` / `I've never been abroad.`（干扰项：`I haven't already printed the slides.`） |
| 判断 1（双重否定与 `yet` 边界） | 表达“我从未尝过辣火锅”可以写作 *I haven't never tried spicy hot pot.*。 | **False**（`never` 本身表否定，不可与 `not` 连用，应作 `I've never tried spicy hot pot.`） |
