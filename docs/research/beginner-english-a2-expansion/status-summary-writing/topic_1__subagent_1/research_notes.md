## 一、CEFR A2 进度汇报写作定位与教学边界

参照 **CEFR Companion Volume（A2 书面产出量表：*Notes, Messages and Forms*）** 与 **Cambridge A2 Key (KET) Writing** 评分标准，本讲是全课**第二篇 `short_essay` 实战节点**。相比第 10 讲仅围绕将来时展开的 50–70 词出行计划，本讲将词数提升至 **60–80 词**，核心进阶在于**在同一篇短文中清晰驾驭“过去成果（至今）→ 具体过去节点 → 下一步计划”三套时态**。

在本课程 v2 `writing`（`subtype: short_essay`）评估体系下，三大评分维度对应明确语法落点：
1. **任务完成度（`task_completion`）**：完整覆盖三要素（阶段成果与待办缺口、关键过去节点、下一步安排），词数稳落 60–80 词区间。
2. **语言准确度（`language_accuracy`）**：现在完成时、一般过去时与将来时切换准确，时间标志与介词（`so far / already / yet / yesterday / by Friday`）零冲突。
3. **连贯衔接（`coherence`）**：三层结构递进清楚，善用时间锚点与 `and / but / so` 串联信息，避免孤立流水账短句。

> **A2 教学边界（防超纲、防重叠）**：
> - **不引入 B1+ 语法**：不展开现在完成进行时（`have been doing`），持续推进中的事项统一用已学**现在进行时**（*I'm still working on...*）或**现在完成时简单式**（*I've studied English for three months.*）表达；不提前展开完整第一条件句（留第 21 讲），结尾 `Let me know if you have any questions.` 按交际整块（chunk）直接复用。
> - **不展开完整商务邮件体裁**：本讲聚焦正文三要素与一句式轻开场/收尾，完整邮件主题行、称呼落款与正式语气留待第 16 单元（`email-structure-etiquette`、`email-memo-full-writing`）。

## 二、进度更新短文三要素结构与 60–80 词蓝图

60–80 词短文宜按**“三要素主体（约 5–6 句）+ 可选一句轻开场/轻收尾”**规划，每层承担唯一的时间视角，从源头杜绝时态互串：

| 结构要素 | 交际功能与必含信息 | 词数 / 句数预算 | 主导时态与辅助结构 | 通用生活与现代职场骨架示例 |
| --- | --- | --- | --- | --- |
| **要素一：已完成成果与当前缺口**<br>*(Achievements & Pending Status)* | 汇报**截至目前**已经做完什么（可附持续时长），并自然交代**尚未完成**或**仍在推进**的事项 | **22–28 词**<br>（1–2 句） | **现在完成时**（核心）：<br>`'ve / 's already + V3`<br>`So far, I've + V3`<br>`haven't + V3 ... yet`<br>辅助：**现在进行时**（`still working on / waiting for`） | *So far this week, I**'ve already finished** the project slides, but I **haven't shared** them with the team **yet**.*<br>*I**'ve learned** 60 new words **this month**, and I**'m still working on** my listening notes.* |
| **要素二：关键过去节点**<br>*(Key Past Milestone)* | 回顾**过去某个具体已结束时间点**发生的关键动作、会议、测试或阶段突破 | **18–24 词**<br>（1–2 句） | **一般过去时**（核心）：<br>`主语 + V2` / `was / were`<br>配已结束时间锚点（`Yesterday,` / `On Tuesday,` / `Last week,`） | ***Yesterday**, I **met** with our designer online and **checked** the new layout.*<br>***On Wednesday**, I **took** a short practice quiz and **got** a good score.* |
| **要素三：下一步计划与截止点**<br>*(Next Steps & Closing)* | 说明接下来打算做什么、承诺交付时间，并以一句礼貌收尾结束汇报 | **18–26 词**<br>（1–2 句） | **将来时**（核心）：<br>`will / 'll + V1`（承诺/交付）<br>`be going to + V1`（既定计划）<br>+ 截止介词 `by + 时间点` | ***Next week**, I**'ll send** the final report **by Friday**. Please let me know if you have any questions.*<br>***Tomorrow**, I**'m going to** review Unit 5 and record a short speaking clip.* |

### 三要素谋篇实操原则
1. **先总后细，先今再昔后明**：要素一先让读者一眼掌握“现在到底完成了多少、还差什么”，符合现代职场“结论先行”习惯；要素二补充具体过去经过作佐证；要素三落到明确行动与时间节点。
2. **可选轻开场控制在 6–8 词**：若需抬头，仅用一句总起（*Here is my update for this week.* / *Here is my study summary for May.*），切勿喧宾夺主挤占正文词数。
3. **每层只锁定一套主时态**：同一信息层内保持时态一致，跨层时借**句首时间锚点**（`So far this week,` → `Yesterday,` → `Next week,`）显性切换，读者几乎零理解成本。

## 三、多时态切换机制与核心语法规则

### 1. 三要素时态 × 时间标志 × 语用触发对照表

依据 **Cambridge *English Grammar Today*** 与 **British Council LearnEnglish (A1–A2)**，进度写作中的时态选择取决于**时间区间是否已经结束**：

| 写作层级 | 目标时态 | 核心语用视角 | 高频时间锚点 / 信号词 | 语法红线（严防跨层误配） |
| --- | --- | --- | --- | --- |
| **要素一：阶段成果** | **现在完成时**<br>`have / has + V3` | **未结束时段 / 截至此刻的结果**（强调现在状态） | `so far`、`already`、`just`、`yet`（否/疑）、`for + 时段`、`since + 起点`、`this week / this month`（仍在进行中） | 严禁与 `yesterday / last week / on Tuesday / ... ago` 同句连用；`already` 居中，`yet` 置句末 |
| **过渡：当前卡点** | **现在进行时**<br>`am / is / are + V-ing` | **此刻仍在持续推进或等待**（尚未收尾） | `still`、`right now`、`at the moment` | 表达“还在做/还在等”须配完整 `be + V-ing`，介词不可漏（`working on`、`waiting for`） |
| **要素二：过去节点** | **一般过去时**<br>`V2` / `didn't + V1` | **已彻底结束的过去时间点**（回答 *When?*） | `yesterday`、`last Monday / last week`、`on Tuesday`、`two days ago`、`this morning`（上午已结束时） | 一旦点出具体过去时间，全句动词须用 `V2`；连词 `and` 后的并列过去动词**也必须保持 `V2`** |
| **要素三：下一步** | **`will / 'll + V1`**<br>**`be going to + V1`** | **`will`**：交付承诺、跟进汇报<br>**`be going to`**：已定学习或工作打算 | `tomorrow`、`next week / next Monday`、`this weekend`、`by Friday / by 5:00 p.m.` | `will` 与 `be going to` 后均接**动词原形**；已预约固定日程亦可用现在进行时（*I'm meeting Leo on Monday.*） |

### 2. 进度写作高频语法细则（A2 必守 5 条）

1. **`will` vs. `be going to` 在要素三的精准选型**：
   - 面对同事、客户或导师作出**工作交付承诺、按期反馈**时，优先用 **`will / 'll`**（*I**'ll email** the updated schedule by Thursday.* / *I**'ll send** another update next Friday.*）。
   - 描述**个人事先规划好的学习安排或待办计划**时，优先用 **`be going to`**（*Next week, I**'m going to** practice speaking for 20 minutes every evening.*）。
2. **截止时间介词：`by` vs. `until`（Cambridge *English Grammar Today* 核对）**：
   - **`by + 时间点`** = “**不晚于**该时间”（用于 `finish / send / submit / upload` 等瞬时完成或交付动作）：
     - 正确：*I'll finish the first draft **by Friday**.* / *Please send your feedback **by 5:00 p.m.***
     - 错误：`*I'll finish the first draft until Friday.`
   - **`until + 时间点`** = “**一直持续到**该时间为止”（用于持续状态或活动，或 `have until ... to do` 窗口表达）：
     - 正确：*I'll work on the slides **until 4:00 p.m.*** / *We have **until Friday** to submit the form.*
3. **时间短语的零介词与介词边界**：
   - **`this / last / next` + 时间名词前不加介词**（正确：`this week / last Tuesday / next Monday`；错误：`*in next week` / `*on last Tuesday`）。
   - 无 `last / next` 修饰的具体星期前须加 **`on`**（*On Wednesday, we reviewed the budget.*）；月份与年份前用 **`in`**（*In April, I started this course.*）。
   - 时间短语置于句首充当全句时间锚点时，**标准加逗号**（`So far this week,` / `Yesterday,` / `On Tuesday,` / `Next week,`）。
4. **高频进展表达的核心词法约束（经 Cambridge Dictionary 核对）**：
   - **`progress` 为不可数名词**：不可加 `a` 或复数 `-s`，固定配动词 **`make`** 而非 `do`（正确：*I've **made good progress** this month.*；错误：`*made a progress` / `*did good progress`）。
   - **`work on` 与 `finish` 接动作规范**：`on` 是介词，后须接**名词或动名词 `V-ing`**（*working on **the report** / working on **writing** the summary*，禁 `*work on to write`）；`finish` 后同样接名词或 `V-ing`（*finished **checking** the notes*，完整动词配价规则留第 22 讲展开，本讲作高频写作用语直记）。
5. **段内并列与转折的自然压缩**：
   - 用 **`and`** 合并同一主语、同一时态下的两个动作，可省去重复主语与助动词（*Yesterday, I **read** two chapters **and wrote** short notes.* / *I**'ve already written** the draft **and checked** the numbers.*）。
   - 用 **`, but`** 在要素一内紧扣“已完成 + 尚未完成”形成对比（*We**'ve already booked** the room, **but** we **haven't sent** the agenda **yet**.*），结构紧凑且避免句式单调。

## 四、语用规范与高复用句型骨架库

### 1. 日常个人小结 vs. 现代职场周报：语域对照

| 语域维度 | 个人学习 / 生活打卡小结 | 现代职场周报 / 团队进度消息 |
| --- | --- | --- |
| **人称视角** | 以第一人称单数 **`I`** 为主，关注个人达成与感受 | 个人任务用 **`I`**，协作成果自然切换 **`We`** |
| **缩写规范** | 推荐自然缩写（`I've / haven't / I'm / I'll`），语气亲切流畅 | 内部群消息/周报可用常见缩写（`I've / we'll`）；面向客户或正式汇报可用完整形（`I have / we will`）显稳重 |
| **轻开场句** | *Here is my study update for this week.*<br>*I've had a busy week with my English practice.* | *Hi team, here is a quick update on the project.*<br>*Here is my weekly progress update.* |
| **轻收尾句** | *I'm happy with my progress so far!*<br>*I hope to keep up this habit next week.* | *I'll share another update next Friday.*<br>*Please let me know if you have any questions.* |
| **时间精度** | 可用相对时段（`this weekend / next week / every day`） | 尽量给出明确交付节点（`by Wednesday / by 5:00 p.m.`），体现可靠度 |

### 2. 三要素高复用微句型骨架（供造句与段落组装）

1. **要素一（已完成 + 未完成对比）**
   - 骨架：`So far this week, I've already [V3 + 宾语], but I haven't [V3 + 宾语] yet.`
   - 例句：*So far this week, I**'ve already updated** the client list, **but** I **haven't emailed** the new price sheet **yet**.*
2. **要素一（持续时长 + 进展小结）**
   - 骨架：`I've [V3 + 活动] for [时长] / since [起点], and I've made good progress.`
   - 例句：*I**'ve practiced** listening **for three weeks**, and I**'ve made good progress** with short dialogues.*
3. **要素一→过渡（进行中任务 / 外部等待）**
   - 骨架：`Right now, I'm still working on [名词 / V-ing] / waiting for [人/事].`
   - 例句：*Right now, I**'m still working on** the summary chart and **waiting for** Anna's feedback.*
4. **要素二（过去具体节点 + 双动作并列）**
   - 骨架：`Yesterday / On [星期], I [V2 + 宾语] and [V2 + 宾语].`
   - 例句：***On Tuesday**, we **held** a short online meeting **and confirmed** the launch date.*
5. **要素三（职场交付承诺 + `by` 截止点）**
   - 骨架：`Next week, I'll [V1 + 宾语] by [截止时间].`
   - 例句：***Next week**, I**'ll upload** the final slides **by Wednesday afternoon**.*
6. **要素三（个人学习计划 + 礼貌收束）**
   - 骨架：`Tomorrow / Next week, I'm going to [V1 + 宾语]. [收尾句]`
   - 例句：***Next week**, I**'m going to** review my vocabulary notes and write a short summary. I'm happy with my progress so far!*

   - **`deadline`**（`category: "word"`，`pos: "n"`；释义：截止日期；最后期限）：`grammar_note` 写明“可数名词，常与 `by`（不晚于）或 `meet a deadline` 搭配，说明下一步计划的交付节点”。
   - *备选单字*：**`draft`**（`word`, `n.` 草稿；初稿，可数名词，常配 `first draft / final draft`，兼顾学习写作与职场周报）。

   - **`writing` — `short_essay`（1 题）**：设计远程办公周报或个人学习打卡小结任务，设 `min_words: 60`、`max_words: 80`、3 条明确 `requirements`（一一对应三要素）及 `rubric`（`task_completion` / `language_accuracy` / `coherence`）；严格遵循仓库规范，`sample_response` 与 `sample_response_tts` 仅在批改复盘与背题态展示。

   - **`cloze`（1 题）**：一篇 65–80 词的办公周报或学习小结短文，设空覆盖现在完成时 / 一般过去时 / 将来时切换、`already / yet`、`by` 与 `make progress`。
   - **`translation`（2 题）**：1 题聚焦要素一“截至目前已完成……但还没……”+ 要素二“昨天……”，1 题聚焦要素三“下周我将在周五前……”，保持全场景通用日常/职场化。
   - **`single_choice`（2 题）与 `true_false`（1 题）**：精准检测 `Yesterday` 禁配现在完成时、`by Friday` vs. `until Friday` 截止表达、`this / next week` 零介词、`progress` 不可数及 `work on + 名词/V-ing`。
