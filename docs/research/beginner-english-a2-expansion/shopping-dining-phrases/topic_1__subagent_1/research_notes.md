## 一、CEFR A2 购物与点餐语法定位及模块分工

在 CEFR A2 能力框架中，学习者需要能在**商店、超市、咖啡馆、餐厅与日常办公采购**等高频消费场景中，得体完成“礼貌提出需求 → 询问尺码/规格与试穿 → 询问价格与确认方式 → 付款与收尾”的完整交互闭环。

### 1. 与前置知识点的能力承接

| 前置知识点 | 既有基础 | 本讲（A2）核心跃升 |
| --- | --- | --- |
| `polite-requests` | `Please + 动词原形`、`Can/Could you … please?`（请他人帮忙） | 拓展至服务消费中的**第一人称礼貌索取**：`I'd like…`、`Can/Could I have/get/try/pay…?` |
| `wh-questions` | `What / Where / How many / How much` + `be / do / does` 倒装 | 精准区分询价双结构：`How much is/are…?` vs `How much does/do … cost?` |
| `quantifiers-amounts` & `countable-articles` | 可数/不可数名词、`a/an/the`、`some/any`、`Would you like some…?` | 运用于真实点单与选购：`an iced latte`、`two coffees`、`some water`、`a pair of shoes` |
| `demonstratives` & `comparatives` | `this/that/these/those`、`-er / more` 比较级 | 运用于指物询价与选码试穿：`How much are these?`、`Do you have this in a larger size?` |

### 2. 本讲内部三子主题与后续课时边界

- **本子主题（Topic 1）**：系统梳理语法规则、句型公式、可分离短语动词语序、支付介词搭配、英美表达对照与礼貌语调规范。
- **留给 Topic 2**：超市收银、咖啡店点单、服装选码换货、刷卡找零与索要小票的完整多轮情景对话脚本。
- **留给 Topic 3**：价格听辨细节（如 `$14.50` vs `$40.15`、折扣 `20% off` 的连读听辨）、直译生硬表达（`I want…`）的系统纠偏与情景听力训练设计。
- **留给第 4、5 讲**：菜单/价签/小票的书面字段精读与算账（`receipts-menus-reading`）以及 45 秒脱稿录音演练自评（`oral-shopping-roleplay`）。

## 二、礼貌点餐与购物需求核心句型（`I'd like` / `Can I have` / `Could I` / `I'll have`）

### 1. `would like`（`'d like`）核心语法规则

在英语消费与服务场合，`would like`（口语几乎总是缩写为 `'d like`）是表达“我想要……”的标准礼貌结构，语义等同于更委婉的 `want`。

1. **形态恒定不变**：`would` 是情态动词，**所有人称一律用 `would like`（`'d like`）**，第三人称单数绝不加 `-s`：
   - 正确：`I'd like a green tea.` / `She'd like a chicken sandwich.` / `We'd like a table for three.`
   - 错误：`*She'd likes a chicken sandwich.` / `*He would likes some water.`
2. **两大合法补语结构**：
   - **结构 A（点选物品/食物）**：`主语 + 'd like + 名词短语 (+ , please).`
     - `I'd like a medium latte and a croissant, please.`（请给我一杯中杯拿铁和一个牛角包。）
     - `We'd like two bottles of sparkling water, please.`（请给我们两瓶气泡水。）
   - **结构 B（表达想做的动作）**：`主语 + 'd like + to + 动词原形 (+ 其他).`
     - `I'd like to order now, please.`（我现在想点餐。）
     - `I'd like to pay by card.`（我想刷卡付款。）
     - `I'd like to exchange this shirt for a medium.`（我想把这件衬衫换成中码。）
   - **强制语法禁区**：`would like` 后接动作时**必须带 `to`（动词不定式）**，绝不能直接接动词原形或 `V-ing`：
     - 错误：`*I'd like buy this umbrella.` / `*I'd like ordering now.`
3. **疑问式（店员提议/询问）与否定婉拒**：
   - 店员询问：`What would you like (to drink / to order)?`（您想点什么？）
   - 店员提议（衔接第 2 讲 `some` 特例）：`Would you like some ice in your tea?` / `Would you like a bag?` / `Would you like to see the menu?`
   - 顾客得体回应：
     - 接受：`Yes, please.` / `Yes, I'd like an orange juice, please.`
     - 婉拒：日常点餐中极少直接说 `I wouldn't like...`（听起来略显生硬），更地道的是 **`No, thank you.`** / **`No, thanks. I'm fine.`** / **`Nothing else, thank you.`**（不需要别的了，谢谢）。

### 2. A2 核心语法辨析：`I'd like` vs `I like`

初学者常因 `'d` 弱读而混淆 `I'd like` 与 `I like`，二者在时态、含义和后续动词搭配上截然不同：

| 对比维度 | `I like`（一般现在时） | `I'd like` = `I would like`（情态动词结构） |
| --- | --- | --- |
| **核心语义** | 泛指**长期喜好、习惯**（“我喜欢……”） | 特指**此时此刻的具体需求**（“我想要……”） |
| **接名词（常见冠词差异）** | 多接复数或不可数名词表泛指：`I like coffee.` / `I like apples.` | 多接具体份数或限定名词：`I'd like **a** coffee, please.` / `I'd like **some** apples.` |
| **接动词形式** | 可接 `V-ing` 或 `to do`：`I like drinking tea.` / `I like to cook.` | **只能接 `to + 动词原形`**：`I'd like **to order** now.`（不可接 `-ing`） |
| **点单语用正误** | 对服务员说 `*I like a sandwich.` 会让对方以为你在聊个人爱好，而非点餐 | 正确点餐：`I'd like a sandwich, please.` |

### 3. 点餐与购物礼貌梯度量表（Politeness Scale）

在英语国家，直接套用中文“我要…… / 给我……”逐字直译容易显得生硬命令化。A2 学习者应掌握以下礼貌层级并按场景选用：

| 礼貌等级 | 句型结构 | 典型例句（日常与职场） | 语用评价与适用场景 |
| --- | --- | --- | --- |
| **低（生硬，须避免）** | `Give me...` / `I want...` | `*Give me a coffee.` / `*I want the bill.` | 祈使命令或直白索求，对店员/服务员显得不礼貌（除非熟人轻松开玩笑，本课要求避免） |
| **中性自然（口语随性）** | `I'll have...` / `I'll take...` / `Can I get...`（美式口语） | `I'll have the tomato soup, please.`<br>`Great, I'll take this jacket.`<br>`Can I get an iced Americano?` | 看完菜单或试穿后**当场决定**（`I'll have` 用于点餐，`I'll take` 用于买商品）；美式咖啡馆柜台极常用 `Can I get...?` |
| **标准礼貌（A2 核心首选）** | `I'd like..., please.`<br>`Can I have..., please?` | `I'd like a chicken salad, please.`<br>`Can I have a glass of warm water, please?` | 最安全、英美通用的日常礼貌表达，餐厅、咖啡馆、超市与商店全场景适用 |
| **更委婉客气（正式/麻烦对方时）** | `Could I have..., please?`<br>`Could I + 动词原形..., please?` | `Could I have the receipt for my company, please?`<br>`Could I try this on in a larger size, please?` | `Could` 是 `can` 的委婉形式（此处**不表过去时**，表礼貌距离），适合正式餐厅、商务接待或提出额外要求（如换码、改配方、分账） |

> **语法提示（预览第 12 单元 `future-will`）**：本讲将 **`I'll have...`**（点餐决定）和 **`I'll take it / them`**（购物决定买下）作为**固定高频语块**直接教授，暂不展开 `will` 的完整将来时语法体系，避免知识超载；到第 12 单元第 8 讲 `future-will` 时再回扣“当场决定（instant decision）”的语法本质。

### 4. 开场与收尾礼貌软化词（Pragmatic Softeners）

1. **`Excuse me,` vs `Sorry,`**：
   - 引起店员注意或准备提问时，必须用 **`Excuse me,`**（打扰一下）：`Excuse me, how much is this notebook?` / `Excuse me, where is the dairy section?`
   - 表达致歉（如撞到别人、没听清请对方重复）用 **`Sorry,`**（抱歉）：`Sorry, could you say that again?`（避免用 `Sorry` 去招呼正在忙的服务员，英式偶见，A2 规范优先 `Excuse me`）。
2. **`, please` 的语序与标点**：
   - 放句尾最自然，书面须在前面加逗号：`I'd like a receipt, please.` / `Can I have a bag, please?`
   - 在 `Could you ...` 句型中也可放在主语后动词前：`Could you please check if you have size L?`
3. **递交与应答闭环**：
   - 递给对方商品、现金或银行卡时说 **`Here you are.`**（通用/略正式）或 **`Here you go.`**（口语常见）。
   - 结束交易道谢：`Thank you.` / `Thanks a lot.` — 回应：`You're welcome.` / `No problem.` / `Have a nice day!`

## 三、试穿、选码与商品咨询句型（`Can I try… on` 与可分离短语动词）

### 1. 可分离短语动词 `try on` 的核心语序规则

`try on`（试穿衣服、鞋子或试戴帽子、眼镜）是 CEFR A2 必须掌握的典型**可分离短语动词（Separable Phrasal Verb）**，由“动词 `try` + 副词小品词 `on`”构成。其宾语位置有严格语法规则：

| 宾语类型 | 合法语序 | 典型例句 | 是否允许 |
| --- | --- | --- | --- |
| **名词短语（短）** | `try + 名词 + on`（口语最常用） | `Can I try **this jacket** on?` | 允许（推荐） |
| **名词短语（长/短均可）** | `try on + 名词` | `Can I try on **this blue jacket**?` | 允许（宾语较长时更自然） |
| **人称代词单数 `it`** | **`try + it + on`** | `This shirt looks nice. Can I try **it** on?` | **唯一合法** |
| **人称代词复数 `them`** | **`try + them + on`** | `These shoes are nice. Can I try **them** on?` | **唯一合法** |
| **代词置于 `on` 之后** | `*try on it` / `*try on them` | `*Can I try on it?` / `*I want to try on them.` | **绝对错误** |

> **关键记忆口诀**：“名词前后都能放，代词 `it / them` 夹中间。”

### 2. 衣物单复数与代词一致性（高频易错点）

英语中部分由“双腿/双脚/双镜片”构成的穿戴物品**天生以复数形式存在**，询问、试穿、评价与买单时必须全程保持复数一致（搭配 `these / those`、`are`、`do`、`them`、`a pair of`）：

| 类别 | 高频词汇 | 试穿句型 | 询价句型 | 买单句型 |
| --- | --- | --- | --- | --- |
| **单数可数衣物** | `shirt`, `T-shirt`, `jacket`, `coat`, `sweater / jumper`, `dress`, `skirt`, `hat`, `scarf`, `bag` | `Can I try **this coat** on?` / `Can I try **it** on?` | `How much **is it**?` / `How much **does it** cost?` | `I'll take **it**, please.` |
| **复数/成双衣物** | `shoes`, `sneakers / trainers`, `boots`, `socks`, `pants / trousers`, `jeans`, `shorts`, `glasses`, `sunglasses` | `Can I try **these shoes** on?` / `Can I try **them** on?` | `How much **are they**?` / `How much **do they** cost?` | `I'll take **them**, please.` |

- **计量提示**：指“一双鞋 / 一条裤子”用 `a pair of shoes / a pair of jeans`；此时中心词 `pair` 为单数（`This pair of shoes is $60.`），但直接指代鞋/裤子本身时仍用复数 `they / them`。

### 3. 选码、颜色、合身度与逛店应答核心句型

1. **寻找试衣间**：
   - `Excuse me, where is the fitting room?`（美式与国际商场通用）
   - `Excuse me, where are the changing rooms?`（英式商场高频）
2. **询问尺码与颜色（核心介词 `in`）**：
   - `Do you have this in (a) medium / large / small?`（这件有中码/大码/小码吗？——尺码前可用零冠词 `in medium` 或加 `a`：`in a medium`；带 `size` 时不说 `a`：`in size M` / `in size 40`）
   - `Do you have this in a larger / smaller size?`（这件有更大/更小一码的吗？）
   - `Do you have these in size 42?`（这双有 42 码吗？）
   - `Do you have this in another color?` / `Does it come in black?`（这款有别的颜色 / 黑色吗？）
3. **表达合身与不合身（衔接形容词基础与 `too`）**：
   - 合身：`It fits well.` / `It fits me perfectly.` / `They're very comfortable.`（注意动词 `fit` 表尺码合适，常用一般现在时）
   - 不合身：`It's a bit too tight / loose / small / big / long.`（`a bit` / `a little` 缓和语气，更符合英语礼貌习惯）
4. **回应店员主动招呼（`Can I help you?` / `How can I help you today?`）**：
   - 仅浏览无需帮助：`No, thanks. I'm just looking.` / `I'm just browsing, thank you.`（切忌生硬回复 `*No.` 或 `*I don't need you.`）
   - 说明采购需求：`Yes, please. I'm looking for a dark blue shirt for a meeting.`（职场通用场景）

## 四、价格询问与结账付款句型（`How much is/are` vs `How much does/do … cost`）

### 1. 两大询价结构公式与语法边界

在日常购物、超市采购与点餐核价中，`be` 动词询价与 `cost` 动词询价语义完全等价，可自由交替使用，但二者**分属两套语法系统，绝不能混拼**：

| 询价体系 | 单数可数 / 不可数名词 | 复数可数名词 | 标准回答形式 |
| --- | --- | --- | --- |
| **`be` 动词体系（口语最高频）** | `How much **is** this coffee?`<br>`How much **is** the milk?`<br>`How much **is** it?` | `How much **are** these apples?`<br>`How much **are** those shoes?`<br>`How much **are** they?` | `It's $4.50.`<br>`They're $6.00.`<br>`That's $12.80 (in total).` |
| **实义动词 `cost` 体系** | `How much **does** this jacket **cost**?`<br>`How much **does** it **cost**?` | `How much **do** these notebooks **cost**?`<br>`How much **do** they **cost**?` | `It **costs** $45.`<br>`They **cost** $10.` |

**四条高频语法铁律**：
1. **`does` 后动词必还原**：`How much does this umbrella **cost**?`（绝不可写 `*How much does this umbrella costs?`）。
2. **陈述句主谓一致**：回答单数物品时 `cost` 须加 `-s`（`It **costs** $15.`），复数物品用原形（`They **cost** $15.`）。
3. **严禁 `be` 与 `cost` 杂糅**：`cost` 是实义动词，不可与 `is / are` 连用构成“假被动”或重复谓语：
   - 错误：`*How much is this bag cost?` / `*It is cost $30.`
   - 正确：`How much is this bag?` 或 `How much does this bag cost?` / `It is $30.` 或 `It costs $30.`
4. **`cost` 的主语必须是物品/服务，不能是人**：
   - 正确：`Lunch here costs about $12.` / `This notebook costs five dollars.`
   - 错误：`*I cost $12 for lunch.`（人作主语应改用 `pay` 或 `spend`，如 `I paid $12 for lunch.`，其中 `spend` 留待后续扩展）。

### 2. 单价、折扣与汇总的常见句法搭配

- **询问单价与按件/按重计价**：
  - `How much are the oranges per kilo / a kilo?` — `They're $3.50 a kilo.`
  - `They're $2 each.`（每个 2 美元。）
- **询问折扣与促销（衔接第 4 讲价签阅读与 Topic 3 听辨）**：
  - `Is this on sale?`（这个打折吗？——介词用 **`on`**）
  - `It's 20% off today.`（今天打八折 / 减价 20%。——注意英文 `20% off` 指“减掉 20%”，即中文的“八折”）
  - `Does this include tax?`（含税吗？）
- **汇总总价（结账固定表达，一律用单数动词）**：
  - `How much is everything altogether?` / `What's the total?`
  - `That's $24.50 altogether / in total.` / `Your total comes to $24.50.`

### 3. 支付方式介词精确搭配（`pay by` / `pay in` / `pay with`）

中国学习者最容易在 `pay` 的介词上出错（如误说 `*pay by cash` 或 `*pay by a card`）。参照 Cambridge Dictionary 规范，三条清晰规则如下：

| 介词搭配 | 核心语义逻辑 | 冠词/限定词要求 | 标准高频搭配与例句 |
| --- | --- | --- | --- |
| **`pay by + 支付方式`** | 抽象支付渠道/系统（同 `by bus`, `by email`） | **零冠词单数**（不加 `a/the`） | `pay by card`, `pay by credit card`, `pay by debit card`, `pay by bank transfer`<br>`Could I pay **by card**?` |
| **`pay in cash`**（或直接 **`pay cash`**） | 货币形态/现金状态（同 `in dollars`, `in full`） | 不可数名词，零冠词 | `Can I pay **in cash**?` / `I'll **pay cash**.`（避免 `*pay by cash`） |
| **`pay with + 具体工具/设备`** | 强调手中的实体卡片、手机、软件或现金 | **可数工具前须带 `a / my / your`** | `pay **with a** credit card`, `pay **with my** phone`, `pay **with** Apple Pay`, `pay **with** cash`<br>`Can I pay **with my phone**?` |

### 4. 结账、分账与索要小票高频句型（日常与职场通用）

- **确认收款方式**：`Do you accept / take credit cards?` / `Can I pay contactless?`（刷感应/碰一碰支付）
- **请求买单（餐厅）**：
  - 英式：`Could we have the bill, please?`
  - 美式：`Could we get the check, please?`
  - 同事工作餐分账（AA 制）：`Can we pay separately, please?` / `Could we split the bill?`（合并付款：`Together, please.` / `On one bill, please.`）
- **索要小票与购物袋**：
  - `Could I have a receipt, please?`（请给我一张小票好吗？——注意 `receipt` 中 `p` 不发音 `/rɪˈsiːt/`，且区分“付款前账单 `bill / check`”与“付款后凭证 `receipt`”）
  - 职场报销高频：`Could I get a printed receipt, please? I need it for my expense report.`
  - `Would you like a bag?` — `Yes, please.` / `No, thanks. I have my own bag.`
- **找零与核对**：
  - 店员：`Here's your change and your receipt.`（这是您的找零和小票。）
  - 顾客：`Thank you!`（小费或凑整场景可补充认知：`Keep the change.` 不用找了。）

## 五、堂食与打包表达及英美差异对照（`take away` vs `eat in`）

在咖啡馆、面包店与简餐厅点单时，柜台人员几乎必问“堂食还是打包？”。A2 学习者需要**同时听懂英美两套主流表达**，并在口头输出时任选一套保持一致。

### 1. 堂食 vs 打包核心对照表

| 交际含义 | 英式 / 国际常用（UK / Commonwealth） | 美式 / 北美常用（US / Canada） | 句法与拼写注意要点 |
| --- | --- | --- | --- |
| **店员经典问法** | `Eat in or take away?`<br>`Are you eating in or taking away?` | `For here or to go?`<br>`Is that for here or to go?` | 典型选择疑问句，语调**前升后降**（见第六节） |
| **在店内用餐（堂食）** | `Eat in, please.` / `To eat in, please.`<br>（标识亦见 `Eat here` / `Dine in`） | `For here, please.`<br>（快餐店亦偶见 `To stay, please.`） | `eat in` 是动词短语；`for here` 是介词短语，不可混拼为 `*for eat in` |
| **打包带走（外带）** | `Take away, please.` / `To take away, please.` | `To go, please.` | **拼写区分**：动词短语分写 **`take away`**（`two coffees to take away`）；英式名词/定语连写 **`takeaway`**（`a takeaway coffee`）；美式名词/定语多用 **`takeout`**（`get takeout`） |
| **点单一步到位** | `I'd like a cappuccino **to take away**, please.` | `I'd like a medium latte **to go**, please.` | 把 `to take away` 或 `to go` 直接附在所点餐品名词短语之后，高效自然 |

### 2. 购物与餐饮高频英美词汇速查（听力兼容必备）

由于真实听力与出国/涉外职场交流会同时遇到英美口音与用词，建议在讲义小贴士中集中点明以下 5 组高频等价词：

| 中文含义 | 英式常用（UK） | 美式常用（US） | 语境例句 |
| --- | --- | --- | --- |
| 堂食 / 打包 | `eat in` / `take away` | `for here` / `to go` | `Two iced teas to go, please.` |
| 餐厅账单 | `bill` | `check` | `Could we have the bill / check, please?` |
| 试衣间 | `changing room` | `fitting room` | `Where is the fitting room?` |
| 店员 | `shop assistant` | `salesclerk / sales associate` | `Ask the shop assistant for size M.` |
| 裤子 / 毛衣 / 运动鞋 | `trousers` / `jumper` / `trainers` | `pants` / `sweater` / `sneakers` | `Can I try these sneakers on?` |

> **防混提示**：美式英语中 `bill` 多指“纸币”（如 `a twenty-dollar bill`）或“水电/手机账单”，而餐厅结账单更常说 `check`；英式英语中纸币说 `note`（`a ten-pound note`），餐厅账单说 `bill`。付款后拿到的收据在英美两地统一叫 **`receipt`**。

## 六、英语礼貌语调、重音与连读规范（Intonation & Politeness）

在英语中，**礼貌不仅取决于词汇选择（`Could I` / `please`），更高度依赖语调曲线（intonation contour）与音高跨度**。中文母语者容易将平直或短促降调直接迁移到英语请求句中，导致“字面礼貌、听感生硬”。本讲作为 `listening_speaking` 课型，需重点建立以下四大语调规则：

### 1. 四大高频消费句型的标准语调模式

| 句型类别 | 语调走势 | 标注示例（重读大写，`↗` 升调，`↘` 降调） | 语用机制与错读后果 |
| --- | --- | --- | --- |
| **1. 礼貌请求一般疑问句**<br>（`Can I…?` / `Could I…?`） | **句尾升调（`↗`）**（更委婉时可用先降后轻升 `↘↗`） | `Can I try THIS on ↗?`<br>`Could I pay by CARD, please ↗?`<br>`Could we have the BILL, please ↗?` | 升调把决定权留给对方，传递开放、商量、客气的态度。<br>**错读警示**：若句尾生硬直降（`Can I have a bag ↘.`），听起来会像不耐烦的指令。 |
| **2. 二选一/多选一选择疑问句**<br>（`A or B?`） | **前项升调（`↗`），末项降调（`↘`）** | `Eat IN ↗ or take aWAY ↘?`<br>`For HERE ↗ or to GO ↘?`<br>`CASH ↗ or CARD ↘?`<br>`SMALL ↗, MEdium ↗, or LARGE ↘?` | 前升提示“还有选项”，末降表示“列表结束，请从中选一个”。<br>**错读警示**：若末项也上扬（`For here or to go ↗?`），会变成“是/否”问句，对方可能误答 `Yes` 导致沟通卡壳。 |
| **3. 陈述句礼貌点单**<br>（`I'd like…, please.` / `I'll have…, please.`） | **商品核心词重读缓降（`↘`），句尾 `, please` 轻柔微升（`↗`）** | `I'd like a MEdium LATte ↘, please ↗.`<br>`I'll have the CHICKen SANDwich ↘, please ↗.` | 陈述句信息完整自然落调，末尾 `, please` 配合轻升调消除生硬感，显得礼貌友好。 |
| **4. 特殊疑问句询价/问位**<br>（`How much…?` / `Where is…?`） | **开场 `Excuse me ↗` 轻升引人注意，主体特殊疑问句温和降调（`↘`）** | `ExCUSE me ↗, how much is this JACKet ↘?`<br>`ExCUSE me ↗, where is the FITting room ↘?` | 特殊疑问句默认用降调获取信息；先用轻升的 `Excuse me` 铺垫，再保持声音平稳缓降，避免生硬质问感。 |

### 2. 句中重音与弱读/连读听辨要点（服务听力与口语输出）

1. **功能词弱读，实义词重读**：
   - 点单和询价时，重音应落在**商品名称、数量、尺码、颜色、价格数字**等关键信息词上，而非 `I'd`、`a`、`can`、`of` 等功能词。
   - 例：`I'd like **TWO** **ICED** **LAT**tes to **GO**, please.`（重读加粗部分，节奏轻重分明，店员一次听清）。
2. **高频连读与缩读听辨清单（听力常见卡点）**：
   - `I'd like a...` → `/aɪd laɪk ə/`（`'d` 极短促，几乎贴在 `like` 前，听力中须靠 `would like` 语境和 `, please` 区分 `I'd like` 与 `I like`；口语输出切勿完全吞掉 `/d/`）。
   - `Can I...` → 弱读连读 `/kənaɪ/`（非重读时 `can` 读 `/kən/` 而非 `/kæn/`）。
   - `Could I...` → 连读 `/kʊdaɪ/`（`d` 与 `I` 自然连读）。
   - `try it on` → 连读 `/traɪ‿ɪt‿ɒn/`（美音常弱化连读近 `/traɪ‿ɪd‿ɑːn/`）；`try them on` → 口语弱读近 `/traɪ‿ðəm‿ɒn/`。
   - `How much is it?` → 连读 `/haʊ ˈmʌtʃ‿ɪz‿ɪt/`；`How much are they?` → `/haʊ ˈmʌtʃ‿ər‿ðeɪ/`。
   - `eat in` → `/iːt‿ɪn/`；`take away` → `/teɪk‿əˈweɪ/`；`for here` → `/fər ˈhɪər/`。

- **分题型配额与考点落点建议（严格对应 `budget_plan.json`）**：
  - `listening`（2 题，需按 v2 规范配齐 `study_translation` 英中逐字稿）：
    1. 咖啡馆/简餐点单对话（融入 `I'd like…`、`For here or to go?` / `Eat in or take away?`、`Could I pay by card?` 与单价/总额信息，并与 Topic 2/3 协调价格听辨点）。
    2. 服装店选码试穿与结账对话（融入 `Can I try it/them on?`、`in a larger size`、`How much does it cost?`、`on sale`、`receipt`）。
  - `cloze`（1 题）：一段日常超市/咖啡馆或同事工作午餐采购对话完形，集中考查 `I'd like`、`try ... on`、`does ... cost`、`pay by card / in cash`、`to go / take away`。
  - `translation`（2 题）：
    1. 英译中：如 `Excuse me, could I try these shoes on in a larger size, please?` 或含 `take away / pay by card` 的礼貌点单句。
    2. 中译英：如“请问这件夹克多少钱？我可以刷卡付款吗？”（`Excuse me, how much does this jacket cost? Could I pay by card?` 或 `How much is this jacket? Can I pay by card?`）。
  - `single_choice`（2 题）：
    1. 考 `try on` 代词中置（`try them on` vs `*try on them`）或 `I'd like to do` vs `I like`。
    2. 考询价语法（`How much does this coat cost?` 排除 `*is ... cost` / `*does ... costs`）或支付介词（`pay by card` / `pay in cash`）。
  - `multiple_choice`（1 题）：考同一消费场景下所有语法和语用均得体的礼貌表达（例如在咖啡馆点一杯拿铁并带走，选出 `I'd like a latte to go, please.`、`Can I have a latte to take away, please?`、`Could I get a latte to go, please?`，排除生硬的 `Give me a latte now.` 与语法错误的 `I'd like taking away a latte.`）。
  - `true_false`（2 题）：
    1. 考语法规则正误（如判断“`Can I try on them?` 与 `Can I try them on?` 两种语序都正确”为**错**，或判断“`How much does this shirt cost?` 中 `cost` 必须用原形”为**对**）。
    2. 考语调与语用正误（如判断“问 `For here or to go?` 时应前项升调、后项降调，以提示对方二选一”为**对**，或判断“`I like a coffee.` 是向服务员礼貌点一杯咖啡的标准说法”为**错**）。

### 3. 生词本候选词条建议（本讲 `vocab_target: 3`，已核对不与现有 71 条词汇重复）

遵循 `design-course-vocabulary` 规范（仅 `category: "word"` 填 `pos`，多词类目省略 `pos`；`grammar_note` 仅在存在真实用法卡点时写一句精炼中文点拨）：

1. **`try on`**（首选）
   - `category`: `"phrase"`（省略 `pos`）
   - `meaning`: 试穿；试戴
   - `grammar_note`: 可分离短语动词；宾语是代词 `it` 或 `them` 时必须放在中间，说 `try it on` / `try them on`，不可说 `try on it`。
   - `example`: `These sneakers look comfortable. Can I try them on?`
   - `example_translation`: 这双运动鞋看起来很舒服，我能试穿一下吗？
2. **`take away`**（首选）
   - `category`: `"phrase"`（省略 `pos`）
   - `meaning`: 打包带走（英式常用；美式对应 `to go`）
   - `grammar_note`: 作动词短语分写为 `take away`（如 `to take away`）；连写 `takeaway` 作名词或定语（如 `a takeaway coffee`）。
   - `example`: `I'd like two chicken sandwiches to take away, please.`

3. **`receipt`**（首选）
   - `category`: `"word"`，`pos`: `"n"`
   - `meaning`: 收据；购物小票
   - `grammar_note`: 可数名词，字母 `p` 不发音，读作 `/rɪˈsiːt/`；指付款后的凭证，区别于付款前的账单 `bill` 或 `check`。
