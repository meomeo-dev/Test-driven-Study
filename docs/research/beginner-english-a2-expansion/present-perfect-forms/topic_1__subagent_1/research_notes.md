## 一、CEFR A1–A2 语法定位与本讲教学边界

参照 **Cambridge English Grammar Profile (EGP)**、**Cambridge *English Grammar Today*** 与 **British Council LearnEnglish (A1–A2 Grammar)**，现在完成时（Present Perfect Simple）是 A2 阶段最具代表性的时态升级点：它把**过去发生的动作**与**当下的结果、现状或经历**连接在一起，让学习者能够自然汇报“事情办妥了”“情况有变化”或“到目前为止有过某种经历”。

### 1. 本讲核心掌握范围（A2 必会）
1. **`have / has + 过去分词（V3）` 完整语法框架**：掌握肯定、否定、一般疑问、简短回答与特殊疑问句，准确落实主谓一致。
2. **缩写规范与 `'s` 辨析**：熟练读写并听辨 `'ve / 's / haven't / hasn't`，牢记肯定简短回答禁缩规则，能一眼区分 `'s` 代表 `has` 还是 `is`。
3. **动词过去分词构成与三态分组记忆**：规则动词 100% 复用既有 `-ed` 规则；不规则动词按 **AAA / ABB / ABA / ABC** 四大形态分组，攻克日常与职场最高频三态变化。
4. **基础语用与 `been (to)` vs. `gone (to)`**：理解现在完成时“重现在结果、不带已结束过去时间点”的底线，区分“去过已回”与“去了未回”。

### 2. 与相邻讲次的教学边界（防重叠、防超纲）
- **与第 12 讲 `ever-never-already-yet` 分工**：本讲聚焦**句式构成与过去分词形态**，不展开 `ever / never / just / already / yet` 的语用分工与句中语序（相关副词留待第 12 讲系统讲练）。
- **与第 13 讲 `for-since-duration` 分工**：本讲不展开 `for + 时间段 / since + 时间点` 以及现在完成时与一般过去时的系统对比，仅在语用红线中提示“不可搭配 `yesterday / last week / two days ago` 等已结束的过去时间点”。
- **与第 23 讲 `basic-passive-voice` 衔接**：本讲牢记的过去分词（V3）搭配 `have / has` 表**主动完成**；第 23 讲将直接复用同一批 V3 搭配 `be` 构成被动语态。

## 二、现在完成时语法框架（`have / has + Past Participle`）

### 1. 助动词 `have / has` 的主谓一致与功能定位
- **`have`**：用于 `I / you / we / they` 及复数名词（*My colleagues **have** arrived.*）。
- **`has`**：用于 `he / she / it`、单数可数名词、不可数名词及单数不定代词 `everyone / someone / nobody`（*Everyone **has** signed the form.*）。
- **助动词定位**：此处 `have / has` 仅作**语法助动词**，不翻译为“拥有”；句子真正的核心动作由其后的**过去分词（past participle，简称 V3 / `done`）**表达。

### 2. 五大核心句式总表

| 句型类别 | 语法公式 | 结构要点 | 日常与职场标准例句 |
| --- | --- | --- | --- |
| **肯定句** | `主语 + have / has + V3` | 仅助动词随主语单复数变化，V3 形态恒定不变 | *I **have finished** the weekly report.*<br>*She **has booked** the flight to Tokyo.* |
| **否定句** | `主语 + have not / has not + V3` | 直接在 `have / has` 后加 `not`；**不可**借用 `don't / didn't` | *We **haven't received** the reply.*<br>*He **hasn't paid** the phone bill.* |
| **一般疑问句** | `Have / Has + 主语 + V3?` | 将 `Have / Has` 提至句首，实义动词仍保持 **V3** | ***Have** you **sent** the invitation?*<br>***Has** the train **arrived**?* |
| **简短回答** | `Yes, 代词 + have / has.`<br>`No, 代词 + haven't / hasn't.` | 只重复助动词，不重复 V3；**肯定简答禁用缩写** | *— Have you read the notice?*<br>*— Yes, I **have**.* / *No, I **haven't**.* |
| **特殊疑问句** | `Wh-疑问词 + have / has + 主语 + V3?` | 问“谁做过”（`Who` 作主语）时默认接单数 `has` | *What **have** you **written** in the email?*<br>*Who **has taken** my umbrella?* |

### 3. 两项高频语法关键点
1. **合法双 `have` 结构（`have had / has had`）**：当实义动词本身就是 `have`（吃、喝、经历、开会、拥有）时，助动词 `have / has` 后接其过去分词 `had`，构成 `have had / has had`，属完全规范的高频地道用法：
   - *I've **had** lunch, thanks.*（我吃过午饭了，谢谢。）
   - *She **has had** three meetings today.*（她今天已经开了三个会了。）
   - *We **haven't had** any news from the hotel.*（我们还没收到酒店的任何消息。）
2. **对比先修 `did` 句型（阻断负迁移）**：一般过去时在 `did / didn't` 之后动词**必须还原原形**；而现在完成时在 `have / has / haven't / hasn't` 之后动词**永远保持过去分词 V3**，绝不还原原形，更不可与 `did` 混用：
   - 一般过去时：*Did you **write** the summary yesterday?* / *I didn't **see** him.*
   - 现在完成时：*Have you **written** the summary?* / *I haven't **seen** him today.*（错误：`*Have you write...` / `*Did you written...`）

## 三、缩写规范（`'ve / 's / haven't / hasn't`）、`'s` 辨析与听口弱读

### 1. 完整形式与缩写对照表

| 人称 / 句式 | 完整形式 | 标准缩写（A2 主推） | 补充变体与使用规范 |
| --- | --- | --- | --- |
| 肯定（非三单） | `I / you / we / they have` | **`I've / you've / we've / they've`** | 口语、消息、日常与半正式邮件中极为常用 |
| 肯定（三单） | `he / she / it has` | **`he's / she's / it's`** | 书面名词主语后建议写完整 `has`（*Lisa has sent...*）；复数名词**不与 `'ve` 缩写**（不写 `*The clients've...`） |
| 否定（非三单） | `I / you / we / they have not` | **`haven't`**（如 *I haven't*） | 另存在 *I've not / we've not*，A2 阶段优先统一使用 `haven't` |
| 否定（三单） | `he / she / it has not` | **`hasn't`**（如 *she hasn't*） | 另存在 *he's not / she's not*，为避免与 `is not` 混淆，强烈推荐 `hasn't` |
| 肯定简短回答 | `Yes, I have.` / `Yes, she has.` | **严禁缩写** | 错误：`*Yes, I've.` / `*Yes, she's.`（句尾肯定助动词不可缩读） |

### 2. 重点语法辨析：`'s` 究竟是 `has` 还是 `is`？

口语和阅读中 `he's / she's / it's` 同时对应 `is` 与 `has`，只需**看 `'s` 后面紧跟的词形**即可一秒判定：

| `'s` 完整还原 | 后接成分 | 所属时态 / 结构 | 地道例句（生活与职场） |
| --- | --- | --- | --- |
| **`has`** | **过去分词（V3）**（表主动完成） | **现在完成时** | *She**'s sent** the updated slides.*（= *She **has** sent*）<br>*He**'s written** a short thank-you note.*（= *He **has** written*）<br>*It**'s stopped** raining.*（= *It **has** stopped*）<br>*He**'s been** to London twice.*（= *He **has** been*） |
| **`is`** | **`V-ing`（现在分词）** | 现在进行时 | *She**'s sending** the slides right now.*（= *She **is** sending*） |
| **`is`** | **形容词 / 名词 / 介词短语** | 一般现在时（主系表） | *He**'s busy** this afternoon.*（= *He **is** busy*）<br>*It**'s a clear plan**.* / *She**'s in Room 302**.* |

> **边界微注**：少数词既可作过去分词也可作状态形容词（如 *It's closed.* / *The screen's broken.*）。无宾语且描述当前静态状况时，按 **`is` + 形容词** 理解；带宾语强调动作完成（*He's **broken** his glasses.*）则为 **`has` + V3**。

### 3. 语音弱读与听口提示（铺垫第 14 讲听力）
- **自然弱读**：肯定陈述句中未缩写的 `have / has` 常弱读为 `/həv/`（`/əv/`）与 `/həz/`（`/əz/`）；缩写 `'ve` 紧贴代词发轻浊音 `/v/`（*I've* `/aɪv/`、*we've* `/wiːv/`），`'s` 按前接音素清浊发 `/s/`（*it's* `/ɪts/`）或 `/z/`（*he's* `/hiːz/`、*she's* `/ʃiːz/`），听辨时须结合后面的 V3 词形（如 *seen / written / sent*）锁定完成时。
- **重读规律**：疑问句句首、简短回答中的 `have / has` 恢复强读（`/hæv/`、`/hæz/`）；否定缩写 `haven't` `/ˈhævnt/` 与 `hasn't` `/ˈhæznt/` 通常重读以突出否定状态。

## 四、过去分词构成与高频不规则动词三态分组记忆

### 1. 规则动词过去分词：100% 复用 `-ed` 过去式规则
所有规则动词的**过去分词（V3）与过去式（V2）在拼写与发音上完全一致**，直接承接先修知识点 `past-regular`（清辅音后 `/t/`、浊辅音/元音后 `/d/`、`/t/ /d/` 后 `/ɪd/`）：
- **直接加 `-ed`**：`finish → finished` `/t/`、`book → booked` `/t/`、`check → checked` `/t/`、`call → called` `/d/`、`start → started` `/ɪd/`
- **词尾有 `e` 加 `-d`**：`update → updated` `/ɪd/`、`arrive → arrived` `/d/`、`save → saved` `/d/`、`invite → invited` `/ɪd/`
- **辅音 + `y` 变 `i` 加 `-ed`**：`reply → replied` `/d/`、`try → tried` `/d/`、`copy → copied` `/d/`（元音 + `y` 直接加：`stay → stayed`）
- **重读闭音节双写加 `-ed`**：`plan → planned` `/d/`、`stop → stopped` `/t/`、`chat → chatted` `/ɪd/`

### 2. A2 高频不规则动词三态（V1–V2–V3）四大形态分组记忆表

本表整合提示词标杆词、先修 `past-irregular` 已学动词（标注 `★` 补齐第三态，共 14 词）及 A2 日常/职场核心高频动词（共 40 词），按音形规律分为 **AAA / ABB / ABA / ABC** 四组：

#### A 组：AAA 型（原形 = 过去式 = 过去分词，三态完全同形）

| 原形 (V1) | 过去式 (V2) | 过去分词 (V3) | 中文含义 | 日常与职场例句 |
| --- | --- | --- | --- | --- |
| `put` ★ | `put` | **`put`** | 放、放置 | *I've **put** the receipt in the folder.* |
| `cut` | `cut` | **`cut`** | 切、削减 | *They've **cut** the travel budget.* |
| `cost` | `cost` | **`cost`** | 花费 | *The repairs have **cost** over 200 dollars.* |
| `set` | `set` | **`set`** | 设置、定好 | *She's **set** a reminder for 3:00 p.m.* |
| `read` ★ | `read` `/red/` | **`read`** `/red/` | 读（拼写同，读音变） | *Have you **read** today's message?* |

## 五、A2 核心语用规范与 `have been (to)` vs. `have gone (to)`

### 1. 本讲先建立的两大基础语用直觉
1. **过去动作 → 当前结果（Present Result）**：说话人关心的不是“过去几点做的”，而是**“现在怎么样了”**（任务完成、物品状态改变、现可进入下一步）。
   - *I've booked a table for six.*（桌位订好了——今晚直接去就行。）
   - *Someone has left a notebook in the meeting room.*（有人把笔记本落在会议室了——本子现在还在那里。）
2. **迄今为止的经历（Life Experience up to Now）**：谈论到目前为止做过或见过的事，不点明具体过去日期。
   - *We've tried the new noodle shop downstairs.*（我们尝过楼下新开的面馆。）
   - *He has given presentations in English twice.*（他用英语做过两次汇报。）
3. **时间状语红线**：现在完成时立足于“现在”，**不可**与已结束的过去时间点连用（错误：`*I have sent the email yesterday.`；正确：*I **sent** the email yesterday.* 或 *I **have sent** the email.*）。

### 2. 重点语用辨析：`have / has been (to)` vs. `have / has gone (to)`

在表达“去某地”时，`go` 在现在完成时中有 **`been`** 和 **`gone`** 两种过去分词，语义完全不同：

| 表达结构 | 当前人员位置 | 核心语义 | 地道例句与语境解读 |
| --- | --- | --- | --- |
| **`have / has been to + 地点`** | **已返回**（人此刻不在该地） | 去过某地（表示人生经历或刚办完事回来） | *I've **been to** Singapore twice.*（我去过新加坡两次，现在不在那儿。）<br>*— Where have you **been**? — I've **been to** the post office.*（你刚才去哪儿了？我去邮局了，现已回来。） |
| **`have / has gone to + 地点`** | **仍在那边或在路上**（人此刻不在这里） | 已经去了某地，尚未返回 | *— Where is Kevin? — He's **gone to** the airport.*（凯文去机场了，现在不在办公室。）<br>*My parents aren't home; they've **gone to** the supermarket.*（爸妈不在家，他们去超市了。） |

- **人称语用规律**：第一、二人称面对面交流时通常只用 **`been to`**（因为说话双方此刻就在现场，如 *I've been to Paris.* / *Have you been to that museum?*），一般不说 `*I've gone to Paris.*`（除非身处巴黎通过短信/电话告知他人）。
- **地点副词省略 `to`**：当后面接 `there / here / home / abroad` 时，**不加 `to`**（正确：*She's **gone home**.* / *Have you **been abroad**?*；错误：`*been to abroad` / `*gone to home`）。

## 六、给下游讲义主笔、生词本与题库命题的衔接建议

1. **讲义导入与旧知激活**：开篇用 1 组简短对比激活先修 `past-irregular` 与 `did-questions`（*Yesterday I **wrote** the report.* → *I'**ve written** the report.*；*Did you **send** it?* → *Have you **sent** it?*），明确告知学员“先修学过的规则 `-ed` 100% 沿用，不规则动词只需补齐第三态 V3”，降低畏难情绪；全篇语料限定在通用生活与现代职场，不引入车间术语。
2. **本讲 3 词生词锚点建议（对应 `vocab_target: 3`，经核对与现有 93 词无重复）**：
   - **`report`**（`word`, `n.` 报告；汇报）—— 现代职场完成时高频宾语（*I've finished the monthly report.*）。
   - **`abroad`**（`word`, `adv.` 在国外；到国外）—— 精准配合 `been abroad / gone abroad` 省略介词 `to` 的语法点拨。
   - **`have been to`**（`phrase` 去过某地，现已返回）—— 直击本讲核心语用辨析，可配极简中文 `grammar_note` 点明与 `have gone to` 的状态差异。
3. **题库覆盖重点（对接 `budget_plan.json` 10 题配额）**：
   - **单选（2）/ 多选（1）**：重点考查 `have / has` 主谓一致（含名词主语与 `everyone`）、`'s`（`has` vs. `is`）辨析、肯定简短回答禁缩规则，以及 `been to` vs. `gone to`。
   - **完形（2）**：聚焦高频不规则动词过去分词（如 `been / gone / done / seen / written / sent / come / taken / paid`）及否定/疑问中“保持 V3 不还原”的硬规则；严格避开 `ever / never / already / yet / for / since` 超纲选项。
   - **听力（1）/ 阅读（1）/ 翻译（2）/ 造句（1，`sentence_making`）**：围绕办公室任务进度核对与日常出行/生活事务展开，刻意加入 `'ve / 's / haven't / hasn't` 缩写听辨，并在翻译与造句中检验主谓一致与正确 V3 拼写（防范 `*have wrote`、`*has went`、`*Did you finished`）。
