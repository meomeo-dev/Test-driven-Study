# 研究笔记：一般现在时动词 have/has 与 have got 的否定句与第三人称单数误用防范

## 1. 典型错误与失效模式（Failure Modes）

在英语学习过程中，表达“拥有”（Possession）存在两套并存但规则迥异的语法体系：
1. **标准一般现在时体系（Standard Present Simple）**：肯定式使用 `have/has`，否定式使用 `don't have / doesn't have`，疑问式使用 `Do/Does ... have`。
2. **“Have Got”体系（英式/口语偏好）**：肯定式使用 `'ve got / 's got`，否定式使用 `haven't got / hasn't got`，疑问式使用 `Have/Has ... got`。

学习者在实际应用中最易陷入以下四种典型错误模式：

### 错误类型 A：体系杂糅（Hybrid Error）—— `doesn't have got`
* **错误示例**：*“He doesn't have got a car.”* 或 *“She doesn't got a computer.”*
* **认知根源**：学习者将第三人称单数否定助动词 `doesn't` 与带有口语色彩的 `got` 强行拼接。他们知晓第三人称单数需要 `does`，但脑海中对“拥有”的词汇记忆仍绑定在 `got` 上。

### 错误类型 B：裸用 `haven't / hasn't`（缺乏 `got`）
* **错误示例**：*“I haven't a car.”* 或 *“He hasn't any time.”*
* **认知根源**：受母语直译（如法语、德语中助动词直接加否定词）或历史上英式英语残留习惯的影响。在现代国际英语中，不加 `got` 的纯 `haven't/hasn't` 表示拥有极为少见（通常仅见于书面或特定英式口语，且常伴随 `got` 省略的语境退化），对初学者而言极易造成混淆。

### 错误类型 C：误用 `don't got`
* **错误示例**：*“They don't got pets.”*
* **认知根源**：过度泛化了一般现在时实义动词否定句加 `don't` 的规则，误将 `got` 视作普通动词原形。

### 错误类型 D：第三人称单数肯定句误用 `have`
* **错误示例**：*“She have a nice room.”*
* **认知根源**：动词原形记忆过深，忽略了主语为第三人称单数（he/she/it/单数名词）时 `have` 必须变为 `has` 的形态变化规则。

## 2. 诊断防范清单（Diagnostic Prevention Checklist）

针对上述失效模式，教学与测评系统应建立以下防范检查项：

- [ ] **系统二选一隔离检查（System Isolation Check）**：明确告知学习者在单句中必须严格二选一，禁止在同一句中混用两套体系（即：不可出现 `doesn't ... got` 或 `don't ... got`）。
- [ ] **否定助动词与 `have` 绑定检查（Auxiliary-Verb Binding）**：当采用标准一般现在时体系时，检查第三人称单数否定是否严格使用 `doesn't have`（而非 `doesn't has` 或 `haven't`）。
- [ ] **`haven't` 尾缀完整性检查（`got` Retention Check）**：当检测到使用 `haven't / hasn't` 表示所属关系时，必须检查其后是否存在 `got`，杜绝孤立的 `haven't/hasn't` 结构。
- [ ] **人称变位一致性检查（Person-Number Agreement）**：在一般现在时肯定句中，核对主语与 `have/has` 的匹配关系。

## 3. 自测题设计建议（Self-Test Design Recommendations）

为了有效诊断并纠正上述错误，建议在第 28 课时练习中引入以下三类自测题：

### (1) 句子改错与辨析题（Error Correction）
* **题型描述**：给出包含混合错误的句子，要求学习者找出错误并分别用**两套正确体系**进行改写。
* **设计示例**：
  > *Original*: He doesn't have got a bicycle.
  > *Task*: Identify the error and rewrite it using:
  > 1. Present Simple system (`don't/doesn't have`): _________________
  > 2. Have got system (`haven't/hasn't got`): _________________

### (2) 对比填空与完形填空（Contrastive Cloze Drills）
* **题型描述**：在情境对话中设置空格，严格限定要求使用的体系（如括号内标注 `[Simple Present]` 或 `[Have Got]`），训练学生在不同语境下的规范输出。

### (3) 句型转换实战（Transformation Drill）
* **题型描述**：将肯定句转换为否定句和一般疑问句，重点考察第三人称单数在 `does not have` 与 `hasn't got` 两种转换路径上的准确性。
