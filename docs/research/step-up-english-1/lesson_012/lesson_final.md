## 2. 权威标准与理论依据
- **ISO 704 (*Terminology work — Principles and methods*)**：国际标准化组织（ISO/TC 37）关于术语学原理与方法的标准。该标准对跨语言借词（Translingual borrowing）、直接借词（Direct loans/Xenonyms）及形态适应（Morphological adaptation）提供了严谨的方法论指导。
- **ISO 1087 / ISO 10241**：支持多语种术语管理、概念体系与词汇标准化的配套规范。

## 3. 核心调研笔记

### 3.1 变元音复数（Mutated Plurals / Ablaut Plurals）
- **历史渊源**：英语中的变元音复数（如 `foot` -> `feet`, `tooth` -> `teeth`, `man` -> `men`, `mouse` -> `mice`）是古代日耳曼语（Old Germanic）中**i-音变（i-mutation / umlaut）**的历史遗留现象。
- **演变机理**：在古英语时期，这些名词的复数形式带有包含高前元音（如 `*-i-` 或 `*-j-`）的后缀。后缀中的高前元音在发音时对其前一音节的重读元音产生了同化作用（Fronting），将后缩元音（如 `ō`、`ū`、`ā`）拉高并前移。随后，随着历史演变后缀脱落，仅留下发生元音变异的主干作为复数的唯一标记。

### 3.2 外来词复数规范（Foreign Loanword Plural Norms）
英语在历史演进中吸收了大量拉丁语、希腊语、法语等外来词，其复数形式在现代英语中呈现出“保留原貌”与“本土化（英语化）”的双轨规范：

#### A. 拉丁语借词
- **`-us` $\rightarrow$ `-i`**：如 `cactus` $\rightarrow$ `cacti`（现代规范中 `cactuses` 亦被广泛接受）；`fungus` $\rightarrow$ `fungi`。
- **`-um` $\rightarrow$ `-a`**：如 `bacterium` $\rightarrow$ `bacteria`；`datum` $\rightarrow$ `data`（在科技与数据科学语境中多作复数，日常亦有作不可数单数趋势）。
- **`-a` $\rightarrow$ `-ae`**：如 `formula` $\rightarrow$ `formulae` 或 `formulas`。
- **`-ex / -ix` $\rightarrow$ `-ices`**：如 `index` $\rightarrow$ `indices` 或 `indexes`。
- **`-is` $\rightarrow$ `-es`**：如 `analysis` $\rightarrow$ `analyses`；`crisis` $\rightarrow$ `crises`。

#### B. 希腊语借词
- **`-on` $\rightarrow$ `-a`**：如 `criterion` $\rightarrow$ `criteria`；`phenomenon` $\rightarrow$ `phenomena`。
