# Course mock examinations

Open `/exam?subject=<id>` from **模拟考试**. The examination provides a dedicated
simulation exam terminal for any course unit with practice questions.

## Examination rules and composition

Mock exams draw questions from the selected course unit:
- Questions are randomly sampled from the eligible pool up to the rule's question count.
- Single-choice, multiple-choice, and judgment options are presented with stable option mapping.
- Multiple-choice selections must match the exact correct set with no partial credit.
- Papers preserve server-owned deadlines, answer state, and navigation across reloads.
- Active unanswered questions expose no answers or explanations until submission.

## Taking an examination

1. Select a unit on the preparation screen and click **开始考试**.
   **继续考试** restores an in-progress paper and its original deadline.
   **重新开始** finalizes the active attempt and creates a new random paper with a fresh timer.
2. Select options using mouse clicks or keyboard shortcuts (numbers 1–4).
3. Click **下一题** or press Enter to save and advance.
4. Click **交卷** to submit the exam. An overview dialog summarizes score and answers.
5. After submission, learners can review each question and full explanations.
