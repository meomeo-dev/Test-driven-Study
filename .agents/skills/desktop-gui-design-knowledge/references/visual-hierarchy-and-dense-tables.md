# 视觉与文字层级、高密度表格（Visual Hierarchy and Dense Tables）

执行到确定文字层级、字号与明度，或设计高密度数据表格（行高、对齐、数字列、空态与加载态）
时加载。来源、核验日期与复核期登记在 `index/knowledge-index.yaml` 的条目
`visual-hierarchy-and-dense-tables`；正文只写结论与可操作的事实。平台字号见
`platform-conventions.md`，密度档位与令牌见 `design-systems-and-tokens.md`。

## 1. 视觉层级

- 手段：位置（左上优先）、尺寸、字重、明度对比、间距（靠近即同组）、分组（分隔线或背景
  层次）、对齐。视觉特征相同即表示层级相同。
- 越往内层越少用线与阴影；阴影只用于浮在内容上方的元素（弹出层、菜单、浮动窗口）。

## 2. 文字层级

文字不超过四级（字号为经验值，未核实，按平台正文字号与密度实测）：

| 级 | 用途 | 字号与字重 | 颜色 |
| --- | --- | --- | --- |
| L1 | 视图标题 | 15～17 px 半粗 | 主文字 |
| L2 | 分组标题、表头 | 12～13 px 半粗 | 主文字 |
| L3 | 正文与数据 | 12～14 px 常规 | 主文字 |
| L4 | 辅助信息：时间、来源、提示 | 11～12 px | 次级文字 |

- 文字明度分三档：主文字、次级文字、禁用文字。次级文字仍须满足正文对比度（见
  `accessibility-baseline.md`）。
- 不用字号区分同一层级的不同对象；导航与标题不用网页式大字号（17～24 px）。

## 3. 高密度表格

对齐与数字：

- 数字右对齐，文本左对齐，列标题与内容同向。
- 数字列用等宽数字 `font-variant-numeric: tabular-nums`；同一列小数位一致；单位写在列标题，
  不写在每个单元格。
- 主流组件库都不专门处理数字列，靠这条 CSS 自行处理。

行高与分隔：

- 行高档位与默认密度见 `design-systems-and-tokens.md` 第 1 节；表格至少提供紧凑与标准两档。
- 斑马纹与行分隔线二选一，不叠用；分组行用背景层次区分；汇总行固定在分组上方或表头下方。
- 表头与首列冻结，滚动时保持可见。

标记与内容：

- 极值用二值标记（是否为最优值），不用连续渐变；颜色之外再加字重、图标或底色。
- 没有数据的单元格写明文字（如「无数据」），不留空白，不写 0。
- 迷你图（sparkline）只表示趋势，不替代数值。
- 选中单元格时检查器显示其出处；关键信息不放在悬停提示中。

组织方式按信息检索口诀（visual information-seeking mantra）：先概览，再缩放与过滤，按需
看细节。概览层只放一眼要看的值；来源、时间、原文放到详情层。

键盘与规模：

- 方向键移动选中单元格，Enter 或 F2 进入编辑，Esc 取消，⌘C 或 Ctrl+C 复制选中内容
  （惯例，未核实，以目标平台的表格控件为准）。
- 行数上百时用虚拟滚动；小矩阵不需要。

状态：

- 空状态写明原因与下一步动作。
- 加载时用骨架行保持布局，不整块转圈。
- 部分失败只标出失败的来源与原因，不遮挡其余数据。
- 错误就地显示原因与重试入口。
