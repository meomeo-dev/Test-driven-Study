# 功能分区与布局（Layout and Regions）

执行到划分窗口功能区、决定检查器 / 底部面板 / 状态栏放什么、设计布局保存与常驻小窗时加载。
来源、核验日期与复核期登记在 `index/knowledge-index.yaml` 的条目 `layout-and-regions`；
正文只写结论与可操作的事实。按软件类别的布局变体见 `professional-software-conventions.md`。

## 1. 通用骨架

- 骨架由五块组成：窄导航、主工作区、可折叠的检查器或辅助面板、可选的底部面板、一条细
  状态栏。各类软件的差别在以哪一块为中心。
- 默认布局只开导航、工作区与状态栏；检查器与底部面板按需展开。面板越多，认知负担越重。
- 单一高频流程用固定骨架加可拖动分隔条即可，不做自由停靠。可停靠布局在笔记本屏幕上容易
  挤压主区，采用时必须同时提供面板最小宽度、单面板最大化与一键重置布局。

## 2. 各区域放什么、不放什么

| 区域 | 放 | 不放 |
| --- | --- | --- |
| 导航栏 | 应用的顶层区域（页面）；可折叠为图标条；设置入口在底部 | 当前页面内的筛选与操作；同一功能的第二个入口 |
| 列表栏 | 当前区域的对象列表、搜索与计数 | 完整详情 |
| 工具栏 | 当前视图的主操作与视图切换，高频在前，次要操作收进「更多」 | 全局状态 |
| 工作区 | 当前任务的主体，占最大面积，只在区域内滚动 | 整页滚动 |
| 检查器（inspector） | 右侧；选中对象的全部字段、原文、出处与次要操作；只读为主，编辑在行内或表单完成 | 主流程必经的操作 |
| 底部面板 | 日志、事件、记录表（blotter），按视图页签切换，可折叠、过滤与清空 | 主流程的输入 |
| 状态栏 | 常驻细条；左侧放工作区级状态（连接、后台任务、配额），右侧放选择级信息（选中摘要、计数）；条目可点击跳到对应视图 | 唯一一处需要立即处理的告警 |

- 检查器默认宽度约为窗口的四分之一（未核实，按内容实测）；窗口宽度容不下列表、工作区与
  检查器三者时默认折叠检查器。
- 文档页签对应可开关的具体对象，视图页签在固定面板之间切换，两者不混用；只有需要并行处理
  多个对象时才用文档页签。
- 单个视图容器内的视图以 3～5 个为宜；能做成命令的功能不做成常驻视图。

## 3. 分隔条与面板

- 分隔条可拖动，双击恢复默认尺寸；为每个窗格设最小宽度。
- 单个面板可最大化；多显示器时面板可浮出为独立窗口。

## 4. 布局是一等对象

- 记住每个面板的尺寸与开合状态，下次启动恢复。
- 命名布局按任务切换；自动保存，可另存；提供一键重置。
- 团队场景可下发默认布局。

## 5. 主窗口加常驻小窗

- 分工：小窗只做「看状态 + 一键动作」；主窗口负责录入、筛选、排错与设置。需要多行编辑、
  查看原文或处理错误时，带着当前对象跳回主窗口。
- 小窗属性：置顶、不进任务栏、显示时不抢焦点、可吸附屏幕边缘、闲置时半透明。
- 关闭主窗口只隐藏，托盘菜单提供「显示」与「退出」。
- 各窗口的状态来自单一数据源并各自订阅，不各自保存一份。
- 小窗与主窗口使用同一套视觉语言与快捷键；小窗失焦时同样降低标题栏对比度。
