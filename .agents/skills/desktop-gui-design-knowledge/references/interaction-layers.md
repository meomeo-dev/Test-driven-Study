# 披露、反馈、键盘、结构与叠放层级（Interaction Layers）

执行到决定信息放在行内、悬停提示、弹出层、检查器、模态还是独立窗口，设计反馈与通知，设计
快捷键体系，或定义 z-index 时加载。来源、核验日期与复核期登记在
`index/knowledge-index.yaml` 的条目 `interaction-layers`；正文只写结论与可操作的事实。

## 1. 信息披露层级

由轻到重六层：行内 → 悬停提示（tooltip）→ 弹出层（popover）→ 检查器（inspector）→ 模态
对话框（modal）→ 独立窗口。

| 层 | 用于 | 不用于 |
| --- | --- | --- |
| 行内 | 一眼要看的值：数值、状态、极值标记 | 塞满字段导致行不可扫读 |
| 悬停提示 | 补充说明：全称、绝对时间、按钮的快捷键 | 关键信息或操作（键盘与触屏用户看不到） |
| 弹出层 | 点击触发的轻量详情或小表单；不嵌套 | 需要长时间停留的内容（改用检查器） |
| 检查器 | 选中对象的完整详情，可常驻、可折叠 | 不可收起且挤压主表 |
| 模态 | 必须先作决定的事：不可逆、阻断 | 普通通知、常规表单；主数据编辑（用检查器或独立窗口，不用模态抽屉） |
| 独立窗口 | 并排比较、多屏监视、常驻小工具 | 一次性动作 |

- 选择驱动详情（主从视图，master-detail）；编辑尽量原位完成（无模式编辑，modeless）。

## 2. 反馈层级

由轻到重五层：

1. 行内：校验错误、解析失败的行与原因；持续显示到问题解决。
2. 状态栏：连接、后台任务、配额；常驻。
3. 非阻塞通知（toast）：刚完成的动作、可撤销提示；数秒后消失。
4. 系统通知：窗口在后台时的重要事件。
5. 模态告警：阻断、不可逆、可能丢失数据。

- 可撤销的操作用撤销代替确认框（undo over confirm）。
- toast 会消失；需要处理的错误同时留在行内或底部面板等可回看的位置。
- 复制成功这类高频动作用 toast 反馈，不弹确认。

## 3. 键盘层级

由外到内四层：

| 层 | 内容 |
| --- | --- |
| 全局 | 应用在后台也生效，如全局热键唤起常驻小窗 |
| 窗口 | 命令面板（⌘K 或 Ctrl+K）、页面切换（⌘1～9 或 Ctrl+1～9）、主操作、撤销重做、查找 |
| 区域 | F6 与 Shift+F6 在区域之间循环，回到区域时恢复上次焦点 |
| 控件 | 复合控件内用方向键移动焦点，Enter 或空格激活，Esc 关闭或返回（焦点管理见 `accessibility-baseline.md` 第 2 节） |

- 快捷键写在菜单项、按钮提示与命令面板结果旁，可被发现；菜单项的加速键随菜单生效并显示
  在菜单中。
- Fitts 定律：常用目标大而近；Hick 定律：减少同屏选项。以键盘为主的用户经命令面板绕过这
  两项限制。
- 全局热键可能与其他应用冲突；注册失败时记录并降级，不影响其余功能。
- 跨平台的快捷键写法见 `platform-conventions.md` 第 3 节。

## 4. 结构层级

层次：应用 → 窗口 → 区域 → 面板 → 分组 → 控件 → 内容。边界表达由强到弱：

| 层 | 边界手段 |
| --- | --- |
| 窗口 | 系统边框与阴影 |
| 区域 | 1 px 分隔线或背景明度差，加可拖动分隔条 |
| 面板 | 标题栏与折叠控件 |
| 分组 | 小标题与留白，不再套边框 |
| 控件 | 悬停、选中、禁用靠明度与色相差异，减少常驻装饰 |

## 5. 叠放层级（z-order）

- 由低到高：基础层 → 固定表头 → 下拉菜单 → 弹出层 → 抽屉 → 模态 → 非阻塞通知 → 悬停提示。
- 公开组件库之间顺序不完全一致（例如下拉菜单是否高于模态、通知是否高于模态）；按产品场景
  确定一次后固定。例：Material UI 的默认值为 appBar 1100、drawer 1200、modal 1300、
  snackbar 1400、tooltip 1500，即通知高于模态。
- 叠放值集中定义为一组令牌，组件内不写魔数。示例：`base 0`、`sticky 100`、
  `dropdown 200`、`popover 300`、`drawer 400`、`modal 500`、`toast 600`、`tooltip 700`。
