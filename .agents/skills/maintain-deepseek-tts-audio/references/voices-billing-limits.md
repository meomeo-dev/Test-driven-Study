# 音色、计费与并发限制

执行到选音色、换音色、估算费用或调整并发时加载。本文件的来源、核验日期与复核期登记在
`index/knowledge-index.yaml` 的条目 `voices-billing-limits` 中；价格、折扣与并发数会漂移，以当次
查阅的官方页面与账号控制台为准。

## 结论

可用音色只有 `stella`（女声）与 `tide`（男声）；费用按计费字符收取，汉字算 2 个；合成前用
`plan-audio` 看「计费字符约 N」；每个账号最多同时 50 个请求，配置默认 4 个并发。

## 音色

| voice_id | 说明 |
| --- | --- |
| `stella` | 海星，女声，接口默认 |
| `tide` | 暗潮，男声 |

- 语种自动识别：普通话、粤语、英语、日语、韩语、马来语、阿拉伯语、印尼语、泰语、越南语。同一套
  音色可以朗读不同语种的句库，不需要按语种换音色。
- 配置里的音色名（如 `female`、`male`）由项目自取，出现在文件路径里；值是 voice_id。
- `check-setup` 对不在上表中的 voice_id 只给警告：官方新增音色后照常可用，写错时合成返回音色错误。
- 不支持语速调节与声音复刻。

## 计费

- 计费单位：每 10,000 字符。刊例价 3 元；限时折扣（5 折）1.5 元，折扣结束日期页面没有写明。
- 计法：汉字算 2 个字符，英文字母、数字、空格等其他字符算 1 个。工具把 Unicode 汉字（Han 文字）
  记 2 个，中文标点与其他字符记 1 个；标点的计法官方没有单独写明。
- `plan-audio` 与 `synthesize-audio --dry-run` 的「计费字符约 N」按上述口径估算，只作合成前的量级
  判断，实际扣费以服务端为准。整套重合成（换音色、`--force`、改 `filterMarkdown`）的字符数等于该
  音色全部句子之和。
- 费用从账号的充值余额或赠送余额中扣减；余额不足时接口返回 HTTP 402，见
  `references/error-handling.md`。

## 并发

- 每个账号最多同时进行 50 个请求，超过返回 HTTP 429；并发按账号计，与 API Key 无关。
- 配置 `request.concurrency` 默认 4；同一账号还有其他程序在调用 DeepSeek 接口时相应调低。

## 适用边界

- 不覆盖 WebSocket 流式合成的会话限制（60 秒无文字结束会话、单会话 30 分钟）。
