## 一、 核验依据与权威参考
依据权威英语语法文献（如 *Cambridge English Grammar Today*、*A Comprehensive Grammar of the English Language*），一般现在时第三人称单数（Third-Person Singular）的核心语法规则如下：
1. **基本规则**：大多数动词词尾直接加 `-s`（如 *work* -> *works*, *play* -> *plays*）。
2. **拼写规则**：
   - 以 `-ch`, `-ss`, `-sh`, `-x`, `-zz` 结尾的动词，加 `-es`（如 *watch* -> *watches*, *miss* -> *misses*）。
   - 以“辅音字母 + `-y`”结尾的动词，变 `-y` 为 `-i` 再加 `-es`（如 *study* -> *studies*）；以“元音字母 + `-y`”结尾的动词直接加 `-s*（如 *play* -> *plays*）。
3. **不规则动词**：*have* -> *has*, *go* -> *goes*, *do* -> *does*, *be* -> *is*。
4. **主谓一致要点**：不定代词（如 *everyone, each*）、学科名词（如 *Mathematics*）以及受长定语/介词短语隔离的主语，在语法上均需按单数处理。
